### Description

Particulate Filter Cleaner

### Purpose

This document provides information for Particulate Filter Cleaner, Part Number 4919052. The cleaner is used to Level 1 clean an ash loaded Diesel Particulate Filter (DPF) from the ISB, QSB, ISC, ISL, QSL, ISM, ISX, and QSX engines. The cleaner is **not** designed to clean soot loaded DPFs. The cleaner requires 8.5 bar \[120 psi\] minimum shop air and 110 VAC 60 HZ electrical power. Adapter kits required to attach the DPF (sold separately) are shown in Table 4. A software unlock programmed card is required and sold separately, but is also included in the ISC, ISL, ISM, ISX,and adapter kit. Replacement filters available for the cleaner, and sold separately, are shown in Tables 2 and 3. Refer to the manufacturer's user manual for appropriate cleaning procedures. Use the following procedures for additional information on the Aftertreatment Diesel Particulate Filter.

- Use the following procedure in the Signature™, ISX, and QSX15 Service Manual, Bulletin [[3666239 — Signature™, ISX, and QSX15 Service Manual\|3666239]]. [[101-011-041-tr — Aftertreatment Diesel Particulate Filter|Refer to Procedure 011-041 in Section 11.]]
- Use the following procedure in the ISM, ISMe, and QSM11 Service Manual, Bulletin [[3666322 — ISM, ISMe, and QSM11 Service Manual\|3666322]]. [[101-011-041-tr — Aftertreatment Diesel Particulate Filter|Refer to Procedure 011-041 in Section 11.]]
- Use the following procedure in the ISC and ISL CM2150 Service Manual, Bulletin 4021569. Refer to Procedure 011-041 in Section 11.
- Use the following procedure in the ISB CM2100 and CM2150 Service Manual, Bulletin 4021578. Refer to Procedure 011-041 in Section 11.
- For the Tier 4i QSB, use the following procedure in the QSB6.7 CM2250 Service Manual, Bulletin 4022255. Refer to Procedure 011-041 in Section 11.
- For the Tier 4i QSL, use the following procedure in the QSL9 CM2250 Service Manual, Bulletin 4022256. Refer to Procedure 011-041 in Section 11.
- Use the following procedure in the ISX15 CM2250 Service Manual, Bulletin 4022250. Refer to Procedure 011-041 in Section 11.
- Use the following procedure in the ISX11.9 CM2250 Service Manual, Bulletin 2883445. Refer to Procedure 011-041 in Section 11.
- For the Tier 4i QSX15, use the following procedure in the QSX15 CM2250 Service Manual, Bulletin 2883557. Refer to Procedure 011-041 in Section 11.
- For the Tier 4i QSX11.9, use the following procedure in the QSX11.9 CM2250 Service Manual, Bulletin 2883561. Refer to Procedure 011-041 in Section 11.
