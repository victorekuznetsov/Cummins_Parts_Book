### Description

Service Tool Component Kit

### Purpose

This document provides information for Service Tool Component Kit, Part Number 5299014. The kit is used to upgrade existing fuel pump lifting fixture kit, Part Number 4918603, now obsolete and superseded by, Part Number 5299015, to have the same functionality as current fuel pump lifting fixture kit, Part Number 5299015, used to remove and install the fuel pump on the QSK50 MCRS and QSK60 MCRS engines.
