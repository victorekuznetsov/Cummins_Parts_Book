### Description

Four Valve Spring Compressor Kit

### Purpose

This document provides information for the four valve spring compressor kit, Part Number 4919358. The kit is used for the removal and installation of the valve spring retainers, valve springs, and valve stem seals on Cummins® Signature™ and ISX CM2250 engines.

For additional information on the use of the four valve spring compressor kit, Part Number 4919358, use the following publications.

Use the following procedures in the Signature™, ISX, and QSX15 Service Manual, Bulletin [[3666239 — Signature™, ISX, and QSX15 Service Manual\|3666239]].

- [[10-002-004-tr — Cylinder Head|Refer to Procedure 002-004]] in Section 2.
- [[10-002-016 — Valve Guide Seal, Cylinder Head|Refer to Procedure 002-016 in Section 2.]]

Use the following procedures in the ISX15 CM2250 Service Manual, Bulletin 4022250.

- Refer to Procedure 002-004 in Section 2.
- Refer to Procedure 002-016 in Section 2.
