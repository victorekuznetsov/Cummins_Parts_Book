### Description

Counterbore Cutter Kit

### Purpose

This document provides information for counterbore cutter kit, Part Number 2892436. The kit is used with counterbore cutter driver, Part Number 3163785 to cut the cylinder block liner counterbore on the Signature™, ISX, ISX15, and QSX15 engines.

Use the following procedures for more information on the operation of the counterbore cutter kit.

- For the Signature™, ISX, and QSX15, use the following procedure in the Signature™, ISX, and QSX15 Service Manual, Bulletin [[3666239 — Signature™, ISX, and QSX15 Service Manual\|3666239]]. Refer to Procedure 001-058 in Section 1.
- For the ISX15 CM2250, use the following procedure in the ISX15 CM2250 Service Manual, Bulletin 4022250. Refer to Procedure 001-058 in Section 1.
