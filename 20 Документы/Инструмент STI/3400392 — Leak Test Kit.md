### Description

Leak Test Kit

### Purpose

This document provides information for Leak Test Kit, Part Number 2892320, used to detect leaks in all engine fluid systems (lubrication, coolant, and fuel) using a cordless “True UV” light that will detect the presence of fluorescent dye additive. The kit is also capable of detecting leaks in air conditioning systems, using the appropriate dye.

Leak Test Kit, Part Number 2892320, will replace all previous leak test kits and black light kits.

Reference the appropriate service manual for the recommended test procedure.
