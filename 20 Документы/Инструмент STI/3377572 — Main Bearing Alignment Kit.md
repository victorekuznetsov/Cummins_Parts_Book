### Purpose

This service tool instruction provides information on the main bearing alignment kits. The main bearing alignment kit contains the necessary tools to check the main bearing bore alignment of various cylinder blocks. The main bearing alignment kits are available for the NH, NT, N14, V28, K19, K38, K50, V903, V504, V555, C, J, L10, M11, ISM, C8.3, QST30, QSK45, and QSK60 engines.

> [!note] Note · Примечание
> The illustrations show checking the main bearing bore on a V28 series engine. The process is similar on **all** other engine families.

Allow the checking bar, centering rings, checking ring and the cylinder block to stabilize to room temperature.

Install the centering rings. Centering ring location will vary depending on engine model. See the Shop Manual for detailed instructions.

![[ck5brsb.png]]

Install the main bearing caps, refer to the appropriate Shop Manual for the installation procedures and specifications.

![[ck6brsl.png]]

Use clean 15W-40 oil to lubricate the checking ring, checking bar and centering rings.

Slide the checking bar through one of the centering rings and install the checking ring on the checking bar. Continue pushing the checking bar through the rest of the centering rings.

Inspect the checking bar for freedom of rotation.

![[mb2rihb.png]]

Push the checking ring through the main bearing bores to be inspected using light finger pressure on each side of the checking ring.

The checking ring **must** pass through each bore with slight resistance.

If the checking ring will **not** go through the bore, inspect the bore for burrs and other obstructions. Remove any burrs if necessary.

If the checking ring does **not** pass through the main bearing bore, an undersized condition exists and the cylinder block bore **must** be repaired.

![[mb2brsd.png]]

If the checking ring will pass through the main bearing bore without any resistance, center the checking ring in the bore. Use a feeler gauge 0.08 mm \[0.003 inch\] that is **not** more than 12.7 mm \[1/2 inch\] wide. Insert the feeler gauge between the checking ring and the cylinder block.

![[mb2risa.png]]

Evaluate the main bearing bore using the feeler gauge. Refer to the appropriate Shop Manual for the detailed inspection procedures.

![[mb2risc.png]]

Remove the checking ring, checking bar and centering rings.

![[mb2rima.png]]
