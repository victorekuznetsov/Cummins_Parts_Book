### Наименование

Комплект для центровки коренных подшипников

### Назначение

Эта инструкция по инструменту для обслуживания предоставляет информацию об основных комплектах выравнивания подшипников. Основной комплект выравнивания подшипников содержит необходимые инструменты для проверки выравнивания цилиндров подшипников различных блоков цилиндров. Основные комплекты выравнивания подшипников доступны для двигателей NH, NT, N14, V28, K19, K38, K50, V903, V504, V555, C, J, L10, M11, ISM, C8.3, QST30, QSK45 и QSK60.

> [!note] Примечание
> На иллюстрациях показана проверка основного несущего цилиндра, который был установлен на двигателе серии V28. Этот процесс аналогичен для всех других семейств двигателей.

Разрешить контрольную полосу, центрирующие кольца, контрольное кольцо и блок цилиндров стабилизировать до комнатной температуры.

Установите центрирующие кольца. Расположение центрирующего кольца будет варьироваться в зависимости от модели двигателя. Смотрите руководство по магазину для подробных инструкций.

![[ck5brsb.png]]

Установите основные подшипники, обратитесь к соответствующему руководству по магазину для процедур установки и спецификаций.

![[ck6brsl.png]]

Используйте чистое масло 15W-40 для смазки проверяющего кольца, проверяющего штанги и центрирующих колец.

Проведите контрольную полосу через одно из центральных колец и установите контрольное кольцо на контрольной полосе. Продолжайте проталкивать контрольную полосу через остальные центрирующие кольца.

Проверьте контрольную полосу на свободу вращения.

![[mb2rihb.png]]

Проталкивайте контрольное кольцо через основные несущие отверстия, которые должны быть проверены с помощью давления легкого пальца на каждой стороне контрольного кольца.

Проверяющее кольцо **должно** проходить через каждый цилиндр, несущий небольшое сопротивление.

Если контрольное кольцо будет **не** проходить через цилиндрический отсек, проверьте цилиндрический отсек на наличие заусениц и других препятствий. Удалите любые заусенцы, если это необходимо.

Если контрольное кольцо проходит через основной несущий цилиндр, то существует негабаритное состояние и цилиндр блок цилиндра должен быть отремонтирован.

![[mb2brsd.png]]

Если контрольное кольцо пройдет через основной несущий цилиндр без какого-либо сопротивления, центрируйте контрольное кольцо в цилиндрическом отверстии. Используйте датчик измерения щупальца 0,08 мм \[0,003 дюйма\], который **не **более 12,7 мм \[1/2 дюйма\] в ширину. Вставьте датчик измерения щупальца между контрольным кольцом и блоком цилиндра.

![[mb2risa.png]]

Оцените основной несущий цилиндр с помощью калибра для щупальца. См. соответствующее руководство по магазину для подробных процедур проверки.

![[mb2risc.png]]

Удалите контрольное кольцо, контрольную полосу и центрирующие кольца.

![[mb2rima.png]]

> **Note · Примечание**
> The illustrations show checking the main bearing bore on a V28 series engine. The process is similar on **all** other engine families.
>
> Allow the checking bar, centering rings, checking ring and the cylinder block to stabilize to room temperature.
>
> Install the centering rings. Centering ring location will vary depending on engine model. See the Shop Manual for detailed instructions.
>
> Install the main bearing caps, refer to the appropriate Shop Manual for the installation procedures and specifications.
>
> Use clean 15W-40 oil to lubricate the checking ring, checking bar and centering rings.
>
> Slide the checking bar through one of the centering rings and install the checking ring on the checking bar. Continue pushing the checking bar through the rest of the centering rings.
>
> Inspect the checking bar for freedom of rotation.
>
> Push the checking ring through the main bearing bores to be inspected using light finger pressure on each side of the checking ring.
>
> The checking ring **must** pass through each bore with slight resistance.
>
> If the checking ring will **not** go through the bore, inspect the bore for burrs and other obstructions. Remove any burrs if necessary.
>
> If the checking ring does **not** pass through the main bearing bore, an undersized condition exists and the cylinder block bore **must** be repaired.
>
> If the checking ring will pass through the main bearing bore without any resistance, center the checking ring in the bore. Use a feeler gauge 0.08 mm \[0.003 inch\] that is **not** more than 12.7 mm \[1/2 inch\] wide. Insert the feeler gauge between the checking ring and the cylinder block.
>
> Evaluate the main bearing bore using the feeler gauge. Refer to the appropriate Shop Manual for the detailed inspection procedures.
>
> Remove the checking ring, checking bar and centering rings.
