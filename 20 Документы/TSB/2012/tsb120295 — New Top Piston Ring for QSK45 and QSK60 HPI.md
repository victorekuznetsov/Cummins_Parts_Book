## New Top Piston Ring for QSK45 and QSK60 HPI

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This document announces the release of a new top piston ring for all QSK45 and QSK60 HPI engines. The new top piston ring combines features from the current Tier 1 and Tier 2 style top piston rings. The new hybrid ring has the Tier 1 ring base geometry, combined with the three degree cutback on the top edge from the Tier 2 ring.

The new piston ring is Part Number [[3647001]]. It supersedes piston ring, Part Number [[4910251]].

The engine serial number (ESN) first for a production engine with the new piston ring is 33196060, built on 26 November 2012.

The new ring, Part Number [[3647001]], is included in the Piston Ring Set, Part Number [[4309254]], and in the Engine Piston Kit Part Number [[4309253]].
