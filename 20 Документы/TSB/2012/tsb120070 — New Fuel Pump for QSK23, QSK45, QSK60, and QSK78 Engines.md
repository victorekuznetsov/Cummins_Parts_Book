## Новый топливный насос для двигателей QSK23, QSK45, QSK60 и QSK78

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом документе представлен новый топливный насос для использования на промышленных двигателях QSK23, QSK45, QSK60 и QSK78.

Новый насос имеет модифицированную конструкцию. Он изменил внутреннюю геометрию корпуса насоса, что позволяет устанавливать уплотнительный фиксатор для повышения долговечности насоса.

Новый насос совместим со старым насосом.

Новые насосы были установлены на новых двигателях, начиная с серийного номера двигателя (ESN) 33192035 для QSK45 и QSK60 и ESN первого 66302303 для QSK78, на заводе двигателей Давентри. Старый насос не устарел и будет по-прежнему доступен для использования в двигателях для выработки электроэнергии.

> This document introduces a new fuel pump for use on QSK23, QSK45, QSK60, and QSK78 industrial engines.

> The new pump is a modified design. It has modified internal pump body geometry that allows installation of the seal retainer to improve pump durability.
