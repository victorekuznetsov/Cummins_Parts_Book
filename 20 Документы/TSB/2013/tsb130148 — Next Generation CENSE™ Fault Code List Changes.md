## Next Generation CENSE™ Fault Code List Changes

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This document announces the changes to the CENSE™ fault code list that will be implemented as part of the Next Generation - CENSE™ CM2330 module launch.

There will be seventeen new fault code numbers that will replace existing ones used by the CENSE™ CM530 module. The old number are found in the Cummins® Description box of the table below.

> [!note] Note · Примечание
> For CENSE™, the lamp information displayed in INSITE™ electronic service tool is original equipment manufacturer (OEM) dependent and may **not** reflect the actual lamp configuration of a given application.
