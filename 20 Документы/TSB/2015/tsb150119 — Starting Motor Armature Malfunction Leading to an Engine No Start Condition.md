## Starting Motor Armature Malfunction Leading to an Engine No Start Condition

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Issue**

Symptoms: Engine will **not** crank and the starting motor is found to be inoperative.

Investigation into malfunctioning starting motors has identified starting motor overrun as the leading cause.

Starting motor overrun occurs when the starting motor is engaged while the engine is operating. This condition causes overheat damage to the starting motor armature winding, leading to an inoperative starting motor.

**Product Affected**

- QSM11 CM570
- QSX15 CM570

**Verification/Confirmation**

Inspecting for starting motor overrun condition and a damaged starting motor armature winding can be difficult. The first thing that should be done is to determine if the equipment has starting motor overrun protection. This will require contacting the original equipment manufacturer (OEM) to see if the unit is equipped with a starting motor lockout feature to prevent starting motor overrun. This document is **not** able to provide inspection criteria as starting motor lockout is an OEM feature.

**Resolution**

Manufacturer installation of starting motor lockout features will vary.

If no starting motor lockout feature is installed on the equipment, contact the OEM about installing a starting motor lockout feature.
