## Техническая поддержка INSITE™

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- Все двигатели, использующие инструмент для электронных услуг INSITETM

**Указания по обслуживанию**

В этом документе проясняется правильный способ сообщения о любых технических проблемах, которые могут возникнуть при использовании электронного инструментария INSITETM.

Если требуется техническая поддержка с помощью инструментария электронного обслуживания Cummins INSITETM, посетите http://care.cummins.com по ссылке ниже.

> [!note] Примечание
> [https://insite.cummins.com/insite/index.html](https://insite.cummins.com/insite/index.html)

Техническую поддержку можно оказать следующими способами:

- Телефон
- Электронная почта
- Live Chat

При запросе технической поддержки электронного инструментария INSITETM потребуется следующая информация:

- Операционная система компьютера (Windows 8.X, Windows 10.X)
- Установлена версия программного обеспечения для электронного обслуживания INSITETM (откройте инструмент для электронного обслуживания INSITETM, нажмите «Помощь» и откройте «О INSITE»). См. рисунок 1.
- Используемый адаптер шины данных INLINE CAN.
- Тип подключения (J1939, USB или Serial)
- Любые номера кода ошибки, которые могли быть отображены во время возникновения проблемы.
- Модель двигателя
- Тип электронного модуля управления (ECM) и версия калибровки ECM (для всех ECM двигателя).
- Краткое и точное описание проблемы. Если вы отправите запрос на техническую поддержку, потребуются файлы изображений ECM и снимки экрана.

**Клиентская коммуникация**

Дистрибьюторы и дилеры Cummins® должны делиться этим документом со всеми клиентами, которые занимаются самообслуживанием.

** Доступны инструменты и обучение**

Обновления инструментов для электронных услуг INSITETM, поддержка шины данных CAN и информация, а также учебный материал для инструментов электронных услуг также доступны по адресу http://care.cummins.com

> ## INSITE™ Electronic Service Tool Technical Support
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> **Product Affected**
>
> - All engines that use INSITE™ electronic service tool
>
> **Service Instructions**
>
> This document clarifies the correct way to report any technical issues that may occur with INSITE™ electronic service tool.
>
> If technical support is required with Cummins INSITE™ electronic service tool, visit http://care.cummins.com using the link below.
>
> **Note · Примечание**
> [https://insite.cummins.com/insite/index.html](https://insite.cummins.com/insite/index.html)
>
> Technical support can be provided by the following methods:
>
> - Telephone
> - Email
> - Live Chat
>
> The following information will be required when requesting INSITE™ electronic service tool technical support:
>
> - Computer operating system (Windows 8.X, Windows 10.X)
> - Version of INSITE™ electronic service tool software installed (Open INSITE™ electronic service tool, click on ‘Help' and open ‘About INSITE'). See Figure 1.
> - Type of INLINE datalink adapter used.
> - Connection type (J1939, USB or Serial)
> - Any error code numbers that may have been displayed at the time of the problem occurring.
> - Engine model
> - Electronic control module (ECM) type and ECM calibration version (for all engine ECMs).
> - A concise and accurate description of the problem. If emailing a request for technical support, ECM image files and screen shots will be required.
>
> **Customer Communication**
>
> Cummins® distributors and dealers should share this document with all self-servicing customers.
>
> **Service Tools and Training Available**
>
> INSITE™ electronic service tool updates, datalink support and information, and electronic service tools training material can also be accessed at http://care.cummins.com
