**Description of Change**

This document informs the field of coolant filtration upgrades. The new coolant filters use StrataPore® media instead of cellulose media.

**Reason for Change**

The upgraded filtration options offer higher capacity, improved filtration performance, and extended maintenance intervals.

**Service Parts Availability**

Service parts are available. See Table 1 for part numbers.

| Table 1, Coolant Filter Part Numbers |  |  |  |  |  |
|---|---|---|---|---|---|
| Original Filtration Part Numbers | Upgraded Filtration Part Numbers |  |  |  |  |
| Description | Cummins® Part Number | Fleetguard® Part Number | Description | Cummins® Part Number | Fleetguard® Part Number |
| On-engine, 15 DCA units, cellulose media | [[3100308]] | WF2075 | On-engine, 15 DCA units, StrataPore® media | [[3098688]] | WF2121 |
| On-engine, no DCA units, cellulose media | [[3827423]] | WF2077 | On-engine, no DCA units, no StrataPore® media\* | 3098690 | WF2123 |
| \* **Only** coolant filters with no diesel coolant additive (DCA) should be used in combination with organic acid technology (OAT) coolant. |  |  |  |  |  |

**Part Compatibility**

The new upgraded coolant filters are backward compatible.

**Part Identification**

The new upgraded coolant filters can be distinguished using the part number printed on the filter can.

**Part Structure**

The upgraded filtration part numbers do **not** obsolete and supersede the existing filtration part numbers. The existing filtration part numbers will remain available.
