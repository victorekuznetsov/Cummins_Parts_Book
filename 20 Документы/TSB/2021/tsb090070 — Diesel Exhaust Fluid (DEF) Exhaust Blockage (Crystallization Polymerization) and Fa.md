## Закупорка выхлопных газов дизельного топлива (DEF) (кристаллизация / полимеризация) и коды разломов 1682, 2973, 2772, 2773, 3548, 3538, 3568, 3582 и 5655

### Суть проблемы

Затронутая продукция

- Все двигатели среднего класса, оснащенные селективным нейтрализатором после обработки (SCR)

Симптомы:

- Диаметры выхлопных труб, уменьшенные кристаллизацией или полимеризацией выхлопной жидкости дизельного топлива (DEF) и/или кристаллами DEF, видимыми снаружи.
- Коды ошибок 1682, 2973, 2772, 2773, 3548, 3538, 3568, 3582 и 5655.

Первопричина:

- Кристаллы DEF могут накапливаться в выхлопной системе по ряду причин, включая:
- Сначала кристаллы DEF образуются, а затем превращаются в полимер с длительным температурным воздействием ниже 290 ° C [554 ° F ].

### Подтверждение

Кристаллизация или полимеризация может привести к четырем типам блокировки/ограничения выхлопных труб.

1. Накопление менее 20% DEF (см. рисунок 1 ниже)
2. Накопление от 20 до 40 % DEF (см. рисунок 2 ниже)
3. 40-50% накоплений DEF (см. рисунок 3 ниже)
4. 50-80% накоплений DEF (см. рисунок 4 ниже)

**Дополнительные пункты**

- Внешняя сборка
- Очистка трубопроводов внутреннего разложения при утечке кристаллизации наблюдается снаружи (газета форсунки DEF). (см. рисунок 6 ниже).
- DEF форсунка изменяется, форсунка считается «мокрым» или с «каплейным» во время простого использования системы.
- Обязанности цикла и дизайн выхлопной системы

### Решение

- Накопление DEF, покрывающее менее 50% площади поперечного сечения, не должно быть удалено.
- Накопление DEF выше 50% должно быть удалено. См. соответствующее Руководство по обслуживанию. Справочная процедура 011-062 в разделе 11.
- В случае повторного накопления DEF, когда разрешение не найдено с использованием вышеупомянутой информации, необходимо поднять запрос на техническую услугу (TSR).

> ## Diesel Exhaust Fluid (DEF) Exhaust Blockage (Crystallization/Polymerization) and Fault Codes 1682, 2973, 2772, 2773, 3548, 3538, 3568, 3582, and 5655
>
> ### Core Issue
>
> Product Affected
>
> - All midrange engines equipped with aftertreatment selective catalyst reduction (SCR)
>
> Symptoms:
>
> - Exhaust pipe diameters reduced by diesel exhaust fluid (DEF) crystallization or polymerization and/or DEF crystals visible externally.
> - Fault Codes 1682, 2973, 2772, 2773, 3548, 3538, 3568, 3582, and 5655.
>
> Root Cause:
>
> - DEF crystals can build up in exhaust system for a number or reasons, including:
> - DEF crystals occur first and then turn into a polymer with prolonged temperature exposure below 290°C \[ 554°F \].
>
> ### Confirmation
>
> Crystallization or polymerization can lead to four types of exhaust piping blockage/restriction.
>
> 1. Less than 20% DEF Accumulation (See Figure 1 below)
> 2. 20 to 40 % DEF accumulation (See Figure 2 below)
> 3. 40 to 50 % DEF Accumulation (See Figure 3 below)
> 4. 50 to 80 % DEF Accumulation (See Figure 4 below)
>
> **Additional Items**
>
> - External Buildup
> - Internal Decomposition Pipe Cleaning when crystallization leak is witnessed externally (DEF Injector Gasket). (See Figure 6 below).
> - DEF injector changes, Injectors seen to be “wet” or with a “drip” during system prime.
> - Duty Cycle and Exhaust System Design Considerations
>
> ### Resolution
>
> - DEF accumulation covering less than 50% of cross sectional area does **not** need to be removed.
> - DEF accumulation above 50% **must** be removed. See corresponding Service Manual. Reference Procedure 011-062 in Section 11.
> - For any instances of reoccurring DEF accumulation where a resolution is **not** found using above information, a Technical Service Request (TSR) is to be raised.
