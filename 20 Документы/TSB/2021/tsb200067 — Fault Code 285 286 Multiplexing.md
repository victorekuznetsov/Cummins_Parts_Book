## Коды неисправностей 285/286: мультиплексирование

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- промышленный
- Генерация электроэнергии

**Описание изменения**

В этом документе объявляется корректировка калибровки, позволяющая отображать и описывать коды ошибок (FC) 285 и 286 на экране данных об ошибках на сайте.

**Причина изменения**

В прошлом было обнаружено, что основная причина кодов 285 или 286 ошибок не просматривается на Insite из-за того, что функция программного обеспечения не включена на калибровках высокой мощности лошади (HHP). Коды ошибок FC285/FC286 генерируются из-за недостающего сообщения J1939 от производителя оригинального оборудования (OEM).

Калибровки имеют функцию, которая будет отображать, что отсутствующее сообщение мультиплекса J1939 вызывает код ошибки 285/286 в вкладке Advanced ECM Data Insite; эта функция была отключена на различных калибровках.

> ## Fault Code 285/286 Multiplexing
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> **Product Affected**
>
> - Industrial
> - Power Generation
>
> **Description of Change**
>
> This document announces a calibration correction to enable the display and description of Fault Code (FC) 285 and 286 on the Fault Data screen on Insite.
>
> **Reason for Change**
>
> In the past, the root cause of Fault Codes 285 or 286 has been found to not be viewable on Insite due to a software feature not being enabled on High Horse Power (HHP) calibrations. Fault Codes FC285/FC286 are generated due to a missing J1939 message from the Original Equipment Manufacturer (OEM).
>
> Calibrations have a feature that will display which missing J1939 multiplex message is causing the 285/286 fault code in the Advanced ECM Data tab of Insite; this feature was turned off on various calibrations.
>
> **Service Instructions**
>
> See Figures 1 and 2 below from Insite.
>
> Figure 1, Before Calibration Correction - Insite Is Not Displaying the SAE J1939 Fault Data Screen
>
> Figure 2, After Calibration Correction - Showing Insite Advanced ECM Data Screen with SAE J1939 Fault Driving the 285 Fault
>
