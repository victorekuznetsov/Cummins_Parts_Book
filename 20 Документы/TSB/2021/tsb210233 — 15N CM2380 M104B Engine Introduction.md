**Инструменты для обслуживания**

Новые сервисные инструменты Cummins®, выпущенные для поддержки двигателя 15N CM2380 M104B:

- Тест на утечку охладителя EGR, номер детали 5573379
- Валентный пружинный компрессор, номер детали 5573421
- Установщик клапанных сидений, номер детали 5573423

Для получения полного списка инструментов обслуживания Cummins®, необходимых для поддержки этого двигателя, обратитесь к местному дистрибьютору Cummins®.

**Инструменты электронного обслуживания InSITETM**

В комплектации для электронных услуг INSITETM версии 8.7.2 или более поздней версии поддерживаются двигатели полного цикла. Версия 8.7.2 или более поздняя включает в себя все диагностические тесты и функции, необходимые для полной поддержки двигателя 15N CM2380 M104B. Обновления электронного инструментария INSITETM доступны через менеджер обновлений Cummins®. Ссылка на следующий веб-сайт для доступа к менеджеру обновлений Cummins®.

> [!note] Примечание
> [https://www.cummins.com/support/digital-products-and-services-support](https://www.cummins.com/support/digital-products-and-services-support)
