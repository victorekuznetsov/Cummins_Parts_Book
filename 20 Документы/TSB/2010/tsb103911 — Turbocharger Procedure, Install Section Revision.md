## Turbocharger Procedure, Install Section Revision

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Service/Parts Topic revises the Install section torque value for the standard and Spiralock® nuts.

- ISX Automotive CM570, QSX13 CM570 and Power Generation CM570

The torque value for the standard nut was changed from 60 N•m \[44 ft-lb\] to 61 N•m \[45 ft-lb\]. The torque value for the Spiralock® nut was changed from 60 N•m \[44 ft-lb\] to 81 N•m \[60 ft-lb\].

- Automotive CM870

The mounting nut torque was changed from 88 N•m \[65 ft-lb\] to 102 N•m \[75 ft-lb\].
