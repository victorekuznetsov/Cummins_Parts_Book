## Aftercooler Vent Hose Removal and Aftercooler Cover Change

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Technical Service Bulletin is to inform the field of a product change for all QSK45 and all QSK60 engines aftercooler water air vent systems, and an aftercooler cover change.

Air Vent Hose Removal

A product change has been introduced to remove the water air vent line system from the QSK product range. This will mean there are now three variations of air vent line installation.

- Old Type 1 - This consists of the original set up with vent lines installed
- Old Type 2 - Vent lines removed and aftercooler core vent outlets plugged (Introduced July 2002).
- New Type - Vent outlet removed from aftercooler cores and new aftercooler covers introduced. Engine serial number first for the QSK60 was 33156143, built - 17th of March 2004, and for the QSK45 was 33156082, built 8th of March 2004.

> [!note] Note · Примечание
> If a NEW type aftercooler core is fitted to an OLD Type 1 or OLD Type 2 engine, the aftercooler cover will also have to be changed. If the covers are to be replaced, depending on aftercooler location on the engine, the correct orientated cover will have to be installed. If a NEW type cover is to be fitted to a OLD Type 1 or OLD Type 2 engine a NEW type core will have to be fitted.

Aftercooler Cover Changes

This change was made to increase the durability of this component. Improvements have been made by adding a number of strengthening ribs in the critical internal and external areas.
