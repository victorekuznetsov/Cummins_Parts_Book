## New Running Level Dipstick

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Service/Parts Topic announces the introduction of a new running level dipstick and hand hole cover for QSK45/60 Industrial engines. This running level dipstick has markings on both sides; one side has the normal static markings and is marked 'Engine Stopped', the other side is for the running level checks and is marked 'Engine Idling'.

Service Parts can be purchased for the QSK45/60 Industrial engines. The installation and calibration procedures are detailed below.

The hand hole cover and dipstick is designed as a direct replacement for the hand hole cover containing the dipstick tube currently fitted to the engine.

Please note that depending on the harness type (phase 1.0 & 1.5 versus phase 2.0), a different hand hole cover is used. All Phase 2 QSK45/60 engines will have run level hardware.

This change went into production at the Daventry Engine Plant on 3rd January 2003. The engine serial number first is 33153219.
