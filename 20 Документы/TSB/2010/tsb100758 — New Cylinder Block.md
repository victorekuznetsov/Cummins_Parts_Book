## New Cylinder Block

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Technical Service Bulletin supersedes topic 07T1-57. Please replace topic 07T1-57 with this topic.

This Technical Service Bulletin introduces a new ISX cylinder block. This new cylinder block features a redesigned block heater port as well as the use of a new block heater and a new block heater port plug. The new cylinder block is backwards compatible to older cylinder blocks by virtue of installing a new block heater or block heater port plug.

If a new block is ordered and the original engine was equipped with a block heater, a new style block heater, Part Number 4965497, along with the mounting capscrew, Part Number [[3093957]], **must** be ordered.

If the original engine was **not** equipped with a block heater, a block heater port plug, Part Number 4985436, along with the mounting capscrew, Part Number [[3093957]], **must** be ordered.

The old style block heater, Part Number 3681362, will still be available for service use.
