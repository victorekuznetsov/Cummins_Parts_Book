## New Connecting Rod Bearing

### Warranty Statement

### Contents

> [!note] Note · Примечание
> The information in this document has been superseded. For the connecting rod bearing information, refer to [[tsb101100 — New Connecting Rod Bearings\|TSB101100]]. This document with be kept active for information purposes **only**.

This document announces the release of a new angle split connecting rod bearing for the QSK45 and QSK60 engines. The new connecting rod bearing contains a new VP2i B-E material.

The VP2i B-E material angle split connecting rod bearing supersedes the VP2q B-E material angle split connecting rod bearing.

Since production changed to a different connecting rod design, this new bearing will be used for service **only**. Therefore, no engine serial number (ESN) first is being provided.

Table 1 identifies the part numbers for the old and new connecting rod bearings.

| Table 1, Connecting Rod Bearings |  |  |
|---|---|---|
| Type | Old Part Number | New Part Number |
| Connecting Rod Bearing | 3636495 | 3639827 |
