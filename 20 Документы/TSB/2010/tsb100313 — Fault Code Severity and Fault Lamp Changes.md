## Fault Code Severity and Fault Lamp Changes

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Technical Service Bulletin announces changes in the:

- Severity of several Quantum™ system fault codes
- Mapping of fault codes to their respective alarm lamp colors on QSK45, QSK60, and QSK78 powered industrial applications.

These changes optimize the Quantum™ high horsepower annunciation and prevent operator confusion over the lamp severity. The lamp color Red now means, STOP the engine immediately, continued operation will cause engine damage.

The improvement affects engine families QSK45, QSK60, and QSK78 built or recalibrated after August 7, 2003. The following table lists specific Quantum™ ECM code revisions affected and revision level. The revision date for these codes is July 8, 2003.

This is the recommended setup for fault annunciation:

1. Pin 18 of the 31-pin OEM connector
2. Level 1 faults, includes engine protection and critical sensor in-range faults
3. Indicates continued operation will cause engine damage
4. Operator **must** stop the engine as soon as safety permits
5. Required lamp
6. Red means stop.

1. Pin 16 of the 31-pin OEM connector
2. Level 2 faults, includes critical sensor out of range faults
3. Indicates critical sensors are **not** functional
4. Operator **must** schedule engine service and have the fault corrected the same day
5. Required lamp, unless separate equipment is provided for monitor and display of level 2 faults.

1. Pin 17 of the 31-pin OEM connector
2. Level 3 faults, includes engine information and non-critical sensor out of range faults
3. Indicates service is required within the next preventative maintenance interval
4. This lamp is **not** required but recommended, unless a separate equipment is provided for monitor and display of level 3 faults.

Depending on the application, some physical wiring changes need to be made to existing equipment when Quantum™ calibration is updated. For three lamp configurations, a correction of the lamp colors is needed for hardware compliance. Two lamp configurations need a minor wiring change. For more details on the action to be taken at the time of software version update, please consult AEB 15.43 and your application engineer or Distributorship Field Service Engineer (DFSE).

The following table lists the hardware configuration required to implement this fault lamp strategy improvement:

| Quantum™ Fault Lamp Hardware Changes |  |  |  |  |
|---|---|---|---|---|

| 18 | Engine Protection | Red, Blue, or White (varies by application) | Stop engine immediately | Red |
| 16 | Stop | Red | Warning - engine will run, but must be repaired the same day | Amber |
| 17 | Warning | Amber | Maintenance - repair at the next planned maintenance | Blue (if used) or none |
