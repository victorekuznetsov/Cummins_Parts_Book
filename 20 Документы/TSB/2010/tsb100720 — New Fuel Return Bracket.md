## Новый топливный возврат

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом бюллетене технического обслуживания представлен переработанный кронштейн для установки обратной линии топлива ISM.

Предыдущие кронштейны возврата топлива ISM использовали прямоугольную латунную фитинг с кольями, чтобы обеспечить обратную линию топлива и фитинг на блок двигателя. Перепроектированный кронштейн возврата топлива ISM включает в себя круглый, заколотый и скошенный стальной фитинг для обеспечения линии возврата топлива к блоку двигателя. Этот новый кронштейн возврата топлива выпускается для всех двигателей ISM, ISMe и QSM в качестве новой части и заменяет все предыдущие части. Новый кронштейн возврата топлива ISM, номер детали[[4985465]]Заменяет часть 3401236. Справочная диаграмма 1 и диаграмма 2 для различий между старой кронштейном возврата топлива ISM и новой кронштейном возврата топлива ISM.

Дата выпуска новой кронштейна возврата топлива ISM для производства - июнь 2008 года.

Дата выхода новой кронштейна возврата топлива ISM для обслуживания - июль 2008 года.

Серийный номер двигателя (ESN) первый - 35233686.

> ## New Fuel Return Bracket
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This Technical Service Bulletin introduces a redesigned ISM fuel return line mounting bracket.
>
> Previous ISM fuel return brackets utilized a rectangular staked brass fitting to secure the fuel return line and fitting to the engine block. The redesigned ISM fuel return bracket includes a round, staked, and brazed steel fitting to secure the fuel return line to the engine block. This new fuel return bracket is being released for all ISM, ISMe, and QSM engines as a new part and replaces all previous parts. The new ISM fuel return bracket, Part Number [[4985465]], supersedes Part Number 3401236. Reference Figure 1 and Figure 2 for the differences between the old ISM fuel return bracket and the new ISM fuel return bracket.
>
> The release date for the new ISM fuel return bracket for production is June 2008.
>
> The release date for the new ISM fuel return bracket for service is July 2008.
>
> The engine serial number (ESN) first is 35233686.
