## New Single Stage Turbocharger

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Service Parts/Topic introduces a new turbocharger for the QSK60 engine, Part Number 4035965.

The affected applications are all QSK60 single-stage turbocharged, high Brake Mean Effective Pressure (BMEP) industrial engines (2500 hp), as detailed below.

The new turbocharger, Part Number 4035965, features a different compressor wheel and compressor housing that are more robust and accommodate changes of altitude better. There is no need to modify the Quantum™ or CENSE™ parameters on existing engines built with the previous turbocharger version, and the new turbocharger Part Number 4035965 can be used in direct replacement of the old unit Part Number 3595429, as well as be used in combination with the old turbochargers on the same engine.

The new turbocharger kit, Part Number 4089756, replaces the old turbocharger service kit, Part Number 4025351.

Please note that this introduces a new core assembly, Part Number 4035968, for service.

The date first in production was September 15, 2003 and the engine serial number first is 33154838.
