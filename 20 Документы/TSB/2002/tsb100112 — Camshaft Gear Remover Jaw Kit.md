## Комплект захватов съёмника шестерни распредвала

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом бюллетене технической службы представлен новый комплект для удаления челюстей распределительного вала, номер детали 3164244. Набор используется для удаления шестерен распределительного вала L10, M11, K19, K38 и K50 с использованием механического набора для удаления распределительного устройства распределительного вала, номер детали 3162895. Новый комплект для удаления, Часть Номер 3164244, устарел и заменяет предыдущую сборку для удаления, Часть Номер 3162896.

> [!note] Примечание
> Штукатурка, номер детали 3164362, используемая в этом комплекте, может быть немного большой для использования в некоторых существующих пластинах для удаления. Это может потребовать расширения слотов пластины для удаления, чтобы принять шпильки большего диаметра.

> [!note] Примечание
> Для вытягивания распределительного механизма требуется два комплекта Части 3164244. **не** использовать в сочетании с распредвалом для удаления челюстей, номер детали 3162896.

> [!quote]- Original (English) · английский оригинал
> ## Camshaft Gear Remover Jaw Kit
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This Technical Service Bulletin introduces a new camshaft gear remover jaw kit, Part Number 3164244. The kit is used to remove L10, M11, K19, K38, and K50 camshaft gears using the mechanical camshaft gear remover kit, Part Number 3162895. The new remover kit, Part Number 3164244, obsoletes and supersedes the previous remover assembly, Part Number 3162896.
>
> **Note · Примечание**
> The stud, Part Number 3164362, used in this kit can be slightly large for use in some existing remover plates. This can require the remover plate slots to be widened to accept the larger diameter studs.
>
> **Note · Примечание**
> Two kits of Part Number 3164244 are required to pull the camshaft gear. Do **not** use in combination with the camshaft jaw remover, Part Number 3162896.
>
> Fig.1, New Camshaft Gear Remover Jaw Kit Part Number 3164244
>
> Fig. 2, Old Mechanical Camshaft Gear Remover Part Number 3162896
>
> The content of camshaft gear remover kit, Part Number 3162895, has been revised to include the new remover jaws. Service Tool Instruction, Bulletin 3377781-1, has been updated to explain the procedure for using the new camshaft gear remover jaws and is included with remover jaw kit, Part Number 3164244.
