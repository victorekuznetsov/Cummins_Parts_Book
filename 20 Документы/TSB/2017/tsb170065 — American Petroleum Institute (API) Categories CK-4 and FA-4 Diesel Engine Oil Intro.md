## Введение масел категорий API CK-4 и FA-4

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом документе объявляется о выпуске двух новых категорий Американского института нефти (API) для дизельных моторных масел. Эти масла были разработаны для использования в дорожных и внедорожных приложениях с использованием дизельного топлива с ультранизким содержанием серы (ULSD).

- Масла категории API CK-4 были выпущены в декабре 2016 года и включают все сорта вязкости масел CJ-4. Поскольку более высокие температуры двигателя и более низкие выбросы являются постоянной тенденцией, требовалось улучшить масла. CK-4 имеет улучшенную стойкость к окислению, стабильность сдвига и контроль аэрации. Категория API CK-4 обратно совместима с технологией API категории CJ-4.
- Масла категории API FA-4 также были выпущены в декабре 2016 года, в основном в виде 10W-30. Масла FA-4 обладают такой же улучшенной стойкостью к окислению, стабильностью сдвига и контролем аэрации масел CK-4. Масла FA-4 также снижают выбросы парниковых газов (повышенная экономия топлива, зависящая от рабочего цикла) за счет снижения вязкости высокой температуры / высокого сдвига (HTHS). Более низкие HTHS приводят к направленно более тонким масляным пленкам, смазывающим металло-металлические интерфейсы. Масла категории API FA-4 являются **не** обратно совместимыми и *** используются только по указанию процедуры рекомендаций и спецификаций по смазочному маслу в разделе V соответствующего руководства по эксплуатации и техническому обслуживанию для использования масел двигателя CES 20087.

> [!warning] ОСТОРОЖНО
> Масла категории API FA-4 никогда не должны использоваться в неутвержденных двигателях, поскольку это приведет к повреждению двигателя.

**Стандарт по инженерному оборудованию Cummins (CES)**

Категория масла API или любая международная сертификация масла не могут быть использованы для выбора соответствующего моторного масла для двигателя Cummins®. ** Только используйте масла, соответствующие Cummins® Engineering Standard (CES). В таблице 1 ниже приводится сравнение между CES и другими классификациями регулирования нефти для справочных **только**. Список масел, которые соответствуют требованиям CES для двигателя, можно получить у местного дистрибьютора Cummins® или найти на QuickServe® Online. Ссылка на веб-ссылку ниже.

> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This document announces the release of two new American Petroleum Institute (API) categories for diesel engine oils. These oils have been designed for use in on-highway and off-highway applications using ultra-low sulfur diesel (ULSD) fuel.
>
> - API category CK-4 oils were released in December 2016 and include all viscosity grades of CJ-4 oils. As higher engine temperatures and lower emissions are a continuing trend, improved oils were required. CK-4 has improved oxidation resistance, shear stability, and aeration control. API category CK-4 is backward compatible with API category CJ-4 oil technology.
> - API category FA-4 oils were also released in December 2016, primarily as a 10W-30 viscosity grade. FA-4 oils carry the same improved oxidation resistance, shear stability, and aeration control of CK-4 oils. FA-4 oils also reduce greenhouse gas emissions (increased fuel economy, dependent on duty cycle) by lowering high temperature/high shear (HTHS) viscosity. Lower HTHS results in directionally thinner oils films lubricating metal-metal interfaces. API category FA-4 oils are **not** backwards compatible and are **only** to be used when directed by the Lubricating Oil Recommendations and Specifications procedure in Section V of corresponding Owners or Operation and Maintenance Manual to use CES 20087 engine oils.
>
> **CAUTION · Осторожно**
> API category FA-4 oils is never to be used in unapproved engines as engine damage will result.
>
> **Cummins Engineering Standard (CES)**
>
> The API oil category, or any international oil certification, are **not** able to be used to select the appropriate engine oil for a Cummins® engine. **Only** use oils that meet the appropriate Cummins® Engineering Standard (CES). Table 1 below provides a comparison between CES and other oil regulatory classifications for reference **only**. A list of oils that meet the appropriate CES for the engine can be obtained from a local Cummins® distributor or can be found on QuickServe® Online. Reference weblink below.
