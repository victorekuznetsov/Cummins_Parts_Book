## Electric Starting Motor Changes

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- KV38 (All Versions)
- KV50 (All Versions)
- QSK38 (All Versions)
- QSK50 (All Versions)

**Description of Change**

A new starting motor is available.

**Reason for Change**

Production has ceased on all MS7 and M125 starting motor and the M128 starting motor is the replacement.

**Service Instructions**

Parts and Compatibility

- If using a single (quantity 1) MS7 or M125 starting motor on an engine. The M128 starting motor is a direct replacement.
- If using dual (quantity 2) MS7 or M125 starting motor on an engine. Then both starting motors **must** be replaced with M128 starting motor.
- If using triple (quantity 3) starting motor. All 3 starting motor **must** be replaced with M128 starting motor.
- Table 3 shows starting motor part number supersession and all new part numbers.
- New brackets have been released to mount the magnetic switches to the M128 starting motor and are listed in Table 3.

Installation

- The orientation of the starting motor when fitting to the flywheel housing is dictated by the flat side of the mounting flange. The flat side of the mounting flange is the side that **must** be oriented to the side face of the cylinder block for correct starting motor orientation. Figure 1 shows the flat face of the starting motor mounting flange.
- The orientation of the starting motor will also dictate the magnetic switch bracket to be used.
- Figure 2 shows the correct mounting bracket depending on starting motor orientation.
- Table 2 communicates the correct magnetic switch bracket part number.
- Figure 3 shows the exploded starting motor assembly detailing the magnetic switch and is applicable for both orientations of mounting bracket and single/dual magnetic switch assemblies.
- A torque table (Table 2) is available for updated joints on the assemblies.
- Figure 4 shows the wiring terminals that **must** be used to wire the starting motor correctly. The T50C (Ignition ‘S') terminal **must** be balanced using 16AWG wire between both T50C (Ignition ‘S') starting motor terminals.

**Part Compatibility**

- Full compatibility when used in single starting motor applications.
- No compatibility when used in dual or triple starting motor applications.
- The obsolete MS7 and M125 are hard engagement starting motor. The M128 starting motor is a soft engagement starting motor. Use of hard and soft engagement starting motors together is **not** allowed.

**Part Inventory Action**

Use existing part number inventory before using the new part number.
