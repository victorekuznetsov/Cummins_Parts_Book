**Issue Summary**

Symptom:

- Fault Code 435
- Fault Code 415
- External lubricating oil leak

Root Cause:

- Engine oil pressure switch leaking lubricating oil

**Verification**

Verify there is an external oil leak from the engine oil pressure switch.

**Resolution**

Replace the existing engine oil pressure switch with the new engine oil pressure switch part number seen in Table 1.
