## New QSK60 and QSK78 Capscrews

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

New capscrews were released to replace capscrews as part of a continuous improvement project. New drawings have been created for the new capscrews. Listed assemblies and options have been updated and previous capscrews have been obsoleted and a supercession was established. Some capscrews were found **not** to need the special coating, so they were replaced with a suitable standard coated fastener.

The capscrews below were obsoleted without a supercession being setup. The parts listed under the new part number header are the replacement capscrews, which should be ordered f the old part number is requested. Table 1 lists the capscrew location, new part number, and old part number.

| Table 1: Capscrew Supercession |  |  |
|---|---|---|
| Capscrew (Location on engine) | New Part Number | Old Part Number |
| QSK45 Full Flow Filter Head | 3644471 | 4080578 |
| Inside QSK60 Thermostat Housing | [[3900633]] | 4098089 |
| QSK60 HPI Turbocharger Oil Plumbing | 3644532 | 3349461 |
| QSK78 Air Cross-over | [[3082439]] | 3089356 |
