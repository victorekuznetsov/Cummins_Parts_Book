## Common Cylinder Liners for C and ISC Series Engines

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This document was originally released between 1994 and 2001. It has been added to QSOL for informational purposes

The purpose of this document is to introduce common cylinder liners for C and ISC Series engines.

In the beginning of 1998, both C and ISC engines began using a common cylinder liners, Part No. 3944344, in production. This cylinder is now the **only** liner in production. However, the old liner, Part No. 3919937, will be retained as a service part for C Series engines built prior to the engine serial numbers listed below.

|  | **Engine Serial Number First** | **Date** |
|---|---|---|
| CDC | 4563466 | 5 January 1998 |
| DEP | 21301477 | 20 Febuary 1998 |

The ISC liner, Part No. 3944344, is 3-mm shorter than the C liner, Part No. 3919937. For this reason the old C block, Part No. 3928964, is designated for the shorter liner. To accept the shorter liner, block machining has been modified to stop 3-mm shorter than the old block (refer to Fig. 1 and 3). **When replacing C Series blocks, the liner must also be replaced.** Old liners in a new block will sit above the head deck by about 3 mm, which is unacceptable (refer to the Fig. 3). The ISC block, Part No. 3945063, will remain the same. Refer to the table below.

> [!note] Note · Примечание
> Replace cylinder liner with like cylinder liner. **Only** use new cylinder liner on C series blocks that are new.

|  | **Old C Block** | **New C Block** | **ISC Block** |
|---|---|---|---|
| **Cylinder Block** | Obsolete, Part No. 3928964 | Production/Service Part No. 3934906 | Production/Service Part No. 3945063 |
| **Cylinder Liner** | Service **Only** Part No. 3919937 | Production/Service Part No. 3944344 | Production/Service Part No. 3944344 |

| **The following blocks have been superseded:** |  |  |
|---|---|---|
| **Old (Obsolete)** | **Style** | **New (Supersedes Old)** |
| 3355051 | Short block | 3934578 |
| 3355054 | Short block | 3934579 |
| 3355446 | Repair kit | 3934904 |
| 3355448 | Repair kit | 3934905 |
| 3355449 | Repair kit | 3934907 |
| 3802559 | Repair kit | 3934906 |
| 3926151 | Short block | 3934596 |
| 3926152 | Short block | 3934597 |
| 3929331 | Short block | 3934598 |
| 3927332 | Short block | 3934599 |

> [!note] Note · Примечание
> All of the above blocks take the new liner, Part No. 3944344.

When replacing liners within the old C block (**not** replacing the block, liner kit, Part No. 3802407, is still available with the old liner.

> [!note] Note · Примечание
> This is a product improvement and is **not** subject to campaign.
