## QST30 Industrial Calibration Revision for Fault Code 772/773 Lamp Strategy Update

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This document announces a change in calibrations for QST30 Industrial engines. The calibration change was made to correct the lamp strategy for Fault Codes 772 and 773. Refererence Table 1 for previous and revised calibrations.

In the previous revisions of each calibration, an amber lamp lit when Fault Code 772 or 773 became active. In the revised calibrations, no lamps light when Fault Code 772 or 773 becomes active. Fault Codes 772 and 773 will continue to be logged with the ECM and can still be used for troubleshooting purposes. The lamp strategy of the revised calibrations meets Cummins® Engineering Standards.

The new calibrations were installed in production engines built on or after July 2011.
