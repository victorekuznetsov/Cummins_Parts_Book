**Issue**

Engine malfunctions have been observed as 150 mm cylinder liners are being used in 152 mm cylinder blocks in error. **Only** 152 mm cylinder liners can be used with 152 mm cylinder blocks.

This document announces new service tools that provide a quick and easy way to determine the size of the cylinder block bore as well as the cylinder liner diameter.

**Verification**

To measure cylinder liners, use gauge, Part Number 5299587.

1. Place cylinder liner upside down on a flat work surface.
2. Slide gauge, Part Number 5299587, over lower end of cylinder liner.
3. If gauge is able to rest on midstop counter bore ledge, cylinder liner is a 150 mm cylinder liner.
4. If gauge is **not** able to rest on midstop counter bore ledge, cylinder liner is a 152 mm cylinder liner

To measure cylinder blocks, use gauge, Part Number 5394467.

1. With cylinder liner removed from cylinder block, insert the gauge into cylinder block liner bore.
2. If gauge, Part Number 5394467, is able to pass completely through midstop counter bore, cylinder block is a 152 mm cylinder block.
3. If gauge, Part Number 5394467, is **not** able to pass completely through midstop counter bore, cylinder block is a 150 mm cylinder block.
