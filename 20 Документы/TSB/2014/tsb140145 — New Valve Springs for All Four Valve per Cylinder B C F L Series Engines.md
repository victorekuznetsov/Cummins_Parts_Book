## Новые пружины клапан для всех четырех клапанов на цилиндр B / C / F / L серии двигателей

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом документе анонсированы новые рессоры клапанов для всех четырех клапанов на цилиндры двигателей серии B/C/F/L.

Клапанные пружины обратно совместимы и прозрачны для сборки. Сервисные части стали доступны 02 сентября 2014 года. В запасных частях они затронуты. Подробнее см. в Частях оповещения MDC-040-14. Доступна визуальная проверка цвета краски, чтобы отличить новые клапанные пружины от устаревших клапанных пружин.

При смене клапанных пружин следует менять обе клапанные пружины под одним и тем же клапанным мостом для любого двигателя среднего класса. См. TSB130158 для справки.
