## QSK19 Industrial Cast Iron Gear Cover

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This document introduces a new front gear cover for the QSK19 Industrial engine.

The new gear cover, Part Number 4333889, is only available for service replacement. The old gear cover, Part Number [[3090327]], is still available for production.

The new gear cover is made from cast iron and provides a more robust mounting surface at the accessory drive than the previous aluminum gear cover. Applications that do not meet the requirements in AEB 21.37 must use this cast iron gear cover. Contact an Authorized Cummins® Distributor for access to this Application Engineering Bulletin. A spacer, Part Number 4333920, must be used with the cast iron gear cover, in order to mount the thermostat housing (Figure 1). [[20-008-015-tr — Coolant Thermostat Housing Support|Refer to Procedure 008-015 in Section 8]] in the QSK19 Industrial Service Manual, Bulletin 4021592, for installation instructions. All capscrew torques remain unchanged for the new cast iron cover.

Table 1 lists the old and new part numbers.

| Table 1: QSK19 Gear Cover Part Numbers |  |  |
|---|---|---|
| Description | Aluminum | Cast Iron |
| Front Gear Cover | [[3090327]] | 4333889 |
| Spacer | N/A | 4333920 |
