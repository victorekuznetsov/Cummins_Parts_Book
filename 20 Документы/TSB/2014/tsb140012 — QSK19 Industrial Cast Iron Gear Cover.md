## Чугунная крышка шестерён QSK19 (промышленное исполнение)

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом документе представлена новая передняя крышка передней части передней части передних передач для промышленного двигателя QSK19.

Новая крышка передач, номер детали 4333889, доступна только для замены. Старая крышка, номер детали[[3090327]]Он по-прежнему доступен для производства.

Новая крышка передач изготовлена из чугуна и обеспечивает более прочную монтажную поверхность на вспомогательном приводе, чем предыдущая алюминиевая крышка передач. Приложения, не соответствующие требованиям стандарта AEB 21.37, должны использовать эту чугунную крышку. Свяжитесь с авторизованным дистрибьютором Cummins® для доступа к этому бюллетеню по разработке приложений. Спейсер, номер детали 4333920, должен использоваться с чугунным чехлом, чтобы установить корпус термостата (рисунок 1).[[20-008-015-tr — Coolant Thermostat Housing Support|См. процедуру 008-015 в разделе 8.]]В руководстве по промышленной службе QSK19, Бюллетень [[4021592 — QSK19, QSK19 CM850 MCRS, and QSK19 CM2150 MCRS Service Manual\|4021592]], для инструкций по установке. Все крутящие моменты болтов остаются неизменными для нового чугунного покрытия.

> ## QSK19 Industrial Cast Iron Gear Cover
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This document introduces a new front gear cover for the QSK19 Industrial engine.
>
> The new gear cover, Part Number 4333889, is only available for service replacement. The old gear cover, Part Number [[3090327]], is still available for production.
>
> The new gear cover is made from cast iron and provides a more robust mounting surface at the accessory drive than the previous aluminum gear cover. Applications that do not meet the requirements in AEB 21.37 must use this cast iron gear cover. Contact an Authorized Cummins® Distributor for access to this Application Engineering Bulletin. A spacer, Part Number 4333920, must be used with the cast iron gear cover, in order to mount the thermostat housing (Figure 1). [[20-008-015-tr — Coolant Thermostat Housing Support|Refer to Procedure 008-015 in Section 8]] in the QSK19 Industrial Service Manual, Bulletin [[4021592 — QSK19, QSK19 CM850 MCRS, and QSK19 CM2150 MCRS Service Manual\|4021592]], for installation instructions. All capscrew torques remain unchanged for the new cast iron cover.
