## Test Lead Kit, Part Number 4919115, Obsoleted and Superseded by Test Lead Kit, Part Number 5299367

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This document announces that test lead kit, Part Number 4919115, has been obsoletes and superseded by test lead kit, Part Number 5299367, effective 1 October 2014.

This new test lead kit is used for testing electrical circuits with properly sized test leads to prevent damage to electrical connector terminals.

Test lead kit, Part Number 4919115, can be updated to test lead kit, Part Number 5299367, using the following steps:

- Remove and scrap all quantities of test lead part number 4919351. This test lead utilizes a 1.5 x 0.80 mm blade, which will cause socket damage if used on the more common 1.2 x 0.60 mm socket.
- Order test lead part number 5299368, which has obsoleted and superseded part number 4919351. This new test lead uses a 1.2 x 0.60 mm blade.
- Order test lead part numbers 4919043, 5299107, and 5299108, all of which were released after the original test lead kit, Part Number 4919115, was released.
- Remove and scrap test lead part number 3164111. Due to similarities between test leads, test lead part number 3164111 was obsoleted and superseded by test lead part number 3164597.
- Remove and scrap Tool Information Bulletin 3400282 from the lid of test lead kit, Part Number 4919115, and order Tool Information Bulletin 3400485, which obsoletes and supersedes 3400282. Install the new Tool Information Bulletin in the lid of the existing test lead kit. Tool Information Bulletin 3400485 will only be available until 1 June 2015.
- Removal of test lead part number 3164775 is optional. Test lead part number 3164775 has been removed from the new test lead kit, Part Number 5299367, but remains an active part number that can be purchased individually if required.
