**Описание изменения**

В этом документе объявляется о введении уникальных порогов кода разности давления фильтра моторного масла для двух типов фильтров моторного масла, доступных сегодня: - канистр фильтров и систем фильтрации EliminatorTM. Кроме того, функция дифференциального давления фильтра моторного масла теперь поддерживает защиту двигателя от износа для двигателей, оснащенных EliminatorTM.

**Причина изменения**

В прошлом двигатели, оснащенные фильтрами EliminatorTM или канистрами с фильтром спин-он, использовали один и тот же порог кода разлома фильтра дифференцированного давления моторного масла. Этот порог кода неисправности был первоначально разработан для оповещения операторов о состоянии обхода фильтра моторного масла, вызванного заглушением фильтра моторного масла.

Из-за различий в конструкции фильтрующих элементов фильтры Eliminator требуют более низкого порога неисправности. Поэтому реализованы два отдельных порога; порог для двигателей, оснащенных фильтрами Spin-On, и еще один специфичный для двигателей, оснащенных EliminatorTM.

**Проверка**

Проверить код модуля управления двигателем (ECM), чтобы убедиться, что эта функция включена. См. таблицы 1, 2, 3, 4, 5, 6, 7 и 8 ниже.

**Клиентская коммуникация**

Введен новый код 3491 с красной лампой (и связанным с ней снижением скорости), чтобы дополнить текущий FC1362 лампой Amber.

Операторы оборудования могут испытывать падение двигателя без какой-либо лампы или FC3491, если программное обеспечение дисплея оборудования не обновляется специально для нового кода неисправности.

Для двигателей, оснащенных фильтровальными канистрами с спиновым приводом, FC1362 (Amber) станет активным, когда дифференциальное давление достигнет достаточного уровня для обхода фильтрации моторного масла: 345кПа[50 psi]. Двигатели, оснащенные фильтрацией EliminatorTM, будут иметь FC1362 (Amber), когда дифференциальное давление увеличится за пределы номинальных стабильных значений, что свидетельствует о правильной работе с подмышками. 62кПа[9 psi]. Если сборка фильтра для моторного масла **не** обслуживается, и дифференциальное давление продолжает увеличиваться, перед обходом фильтрации моторного масла будет принята FC3491/FC612 (Красный): 96.5kPa[14 psi]. Этот FC3491/FC612 сопровождается выпадением двигателя, чтобы ограничить способность двигателя заставлять моторное масло работать в обход фильтра.

**Указания по обслуживанию**

Для морских установок, использующих панели C-Command Elite или Elite Plus, панель контролирует дифференциальное давление моторного масла. 1. Подключите кабель Ethernet к персональному компьютеру, а другой конец к коммутатору Ethernet внутри панели. Если нет Ethernet-переключателя, подключитесь непосредственно к блоку управления дизельным топливом (DCU). См. рисунок 1.

Рисунок 2, DCU Меню Экран.

> **Description of Change**
>
> This document announces the introduction of unique lubricating oil filter differential pressure fault code thresholds for the two lubricating oil filter types available today: spin-on filter canisters and Eliminator TM filtration systems. In addition, the lubricating oil filter differential pressure feature now supports engine protection derates for engines equipped with Eliminator TM.
>
> **Reason for Change**
>
> In the past, engines equipped with either Eliminator TM filters or spin-on filter canisters used the same lubricating oil filter differential pressure fault code threshold. This fault code threshold was originally designed to alert operators to the condition of lubricating oil filter bypass caused by lubricating oil filter plugging.
>
> Due to the differences in filter element design, Eliminator TM filters require a lower fault threshold. Therefore, two separate thresholds have been implemented; a threshold for engines equipped with Spin-On filters, and another specific for engines equipped with Eliminator TM.
>
> **Verification**
>
> Verify engine control module (ECM) code to ensure this feature is enabled. See Tables 1, 2, 3, 4, 5, 6, 7, and 8 below.
>
> **Customer Communication**
>
> A new Fault Code 3491 with Red Lamp (and an associated speed derate) has been introduced to complement the current FC1362 with Amber Lamp.
>
> Equipment operators can experience an engine derate without any lamp or FC3491 displayed if the equipment's display software is not updated specifically for the new fault code.
>
> For engines equipped with spin-on filter canisters, FC1362 (Amber) will become active when the differential pressure reaches sufficient levels to drive lubricating oil filtration bypass: 345kPa \[ 50 psi \]. Engines equipped with Eliminator TM filtration will see a FC1362 (Amber) once the differential pressure increases beyond nominal stable values indicative of proper backflush operation: 62kPa \[ 9 psi \]. If the lubricating oil filter assembly is **not** serviced, and differential pressure continues to increase, a FC3491/ FC612 (Red) will be received before the differential pressure drives lubricating oil filtration bypass: 96.5kPa \[ 14 psi \]. This FC3491/ FC612 is accompanied by an engine derate to limit the engine ability to force lubricating oil filter bypass operation.
>
