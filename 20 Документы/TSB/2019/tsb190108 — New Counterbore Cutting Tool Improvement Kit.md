## Новый набор инструментов для улучшения Counterbore Cutting

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- ISX (все версии)
- ISX15 (все версии)
- X15 (все версии)
- QSX (все версии)
- QSX15 (все версии)

**Описание изменения**

Доступен новый комплект для улучшения резания контрбора. Существующая конструкция режущего инструмента была изменена, чтобы уменьшить напряжение и напряжение, необходимые для выполнения операции резания.

![[17r00324.png]]

Рисунок 1, Набор усовершенствований для резки противоборок, Номер детали 5395552.

1. Клип, удержание провода
2. Пин, Клавис
3. Адаптер, привод
4. Водитель, резчик с контрбором
5. Подшипник, игла
6. Раса, внешний подшипник
7. Пружина, сжатие
8. Ошейник, остановись.

**Причина изменения**

- Используется для помощи и улучшения эргономики операций резания цилиндров с блоком цилиндров с двигателем, установленным в транспортном средстве.
- Может использоваться со всеми специальными наборами для резки цилиндров с цилиндрами, которые используют блок привода резца с противоборствующим выступом, номер детали 3163785, в качестве приводного блока для пластины резца.

**Указания по обслуживанию**

- Ошейник стоп, номер детали 5395558, имеет утопленную поверхность и выступ, что уменьшает тенденцию ошейника отходить от приводного блока во время вращения. Остановочный воротник может использоваться в качестве прямой замены воротника, который поставляется с приводным блоком. Утопленная поверхность на ошейнике остановки **должна** обращена к корпусу приводного устройства.
- Есть две переменные, которые контролируют качество ручной обработки цилиндра счетчика, что улучшает этот набор улучшений резания счетчика:
- Весенняя упаковка будет генерировать постоянное давление вниз. Ручное давление не потребуется.
- Последовательная ротация может быть достигнута с использованием любого из следующих условий, как позволяют ситуация и предпопоказаний пользователя:

> **Description of Change**
>
> A new counterbore cutting improvement kit is available. The existing counterbore cutting tool design has been changed to reduce the stress and strain required to perform the counterbore cutting operation.
>
> Figure 1, Counterbore Cutting Improvement Kit, Part Number 5395552.
>
> 1. Clip, wire retaining
> 2. Pin, clevis
> 3. Adapter, drive
> 4. Driver, counterbore cutter
> 5. Bearing, needle
> 6. Race, outer bearing
> 7. Spring, compression
> 8. Collar, stop
>
> **Reason for Change**
>
> - Is used to aid and improve the ergonomics of cylinder block counter bore cutting operations with the engine installed in the vehicle.
> - Can be used with all engine-specific counter bore cutting kits that use counterbore ledge cutter drive unit, Part Number 3163785, as the drive unit for the cutter plate.
>
> **Service Instructions**
>
> - The stop collar, Part Number 5395558, has a recessed surface and ledge that reduces the collar's tendency to back away from the drive unit during rotation. The stop collar can be used as a direct replacement for the collar that comes with the drive unit. The recessed surface on the stop collar **must** face the drive unit body.
