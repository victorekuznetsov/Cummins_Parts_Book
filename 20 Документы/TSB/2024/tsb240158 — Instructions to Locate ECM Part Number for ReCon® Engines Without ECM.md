**Issue**

ReCon® engine part numbers as listed in [[tsb230228 — ReCon® Engines Without Electronic Control Modules (ECM)\|TSB230228]], TSB240194 and [[tsb240195 — ReCon® Engines without Electronic Control Modules (ECM)\|TSB240195]] will be shipped without an engine control module (ECM).

**Resolution**

This document is to guide on how to search ECM part numbers for these engines.

**Service Instructions**

- Navigate to quickserveonline.com and log in.
- Using the ReCon® engine serial number search in Parts Catalog/ReCon® information as shown in Figure 1.

![[17r02224.png]]

Figure 1, Engine Serial Number Search.

- Locate the PH option to look for ECM part number. For example, PH01844-SM from Figure 2.

![[17r02225.png]]

Figure 2, PH Option Example.

- Use search bar “Search All Products/Engines/System for:” to find the PH option. In this example, the option is PH01844-SM in the Build of Materials of the ReCon® engine, the zero and –SM must be removed to appear in the search bar as shown in Figure 3.

![[17r02226.png]]

Figure 3, Search All Products Example.

- Select the links from the search results until ECM part number is found as shown in Figure 4.

![[17r02227.png]]

Figure 4, ECM Part Number Found in Search Results.

- If ECM part number is not found, create a QSOL ticket to address this request. See Figure 5.

![[17r02228.png]]

Figure 5, QSOL Ticket Interface.
