## Coolant Thermostat Housing and Cover Plate Standardization

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- K38 (All Versions)
- K50 (All Versions)
- KTA38 (All Versions)
- KTA50 (All Versions)
- KTAA38 (All Versions)
- QSK38 (All Versions)
- QSK50 (All Versions)

**Description of Change**

- Changes have been made to the coolant thermostat housing and cover plate assembly as part of a change to an edge bonded rubber gasket in place of o-rings.
- Change removes the o-ring counter bores on the cover plate and removes and obsoletes the o-ring compatible coolant thermostat housing.
- The o-rings are still available through parts.cummins.com to maintain the o-ring design. Reference Table 1 below for part number information.

**Reason for Change**

Changes made between 2011 and 2018 to the edge bonded gasket as part of a parts and option standardization project.

**Service Instructions**

- O-rings for the o-ring design assembly are still available to purchase, ensuring support for engines and customers still using the o-ring design. See Table 1 below,
- If the either the coolant thermostat housing, or the Cover Plate requires changing, then the customer will need to use the gasket with the New Part Numbers listed in Table 1.

**Service Parts Availability**

Service parts are available. See Table 1 for part numbers.

| Table 1, Service Parts |  |  |  |  |
|---|---|---|---|---|
| Part Description | Existing Part Number | Obsolete | Superseded | New Part Number |
| PLATE, COVER | 3003379 | Yes | Yes | 5376167 |
| HOUSING, THERMOSTAT | 3035844 | Yes | Yes | [[4372912]] |
| SEAL, ORING | [[3818885]] | No | No | - |
| GASKET | - | - | - | [[3650106]] |

**Part Compatibility**

- The new gasket is **not** backwards compatible with the existing coolant thermostat housing.
- New coolant thermostat housing is compatible with the existing cover plate when the cover plate is fitted in reverse orientation and used with a gasket.

**Part Inventory Action**

Use existing part number inventory before using the new part number.
