![[05600304.png]]

QSK19 MCRS Marine Sea Pro™ 5 Stage 1 Single Flow Fuel Filter Head

Stage 0 Filter - Marine applications specifiy a primary, off engine filtration system that is supplied by the customer. This is the first filter system after the fuel storage tank and is referred to as the Stage 0 filtration system. The Stage 0 filter system **must** include a water separator and typically uses a more course media (10 micron maximum) with a larger capacity as compared to the Stage 1 (7 micron) and Stage 2 (3 micron) filter systems. A fuel centrifuge is a common accetable alternative to element type filter media for Stage 0 filtration.
