> | **Tool Number** 3376375 | **Fuel Measuring Device** Measure the rate of fuel consumption of a Cummins® diesel engine. |  |
> | **Tool Number** 3377462 | **Digital Optical Tachometer** Used to measure engine speed (RPM). |  |
> | **Tool Number** 3822566 | **Blowby Check Tool (0.302 inch orifice)** Used with manometer, Part Number ST-1111-3, to measure the engine crankcase pressure. |  |
> | **Tool Number** 3823567 | **Blowby Check Tool (0.354 inch orifice)** Used with manometer, Part Number ST-1111-3, to measure the engine crankcase pressure. |  |
> | **Tool Number** 3822568 | **Blowby Check Tool (0.406 inch orifice)** Used with manometer, Part Number ST-1111-3, to measure the engine crankcase pressure. |  |

> | **Tool Number** 4918416 | **Inline™ 5 Datalink Adapter Kit** Used with INSITE™ 6.3 or later electronic service tool. |  |
> | **Tool Number** 3163099 | **Inline™ Datalink Adapter Kit** Used with INSITE™ electronic service tool. |  |
> | **Tool Number** 3163682 | **Inline™ II Datalink Adapter Kit** Used with INSITE™ electronic service tool. |  |
> | **Tool Number** 3163891 | **Engine Control Harness** Used to operate engine out of chassis. Use with engine control box, Part Number 3163890. For engines with mechanically actuated injectors. |  |
