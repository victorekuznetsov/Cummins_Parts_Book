### Общие сведения

Большинство операций по техническому обслуживанию, описанных в этом руководстве, могут выполняться с помощью обычной ручной оснастки (метрические и SAE гаечные ключи, розетки и отвертки).

Ниже приведен список специальных инструментов обслуживания, необходимых для некоторых операций по техническому обслуживанию:

| Инструмент Часть Номер | Наименование |
|---|---|
| СТ-1293 | Измеритель напряжения пояса (V-Belts) |
| 3400157 | Ремень фильтрации масла (тип ленты), диаметр фильтра от 118 до 130 мм \[4.7-5.12 in\] |
| 3400158 | Вода, топливо, маслофильтр (тип штампа), диаметр фильтра до 152 мм[6.0 in\) |
| 3822524 | Измеритель напряжения пояса (тип щелчка) 63-203 Н•м \[50-150 футов-lb\] |
| 3822525 | Измеритель напряжения пояса (тип щелчка) 136-407 Н•м \[100-300 футов-lb\] |
| 3164795 | Смартфон крутящего момента (Dial Type) 0-34 Н•м \[0-300 фунт-дюйм\] |
| 3824901 | Калибр клапан Lash |
| 3164794 | Звонок крутящего момента (Click Type) 14-136 Н•м \[10-100 футов-лб\] |
| CC2602 | Fleetguard тест-набор охлаждающей жидкости |
| CC2800 | Рефрактометр Fleetguard Battery |
| 4918282 | Защитное покрытие цилиндрической головки |

- Смотрите соответствующие разделы для описания инструментов и как их использовать.
- Свяжитесь с ближайшим авторизованным ремонтным центром Cummins для получения необходимых инструментов обслуживания.
