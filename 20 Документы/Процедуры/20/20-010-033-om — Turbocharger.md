### General Information

Inspection of the turbocharger is recommended at engine half life to rebuild.

Half life rebuild varies by application. Contact a Cummins® Authorized Repair Location if **not** sure of this service.

![[10400021.png]]

### Maintenance Check

Remove the intake and exhaust piping from the turbocharger.

![[10400021.png]]

Inspect the turbocharger compressor impeller for damage.

Inspect for broken, bent, or damaged blades.

Do **not** attempt to repair or straighten the blades.

Contact a Cummins® Authorized Repair Location if damage is found.

![[10400022.png]]

Use dial depth gauge, Part Number ST-537, or a dial indicator to measure the axial motion (end-to-end).

| Compressor Inlet Axial Endplay |  |  |  |
|---|---|---|---|
|  | mm |  | in |
| Holset® HX82/HX83/HE800 Turbocharger | 0.025 | MIN | 0.001 |
|  | 0.152 | MAX | 0.006 |

Make sure movement is within MIN/MAX Total Indicator Reading (TIR) values shown above.

> [!note] Note · Примечание
> If the end clearance exceeds the specifications, the turbocharger **must** be replaced or rebuilt. Contact a Cummins® Authorized Repair Location.

![[tb800jb.png]]

Measure the radial clearance (side-to-side) at the compressor impeller nose using a dial gauge.

| Compressor Impeller Radial Endplay |  |  |  |
|---|---|---|---|
|  | mm |  | in |
| Holset® HX82/HX83/HE800 Turbocharger | 0.254 | MIN | 0.01 |
|  | 0.787 | MAX | 0.031 |

Make sure movement is within MIN/MAX Total Indicator Reading (TIR) values shown above.

> [!note] Note · Примечание
> If the radial clearance exceeds the specifications, the turbocharger **must** be replaced or rebuilt. Contact a Cummins® Authorized Repair Location.
