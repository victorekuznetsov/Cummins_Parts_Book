### Установка

Установите новое кольцо на ESS.

Установите новый ESS в монтажное отверстие в блоке цилиндров.

Закрепите ESS с помощью инструмента установки.

> [!tip] Момент затяжки
> 20 Н·м [15 фунт-фут]

![[19400428.png]]

Подключите датчик к проводах датчика. Соедините разъёмы до фиксации.

![[19400429.png]]


> [!quote]- Original (English) · английский оригинал
> ### Install
>
> Install a new o-ring onto the ESS.
>
> Install the new ESS into the mounting hole in the cylinder block.
>
> Tighten the ESS with the installation tool.
>
> **Момент затяжки · Torque Value**
> 20 n•m [15 ft-lb]
>
> Connect the sensor to the sensor harness. Push the connectors together until they lock.
