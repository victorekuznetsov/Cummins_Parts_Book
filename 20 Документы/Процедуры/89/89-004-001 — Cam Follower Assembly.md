### Preparatory Steps

- Remove the rocker lever cover. [[89-003-011 — Rocker Lever Cover|Refer to Procedure 003-011]] in Section 3.
- Remove the rocker levers. [[89-003-009 — Rocker Lever Assembly|Refer to Procedure 003-009]] in Section 3.
- Remove the push rods. [[89-004-014 — Push Rods or Tubes|Refer to Procedure 004-014]] in Section 4.
- Remove the crankcase breather assembly, if necessary. [[89-003-001-tr — Crankcase Breather (External)|Refer to Procedure 003-001]] in Section 3.
- Remove the fuel supply lines, if necessary. [[89-006-024 — Fuel Supply Lines|Refer to Procedure 006-024]] in Section 6.
- Remove the fuel drain lines, if necessary. [[89-006-013 — Fuel Drain Lines|Refer to Procedure 006-013]] in Section 6.
- Remove the fuel filters, if necessary. [[89-006-015 — Fuel Filter (Spin-On Type)|Refer to Procedure 006-015]] in Section 6.
- Remove the alternator, if necessary. [[89-013-001 — Charging System Alternator|Refer to Procedure 013-001]] in Section 13

### Remove

Remove the cam follower cover.

Remove and inspect the gasket.

Discard the gasket if it is damaged.

![[04400039.png]]

Mark the location of the cam follower assemblies as they are removed, so they can be installed in the original location.

Remove the cam follower assembly capscrews.

Pull the cam follower assembly out until the shaft is off the ring dowels.

> [!note] Note · Примечание
> If one of the followers is in the raised position on the cam lobe, it may be necessary to bar the engine over in order to remove the assembly from the block.

![[kf400ha.png]]

### Clean and Inspect for Reuse

> [!danger] WARNING · Опасно
> When using solvents, acids or alkaline materials for cleaning, follow the manufacturer's recommendations for use. Wear goggles and protective clothing to reduce the possibility of personal injury.

Use solvent to clean the cam follower assembly.

Do **not** touch the machined surfaces of the cam follower roller with bare hands. Use rubber gloves or a similar covering.

![[kf4lvea.png]]

The shaft **must** rotate easily. If resistance is apparent, disassemble and check for burrs on the shaft.

![[04b00014.png]]

Inspect the cam follower lever and roller for damage.

The cam follower lever assembly **must** be replaced if damaged.

![[04b00015.png]]

The roller **must** rotate freely.

Measure the side clearance of the roller.

| Cam Follower Roller Side Clearance |  |  |  |
|---|---|---|---|
|  | mm |  | in |
| 1 | 0.075 | MIN | 0.003 |
|  | 0.305 | MAX | 0.012 |
| 2 | 0.082 | MIN | 0.003 |
|  | 0.114 | MAX | 0.005 |

If the clearances do **not** meet specifications, the cam follower **must** be replaced.

![[04b00016.png]]

Measure the lever bore side diameter. Replace if worn or damaged.

| Lever Bore Inside Diameter |  |  |
|---|---|---|
| mm |  | in |
| 25.000 | MIN | 0.984 |
| 25.021 | MAX | 0.985 |

![[04400018.png]]

Inspect the push rod socket for an even seating pattern or excessive wear.

When parallel grooves and scratches are observed, or the contact area extends into the oil hole chamfer of the socket, the socket **must** be replaced.

![[kf1rosd.png]]

Check the shaft for damage or roughness. Measure the outside diameter.

| Shaft Outside Diameter |  |  |
|---|---|---|
| mm |  | in |
| 24.947 | MIN | 0.982 |
| 24.962 | MAX | 0.983 |

![[04600030.png]]

### Install

Do **not** touch the cleaned machined surfaces of the cam follower roller with bare hands. This can cause rust to form.

Use clean 15W-40 engine oil to lubricate the camshaft cam follower rollers and cam follower shaft.

Install the cam follower assembly. The shaft **must** fit on ring dowels. The side of the shaft with the ball pressed in **must** face the front of the engine.

Install and tighten the mounting screws.

Torque Value:

![[kf400ha.png]]

Install the cam follower gasket and cover.

Install the cam follower cover capscrews.

> [!tip] Момент затяжки · Torque Value
> 10 n•m [90 in-lb]
