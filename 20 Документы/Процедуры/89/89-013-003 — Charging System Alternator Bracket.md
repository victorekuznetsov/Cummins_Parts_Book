### Preparatory Steps

**Engines with 140A Alternator:**

Install accessory drive. [[89-009-009 — Alternator Drive Gear and Shaft|Refer to Procedure 009-009]] in Section 9.

Install alternator drive pulley. [[89-009-010 — Charging System Alternator Drive Pulley|Refer to Procedure 009-010]] in Section 9.

### Install

Install the alternator bracket on the gear case cover using four capscrews.

> [!tip] Момент затяжки · Torque Value
> 65 n•m [48 ft-lb]

![[00r00638.png]]

Install the 2 capscrews on the cylinder block, shown below.

> [!tip] Момент затяжки · Torque Value
> 113 n•m [83 ft-lb]

![[00r00639.png]]

Install the belt tensioner on to the alternator mounting bracket.

To orient the tensioner, align the boss on the mounting face of the tensioner with the hole on the alternator bracket.

> [!tip] Момент затяжки · Torque Value
> 46 n•m [34 ft-lb]

![[00r00640.png]]

### Finishing Steps

Install the alternator and alternator belt. [[89-013-001 — Charging System Alternator|Refer to Procedure 013-001]] in Section 13.

### Remove

- Remove the freon compressor bracket
- Remove the alternator
- Remove alternator belt.

Remove the alternator tensioner and capscrew.

Remove the alternator bracket and capscrews.
