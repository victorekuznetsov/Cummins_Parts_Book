### Общие сведения

Эта процедура применяется для двигателей передних передних передних тяг **только**, в которых уже снят распределительный вал. Видишь?[[40-001-008-tr — Camshaft|Процедура 001-008]].

> [!note] Примечание
> Для двигателей задних зубчатых составов, распредвальная передача должна быть удалена для удаления распредвала. Видишь?[[40-001-012-tr — Camshaft Gear (Camshaft Installed)|Процедура 001-012]].

![[ck800wa.png]]

### Снятие

На болтовых распределительных валах удалите болт распределительного вала и шайбу.

> [!note] Примечание
> Вентиляционные распределительные валы используются только на двигателях 1991 года с встроенным насосом для впрыска.

![[cg9boma.png]]

Трансмиссия вала может быть снята с распределительного вала следующими способами:

> [!warning] ОСТОРОЖНО
> Трансмиссия вала должна быть полностью поддерживаемой при использовании гидравлического пресса. Несоблюдение надлежащей поддержки распределительной передачи приведет к повреждению распределительной передачи.

Используйте гидравлический пресс

![[cg9gefa.png]]

Используйте инструмент для удаления и установки распределительного устройства, номер детали 3823589.

![[3823589.png]]

Удалить распределительную передачу из носа распределительного вала.

![[01d00327.png]]

Удалите распределительную передачу, находящую ключ или штифт.

![[cg4kema.png]]

### Очистка и проверка при повторном использовании

> [!danger] ОПАСНО
> При очистке растворителями, кислотами и щелочными составами соблюдайте указания их изготовителя. Носите очки и защитную одежду, чтобы избежать травм.

> [!danger] ОПАСНО
> Некоторые растворители огнеопасны и токсичны. Перед применением прочитайте указания изготовителя.

> [!danger] ОПАСНО
> При работе со сжатым воздухом применяйте защиту глаз и лица. Разлетающиеся частицы и грязь могут привести к травме.

Используйте растворитель для очистки распределительного механизма.

Просушите сжатым воздухом.

![[cg9geea.png]]

Осмотр зубьев распределительного вала для питтинга. Ищите трещины в корне зубов.

Осмотрите зубья распределительного вала на предмет обесцвечивания или признаков чрезмерного нагрева (смазки).

Если есть какие-либо повреждения, замените распределительную передачу.

> [!note] Примечание
> Если есть повреждение зубьев распределительного вала или есть признаки чрезмерного тепла, обязательно проверьте связанные с коленчатым валом и топливными насосами передачи на предмет повреждения. Измерить обратную реакцию распределительного вала при установке.

![[cg9gesc.png]]

> [!note] Примечание
> Если фреттинг, заусенцы или заусеницы из поднятого материала могут быть удалены **не**, то абразивная прокладка, номер детали 3823258, заменяет распределительную передачу.

Осмотрите цилиндрический вал для трения или заусенцев.

Осмотрите валы для заусенцев.

![[cg9gesd.png]]

Осмотрите нос распредвала на наличие ладов или заусенцев.

> [!note] Примечание
> Если лады или заусеницы могут быть удалены с помощью абразивной прокладки, номер детали 3823258 или эквивалент, замените распределительный вал.

![[cg900sj.png]]

### Установка

Смазать нос распредвалом с помощью LubriplateTM 105 или эквивалента.

![[cg900wc.png]]

Установите распределительное устройство, определяющее местонахождение ключа или штифта для дюбеля, с помощью пластикового молотка.

![[cg9kema.png]]

Трансмиссия распредвала может быть установлена с помощью следующих методов:

> [!warning] ОСТОРОЖНО
> При перегреве шасси будет постоянно искажаться. Температура печи никогда не должна превышать для данного типа распределительного устройства температурные характеристики, приведенные ниже.

Необработанные гирсы Camshaft (1991)

Нагрейте распределительную передачу до 149 ° C \[300° F \] в течение 45 минут.

Все остальные Camshaft Gears

Нагрейте распределительную передачу до 177 ° C \[350° F \] в течение 45 минут.

![[cg9gewf.png]]

> [!danger] ОПАСНО
> Чтобы предотвратить травмы, надевайте защитные перчатки для управления горячим снаряжением.

Установите кулачковую передачу с временными метками вдали от кулачковой вал.

Установите кулачковую передачу на нос кулачковой вал. Выровняйте камуфляжную передачу с помощью камуфляжного ключа/двенадцатиконтактного штифта.

![[cg9gehb.png]]

С помощью инструмента для удаления и установки распределительного устройства, номер детали 3823589.

> [!note] Примечание
> Установите кулачковую передачу с временными метками вдали от кулачковой вал.

Установите кулачковую передачу на нос кулачковой вал. Выровняйте камуфляжную передачу с помощью камуфляжного ключа/двенадцатиконтактного штифта.

![[01d00327.png]]

> [!warning] ОСТОРОЖНО
> Убедитесь, что передача сидит на плече распредвала.

Используйте калибр для измерения щупальца 0,025 мм \[0,001 дюйма\], чтобы увидеть, можно ли вставить калибр для щупальца между распределительным механизмом и плечом на распределительном вале. Если датчик измерения щупальца может быть вставлен, то механизм распредвала **не** правильно сидит.

![[cg9gese.png]]

Для болтовых распределительных шестерен установите болт и шайбу распределительного вала.

Зажгите затвор.

> [!quote]- Original (English) · английский оригинал
> ### General Information
>
> This procedure is for front gear train engines **only** in which the camshaft has already been removed. Refer to [[40-001-008-tr — Camshaft|Procedure 001-008]].
>
> **Note · Примечание**
> For rear gear train engines, the camshaft gear **must** be removed to remove the camshaft. Refer to [[40-001-012-tr — Camshaft Gear (Camshaft Installed)|Procedure 001-012]].
>
> ### Remove
>
> On bolted camshafts, remove the camshaft bolt and washer.
>
> **Note · Примечание**
> Bolted camshafts are **only** used on 1991 engines with an inline injection pump.
>
> The camshaft gear can be removed from the camshaft by the following methods:
>
> **CAUTION · Осторожно**
> The camshaft gear must be fully supported when using a hydraulic press. Failure to properly support the camshaft gear will result in damage to the camshaft gear.
>
> Use a hydraulic press
>
> Use the camshaft gear removal and installation tool, Part Number 3823589.
>
> Remove the camshaft gear from the nose of the camshaft.
>
> Remove the camshaft gear locating key or dowel pin.
>
> ### Clean and Inspect for Reuse
>
> **WARNING · Опасно**
> When using solvents, acids, or alkaline materials for cleaning, follow the manufacturer's recommendations for use. Wear goggles and protective clothing to avoid personal injury.
>
> **WARNING · Опасно**
> Some solvents are flammable and toxic. Read the manufacturer's instructions before using.
>
> **WARNING · Опасно**
> Wear appropriate eye and face protection when using compressed air. Flying debris and dirt can cause personal injury.
>
> Use solvent to clean the camshaft gear.
>
> Dry with compressed air.
>
> Inspect the camshaft gear teeth for pitting. Look for cracks at the root of the teeth.
>
> Inspect the camshaft gear teeth for discoloration or signs of excessive heat (bluing).
>
> If any damage is present, replace the camshaft gear.
>
> **Note · Примечание**
> If there is damage to the camshaft gear teeth or there are signs of excessive heat, make sure to inspect the associated crankshaft and fuel pump gears for damage. Measure camshaft gear backlash upon installation.
>
> **Note · Примечание**
> If the fretting, burrs, or raised material burrs can **not** be removed, with abrasive pad, Part Number 3823258, replace camshaft gear.
>
> Inspect the camshaft bore for fretting or burrs.
>
> Inspect the camshaft gear for burrs.
>
> Inspect the camshaft nose for frets or burrs.
>
> **Note · Примечание**
> If frets or burrs can **not** be removed with an abrasive pad, Part Number 3823258, or equivalent, replace the camshaft.
>
> ### Install
>
> Lubricate the camshaft nose with Lubriplate™ 105, or equivalent.
>
> Install the camshaft gear locating key or dowel pin with a plastic mallet.
>
> The camshaft gear can be installed by using the following methods:
>
> **CAUTION · Осторожно**
> The camshaft gear will be permanently distorted if overheated. The oven temperature must never exceed, for the given camshaft gear type, the temperature specification given below.
>
> Non-Bolted Camshaft Gears (1991 Engines only)
>
> Heat the camshaft gear to 149°C \[300°F\] for 45 minutes.
>
> All Other Camshaft Gears
>
> Heat the camshaft gear to 177°C \[350°F\] for 45 minutes.
>
> **WARNING · Опасно**
> To prevent personal injury, wear protective gloves to handle the hot gear.
>
> Install the camshaft gear with the timing marks away from the camshaft.
>
> Install the camshaft gear onto the nose of the camshaft. Align the camshaft gear keyway with the camshaft locating key/dowel pin.
>
> Using the camshaft gear removal and installation tool, Part Number 3823589.
>
> **Note · Примечание**
> Install the camshaft gear with the timing marks away from the camshaft.
>
> Install the camshaft gear onto the nose of the camshaft. Align the camshaft gear keyway with the camshaft locating key/dowel pin.
>
> **CAUTION · Осторожно**
> Make sure the gear is seated against camshaft shoulder.
>
> Use a 0.025 mm \[0.001 inch\] feeler gauge to see if the feeler gauge can be inserted between the camshaft gear and the shoulder on the camshaft. If the feeler gauge can be inserted, the camshaft gear is **not** properly seated.
>
> For bolted camshaft gears, install the camshaft bolt and washer.
>
> Tighten the bolt.
>
