### Install

Install a new gasket, and apply anti-seize compound to the mounting studs.

> [!note] Note · Примечание
> Use **only** lead-free anti-seize compound compatible with oxygen sensors.

![[11900005.png]]

Install a new gasket, and apply anti-seize compound to the mounting studs.

![[xm9gkha.png]]

Install the turbocharger.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[10900008.png]]

Install the turbocharger.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[tb9gkha.png]]

Use a new gasket and connect the oil drain tube.

> [!tip] Момент затяжки · Torque Value
> 24 n•m [18 ft-lb]

![[10900009.png]]

Install the turbocharger coolant lines.

> [!note] Note · Примечание
> Keep coolant line horizontal when tightening.

![[pe9bdmb.png]]

> [!note] Note · Примечание
> New turbochargers **must** be prelubricated before startup.

Pour 50 to 60 cc \[2 to 3 oz\] of clean engine oil into the oil supply fitting.

Rotate the turbine wheel to allow the oil to enter the bearing housing.

![[10900043.png]]

Connect the oil supply line.

> [!tip] Момент затяжки · Torque Value
> 35 n•m [26 ft-lb]

![[xs9ftha.png]]

If required, loosen the compressor housing v-band clamp and position the housing to align with the turbocharger air outlet tube.

![[10900024.png]]

Install the wastegate actuator capsule actuator hose.

![[tb9feaa.png]]

Install charged air cooler hose.

Install the air inlet and exhaust piping.

> [!tip] Момент затяжки · Torque Value
> 8 n•m [71 in-lb]

Fill the cooling system. [[40-008-018-tr — Cooling System|Refer to Procedure 008-018 in Section 8.]]

Operate the engine. Check for leaks.

![[10900025.png]]
