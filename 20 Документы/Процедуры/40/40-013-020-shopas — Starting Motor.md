### Измерение

Используя внутренний микрометр или более верньерный суппорт, измеряйте расстояние от стартового моторного крепежа до передней стороны передней стороны кольцевой передачи маховика.

> [!note] Примечание
> Включите любые прокладки, ранее удаленные при завершении измерения.

| Запуск моторного пространства |  |  |
|---|---|---|
| мм |  | в |
| 49.28 | Мин | 1.94 |
| 52.32 | Макс | 2.06 |

Добавить или удалить прокладки по мере необходимости для достижения правильного стартового интервала двигателя.

![[13d00053.png]]

### Установка

Для двигателей с мокрыми корпусами маховиков нанесите шириной от 1,5 до 2,0 мм \[0,06 до 0,09 дюйма] герметик, номер детали 3164067, на корпус маховика, начинающий моторный монтаж фланга.

> [!note] Примечание
> Если требуется стартовый моторный спейсер, обязательно нанесите герметик на ту сторону спейсера, которая связывается с пусковым двигателем.

![[13d00054.png]]

> [!danger] ОПАСНО
> Масса этого узла больше 23 кг \[50 фунтов\]. Чтобы не получить тяжёлую травму, поднимайте этот узел с помощником или подходящим грузоподъёмным оборудованием.

Установите три болта, пусковой двигатель и пусковой моторный спейсер, если это необходимо.

> [!tip] Момент затяжки
> 43 Н·м [32 фунт-фут]

>

>
> **Note · Примечание**
> Include any spacers previously removed when completing the measurement.
>
> | Starting Motor Spacing |  |  |
> |---|---|---|
> | mm |  | in |

> | 52.32 | MAX | 2.06 |

> Add or remove spacers as necessary to achieve the correct starting motor spacing.
>
> ### Install
>
> For engines with wet flywheel housings, apply a 1.5 to 2.0 mm \[0.06 to 0.09 in\] wide bead of sealant, Part Number 3164067, to the flywheel housing starting motor mounting flange.
>
> **Note · Примечание**
> If a starting motor spacer is required, make sure to apply sealant to the side of the spacer that contacts the starting motor.
>
> **WARNING · Опасно**
> This component or assembly weighs greater than 23 kg \[50 lb\]. To prevent serious personal injury, be sure to have assistance or use appropriate lifting equipment to lift this component or assembly.
>
> Install the three capscrews, the starting motor, and starting motor spacer, if required.
