### Install

Distributor-Type Pump

Assemble the fuel drain line and fuel drain manifold in the reverse order of disassembly.

> [!note] Note · Примечание
> Use new seals for the fittings.

![[ft9tbhg.png]]

The installation torque for the banjo fitting screw is as follows:

> [!tip] Момент затяжки · Torque Value
> 9 n•m [80 in-lb]

> [!note] Note · Примечание
> Use new sealing washers for the fuel drain manifold.

![[ft9waha.png]]

Install the clamp capscrews.

> [!tip] Момент затяжки · Torque Value
> 24 n•m [18 ft-lb]

![[fs9csma.png]]

Bosch® In-Line pump

Install the fuel drain manifold in the reverse order of removal.

| Injector Banjo | 9 n.m | \[80 in-lb\] |
|---|---|---|

| Fuel Filter Head | 13 n.m | \[115 in-lb\] |
|---|---|---|

> [!note] Note · Примечание
> The fuel line support bracket capscrew in the intake manifold requires liquid Teflon™ sealant.

![[ft9wama.png]]
