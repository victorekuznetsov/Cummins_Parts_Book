### Inspect

Check the exterior of the turbocharger for damage.

Check the wheel for fretting and broken vanes.

Use a dial indicator to measure the turbocharger end clearance.

Measure the end clearance.

| Holset® HX82 Turbocharger End Clearance |  |  |
|---|---|---|
| mm |  | in |
| 0.025 | MIN | 0.001 |
| 0.152 | MAX | 0.006 |

If the end clearance exceeds the specifications, the turbocharger **must** be replaced.

![[tb800jb.png]]

Measure the radial clearance (side to side) at compressor impeller nose using a dial gauge

| Holset® HX82 Turbocharger |  |  |  |
|---|---|---|---|
|  | mm |  | in |
| Compressor/Impeller | 0.254 | MIN | 0.010 |
|  | 0.787 | MAX | 0.031 |

Make sure movement is within MIN/MAX Total Indicator Reading (TIR) values shown above.

If the end clearance exceeds the specifications, the turbocharger **must** be replaced.
