### Осмотр

Проверьте внешний вид турбокомпрессора на предмет повреждений.

Проверьте колесо на наличие фреттинга и сломанных лопастей.

Используйте индикатор циферблата для измерения конечного зазора турбокомпрессора.

Измерьте конечный зазор.

| Holset® HX82 Turbocharger End Clearance |  |  |
|---|---|---|
| мм |  | в |
| 0.025 | Мин | 0.001 |
| 0.152 | Макс | 0.006 |

Если конечный зазор превышает технические характеристики, турбокомпрессор должен быть заменен.

![[tb800jb.png]]

Измерить радиальный зазор (бок в сторону) на носу рабочего колеса компрессора с помощью циферблата калибра

| Holset® HX82 Turbocharger |  |  |  |
|---|---|---|---|
|  | мм |  | в |
| Компрессор/импеллер | 0.254 | Мин | 0.010 |
|  | 0.787 | Макс | 0.031 |

Убедитесь, что движение находится в пределах значений MIN/MAX Total Indicator Reading (TIR), показанных выше.

Если конечный зазор превышает технические характеристики, турбокомпрессор должен быть заменен.

> ### Inspect
>
> Check the exterior of the turbocharger for damage.
>
> Check the wheel for fretting and broken vanes.
>
> Use a dial indicator to measure the turbocharger end clearance.
>
> Measure the end clearance.
>
> | Holset® HX82 Turbocharger End Clearance |  |  |
> |---|---|---|
> | mm |  | in |
> | 0.025 | MIN | 0.001 |
> | 0.152 | MAX | 0.006 |
>
> If the end clearance exceeds the specifications, the turbocharger **must** be replaced.
>
> Measure the radial clearance (side to side) at compressor impeller nose using a dial gauge
>
> | Holset® HX82 Turbocharger |  |  |  |
> |---|---|---|---|
> |  | mm |  | in |
> | Compressor/Impeller | 0.254 | MIN | 0.010 |
> |  | 0.787 | MAX | 0.031 |
>
> Make sure movement is within MIN/MAX Total Indicator Reading (TIR) values shown above.
>
> If the end clearance exceeds the specifications, the turbocharger **must** be replaced.
