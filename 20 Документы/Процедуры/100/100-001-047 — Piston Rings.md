### Проверка анализа неудач

Используйте новое поршневое кольцо и калибр для измерения бокового зазора прямоугольных промежуточных и масляных управляющих кольцевых канавок.

|  | мм |  | в |
|---|---|---|---|
| Промежуточное кольцо | 0.07 | Мин | 0.003 |
|  | 0.15 | Макс | 0.006 |
| Кольцо контроля нефти | 0.02 | Мин | 0.001 |
|  | 0.13 | Макс | 0.005 |

![[pi900ta.png]]

Измерьте разрыв поршневого кольца.

Чтобы измерить разрыв поршневого кольца, используйте верхний конец поршня, чтобы выровнять поршневые кольца в области износа цилиндра, где они используются.

| Измерения |  |  |
|---|---|---|
|  | мм | в |
| А. | 80 | 3.5 |

![[pi9rita.png]]

Используйте калибр для измерения разрыва конца поршневого кольца. Замените кольцо, если оно не соответствует следующим требованиям:

|  | мм |  | в |
|---|---|---|---|
| Топ | 0.40 | Мин | 0.016 |
|  | 0.70 | Макс | 0.028 |
| промежуточный | 0.25 | Мин | 0.010 |
|  | 0.55 | Макс | 0.022 |
| Контроль над нефтью | 0.25 | Мин | 0.010 |
|  | 0.55 | Макс | 0.022 |

> [!note] Примечание
> Добавить 0,09 мм \[0,004 в\] на каждые 0,03 мм \[0,001 в\] износа цилиндра, до максимального предела износа цилиндра.

![[pi9ritc.png]]

Определите кольцевые наборы для установки в цилиндре, где измерялся конечный зазор.

![[pi9rige.png]]


> [!quote]- Original (English) · английский оригинал
> ### Failure Analysis Inspection
>
> Use a new piston ring and feeler gauge to measure the side clearance of the rectangular intermediate and oil control ring grooves.
>
> |  | mm |  | in |
> |---|---|---|---|
> | Intermediate Ring | 0.07 | MIN | 0.003 |
> |  | 0.15 | MAX | 0.006 |
> | Oil Control Ring | 0.02 | MIN | 0.001 |
> |  | 0.13 | MAX | 0.005 |
>
> Measure the piston ring gap.
>
> To measure the piston ring gap, use the top end of a piston to align the piston rings in the wear area of the cylinder where used.
>
> | Measurements |  |  |
> |---|---|---|
> |  | mm | in |
> | A | 80 | 3.5 |
>
> Use a feeler gauge to measure the piston ring end gap. Replace the ring if it does **not** meet the following specifications:
>
> |  | mm |  | in |
> |---|---|---|---|
> | Top | 0.40 | MIN | 0.016 |
> |  | 0.70 | MAX | 0.028 |
> | Intermediate | 0.25 | MIN | 0.010 |
> |  | 0.55 | MAX | 0.022 |
> | Oil Control | 0.25 | MIN | 0.010 |
> |  | 0.55 | MAX | 0.022 |
>
> **Note · Примечание**
> Add 0.09 mm \[0.004 in\] for every 0.03 mm \[0.001 in\] of bore wear, up to the maximum bore wear limit.
>
> Identify the ring sets for installation in the cylinder where the end gap was measured.
