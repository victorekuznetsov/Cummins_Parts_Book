# Water Pump Drive Gear and Shaft
**Шестерня и вал привода водяного насоса**

### Disassemble

with Mechanically Actuated Injector

**Only** remove the gear from the shaft when the gear or the shaft **must** be replaced.

Use an arbor press. Support the shaft and gear assembly as shown.

Push the shaft from the gear.

![[dw6gema.png]]

### Inspect for Reuse

with Mechanically Actuated Injector

Measure the outside diameter of the shaft at the gear location.

| Shaft Outside Diameter |  |  |
|---|---|---|
| mm |  | in |
| 39.776 | MIN | 1.5660 |
| 39.802 | MAX | 1.5670 |

![[dw6shtb.png]]

Measure the inside diameter of the gear.

| Gear Inside Diameter |  |  |
|---|---|---|
| mm |  | in |
| 39.726 | MIN | 1.5640 |
| 39.751 | MAX | 1.5650 |

Inspect the gear teeth for wear or damage.

![[dp8geta.png]]

### Assemble

with Mechanically Actuated Injector

Install the shaft into the housing.

Apply Loctite® 609, Part Number 3823718, or equivalent, to the gear inside diameter

Support the gear in a press.

Press the shaft into the gear.

![[09600016.png]]

Measure the water pump drive end clearance.

| Water Pump Drive End Clearance |  |  |
|---|---|---|
| mm |  | in |
| 0.23 | MIN | 0.009 |
| 0.33 | MAX | 0.013 |

If the end clearance is **not** within specifications, make sure that both thrust bearings are correctly positioned in the water pump drive housing counterbores.

If the bearings are correctly positioned and the end clearance is **not** within specifications, the drive **must** be completely disassembled and individual component dimensions checked.

![[dw6drta.png]]

### Install

with Mechanically Actuated Injector

Lubricate the bushing in the front gear housing cover with Lubriplate™ 105, Part Number 3163086, 3163087, or equivalent.

Install the gasket (1) on the drive pilot.

Install the pump drive (2), allowing the gear to turn as it meshes with the idler gear.

Align the capscrew holes, and install the water pump drive mounting capscrews and lock washers.

> [!note] Note · Примечание
> The capscrews (4) are 7/16-14x2 ¾ inch. The capscrew (5) is 7/16-14x1 ¼ inch.

Install and tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 60 n•m [40 ft-lb]

![[dw6drha.png]]

Measure the water pump drive end clearance after the drive is installed.

| Water Pump Drive End Clearance - Installed |  |  |
|---|---|---|
| mm |  | in |
| 0.23 | MIN | 0.009 |
| 0.33 | MAX | 0.013 |
