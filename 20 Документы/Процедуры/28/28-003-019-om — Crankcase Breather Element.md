# Crankcase Breather Element
**Элемент сапуна картера**

> [!abstract] Процедура · `28-003-019-om`
> **Двигатели:** [[33239746 — QSK60 CM2150 MCRS CPL 3451|33239746]], [[33239899 — QSK50 CM2150 MCRS CPL 3379|33239899]]
> **Семейство:** K38/K50 · QSK38, QSK50, QSK60
> **Входит в руководства:** [[3810497 — K38, K50, QSK38 and QSK50 Operation and Maintenance Manual|3810497]]
> **Секции:** Section 10 - Maintenance Procedures at 10,000 Hours
> **Даты:** изменён 2011-01-07
> **Источник:** [QuickServe](https://quickserve.cummins.com/qs3/pubsys2/xml/en/procedures/28/28-003-019-om.html) · [PDF-оригинал](https://github.com/victorekuznetsov/Cummins_Parts_Book/raw/claude/cummins-parts-knowledge-base-qa0n50/bulletins/procedures/28-003-019-om.pdf)

### Preparatory Steps

- Remove the crankcase breather. [[28-003-001-om — Crankcase Breather (External)|Refer to Procedure 003-001 in Section A.]]

![[ck800wa.png]]

### Remove

Loosen the eight cover mounting captive capscrews.

Remove the element cover.

> [!note] Note · Примечание
> Discard the crankcase breather element in accordance with local environmental regulations.

Remove and discard the crankcase breather element.

Wipe out any excess dirt or oil from the inside of the cover.

![[03s00044.png]]

### Install

Install the new crankcase breather element in the breather housing.

Make sure the element is properly seated in the housing so its seal will **not** be cut, crimped, or otherwise compromised when installing the housing cover.

Install the cover.

Tighten the eight captive mounting capscrews.

> [!tip] Момент затяжки · Torque Value
> 5.2 n•m [46 in-lb]

![[03s00044.png]]

### Finishing Steps

- Install the crankcase breather. [[28-003-001-om — Crankcase Breather (External)|Refer to Procedure 003-001 in Section A.]]

![[ck800wa.png]]
