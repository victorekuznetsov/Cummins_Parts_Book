> ### Injectors and Fuel Lines
>
> | **Tool Number** 3163194 | **Single Injector Diagnostic Cutout Tool (Mechanically Actioned Injectors)** Used to locate defective or weak injectors (QSK45 = 7) (QSK60 = 9). |  |
> |---|---|---|
> | **Tool Number** 3163270 | **In-Line Fuel Sight Glass - Number 16 SPG** Used to check for air in the fuel system. The sight glass is used with fuel line size SAE 16. |  |
> | **Tool Number** 3163303, 3163304, 3163305 | **Injector Timing Tool Update Kit** Update kit for previous universal injection timing tool, Part Number 3824942, used only for QSKV engines. |  |
> | **Tool Number** 3376859 | **Fitting, Quick-Disconnect - Female** Used to connects gauges when measuring various fuel pressures. |  |
> | **Tool Number** 3376891 | **Fluorescent Tracer** Use to instert in the engine oil or the fuel. Use black light to read oil or fuel leaks. |  |
> | **Tool Number** 3377244 | **Fitting, Quick-Disconnect - Male** Used to perform a pressure-side air-in-fuel test. |  |
> | **Tool Number** 3400157 | **Filter Wrench** Used to remove spin on filters. |  |
> | **Tool Number** 3822934 | **Lubricant™ DS-ES** Used to lubricate the pins in electrical connectors. |  |
> | **Tool Number** 3824241 | **Pressure Gauge** Used to measure fuel drain pressure. Install between the fuel drain hose and the engine fuel drain fitting. |  |
> | **Tool Number** 3824510 | **QD™ Contact Cleaner** Non-petroleum cleaner used to clean electrical connections. |  |
> | **Tool Number** 3824830 | **Injector Removal/Installation Tool** Used to remove and install QSK injectors. |  |
> | **Tool Number** 3824942 | **Injection Timing Tool** Used to check injection timing. The timing fixture is designed to determine the push tube travel in relation to the piston travel. |  |
> | **Tool Number** 4918612 | **Fuel system Tester** Used to measure the fuel inlet restriction. |  |
> | **Tool Number** 4918620 | **Installer, Injector** Used to align the injectors for proper installation of the injector fuel lines. |  |
> | **Tool Number** 4918935 | **Kit, Protective Cover** Used to protect injectors and injector fuel supply lines from debris. |  |
> | **Tool Number** ST-434 | **Vacuum Gauge** Used to measures fuel pump inlet restriction. Includes most hose adapters. |  |
> | **Tool Number** ST-1273 | **Pressure Gauge** Used to measures injector drain line restriction when used with drain adapter. |  |
> | **Tool Number** ST111-3 | **Manometer** Used to check for stuck check balls in injectors for a slow shutdown symptom. |  |
> | **Tool Number** 2892293 | **Injector Tester** Used to test all MCRS injectors to determine if the solenoid is functioning properly. |  |
