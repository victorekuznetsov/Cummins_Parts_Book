| **Tool Number** 3824830 | **Injector Removal/Installation Tool** Used to remove and install QSK injectors. |  |

| **Tool Number** 4918612 | **Fuel system Tester** Used to measure the fuel inlet restriction. |  |
| **Tool Number** 4918620 | **Installer, Injector** Used to align the injectors for proper installation of the injector fuel lines. |  |
| **Tool Number** 4918935 | **Kit, Protective Cover** Used to protect injectors and injector fuel supply lines from debris. |  |
| **Tool Number** ST-434 | **Vacuum Gauge** Used to measures fuel pump inlet restriction. Includes most hose adapters. |  |
| **Tool Number** ST-1273 | **Pressure Gauge** Used to measures injector drain line restriction when used with drain adapter. |  |
| **Tool Number** ST111-3 | **Manometer** Used to check for stuck check balls in injectors for a slow shutdown symptom. |  |
| **Tool Number** 2892293 | **Injector Tester** Used to test all MCRS injectors to determine if the solenoid is functioning properly. |  |
