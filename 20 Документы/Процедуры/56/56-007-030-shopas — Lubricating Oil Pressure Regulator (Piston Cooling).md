### Install

Lubricate the spool (1) with clean engine oil.

Install the spool (1) and spring (2) into the flywheel housing.

Install the o-ring (3) onto the straight thread o-ring plug (4).

Install the straight thread o-ring plug into the flywheel housing and tighten.

> [!tip] Момент затяжки · Torque Value
> 60 n•m [44 ft-lb]
