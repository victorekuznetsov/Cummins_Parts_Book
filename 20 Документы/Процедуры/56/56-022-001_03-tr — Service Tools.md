| **Tool Number** 3824901 | **Valve Setting Gauge Kit** Kit contains two 25.4-mm \[1-in\] wide feeler gauges for centering under the swivel foot of the rocker lever when setting the valves. The kit contains an intake valve gauge at 0.36 mm \[0.014 in\] and an exhaust valve gauge at 0.81 mm \[0.032 in\]. |  |
| **Tool Number** 3162458 | **Rocker Lever Bushing Mandrel** Used to install and/or remove the rocker lever bushings. |  |
| **Tool Number** 3375432 | **Crack Detection Kit** Used to inspect the housing for cracks. |  |
| **Tool Number** 4918282 | **Cylinder Head Protective Cover** Used to prevent debris from entering the camshaft follower cavity while the rocker lever cover is removed. |  |
