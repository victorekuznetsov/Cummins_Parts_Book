### Disassemble

> [!note] Note · Примечание
> **Only** remove the gear from the shaft when the gear or the shaft **must** be replaced.

Install the shaft and gear in an arbor press as shown. Use a suitable mandrel to push the shaft from the gear.

![[hd4gema.png]]

### Clean and Inspect for Reuse

> [!danger] WARNING · Опасно
> When using solvents, acids or alkaline materials for cleaning, follow the manufacturers recommendations for use. Wear goggles and protective clothing to reduce the risk of personal injury.

> [!danger] WARNING · Опасно
> Wear appropriate eye and face protection when using compressed air. Flying debris and dirt can cause personal injury.

Clean the shaft and gear with solvent.

Dry with compressed air.

![[09600107.png]]

Check the gear teeth and gear bore for damage.

Replace the gear if damaged.

![[09600057.png]]

Measure the inside diameter of the gear if it is to be reused.

| Hydraulic Pump Drive Gear Inside Diameter |  |  |
|---|---|---|
| mm |  | in |
| 44.98 | MIN | 1.771 |
| 45.02 | MAX | 1.772 |

![[hd8geta.png]]

Inspect the shaft in the gear fit area for fretting, burrs, or other damage.

Clean burrs with a piece of emery cloth.

![[09600059.png]]

Measure the shaft diameters.

| Hydraulic Pump Drive Shaft Diameters |  |  |  |
|---|---|---|---|
|  | mm |  | in |
| (1) | 43.928 | MIN | 1.7294 |
|  | 43.940 | MAX | 1.7299 |
| (2) | 45.094 | MIN | 1.7753 |
|  | 45.106 | MAX | 1.7758 |
| (3) | 49.820 | MIN | 1.9614 |
|  | 49.832 | MAX | 1.9619 |
| (4) | 41.994 | MIN | 1.6533 |
|  | 42.006 | MAX | 1.6538 |

If the diameters are **not** within specification, the shaft **must** be replaced.

![[09k00004.png]]

### Assemble

> [!note] Note · Примечание
> If replacing the gear, make sure that the replacement contains the same number of teeth.

Use Loctite™ 609, or equivalent, to apply a smooth layer on the inside diameter of the gear.

Use an arbor press to support the gear as shown with the part number facing down.

Press the shaft through the gear until the shaft shoulder touches the gear.

![[hd4geha.png]]
