### Установка

Использование блок-штифферента было прекращено для двигателей QSK45 и QSK60.

**Не** Установите блок-тарелку.

![[01600294.png]]


> [!quote]- Original (English) · английский оригинал
> ### Install
>
> The block stiffener plate use has been discontinued for the QSK45 and QSK60 engines.
>
> Do **not** install the block stiffener plate.
