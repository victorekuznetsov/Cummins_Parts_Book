### Check for Correct Component

Compare the assembly number (1) on the turbocharger data plate with the turbocharger specified in the Control Parts List (CPL), Bulletin 3379133 (2).

The CPL number for each engine is listed on the engine dataplate (3).

![[tb1plga.png]]

### Install

Holset® turbocharger(s) are used on the QSK45 and the QSK60 engines. Refer to the data tag on the turbocharger to determine the model.

![[10400034.png]]

All turbocharger fittings are the flat face o-ring type. Make sure the o-ring is in place before attaching the hose(s) to the fittings.

The Holset® turbocharger uses a 9/16-18 UNF straight thread, o-ring type of oil supply fitting.

![[10400015.png]]

> [!danger] WARNING · Опасно
> This component or assembly weighs greater than 23 kg \[50 lb\]. To prevent serious personal injury, be sure to have assistance or use appropriate lifting equipment to lift this component or assembly.

> [!note] Note · Примечание
> Make sure that the turbocharger is correctly aligned during installation to prevent damage to the turbocharger bellows

Apply an anti-seize compound to the mounting capscrew threads.

Install a new turbocharger gasket (1).

Install the turbocharger (2) with capscrews (3), spacers (5), and flange nuts (4).

Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 55 n•m [40 ft-lb]

![[10600113.png]]

Install and tighten the V-band clamp between the exhaust bellows and turbocharger.

> [!tip] Момент затяжки · Torque Value
> 9 n•m [80 in-lb]

![[11600045.png]]

Install the inlet piping and clamp to the turbocharger.

Tighten the clamp.

> [!tip] Момент затяжки · Torque Value
> 8 n•m [71 in-lb]

![[tb4ilna.png]]

Install a new gasket (4) on the turbocharger oil drain line.

Lubricate the oil drain line mounting capscrews with anti-seize compound, Part Number 3824879.

Install the drain line (2) and two drain line mounting capscrews (1) to the turbocharger (1).

Tighten the turbocharger drain line mounting capscrews.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[10600098.png]]

Pour 50 to 60 cc \[2.0 to 3.0 oz\] of clean engine oil into the turbocharger oil supply fitting.

![[10600109.png]]

Make sure the o-ring is in the correct position and is **not** damaged.

Install the oil supply hose.

Tighten the hose fitting.

> [!tip] Момент затяжки · Torque Value
> 54 n•m [40 ft-lb]

![[10600076.png]]

Install the hose and two clamps between the low-pressure turbocharger outlet and the intercooler intake crossover.

Tighten the clamps.

> [!tip] Момент затяжки · Torque Value
> 8 n•m [71 in-lb]
