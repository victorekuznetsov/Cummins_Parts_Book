> ### Engine Testing
>
> | **Tool Number** ST-434 | **Vacuum Gauge** Used to check fuel pump inlet restriction. |  |
> |---|---|---|
> | **Tool Number** ST-1273 | **Pressure Gauge \[0 to 75 in Hg\]** Used to measure intake manifold pressure and fuel drain line restriction. |  |
> | **Tool Number** ST-1111-3 | **Manometer** Used with blowby check tool, Part Number 3822568, for measuring blowby. Also, used to measure air inlet restriction and exhaust restriction. |  |
> | **Tool Number** 3375275 | **Pressure Gauge \[0 to 100 psi\]** Used to measure lubricating oil pressure. |  |
> | **Tool Number** 3377462 | **Digital Optical Tachometer** Used to measure engine speed (rpm). |  |
> | **Tool Number** 3377464 | **Reflective Tape (for optical tachometer, Part Number 3377462)** Used with optical tachometer, Part Number 3377462, to measure rpm. |  |
> | **Tool Number** 3822568 | **Blowby Check Tool (10-mm \[0.406-in\] orifice)** Used with manometer, Part Number ST-1111-3, to measure the engine crankcase pressure. |  |
> | **Tool Number** 3163890 | **Engine Control** Used on an engine dynamometer to control the QSK45, QSK50, and QSK60 engines. |  |
> | **Tool Number** 4918643 | **Engine Control Harness** Used on the QSK50 and QSK60 engines with electronically actuated injectors and is used with the engine control. |  |
> | **Tool Number** 3163891 | **Engine Control Harness** Used on the QSK45 and QSK60 engines with mechanically actuated injectors and is used with the engine control. |  |
> | **Tool Number** 4918416 | **INLINE™5 Adapter Kit** Used with the Engine Control, Part Number 3163890 and the Engine Control harness, Part Number 4918643. Used with the SAE J1708 and SAE J1939 standard protocol. Used with INSITE electronic service tool 6.3 or later versions. |  |
> | **Tool Number** 3163264 | **Lifting Fixture** Used to lift the engine during installation and removal. This kit contains the lift fixture, Part Number 3163265, and four lifting straps, Part Number 3163267. |  |
> | **Tool Number** 5394335 | **Cylinder Diagnostic Tool** Used to perform compression and leak down tests. |  |
