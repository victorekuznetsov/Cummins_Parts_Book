### Remove

Slip Fit

Remove the freon compressor drive belt, if equipped. Refer to the manufacturer's instructions.

Remove the accessory drive pulley retaining capscrew.

![[ad2csmb.png]]

The accessory drive pulley is slip fit, and does **not** require a puller to be removed from the engine.

Remove the accessory drive pulley.

![[ad2pumc.png]]

Interference Fit

Remove the freon compressor drive, if equipped. Refer to the manufacturer's instructions.

Remove the pulley retainer capscrew.

> [!note] Note · Примечание
> Earlier production engines have a retainer snap ring and no capscrews.

![[ad2csmb.png]]

Use a standard puller, Part Number ST-647 or Part Number 3376104, to remove the pulley.

![[ad2pumc.png]]

### Install

Slip Fit

> [!note] Note · Примечание
> Accessory drive seal dust seals are **only** to be installed on single v-groove stamped steel accessory drive pulleys. The dust seal is **not** compatible with other pulleys.

Place a light film of oil or antifreeze on the inside diameter of the accessory drive oil seal dust seal.

Install the dust seal onto the accessory drive pulley hub so that the larger outside diameter of the dust seal is facing away from the pulley. Push the dust seal onto the hub until the inside diameter of the dust seal is flush with the pulley hub end.

![[ad2puhg.png]]

> [!warning] CAUTION · Осторожно
> To prevent dowel pin damage, the slot (1) in the pulley must align with the dowel pin (2) in the shaft.

The timing marks on the pulley **must** be facing away from the engine.

This is a slip fit pulley and does **not** require the use of an installation tool.

Install the pulley on the shaft by hand.

![[ad2puhd.png]]

Install the M20-2.50 x 45 pulley retaining capscrew.

> [!tip] Момент затяжки · Torque Value
> 540 n•m [398 ft-lb]

Install and adjust the freon compressor drive belt, if equipped. Refer to the manufacturer's specifications.

![[ad2cshf.png]]

Interference Fit

> [!warning] CAUTION · Осторожно
> The slot (1) in the pulley must align with the dowel pins (2) in the shaft or the pin will be damaged.

> [!note] Note · Примечание
> The timing marks on the pulley must be facing away from the engine.

Install the pulley on the shaft by hand.

Use pulley pusher adapter, Part Number 3377453 and installation tool, Part Number 3376326, to install the pulley.

> [!note] Note · Примечание
> Use pulley pusher adapter, Part Number 3376383 on earlier production engines.

> [!note] Note · Примечание
> Earlier production engines use a retaining snap ring and no capscrew.

Install the (M20-2.50 x 45) pulley retainer capscrew.

> [!tip] Момент затяжки · Torque Value
> 540 n•m [398 ft-lb]

Install and adjust the freon compressor drive belt, if equipped. Refer to the OEM service manual.
