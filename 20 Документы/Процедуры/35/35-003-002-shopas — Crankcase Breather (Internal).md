### Install

With EGR

Install the breather tube, bracket, and capscrew on the engine.

Tighten the bracket capscrew.

> [!tip] Момент затяжки · Torque Value
> 27 n•m [20 ft-lb]

![[03200060.png]]

Without EGR

Install the breather tube, bracket, and capscrew on the engine.

Tighten the bracket capscrew.

> [!tip] Момент затяжки · Torque Value
> 27 n•m [239 in-lb]
