# Camshaft Gear (Camshaft Removed)
**Шестерня распредвала (вал снят)**

> [!abstract] Процедура · `35-001-013-shopas`
> **Двигатели:** [[35354607 — QSM11 CM570 CPL 8608|35354607]], [[35373113 — QSM11 CM570 CPL 8471|35373113]], [[71156161 — QSM11 CM570 CPL 8543|71156161]]

> **Даты:** изменён 2005-10-11

### Install

The accompanying chart lists different camshaft key part numbers, the degree of offset, and the approximate injector timing change from nominal.

![[lt200nb.png]]

Install the thrust plate on the camshaft.

![[cg8plma.png]]

Be sure the gear mounting surface is clean and free of oil, dirt, or debris.

Use a leather hammer to install the camshaft gear key.

> [!note] Note · Примечание
> If the same camshaft and gear are used again, use the same part number key as the one that was removed. Be sure the arrow on the key is pointing in the same direction as when it was removed. If a different camshaft and gear are used, install a straight key.

![[cg8keha.png]]

> [!danger] WARNING · Опасно
> Use insulated gloves, Part Number 3823730, and/or hot clamp pliers, Part Number 3823732, when handling heated parts. Hot parts can cause serious personal injury.

Heat the gear in an oven for a minimum of 1 hour, but no longer than 6 hours.

| Measurements |  |  |
|---|---|---|
|  | celsius | fahrenheit |
| Temperature | 235 | 450 |

Use Lubriplate™ 105, or equivalent, to coat the camshaft nose before installing the camshaft gear.

![[dp8gewa.png]]

> [!warning] CAUTION · Осторожно
> The timing marks and gear part number must be facing away from the camshaft when the gear is installed to prevent engine damage.

The gear **must** be installed within 30 seconds after being removed from the oven.

Remove the gear from the oven. Align the keyway in the gear with the key in the camshaft, and install the gear on the camshaft.

Keep the camshaft in a vertical position with the gear up until the gear has cooled.

![[cg2geha.png]]

Measure the clearance between the gear hub and the thrust plate.

| mm |  | in |
|---|---|---|
| 0.13 | MIN | 0.005 |
| 0.33 | MAX | 0.013 |

![[cg8plja.png]]

Install the camshaft. Refer to Procedure [[35-001-008-tr — Camshaft|001-008]].

Install the camshaft idler gear. Refer to Procedure [[35-001-036-tr — Idler Gear, Camshaft|001-036]].

![[cg200hb.png]]

> [!warning] CAUTION · Осторожно
> Failure to check engine timing can cause severe engine damage.

Check the engine timing. Refer to Procedure [[35-006-025-tr — Static Injection Timing|006-025]].

![[it200sc.png]]

Install the gear cover. Refer to Procedure [[35-001-031-tr — Gear Cover, Front|001-031]].

Operate the engine to normal operating temperature and check for leaks.

![[gc200hd.png]]
