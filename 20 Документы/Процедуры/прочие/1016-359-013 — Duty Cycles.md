### General Information

Duty cycle intervals are based on the idle time, fuel consumption, and Gross Vehicle Weight (GVW).

Determine the duty cycle. See Table 1, Duty Cycle Identification.

- If any condition under "Extreme" applies, the duty cycle is "Extreme."
- If any condition under "Severe" applies, and no conditions under "Extreme" apply, the duty cycle is "Severe."
- If any condition under "Normal" applies, and no conditions under "Severe" apply, the duty cycle is "Normal."

| Table 1, Duty Cycle Identification |  |  |  |
|---|---|---|---|
| Conditions | Duty Cycle |  |  |
| Normal | Severe | Extreme |  |
| Idle time | Less than 40% | Greater than 40% | - |
| Fuel consumption | Less than 40 kg/100 km \[ 142 lb/100 miles \] | 40 kg/100 km \[ 142 lb/100 miles \] to 55 kg/100 km \[ 195 lb/100 miles \] | Greater than 55 kg/100 km \[ 195 lb/100 miles \] |
| GVW | Less than 49 tonnes \[ 108,027 lb \] | Greater than 49 tonnes \[ 108,027 lb \] | - |
