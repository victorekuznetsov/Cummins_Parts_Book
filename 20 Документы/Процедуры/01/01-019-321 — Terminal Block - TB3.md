### Общие сведения

Терминальные блоки обеспечивают подключение клиентов для проводов, поставляемой клиентами, которая взаимодействует с управлением. Блоки терминала расположены на всех печатных платах ECM (кроме топливной платы), за исключением TB3, который монтируется на собственной терминальной рельсе.

![[19802812.png]]

### Снятие

Удалите клиентскую проводку на терминальные блоки.

Удалите проводку из ремня управления генератором и параллельной ремни со стороны TB3.

![[19802838.png]]

Освободите винт, который удерживает верхний зажим на концевой рельс. Этот клип удерживает терминальные блоки на месте.

![[19802823.png]]

Скользите с терминала, блокирует и выключает железнодорожный терминал.

![[19802824.png]]

### Установка

Скользите с терминала на железнодорожный вокзал.

![[19802824.png]]

Установите клип, который удерживает терминальные блоки на месте. Найдите зажим поверх оконечных блоков и затяните винт.

![[19802823.png]]

Подключите проводку от управляющей проводов генератора (и параллельной проводов, если применимо) к стороне соответствующих оконечных блоков на TB3.

Установите клиентскую проводку на терминальные блоки.

Используя инструмент электронного сервиса, проверьте наличие активных кодов неисправностей.

![[19802838.png]]


> [!quote]- Original (English) · английский оригинал
> ### General Information
>
> The terminal blocks supply customer connections for customer-supplied wiring that interfaces with the control. Terminal blocks are located on all ECM circuit boards (except fuel board), with the exception of TB3, which is mounted on its own terminal rail.
>
> ### Remove
>
> Remove customer wiring to the terminal blocks.
>
> Remove wiring from generator control harness and parallel harness from side of TB3.
>
> Loosen the screw that holds the upper clip to the terminal rail. This clip holds the terminal blocks in place.
>
> Slide the terminal blocks up and off the terminal rail.
>
> ### Install
>
> Slide the terminal blocks down onto the terminal rail.
>
> Install the clip that holds the terminal blocks in place. Locate clip on top of terminal blocks and tighten the screw.
>
> Connect wiring from generator control harness (and paralleling harness if applicable) to the side of the appropriate terminal blocks on TB3.
>
> Install customer wiring to terminal blocks.
>
> Using the electronic service tool, check for active fault codes.
