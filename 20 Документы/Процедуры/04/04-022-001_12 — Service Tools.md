> [!quote]- Original (English) · английский оригинал
> | **Tool Number** ST-302 | **Ball Joint Vise** Use to hold the air compressor for disassembly or assembly. |  |
> |---|---|---|
> | **Tool Number** ST-647 | **Standard Puller** Use to pull the drive gear. Use with puller capscrews that have M8 x 1.25-6H thread. |  |
> | **Tool Number** ST-749 | **Mounting Plate** Use to mount the air compressor to the vise. |  |
> | **Tool Number** ST-755 | **Piston Ring Compressor** Use to compress all piston rings to permit easy installation of piston and rod assemblies. |  |
> | **Tool Number** ST-1143 | **Air Compressor Bushing Mandrel** Use to remove and install the crankshaft bushing in the crankcase and the support. |  |
> | **Tool Number** 3375072 | **Dial Bore Gauge** Use to measure the cylinder bores. |  |
> | **Tool Number** 3375182 | **Valve Spring Tester** Use to check the exhaust valve, intake valve, and unloader valve cap springs. |  |
> | **Tool Number** 3376399 | **O-Ring Pick** Use to remove and install o-rings. |  |
> | **Tool Number** 3376663 | **Coupling Puller** Use to remove the spline coupling hub. |  |
> | **Tool Number** 3823923 | **Spacer** Use with coupling puller, Part No. 3376663, to remove the hydraulic pump drive coupling. |  |
> | **Tool Number** 3377415 | **Air Compressor Seat Installation Tool** Use to install the exhaust valve seats. |  |
> | **Tool Number** 3377416 | **Air Compressor Seat Removal Tool** Use to remove the exhaust valve seats. |  |
> | **Tool Number** 3823528 | **Air Compressor Seat Socket** Use to remove the exhaust valve seat and the inlet valve cage. |  |
