### Общие сведения

Используйте либо герметики, перечисленные ниже, либо герметики, содержащие эквивалентные свойства.

| Пункт Описание | Метод уплотнения |
|---|---|
| Трубные вилки | предварительно покрытый тефлонTM или герметик трубы |
| Кубок штепсельных заглушки | Локтит 271 или герметик Cummins, номер детали 3375068 |
| О-кольца | ЛюбриплайтTM 105 |
| Задняя кулачная валовая вилка расширения | Локтит 271 или герметик Cummins, номер детали 3375068 |
| Шпильки топливных насосов | Локтайт 242 |
| Слив турбокомпрессора (в блоке) | Локтит 271 или герметик Cummins®, номер детали 3375068 |
| Масляная измерительная трубка (в блоке) | Локтит 271 или герметик Cummins, номер детали 3375068 |
| Мокрый корпус маховика для блокировки | Тюлень из трех бондов, номер детали 3823494 |
| Побочное масло заполните | Локтит 271 или герметик Cummins, номер детали 3375068 |
| Поддон для масла на шестеренках | Тюлень из трех бондов, номер детали 3823494 |
