### Измерение

Снимите шланг для слива топлива и установите адаптер, часть номер ST-434-1.

Установите на адаптер калибр давления 0-763 мм-Hg \[0-30 в Hg\].

Работайте с двигателем на высоком холостом ходу и без нагрузки. Проверьте и запишите чтение ограничений.

| Сопротивление магистрали слива топлива |  |  |  |  |
|---|---|---|---|---|
|  | хг |  | в хг |  |
| Скриншоты Check клапан |  | 165 | Макс | 6.5 |
| Без проверки клапан |  | 229 | Макс | 9 |

Спецификация "с контрольным клапаном" относится к приложениям с топливными баками, установленными там, где максимальный уровень топлива топливного бака находится на или над прокладкой головки цилиндра двигателя.

Если ограничение превышает технические требования, проверьте линии стока на предмет причины ограничения. Топливные охладители и топливные нагреватели могут вызвать чрезмерное ограничение линии слива. Чрезмерное ограничение может привести к низкой мощности и плохой экономии топлива.

Удалите адаптер и измеритель давления. Установите шланг для слива топлива.

> [!tip] Момент затяжки
> 35 Н·м [26 фунт-фут]

Если повреждение привело к попаданию в выхлопную систему охлаждающей жидкости, масла, избыточного топлива или черного дыма, необходимо проверить систему последующей обработки.[[101-014-013-tr — Aftertreatment Testing|См. процедуру 014-013 в разделе 14.]]

> ### Measure
>
> Remove the fuel drain hose and install adapter, Part Number ST-434-1.
>
> Install a 0-763 mm-Hg \[0-30 in Hg\] pressure gauge onto the adapter.
>
> Operate the engine at high idle and no load. Check and record the restriction reading.
>
> | Fuel Drain Line Restriction |  |  |  |  |
> |---|---|---|---|---|
> |  | mm-hg |  | in-hg |  |
> | With Check Valve |  | 165 | MAX | 6.5 |
> | Without Check Valve |  | 229 | MAX | 9 |
>
> The ‘with check valve' specification refers to applications with fuel tanks mounted where the maximum fuel level of the fuel tank is at or above the engine cylinder head gasket.
>
> If restriction exceeds specifications, inspect the drain lines for the cause of the restriction. Fuel coolers and fuel heaters can cause excessive drain line restriction. Excessive restriction can cause low power and poor fuel economy.
>
> Remove the adapter and pressure gauge. Install the fuel drain hose.
>
> **Момент затяжки · Torque Value**
> 35 n•m [26 ft-lb]
>
> If damage resulted in coolant, oil, excessive fuel, or excessive black smoke entering the exhaust system, the aftertreatment system **must** be inspected. [[101-014-013-tr — Aftertreatment Testing|Refer to Procedure 014-013 in Section 14.]]
