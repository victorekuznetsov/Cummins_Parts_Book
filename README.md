# Каталог запасных частей Cummins

Интерактивный каталог запчастей двигателя Cummins, собранный из официального
каталога **parts.cummins.com** по серийному номеру двигателя (ESN).

Каталог работает **офлайн**: откройте `catalog/index.html` двойным щелчком.
Ни сервера, ни интернета не требуется.

По вопросам работы каталога запасных частей, ошибок, замечаний обращаться
к Кузнецову В.Е. — KuznetsovVE@industrservice.ru

## Возможности

- **Чертёж рядом со списком позиций.** Номер на чертеже = номер позиции в
  таблице. У многолистовых узлов — карусель листов, щелчок увеличивает чертёж.
- **Карточка детали** (щелчок по номеру): все ракурсы фотографии,
  масса и габариты в метрических единицах, признак «продаётся отдельно»,
  класс опасного груза, список узлов, где деталь применяется.
- **Замены номеров.** Цепочка «старый → действующий» с пометкой снятых с
  производства. Поиск находит деталь и по **старому** номеру — в выдаче он
  помечается «вместо ...».
- **Поиск** по номеру и наименованию сразу по всему каталогу.
- **Заказ:** требуемое количество по каждой позиции, редактирование корзины,
  серийный номер машины, выгрузка в CSV (открывается в Excel) и печать.
  Заказ сохраняется в браузере.
- **Цены** подтягиваются из прайс-листа, если он передан при сборке
  (`--prices прайс.xlsx`); без него столбец «Цена» пустой.

## Как открыть

Скачайте репозиторий и откройте `catalog/index.html` двойным щелчком
(Chrome, Edge, Firefox). Всё работает локально по `file://`.

## Как это собрано

### 1. Выгрузка с parts.cummins.com

```
pip install playwright requests openpyxl
playwright install chromium

python crawler.py 37292556                 # состав двигателя, узлы, чертежи
python crawl_details.py 37292556           # карточки деталей и фотографии
```

`crawler.py` заводит анонимную сессию (пользователь `PUBLIC`) в браузере и
дальше ходит в REST-шлюз каталога. Учётная запись не требуется.
`crawl_details.py` переносит куки сессии в `requests` и качает в 8 потоков —
863 детали со всеми фотографиями выгружаются примерно за 7 минут.

Повторный запуск дозагружает только недостающее.

**Используемые точки API** (`https://parts.cummins.com/gateway/api/IACDataServices`):

| Запрос | Что отдаёт |
|---|---|
| `/v2/esnInfo/{ESN}?esnType=mbom` | паспорт двигателя и весь состав: узлы, детали, системы |
| `/v2/componentDetails/option?componentHash=…&esn=…` | спецификация узла: позиция (`callOut`), количество, типоразмер, чертежи |
| `/protected/partDetails?partNo=…&smn=` | карточка детали: атрибуты, замены номеров, где применяется, ракурсы фото |
| `/v2/esnInfo/{ESN}/kitSets`, `/gasketSets` | ремкомплекты и комплекты прокладок |
| `/graphics/rtgraphics/english/parts/…png` | чертежи узлов |
| `/graphics/parts/{ppp}/{номер}/{номер}_iso.png` | фотографии деталей |

Шлюз требует заголовок `x-xsrf-token` (значение берётся из куки `XSRF-TOKEN`);
без него отвечает `403`.

### 2. Сборка каталога

```
python tools/build_catalog.py 37292556 [--prices прайс.xlsx]
```

Читает `data/<ESN>/` и создаёт `catalog/data.js` (все данные одним файлом —
именно поэтому каталог открывается без сервера), копирует чертежи и фотографии.
Оболочка `index.html` / `app.js` / `styles.css` статическая и не перезаписывается.

### 3. Проверка

```
python tools/verify_catalog.py
```

Открывает собранный каталог в настоящем браузере по `file://` и проверяет:
позиция 1 присутствует в каждой системе, чертежи и фотографии загружаются,
работает поиск по номеру и по заменённому номеру, открывается карточка детали,
считается и сохраняется заказ, в консоли нет ошибок. Скриншоты складывает в
`catalog/_screenshots/`.

## Структура

```
crawler.py            выгрузка состава двигателя, узлов и чертежей
crawl_details.py      выгрузка карточек деталей и фотографий (многопоточно)
tools/build_catalog.py  сборка catalog/data.js из выгрузки
tools/verify_catalog.py проверка готового каталога в браузере
tools/recon/          скрипты разведки API (как разбирался сайт)
data/<ESN>/           выгрузка в JSON: engine, options, partdetails, kits
catalog/              готовый каталог: index.html, app.js, styles.css, data.js,
                      drawings/, parts/
```

Картинки в `data/<ESN>/drawings` и `data/<ESN>/parts` в репозиторий не
кладутся: те же файлы лежат в `catalog/`, а при необходимости качаются заново.

## Добавить другой двигатель

```
python crawler.py <ESN>
python crawl_details.py <ESN>
python tools/build_catalog.py <ESN>
```

Проверьте в отчёте `data/<ESN>/report.json`, что `parts_lost` пуст.
