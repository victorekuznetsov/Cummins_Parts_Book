# Каталог запасных частей Cummins — публикуемая версия (Vercel)

Статический онлайн-каталог запчастей двигателей Cummins, собранный из
официального каталога **parts.cummins.com** по серийным номерам (ESN).
Оформление — фирменный стиль «Развитие», светлая и тёмная тема.

Это **ветка `main`** — только то, что нужно для публикации на Vercel:
страница каталога, данные двигателей и чертежи. Фотографии деталей
подгружаются напрямую с публичного CDN Cummins, поэтому в деплой не
кладутся десятки тысяч файлов.

Вся исходная выгрузка, сырые данные `data/<ESN>/`, скрипты сборки
(`crawler.py`, `crawl_details.py`, `tools/`) и брендбук — в ветке
**`rawdata`**.

По вопросам работы каталога, ошибок и замечаний — Кузнецов В.Е.,
KuznetsovVE@industrservice.ru

## Что внутри

```
index.html · app.js · styles.css   оболочка каталога (статическая)
engines.js                          список двигателей для переключателя
data/<ESN>.js                       состав каждого двигателя (window.CATALOGS)
data/prices.js                      базовый прайс: текущий и несогласованный
drawings/<ESN>/*.png                чертежи узлов (локально)
brand/                              логотипы «Развитие» (свет/тёмная тема)
vercel.json                         конфигурация статического деплоя
```

Фотографии деталей грузятся с `parts.cummins.com/graphics/parts/...`
(публично, без авторизации). Если фото недоступно — оно просто не
показывается, остальной каталог работает.

## Возможности

- Переключатель двигателей; поиск по номеру, наименованию и заменённым
  (старым) номерам сразу по всем двигателям, а также по номерам комплектов.
- Чертёж рядом со списком позиций; карточка детали (фото, масса и габариты,
  цепочка замен номера, где применяется).
- **Комплекты (kits)** — см. раздел ниже.
- Две цены в списке позиций: «Текущая» и «Несогласованная» (из `data/prices.js`).
- Заказ с выгрузкой в CSV и печатью; сохраняется в браузере.
- Выгрузка всех номеров модели / всех каталогов в Excel, выгрузка комплектов
  с составом, проверка списка номеров на наличие, загрузка цен из файла.
- Светлая и тёмная тема (переключатель в шапке).

## Комплекты (kits)

Cummins поставляет часть номеров только в составе ремкомплектов. Состав
комплектов приходит в тех же данных двигателя (`kits` в `data/<ESN>.js`), и
каталог использует его так:

- В списке позиций деталь, входящая в комплект, помечена «🧰 Можно заказать
  комплектом» со ссылками на состав каждого комплекта.
- Если деталь **не продаётся отдельно** (`Sellable: N`), кнопка заказа
  заблокирована («не продаётся»), а вместо неё предлагается заказ комплектом.
  Если деталь продаётся и отдельно, и в комплекте — в строке появляется выбор
  «деталь или комплект».
- В карточке детали есть блок «Заказать комплектом» с ценами комплектов.
- Карточка комплекта показывает полный состав: номер, наименование (русское —
  из базы знаний), количество (повторы в исходных данных схлопнуты в «Кол-во»)
  и обе цены; из состава можно перейти в карточку любой детали.
- Кнопка «🧰 Все комплекты» — страница всех комплектов двигателя с ценами;
  «↓ Комплекты и состав (Excel)» — выгрузка по строке на каждую составляющую.
- Поиск и «Проверить список» находят номера комплектов, а для обычных номеров
  показывают, в какие комплекты они входят.

## Цены

`data/prices.js` — базовый прайс, который каталог показывает сразу, без
загрузки файла вручную:

- `window.CUMMINS_PRICES` — несогласованный прайс (столбец «Несогласованная»),
- `window.CUMMINS_PRICES_CUR` — текущий прайс (столбец «Текущая»).

Ключ — нормализованный номер детали (верхний регистр, без пробелов и дефисов).
Файл генерируется из прайс-листов ГЕ скриптом `build/gen_data.js` каталога
NHL_Parts_Book. Прайс, загруженный кнопкой «Обновить цены», сохраняется в
браузере и накладывается поверх несогласованного; столбец «Текущая» он не
меняет.

## Деплой на Vercel

Статический сайт + Edge-функции для входа, сборка не нужна. Vercel обслуживает
файлы из корня репозитория; `vercel.json` задаёт заголовки кеширования.
Framework Preset: **Other**, Build Command: пусто, Output Directory: пусто
(корень). После первого деплоя обязательно задайте `AUTH_SECRET` (см.
«Доступ» ниже) — без него вход не работает (сервер отказывает всем, а не
открывает каталог).

## Доступ

Каталог закрыт логином на сервере (Vercel Edge Middleware + `middleware.js` +
`auth/`), а не клиентским паролем — обхода через просмотр исходного кода нет.

1. **Сгенерировать секрет** (один раз на деплой):
   `node build/make_user.mjs secret` → вставить значение в Vercel:
   Settings → Environment Variables → `AUTH_SECRET` → Redeploy.
2. **Управлять логинами** (пишет в `auth/accounts.mjs`, пароли хранятся только
   как PBKDF2-хеши — не в открытом виде):
   ```
   node build/make_user.mjs set <логин> <пароль> --role permanent
   node build/make_user.mjs set <логин> <пароль> --role temporary --expires 2026-09-22
   node build/make_user.mjs list
   node build/make_user.mjs del <логин>
   ```
   Постоянные логины не имеют срока действия; временные отключаются сами
   после `--expires` (проверяется на сервере при каждом входе).
3. Изменения в `auth/accounts.mjs` — это данные (хеши), не секрет; их нужно
   закоммитить и задеплоить.

Локально (`file://`) каталог открывается без входа — middleware работает
только на самом Vercel-хостинге.
