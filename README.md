# Каталог запасных частей Cummins

Интерактивный каталог запчастей двигателей Cummins, собранный из официального
каталога **parts.cummins.com** по серийным номерам двигателей (ESN).

Каталог работает **офлайн**: откройте `catalog/index.html` двойным щелчком.
Ни сервера, ни интернета не требуется. В шапке — переключатель двигателей.

По вопросам работы каталога запасных частей, ошибок, замечаний обращаться
к Кузнецову В.Е. — KuznetsovVE@industrservice.ru

## Возможности

- **Переключатель двигателей** в шапке; поиск идёт сразу по всем двигателям
  каталога и подсказывает, к какой машине относится найденная деталь.
- **Чертёж рядом со списком позиций.** Номер на чертеже = номер позиции в
  таблице. У многолистовых узлов — карусель листов, щелчок увеличивает чертёж.
- **Карточка детали** (щелчок по номеру): все ракурсы фотографии, масса и
  габариты в метрических единицах, признак «продаётся отдельно», класс опасного
  груза, список узлов, где деталь применяется.
- **Замены номеров.** Цепочка «старый → действующий» с пометкой снятых с
  производства. Поиск находит деталь и по **старому** номеру — в выдаче он
  помечается «вместо ...».
- **Поиск** по номеру, наименованию и заменённым номерам.
- **Заказ:** требуемое количество по каждой позиции, редактирование корзины,
  серийный номер машины, выгрузка в CSV (открывается в Excel) и печать.
  Заказ свой для каждого двигателя и сохраняется в браузере.
- **Цены** подтягиваются из прайс-листа, если он передан при сборке
  (`--prices прайс.xlsx`); без него столбец «Цена» пустой. Цены можно также
  загрузить прямо в открытом каталоге кнопкой **«Обновить цены»** — CSV с
  двумя столбцами (номер детали; цена). Цены сохраняются в браузере и
  применяются сразу ко всем двигателям.
- **Выгрузка всех номеров в Excel** (кнопки слева): «Все номера этой модели»
  — полный перечень деталей текущего двигателя, «Все номера всех каталогов»
  — по всем двигателям сразу (машина, модель, ESN, действующий номер, цена).
- **Проверка списка**: вставьте свой список номеров (или загрузите файл) —
  каталог покажет, каких деталей нет, какие есть и в каких машинах, а какие
  найдены как **заменённый** (старый) номер. Результат выгружается в Excel.
- **Фирменный стиль «Развитие», светлая и тёмная тема.** Логотип и палитра —
  по брендбуку (акцент мятный `#3EF0AF`, графит `#2A3138`). Переключатель темы
  в шапке (☾ / ☀), выбор запоминается в браузере; при первом открытии тема
  берётся из настроек системы.

## Как открыть

Скачайте репозиторий и откройте `catalog/index.html` двойным щелчком
(Chrome, Edge, Firefox). Всё работает локально по `file://`.

## Как это собрано

### 0. Проверка списка ESN — какие каталоги вообще нужны

```
python tools/check_esn.py esn_list.txt
```

Читает список серийных номеров (лишнюю разметку игнорирует), показывает по
каждому модель, CPL, конфигурацию и дату сборки и **группирует по CPL**: на
каждый CPL достаточно одного каталога. 46 номеров проверяются примерно за минуту.

Чем именно различается состав двигателей одного CPL, показывает

```
python tools/diff_esn.py <ESN1> <ESN2> ...
```

### 1. Выгрузка с parts.cummins.com

```
pip install playwright requests openpyxl
playwright install chromium

python crawler.py 33239899                 # состав двигателя, узлы, чертежи
python crawl_details.py 33239899           # карточки деталей и фотографии
```

Учётная запись не нужна: `crawler.py` заводит анонимную сессию (пользователь
`PUBLIC`) в браузере, дальше работа идёт с REST-шлюзом каталога.
`crawl_details.py` переносит куки сессии в `requests` и качает в 8 потоков.
Повторный запуск дозагружает только недостающее.

Замеры на двигателе с 863 деталями: структура и чертежи — 2 мин 45 с,
карточки и 2946 фотографий — 7 мин 30 с (115 деталей в минуту), около 250 МБ.

**Используемые точки API** (`https://parts.cummins.com/gateway/api/IACDataServices`):

| Запрос | Что отдаёт |
|---|---|
| `/v2/esnInfo/{ESN}?esnType=mbom` | паспорт двигателя и весь состав: узлы, детали, системы |
| `/v2/componentDetails/option?componentHash=…&esn=…` | спецификация узла: позиция (`callOut`), количество, типоразмер, чертежи |
| `/protected/partDetails?partNo=…&smn=` | карточка детали: атрибуты, замены номеров, где применяется, ракурсы фото |
| `/v2/esnInfo/{ESN}/kitSets`, `/gasketSets` | ремкомплекты и комплекты прокладок |
| `/graphics/rtgraphics/english/parts/…png` | чертежи узлов |
| `/graphics/parts/{ppp}/{номер}/{номер}_iso.png` | фотографии деталей |

Шлюз требует заголовок `x-xsrf-token` (значение куки `XSRF-TOKEN`); без него
отвечает `403`.

### 2. Сборка каталога

```
python tools/build_catalog.py 33239899 --machine NTE200 --fleet-from esn_report.json
```

Читает `data/<ESN>/`, создаёт `catalog/data/<ESN>.js`, копирует чертежи и
фотографии в подпапки по ESN и дописывает двигатель в переключатель
(`catalog/engines.js`). Оболочка `index.html` / `app.js` / `styles.css`
статическая и не перезаписывается.

### 3. Проверка

```
python tools/verify_catalog.py
```

Открывает готовый каталог в настоящем браузере по `file://` и проверяет:
позиция 1 присутствует в каждой системе, чертежи и фотографии загружаются,
работает поиск по номеру и по заменённому номеру, открывается карточка детали,
считается и сохраняется заказ, в консоли нет ошибок. Скриншоты складывает в
`catalog/_screenshots/`.

## Чего нет в источнике

Для части узлов Cummins **не публикует чертёж**: у них `graphicCount: 0`,
выведенные по общей формуле адреса файлов дают 404, а на самом сайте вместо
чертежа показывается заглушка. У QST30 таких узлов 24 из 68 — в том числе ТНВД,
ЭБУ и Performance Parts. Списки позиций у них при этом полные.

Наименования деталей отдаются только на английском: русские названия сайт
подставляет на стороне браузера из своего словаря, в API их нет.

## Структура

```
crawler.py              выгрузка состава двигателя, узлов и чертежей
crawl_details.py        выгрузка карточек деталей и фотографий (многопоточно)
tools/check_esn.py      проверка списка ESN и группировка по CPL
tools/diff_esn.py       чем различается состав двигателей одного CPL
tools/build_catalog.py  сборка catalog/data/<ESN>.js из выгрузки
tools/verify_catalog.py проверка готового каталога в браузере
tools/recon/            скрипты разведки API (как разбирался сайт)
data/<ESN>/             выгрузка в JSON: engine, options, partdetails, kits
catalog/                готовый каталог: index.html, app.js, styles.css,
                        engines.js, data/<ESN>.js, drawings/<ESN>/, parts/<ESN>/
```

Картинки в `data/<ESN>/drawings` и `data/<ESN>/parts` в репозиторий не
кладутся: те же файлы лежат в `catalog/`, а при необходимости качаются заново.

## Добавить ещё один двигатель

```
python crawler.py <ESN>
python crawl_details.py <ESN>
python tools/build_catalog.py <ESN> --machine <машина>
python tools/verify_catalog.py
```

Проверьте в `data/<ESN>/report.json`, что `parts_lost` пуст.
