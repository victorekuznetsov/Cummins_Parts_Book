# База знаний Cummins — хранилище Obsidian

Готовое хранилище (vault) Obsidian: техническая документация Cummins QuickServe
и каталоги запчастей тридцати двигателей, связанные перекрёстными ссылками.
Каталоги самих машин сюда не входят — они живут в репозитории
`NHL_Parts_Book`.

## Как открыть

1. Скачайте только эту ветку (без 2 ГБ исходных PDF):

   ```
   git clone --depth 1 --branch obsidian-vault \
     https://github.com/victorekuznetsov/Cummins_Parts_Book.git cummins-kb
   ```

2. В Obsidian: **Open folder as vault** → выберите папку `cummins-kb`.
3. Откроется хранилище с готовыми настройками. Начните с заметки **00 Главная**.

Плагины не нужны — всё работает на стандартном Obsidian.

## Что внутри

| Папка | Содержимое |
|---|---|
| `00 Главная.md` | стартовая страница со сводкой и ссылками |
| `Как искать в этой базе.md` | шпаргалка по поиску, полям и тегам |
| `01 Индексы` | указатели: руководства, процедуры, TSB, детали, цены, узлы, комплекты |
| `10 Двигатели` | паспорта тридцати двигателей по ESN |
| `11 Машины/Парк` | парк: машина → VIN → ESN → CPL → каталог двигателя |
| `20 Документы` | 6 775 документов QuickServe в Markdown |
| `30 Детали` | 11 517 карточек артикулов |
| `40 Узлы` · `50 Комплекты` | состав узлов каталога и ремкомплектов |
| `60 Темы` | тематические карты (моменты затяжки, диагностика, смазка …) |
| `90 Приложения` | иллюстрации процедур, чертежи узлов, фотографии деталей |
| `_build` | скрипты, которыми хранилище собрано (для пересборки на новой выгрузке) |

## Источники

* Документы — `quickserve.cummins.com` (выгрузка в ветке `main` того же
  репозитория, папка `bulletins/`: HTML + PDF).
* Каталоги запчастей — `parts.cummins.com` по серийным номерам двигателей.
* Цены — прайс «Горная Евразия» (текущий и несогласованный) из
  `data/prices.js` каталога.

Иллюстрации процедур извлечены из PDF-оригиналов: на сервере Cummins они закрыты
авторизацией, поэтому взяты из скачанных файлов и сопоставлены с текстом
по порядку следования.

Тексты документов оставлены в оригинале (английский). Переведены названия
документов, деталей, узлов, а также вся навигация и индексы.
