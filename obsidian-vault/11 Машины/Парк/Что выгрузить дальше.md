# Что выгрузить дальше

Порядок один и тот же: **серийный номер → CPL → каталог → документация**.
Каталог и документация определяются CPL, а не серийным номером: на каждый
CPL нужен один комплект, остальные двигатели группы им покрываются.

## Чего не хватает

| Что | Объём | Чем закрывается |
|---|---|---|
| Документация QuickServe по CPL 4342 (X15 CM2350) | 1 машина DH46C3 RS | вход в QuickServe |
| Документация QuickServe по CPL 8761 (QSX15 CM570) | 1 машина DH46C3 RS | вход в QuickServe |
| CPL для парка «Полюс Алдан» | 98 серийных номеров | запрос к parts.cummins.com |
| Каталоги и документация по этим CPL | ~10–20 групп | после определения CPL |

## Почему это не сделано здесь

- **QuickServe требует входа** — логин, пароль и Company Id, которые вводятся
  вручную в окне браузера. Сохранённой сессии в песочнице нет.
- **parts.cummins.com отдаёт CPL только настоящему браузеру**: обычный
  HTTP-запрос получает 403, а браузеру в этой песочнице закрыт выход в сеть.
  Статические файлы (фотографии деталей) при этом качаются — они и выгружены.

## Порядок на рабочей машине

Файлы со списками лежат в репозитории, в папке `fleet/`:

| Файл | Что внутри |
|---|---|
| `fleet/polyus_esn.tsv` | 98 серийных номеров «Полюс Алдан» в формате скриптов |
| `fleet/polyus.tsv` | тот же парк с моделью, участком и годом |
| `fleet/polyus_no_esn.tsv` | 34 двигателя без номера — номер нужен с таблички |
| `fleet/fleet.tsv` | прежний парк, 51 машина |

```
# 1. CPL по серийным номерам (parts.cummins.com, логин не нужен)
python tools/check_esn.py fleet/polyus_esn.tsv --json fleet/polyus_report.json

# 2. Каталоги по новым CPL
python tools/build_catalog.py <ESN-представитель каждой группы>

# 3. Вход в QuickServe (один раз, Company Id вводится вручную)
QS_USER=... QS_PWD=... python quickserve/qs_login2.py

# 4. Документация: недостающие CPL текущего парка плюс новые
python quickserve/qs_scope.py 80201235 85201236 <новые ESN>
python quickserve/enum_service.py
python quickserve/enum_procedures.py && python quickserve/add_procedures.py
python quickserve/download_docs.py
```

Дальше пересборка базы обычным порядком: `build_docs.py` → `verify_figures.py`
→ `build_catalog.py` → `build_fleet.py` → `translate_docs.py` → `write_*.py`
→ `web_data.py`.
