### Заводская табличка двигателя

Диаграмма двигателя обеспечивает идентификацию модели и другую важную информацию о двигателе.

Иметь следующие данные о двигателе при общении с авторизованным местом ремонта Cummins. Информация на табличке данных является **обязательной** при поиске частей обслуживания:

1. Серийный номер двигателя (ESN)
2. Список контрольных частей (CPL)
3. Модель
4. Рекламная мощность и обороты.

![[oi1plgc.png]]

Например, на двигателях CELECTTM Plus поверх ECM расположена табличка с электронным модулем управления (ECM).

Сокращения в сопроводительной иллюстрации объясняются следующим образом:

p/n = число частей

s/n = серийный номер

d/c = код даты.

![[fs8plgb.png]]

Модуль управления CentinelTM имеет табличку с данными, расположенную на передней крышке. Информация, содержащаяся на табличке, является:

1. Серийный номер
2. Номер детали базового модуля.

Существует три различных номера деталей модуля управления CentinelTM, доступных для использования в системе CentinelTM. Они:

1. Высокомощный 12 VDC или 24 VDC, номер детали модуля
2. Heavy-Duty 12/24 VDC, номер модуля.

При заказе запасных частей закажите номер детали, который является специфическим для конфигурации вашей системы.
