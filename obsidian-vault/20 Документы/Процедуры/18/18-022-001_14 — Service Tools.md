> | **Tool Number** ST-1135 | **Lubricating Oil Sampling Filter** Used to monitor oil contamination. |  |
> | **Tool Number** ST-1273 | **Pressure Gauge \[0-75 In-Hg\]** Used to measure intake manifold pressure and fuel drain line restriction. |  |
> | **Tool Number** 3375275 | **Pressure Gauge \[0-160 psi\]** Used to measure lubricating oil pressure. |  |
> | **Tool Number** 3375932 | **Pressure Gauge \[0-300 psi\]** Used to measure fuel pressure. Includes necessary hoses and hardware to attach to a fuel pump. Part Number ST-435-6 is the pressure gauge. |  |
> | **Tool Number** 3376375 | **Fuel Measuring Device** Measure the rate of fuel consumption of a Cummins diesel engine. |  |
> | **Tool Number** 3377462 | **Digital Optical Tachometer** Used to measure engine speed (RPM). Use with reflective tape, Part Number 3377464. |  |
> | **Tool Number** 3822566 | **Blowby Check Tool (0.302 inch orifice)** Used with manometer, Part Number ST-1111-3, to measure the engine crankcase pressure. |  |
> | **Tool Number** 3823567 | **Blowby Check Tool (0.354 inch orifice)** Used with manometer, Part Number ST-1111-3, to measure the engine crankcase pressure. |  |
> | **Tool Number** 3822568 | **Blowby Check Tool (0.406 inch orifice)** Used with manometer, Part Number ST-1111-3, to measure the engine crankcase pressure. |  |
> | **Tool Number** 5394335 | **Cylinder Diagnostic Tool** Used to perform compression and leak down tests. |  |
