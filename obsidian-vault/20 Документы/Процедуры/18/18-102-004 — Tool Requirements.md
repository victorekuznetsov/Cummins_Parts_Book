### Общие сведения

Большинство операций по техническому обслуживанию, описанных в этом руководстве, могут выполняться с помощью обычной ручной оснастки (драншеи, розетки и отвертки).

Ниже приведен список специальных инструментов обслуживания, необходимых для некоторых операций по техническому обслуживанию:

| Инструмент Часть Номер | Наименование |
|---|---|
| 3375049 | Нефтяной фильтр Wrench |
| 3376592 | Торк-ренч (Inch Pound) |
| 3376807 | Вода/фильтр топлива |
| 3822524 | Измеритель напряжения пояса (Click-Type) |
| 3822525 | Измеритель напряжения пояса (Click-Type) |
| 3822648 | Инструмент настройки Top Stop Tappet (только для двигателей, оборудованных STC) |
| 3823348 | Инструмент настройки Top Stop Tappet (только для двигателей, оборудованных STC) |
| СТ-1293 | Измеритель напряжения пояса (V-пояса) |
| 3823138 | Измеритель напряжения пояса (Poly V-belt) |

Смотрите соответствующие разделы для описания инструментов и как их использовать.

Свяжитесь с ближайшим авторизованным ремонтным центром Cummins для получения необходимых инструментов обслуживания.
