### Общие сведения

Набор Cummins® Inboard Joystick должен быть настроен на судно, в котором он установлен, для максимальной производительности. Судовые джойстики поставляются с предварительно загруженным файлом личности по умолчанию при заказе с завода. Новые джойстики должны быть обновлены с помощью настроенного файла личности судна, который специфичен для производителя оригинального оборудования судна (OEM) и модели. Необходимо загрузить наиболее актуальную для судна индивидуальность судна. Инструмент конфигурации судна обеспечивает возможность загрузки и загрузки файлов личности в джойстик судна. Используйте следующую процедуру, чтобы найти и выбрать персоналию судна.[[326-015-044 — Managing Vessel Personalities|См. процедуру 015-044 в разделе 15.]]

Выпущена новая версия инструмента конфигурации для системы Cummins® Inboard Joystick. Версия 3 и выше теперь является существующей версией инструмента, который заменяет устаревшую версию 2 и более старую.

### Настройка информации

Следующее оборудование необходимо для подключения к бортовой системе джойстиков для управления персоналом судна.

#### Вариант 1:

1. Совместимый ноутбук
2. JOYSTICKCONFIG-SERVICE электронная сервисная инструментация
3. USB-кабель RS232, Cummins® Part Number 5299129
4. USB-накопитель RS232 для последовательного адаптера.

#### Вариант 2:

1. Совместимый ноутбук
2. JOYSTICKCONFIG-SERVICE электронная сервисная инструментация
3. PS3USBUSB - последовательный адаптер
4. Универсальный последовательный удлинитель кабеля.

Инструменты для электронного обслуживания JOYSTICKCONFIG-SERVICE можно найти на сайте INSITE.CUMMINS.COM в разделе связанных с ними инструментов или на полке программного обеспечения Cummins® под названием JOYSTICKCONFIG-SERVICE.

Драйвер последовательного адаптера USB-RS232 можно найти на полке программного обеспечения Cummins®. В качестве альтернативы, администратор компьютера может установить драйвер, который предварительно загружается в кабель последовательного адаптера USB RS232, Cummins® Part Number 5299129.

Если **не** с помощью кабельной части № 5299129, то на полке оборудования Cummins® можно найти альтернативный кабель PS3USBUSB для последовательного адаптера. Альтернативный кабель автоматически установит необходимый драйвер на ноутбук Cummins®. Универсальный последовательный удлинитель должен использоваться с альтернативным кабелем в варианте 2.

Серийный адаптер подключается к порту USB на ноутбуке. Противоположный конец кабеля подключается к соединению для передачи данных интерфейса двигателя с помощью службы оснастки. Это соединение расположено рядом с модулем интерфейса двигателя.

Для требований совместимости ноутбука, справка INSITE.CUMMINS.COM.

> [!note] Примечание
> Для сотрудников Cummins® все программное обеспечение должно быть загружено с полки программного обеспечения Cummins®, поиск по ключевым словам «джойстик».

### Настройка

Версия 2 и более старый инструмент конфигурации

Для установления связи с бортовой системой джойстиков Cummins® сделайте следующее в порядке ниже.

1. Подключите адаптерный кабель к ноутбуку и интерфейсу подруливающего устройства для передачи данных. Дайте компьютеру одну минуту, чтобы распознать кабель.
2. Поверните переключатель зажигания, который приводит в действие электронный дросселирующий сдвиг Cummins® и бортовую систему джойстика Cummins® в положение ON.
3. Откройте инструмент электронного сервиса JOYSTICKCONFIG-SERVICE.
4. Нажмите кнопку «Обновить» (1).
5. Выберите порт COM из выпадающего меню (2), которое идентифицирует порт COM с подключенным адаптерным кабелем.
6. Нажмите «Открытый Comm Port» (3).
7. Откроется всплывающее окно, в котором говорится, что порт COM был успешно открыт. Нажмите OK.

![[15900118.png]]

Версия 3 и более мощный инструмент конфигурации

Чтобы установить связь с бортовой системой джойстиков Cummins®, выполните нижеследующее в порядке.

1. Подключите адаптерный кабель, номер детали 5299129, к компьютеру и интерфейсу подруливающего устройства для передачи данных. Дайте компьютеру 1 минуту, чтобы распознать адаптерный кабель.
2. Поверните переключатель зажигания, который приводит в действие электронный дросселирующий сдвиг Cummins® и бортовую систему джойстика Cummins® в положение ON.
3. Активируйте джойстик, который вы будете использовать во время процесса настройки. Желаемый джойстик **должен** оставаться активным в процессе настройки.
4. После активации нужного джойстика откройте инструмент электронного сервиса JOYSTICKCONFIG-SERVICE.
5. Выберите порт COM из выпадающего меню (2), которое идентифицирует порт COM с подключенным адаптерным кабелем. Подождите, пока порт COM будет идентифицирован и подключен. Как правило, инструмент будет автоматически искать и подключаться к TIM и активированному джойстику.

### Подключай

Версия 2 и более старый инструмент конфигурации

Каждая станция управления рычагом и бортовой джойстик в сети контроллера (CAN) имеет идентификационный номер устройства. Это также можно назвать идентификатором ручки. Используйте следующую процедуру, если необходимо идентифицировать идентификатор ручки для конкретной станции управления рычагом или бортового джойстика.[[326-015-054 — Vessel Configuration|См. процедуру 015-054 в разделе 15.]]

Чтобы установить связь с бортовым джойстиком в системе бортового джойстика Cummins®, сделайте следующее:

1. Нажмите кнопку «Поиск идентификаторов Joystick» (4).
2. Откроется всплывающее окно, уведомляющее пользователя о том, что обнаружение джойстика может занять до 15 секунд. Нажмите OK.
3. Откроется всплывающая коробка, отображающая количество встроенных джойстиков, обнаруженных в бортовой системе джойстиков. Нажмите OK.
4. Используйте раскрывающееся меню (5) для выбора соответствующего идентификационного номера бортового джойстика.
5. Откроется всплывающее окно, в котором говорится, что порт COM был успешно открыт. Нажмите OK.
6. Нажмите на кнопку «Определить джойстик» (6), чтобы проверить связь между инструментом и бортовым джойстиком. После нажатия кнопки встроенные джойстики светодиодных фонарей будут мигать по кругу в течение 30 секунд.

![[15900119.png]]

Версия 3 и более мощный инструмент конфигурации

Выпущена новая версия джойстика и рычагов управления. Унаследованное программное обеспечение для джойстика 2, а станция управления рычагом 3. Существующее программное обеспечение для джойстика версии 3 и выше, а станция управления рычагом версии 4. Каждая станция управления и джойстик больше не будут предварительно настроены с идентификаторами станции. Станция управления 4 и джойстик версии 3 и выше будут идентифицированы как ID станции 1. Используйте следующую процедуру — идентификатор ручки для конкретной станции управления рычагом или бортового джойстика, который должен быть идентифицирован.[[326-015-054 — Vessel Configuration|См. процедуру 015-054 в разделе 15.]]

Для установления связи с бортовым джойстиком в системе бортового джойстика Cummins® выполните следующее:

1. Выберите нужный джойстик из выпадающего меню «Выберите джойстик».
2. Версия Cummins® Thruster Interface Module (TIM) будет отображаться зеленым цветом при успешном подключении.
3. Версия джойстика и идентификационный номер будут отображаться зеленым цветом при успешном подключении.
4. Выберите кнопку «Определить джойстик» (6) для проверки соединения между инструментом и бортовым джойстиком. После выбора кнопки встроенный джойстик светодиодные фонари будут мигать по кругу в течение 30 секунд.

### Читать

Версия 2 и более старый инструмент конфигурации

Имя файла и параметры в файле личности могут быть прочитаны из файла личности, расположенного на ноутбуке Cummins® или в бортовом джойстике. Эта информация может быть полезна для целей проверки.

Чтобы прочитать параметры для файла личности, установленного в бортовом джойстике, сделайте следующее:

1. Выберите нужный бортовой джойстик.
2. Нажмите «Прочитать все параметры джойстика» (1).
3. Появится всплывающее окно, показывающее, что чтение данных было успешным. Всплывающее окно (3) также отображает пересмотр программного обеспечения, пересмотр оборудования и идентификатор файла параметров для встроенного джойстика. Нажмите OK.

> [!note] Примечание
> Запишите идентификатор файла параметра, чтобы его можно было использовать при передаче файла на ноутбук Cummins®.

После пропоказаний данных к ним можно получить доступ, нажав несколько кнопок на правой стороне экрана (2).

Используйте следующую процедуру, чтобы найти и выбрать персоналию судна.[[326-015-044 — Managing Vessel Personalities|См. процедуру 015-044 в разделе 15.]]

Функция кнопки Thruster позволит пользователю выбрать тип Joystick и связанный идентификатор.

- Тип джойстика позволяет пользователю выбрать, является ли джойстик автономным блоком или связанным блоком. Если джойстик является «стоянкой в одиночестве», он находится не рядом с рычажной станцией управления, а расположен у собственного руля. Если джойстик связан, он находится рядом с рычажной станцией управления на том же штурвале. Если версия 3 и более джойстик и станция управления версии 4 соединены вместе, можно использовать Transparent Transfer. По умолчанию устанавливается тип джойстика.
- Выпадающий ящик Associated ID позволяет выбрать станцию управления рычагом, с которой связан джойстик. Джойстик может быть связан только с станцией управления рычагом, если они находятся на одной и той же станции руля. Для правильной работы идентификатора ручки джойстика **должен быть установлен на идентификатор ручки станции управления рычагом на том же руле. Если джойстик находится на своем собственном специальном шлеме, выпадающий ящик Associated Handle ID будет выселен и **не выбирается.
- Прозрачная передача позволяет пользователю взять под контроль джойстик или головку управления движением или либо рычаги управления (глава управления) или движение джойстика. Эта функция позволит джойстику быть доступным для работы всякий раз, когда головка управления находится в нейтральном положении. Для использования функции «Прозрачный перенос» джойстик и головка управления должны быть соединены вместе. Для получения дополнительной информации используйте следующую процедуру.[[326-015-178 — Transparent Transfer|См. процедуру 015-178 в разделе 15.]]

Чтобы соединить джойстик и управлять головной станцией, выполните следующее:

1. Выключи двигатель. Убедитесь, что система ETS/CIJ включена.
2. Переместить джойстик в полное обратное положение.
3. Выберите следующие кнопки в указанной последовательности. Эти три варианта кнопок должны быть завершены в течение 5 секунд.
4. Когда этап 3 будет завершен, сигнал тревоги и системный свет будет мигать со скоростью 2 Гц (2 мига / секунда).
5. У пользователя будет 10 секунд, чтобы завершить процесс сопряжения с этого времени.
6. Нажмите и отпустите кнопку ACTIVE/TAKE на головке управления.
7. Когда процесс сопряжения завершается нажатием/освобождением кнопки ACTIVE/TAKE, головка управления и джойстик подтвердят сопряжение быстро мигающими (пять раз) светодиодами Joystick Activation/Station Select на джойстике и головке управления.

### передача

Версия 2 и более старый инструмент конфигурации

Выберите «Передача данных» (8) на главном экране. Откроется экран передачи данных.

Существует три возможных способа передачи данных личных файлов.

1. Перенос с джойстика на компьютер
2. Перенос с компьютера на джойстик
3. Перенос из джойстика в джойстик.

Передача данных — это всегда процесс, состоящий из двух шагов.

Используйте следующую процедуру, если необходимо идентифицировать идентификатор ручки для конкретной станции управления рычагом или бортового джойстика.[[326-015-054 — Vessel Configuration|См. процедуру 015-054 в разделе 15.]]

Чтобы перейти с джойстика на компьютер, сделайте следующее:

1. Нажмите «Читать настройки от JS до локального хранилища инструментов».
2. Откроется новое окно. Используйте раскрывающееся меню, чтобы выбрать подходящий идентификационный номер бортового джойстика. Нажмите OK. Запишите идентификатор файла параметра
3. Нажмите «Сохранить настройки из локального хранилища инструментов для файла». Сохраните файл на компьютере с расширением a.jst. Важно назвать файл с тем же идентификатором файла параметра, который был записан при чтении файла с джойстика.

Используйте следующую процедуру для получения подробной информации об управлении персоналом судна.[[326-015-044 — Managing Vessel Personalities|См. процедуру 015-044 в разделе 15.]]

![[15900106.png]]

Чтобы перевести с компьютера на джойстик, сделайте следующее:

1. Нажмите «Читать настройки из файла в инструмент локального хранения».
2. Откроется окно, позволяющее выбрать файл личности, хранящийся на компьютере или внешнем большом диске. Выберите файл.
3. Нажмите «Настройки для JS из локального хранилища инструментов».
4. Откроется новое окно. Используйте раскрывающееся меню, чтобы выбрать подходящий идентификационный номер бортового джойстика. Нажмите OK.

1. Нажмите «Читать настройки из JS в локальное хранилище инструментов».
2. Откроется новое окно. Используйте раскрывающееся меню, чтобы выбрать подходящий идентификационный номер бортового джойстика. Нажмите OK.
3. Нажмите «Настройки для JS из локального хранилища инструментов».
4. Откроется новое окно. Используйте раскрывающееся меню, чтобы выбрать подходящий идентификационный номер бортового джойстика. Нажмите OK.

1. Используйте раскрывающееся меню «Joystick ID», чтобы выбрать соответствующий идентификационный номер бортового джойстика.

4. Нажмите «Сохранить».

### Завершающие операции

Чтобы отключить электронный инструмент обслуживания от бортовой системы джойстика Cummins®, сделайте следующее:

1. Нажмите кнопку «Закрыть порт Comm» и закройте инструмент электронного сервиса.
2. Поверните переключатель зажигания, который приводит в действие электронный дросселирующий сдвиг Cummins® и бортовую систему джойстика Cummins® в положение OFF.
3. Удалите адаптерный кабель. Убедитесь, что порт инструмента для обслуживания правильно запечатан, установив соответствующий колпачок.

1. Поверните переключатель зажигания, который приводит в действие электронный дросселирующий сдвиг Cummins® и бортовую систему джойстика Cummins® в положение выключения.
