| **Tool Number** ST-1111-3 | **Manometer** Used to measure fuel drain line restriction. |  |
|---|---|---|
| **Tool Number** ST-998 | **Sight Glass** Used to check for air in fuel suction line. Use Part Number ST-998 with Number 10 hose. |  |
| **Tool Number** 3164001 | **Injector Leak Test Kit** Used in conjunction with a manometer (ST1111-3) to test injectors for leaks that cause an engine to exhibit slow shutdown or excessive run-on after a Key OFF condition. |  |
| **Tool Number** 3376807 | **Filter Wrench** Used to remove or tighten spin-on fuel filters. |  |
| **Tool Number** 3823461 | **Chip Removing Unit** Used to remove carbon from the top of the piston. |  |
| **Tool Number** 3824645 | **Pressure/Vacuum Module** Used with 3377161 Digital Multimeter or 3824648 Automotive Meter. The pressure transducer range is 500 psi and the vacuum range is 29.92 in Hg. |  |
| **Tool Number** 3164197 | **Injector Seal Replacer Kit** The injector seal replacer kit, Part Number 3164197, is used to replace the oil seal on the injector for Signature™, ISX, and QSX15 Engines. |  |
