| **Tool Number** 5573072 | **Marked Socket** Used to tighten the main bearing capscrews and cylinder head capscrews. Part Number 3163059 is a 3/4 inch impact wrench with ample range to tighten bolts. |  |

| **Tool Number** 3163069 | **Injector Cam and Valve Gear Puller** Used to pull the cam gear. The puller will only work on camshaft gears with puller holes. |  |
| **Tool Number** 3162464 | **Mounting Plate** Used with either Part Number 3375193 or Part Number 3375194 engine stand. |  |
| **Tool Number** 3163483 | **Injector Installation and Removal Tool** Used to remove and install injectors. |  |
| **Tool Number** 3163826 | **Thick Wear Sleeve/Wet Flywheel Housing Oil Seal Installation and Removal Tool** Used to remove and install the wear sleeve and wet flywheel housing oil seal on QSX15 engines. |  |
| **Tool Number** 4918530 | **Crankshaft Adapter and Gear Removal Kit** Used to remove and install the crankshaft adapter and crankshaft gear. |  |
| **Tool Number** 4918675 | **Loctite™ 518 Flexible Anerobic Gasket Sealant (Color Red)** Used to seal the main bearing cap to the mating surface of the cylinder block. |  |
| **Tool Number** 4918874 | **Protective Plug** Used to plug the front oil passage of the cylinder block during a repair process. For use on engines built after August 2006. |  |
| **Tool Number** 4918875 | **Protective Plug** Used to plug the rear oil passage of the cylinder block during a repair process. For use on engines built after August 2006. |  |

| **Tool Number** 3163901 | **Tap** Used to salvage/repair damaged cylinder head capscrew threads in the cylinder block. Used with Part Number 3164021 Thread Salvage Kit. |  |

The kit is used with the Counterbore cutter driver, Part Number 3163785 and any engine-specific counterbore cutter kit that uses Part Number 3163785. |  |
