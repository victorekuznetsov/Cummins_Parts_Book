### Снятие

> [!danger] ОПАСНО
> Датчик давления масла предварительного фильтра вводится в контрольный клапан. Если датчик изменяется во время работы двигателя, контрольный клапан должен оставаться на месте. Чтобы уменьшить вероятность получения травм и повреждения двигателя, не снимайте контрольный клапан во время работы двигателя.

Устраните винт разъема C Command Elite Plus с проводкой предварительного фильтра масла.

Удалите разъем C Command Elite Plus с проводкой предварительного фильтра для датчика давления масла.

Удалите датчик давления масла предварительного фильтра из контрольного клапана, повернув датчик давления предварительного фильтра ** против часовой стрелки ** с помощью гаечного ключа.

![[19600976.png]]

### Установка

Установите датчик давления масла предварительного фильтра в контрольный клапан, повернув датчик давления ** по часовой стрелке **.

![[19600976.png]]

Установите соединительный гай и затяните.

Если разъем проводов C Command Elite Plus ** не** выровнен, выполните следующие действия:

- Удалите орех
- Расширьте разъем из корпуса и выровните разъем с разъемом C Command Elite Plus.
- Установите и затяните соединительный орех.

Установите разъем C Command Elite Plus.

Затягивайте винт разъема C Command Elite Plus.

> [!quote]- Original (English) · английский оригинал
> ### Remove
>
> **WARNING · Опасно**
> The pre-filter oil pressure sensor is threaded into a check valve. If the sensor is changed while the engine is running the check valve must remain in place. To reduce the possibility of personal injury and engine damage do not remove the check valve while engine is running.
>
> Loosen the C Command Elite Plus harness pre-filter oil pressure sensor connector screw.
>
> Remove the C Command Elite Plus harness pre-filter oil pressure sensor connector.
>
> Remove the pre-filter oil pressure sensor from the check valve by turning the pre-filter pressure sensor **counterclockwise** with a wrench.
>
> ### Install
>
> Install the pre-filter oil pressure sensor into the check valve by turning the pressure sensor **clockwise**.
>
> Install the connector nut and tighten.
>
> If the C Command Elite Plus harness connector is **not** aligned, perform the following steps:
>
> - Remove the nut
> - Extend the connector out of the housing and align the connector with the C Command Elite Plus harness connector
> - Install and tighten the connector nut.
>
> Install the C Command Elite Plus harness connector cap.
>
> Tighten the C Command Elite Plus harness connector screw.
