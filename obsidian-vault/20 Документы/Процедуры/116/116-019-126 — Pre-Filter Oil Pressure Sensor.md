# Pre-Filter Oil Pressure Sensor
**Датчик давления масла до фильтра**

### Remove

> [!danger] WARNING · Опасно
> The pre-filter oil pressure sensor is threaded into a check valve. If the sensor is changed while the engine is running the check valve must remain in place. To reduce the possibility of personal injury and engine damage do not remove the check valve while engine is running.

Loosen the C Command Elite Plus harness pre-filter oil pressure sensor connector screw.

Remove the C Command Elite Plus harness pre-filter oil pressure sensor connector.

Remove the pre-filter oil pressure sensor from the check valve by turning the pre-filter pressure sensor **counterclockwise** with a wrench.

![[19600976.png]]

### Install

Install the pre-filter oil pressure sensor into the check valve by turning the pressure sensor **clockwise**.

![[19600976.png]]

Install the connector nut and tighten.

If the C Command Elite Plus harness connector is **not** aligned, perform the following steps:

- Remove the nut
- Extend the connector out of the housing and align the connector with the C Command Elite Plus harness connector
- Install and tighten the connector nut.

Install the C Command Elite Plus harness connector cap.

Tighten the C Command Elite Plus harness connector screw.
