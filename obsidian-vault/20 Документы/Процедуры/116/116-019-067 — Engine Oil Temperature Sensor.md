### Снятие

> [!warning] ОСТОРОЖНО
> Не снимайте температурный кожух моторного масла. Если температура масла удаляется, моторное масло будет стекать.

Датчик температуры моторного масла расположен в сухом корпусе скважины, который втиснут в масляную кастрюлю.

Устраните винт разъема C Command Elite Plus для проводов ремня температуры масла двигателя.

Удалите разъем C Command Elite Plus с помощью датчика температуры масла двигателя.

![[19600974.png]]

Удалите гайку разъема и выполните монтаж разъема и датчика температуры из сухого корпуса скважины.

![[19600975.png]]

### Установка

Скользите датчик температуры и соединительный узел в сухой корпус скважины.

![[19600975.png]]

Установите соединительный гай и затяните.

Установите разъем C Command Elite Plus.

Затягивайте винт разъема C Command Elite Plus.

![[19600974.png]]


> [!quote]- Original (English) · английский оригинал
> ### Remove
>
> **CAUTION · Осторожно**
> Do not remove the engine oil temperature housing. If the oil temperature housing is removed the engine oil will drain.
>
> The engine oil temperature sensor is located in a dry well housing which is threaded into the oil pan.
>
> Loosen the C Command Elite Plus harness engine oil temperature sensor connector screw.
>
> Remove the C Command Elite Plus harness engine oil temperature sensor connector.
>
> Remove the connector nut and slide the connector and temperature sensor assembly out of the dry well housing.
>
> ### Install
>
> Slide the temperature sensor and connector assembly into the dry well housing.
>
> Install the connector nut and tighten.
>
> Install the C Command Elite Plus Harness connector cap.
>
> Tighten the C Command Elite Plus harness connector screw.
