### ECM Dataplate

Внешний электронный модуль управления (ECM) расположен на передней панели ECM и содержит следующую информацию:

- P/N - номер детали ECM
- S/N - серийный номер ECM
- D/C - Дата кода (дата изготовления ECM)
- ESN - серийный номер двигателя
- ECM CODE - идентификатор калибровки ECM.

> [!quote]- Original (English) · английский оригинал
> ### ECM Dataplate
>
> The external electronic control module (ECM) dataplate is located on the front of the ECM and contains the following information:
>
> - P/N - ECM part number
> - S/N - ECM serial number
> - D/C - Date code (the date the ECM was manufactured)
> - ESN - Engine serial number
> - ECM CODE - The ECM calibration identifier.
