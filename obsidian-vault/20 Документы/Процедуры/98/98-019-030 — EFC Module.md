# EFC Module

### General Information

The electronic fuel control (EFC) module contains the EFC actuator valve. The module is mounted directly on top of the modified PT® fuel pump.

![[19801556.png]]

### Inspect for Reuse

Inspect the mounting bore of the EFC in the CENTRY™ module for damage, which can cause leakage. Inspect for debris in the mounting bore.

If damage or debris exists, clean or replace the EFC module.

![[19801971.png]]

### Remove

> [!note] Note · Примечание
> The module does **not** have to be removed to remove the valve unless the valve is stuck in the module or there is **not** enough room to pull the valve out of the engine. To remove the EFC valve, refer to Procedure 019-102.

Disconnect the electrical leads from the valve.

![[19801959.png]]

Remove the main engine harness hold-down clamp from the side of the engine block.

![[19801922.png]]

> [!warning] CAUTION · Осторожно
> Do not overtwist, bend, or pull on the main engine harness.

Remove the ECM. Refer to Procedure [[98-019-031 — Engine Control Module|019-031]].

![[19801900.png]]

Remove the two ECM harness connector capscrews from the ECM unit.

![[19801896.png]]

Disconnect the fuel tubing from the fuel shutoff valve.

Disconnect the voltage supply wire from the fuel shutoff solenoid.

![[19801965.png]]

> [!note] Note · Примечание
> On some engine configurations, it will **not** be necessary to remove the fuel shutoff valve from the EFC module in order to remove the module.

Remove the two capscrews, lockwashers, and flat washers securing the fuel shutoff valve to the EFC module.

Remove the fuel shutoff valve from the EFC module.

![[19801966.png]]

Remove the two mounting capscrews securing the EFC module to the PT fuel pump.

Remove the EFC module.

![[19801967.png]]

### Install

Check to make sure the replacement module does have an EFC bypass plug installed.

![[19801986.png]]

If necessary, install the gasket and EFC bypass plug into the module. Tighten the plug.

> [!tip] Момент затяжки · Torque Value
> 1.0 n•m [9 in-lb]

Insert the rectangular seal into the bottom of the module.

![[19801987.png]]

Install the EFC valve into the module. Refer to Procedure [[98-019-102 — Fuel Control Valve|019-102]].

Install the module onto the PT fuel pump and tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 16 n•m [142 in-lb]

![[19801967.png]]

Install the fuel shutoff solenoid and tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 14 n•m [124 in-lb]

![[19801966.png]]

Connect the fuel tubing to the fuel shutoff valve.

Connect the electrical connections on the fuel shutoff solenoid.

![[19801965.png]]

> [!warning] CAUTION · Осторожно
> Do not overtighten the connector capscrews; this can cause the capscrews to break and damage the ECM.

Install the ECM harness connector to the ECM unit. Refer to Procedure [[98-019-031 — Engine Control Module|019-031]].

![[19801896.png]]

> [!warning] CAUTION · Осторожно
> Do not overtwist, bend, or pull on the main engine harness; this can cause damage to the connector pins and the ECM.

Install the ECM. Refer to Procedure [[98-019-031 — Engine Control Module|019-031]].

![[19801900.png]]

Install the hold-down clamp securing the main engine harness to the side of the engine block.

![[19801922.png]]

Connect the electrical leads to the EFC valve.

![[19801959.png]]
