### General Information

The crankshaft is a balanced, forged-steel unit. Four-cylinder engines have five main bearings. Six-cylinder engines have seven main bearings. The lower bearing shells are all the same. All of the upper bearing shells are also the same with the exception of the journal adjacent to the rear one. The next to last journal is fitted with a flanged upper bearing shell. The flanges control the end thrust of the crankshaft.

![[ks900gl.png]]

The crankshaft uses forged counterweights.

Oversize main bearings and thrust bearings are available for service. Cummins Inc., recommends regrinding **all** of the main or the connecting rod journals when one requires regrinding. Refer to the B Series Shop Manual, Bulletin 3666017.

Refer to Procedure [[40-001-052-tr — Vibration Damper, Viscous|001-052]].

![[da9puma.png]]

Remove the front gear cover.

Refer to Procedure 001-031.

![[gc9hshb.png]]

Remove the lubricating oil pan.

Refer to Procedure 007-025.

### Remove

> [!danger] WARNING · Опасно
> This component weighs 23 kg \[50 lb\] or more. To reduce the possibility of personal injury, use a hoist or get assistance to lift this component.

> [!note] Note · Примечание
> Lift the crankshaft straight up to reduce the possibility of damage to the crankshaft and cylinder block.

Install nylon lift sling, Part Number 3375957, around the Number 3 and Number 4 rod bearing journals.

Attach the sling to a hoist, remove the crankshaft.

![[ks900ma.png]]

### Clean

Use fine crocus cloth to polish the machined surfaces.

Use a bristle brush to clean the oil drillings.

![[ks200ec.png]]

### Inspect for Reuse

Inspect the threaded capscrew holes for damage.

Use one of the following methods to repair any threaded holes:

- Chase the threads
- Use the threaded insert kit, Part Number 3822709.

> [!note] Note · Примечание
> If more than two threaded holes are damaged in one end, the crankshaft **must** be replaced.

![[ks900sf.png]]

Measure the front and rear oil seal contact areas for a wear groove.

### Install

Use a light preservative oil to lubricate the crankshaft to prevent rust.

> [!note] Note · Примечание
> If the crankshaft is **not** going to be used immediately, protect the part with a plastic cover to prevent dirt from sticking to the oil.

![[ks200wb.png]]

Install the upper main bearings.

Refer to Procedure [[40-001-006 — Bearings, Main|001-006]].

![[mb900wb.png]]

Install the upper thrust bearing.

Refer to Procedure [[40-001-006 — Bearings, Main|001-006]].

![[mb9bemf.png]]

> [!danger] WARNING · Опасно
> This component weighs 23 kg \[50 lb\] or more. To reduce the possibility of personal injury, use a hoist or get assistance to lift this component.

Use a hoist and nylon lift sling, Part Number 3375957.

Install the sling around the Number 3 and Number 4 connecting rod bearing journals.

Install the crankshaft.

![[ks900ma.png]]

Install the lower main bearing.

Refer to Procedure [[40-001-006 — Bearings, Main|001-006]].

![[01900183.png]]

> [!note] Note · Примечание
> The main bearing caps are numbered for location. Number 1 starts with the front of the cylinder block and the numbers **must** face the camshaft side of the engine.

When installed correctly, the main bearing tangs should both be on the same side.

![[mb900hb.png]]

Position the main bearings and main bearing caps onto the crankshaft.

![[mb900hc.png]]

The thrust bearing journal does **not** have tangs or slots. Care **must** be taken to make sure the number stamped on the main bearing cap is positioned to the camshaft side of the engine.

![[mb900sa.png]]

Lubricate the main bearing capscrew threads and underside of the capscrew head with clean lubricating engine oil.

![[mb9cswa.png]]

Tap the main bearing cap gently into position.

> [!note] Note · Примечание
> Make sure the main bearing is still aligned with the cap.

When seated, the main bearing capscrews can be threaded in by hand.

![[mb900ha.png]]

Tighten the main bearing capscrews evenly following the illustrated sequence.

| **Torque Value:** | Step 1 | 60 n.m \[44 ft-lb\] |
|---|---|---|

|  | Step 2 | 90 n.m \[66 ft-lb\] |
|---|---|---|

|  | Step 3 | Turn clockwise 90 degrees |
|---|---|---|

![[mb9csha.png]]

> [!note] Note · Примечание
> The crankshaft **must** rotate freely after the main bearings have been installed.

Inspect the main bearing installations and the size of the main bearings if the crankshaft will **not** rotate freely.

![[ks900se.png]]

### Rotation Check

Barring Tool, Part Number 3824591

The barring tool inserts into the flywheel housing and engages the flywheel ring gear. The crankshaft can then be rotated by hand using a 1/2-inch-drive ratchet or breaker bar.
