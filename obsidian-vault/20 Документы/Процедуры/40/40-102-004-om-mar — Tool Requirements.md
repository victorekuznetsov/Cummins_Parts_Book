### Общие сведения

Большинство операций по техническому обслуживанию, описанных в этом руководстве, могут выполняться с помощью обычной ручной оснастки (метрической и S.A.E.). гаечные ключи, розетки и отвертки.

Ниже приведен список специальных инструментов обслуживания, необходимых для некоторых операций по техническому обслуживанию:

| Инструмент Часть Номер | Наименование |
|---|---|
| 3375045 | Зубной ключ 136 Н•м \[100 футов-лб\] |
| Локально полученный | Силиконовый смазочный баллончик |
| Локально полученный | Брасс-стержнь, 4,76 мм \[3/16 в\] диаметр |
| CC-2602J | Испытательный комплект Fleetguard DCA4 |
| CC-2802 | Измерительный комплект с охлаждающим покрытием |
| 3824591 | Шестерня валоповоротного устройства |
| 3375049 | Фильтр маслом гаечный ключ |
| 3824556 | Напорный кулер (CAC) |
| 3376807 | Охладитель двигателя и гаечный ключ топливного фильтра |
| 3822524 | Измеритель напряжения ремня, тип щелчка (v-ремни и v-риббированные с четырьмя или пятью ребрами) |
| 3822525 | Измеритель напряжения ремня, тип щелчка (v-риббированный с шестью-двенадцатью ребрами) |

Свяжитесь с ближайшим авторизованным ремонтным центром Cummins® для получения необходимых инструментов обслуживания.
