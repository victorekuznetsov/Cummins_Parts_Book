# Aftertreatment Diesel Exhaust Fluid Dosing Unit Pressure Relief Valve

> [!abstract] Процедура · `00-011-151`
> **Входит в руководства:** [[5411181 — X15 CM2350 X114B - Efficiency Series Service Manual|5411181]]
> **Секции:** Section 11 - Exhaust System
> **Даты:** изменён 2019-04-25
> **Источник:** [QuickServe](https://quickserve.cummins.com/qs3/pubsys2/xml/en/procedures/00/00-011-151.html) · [PDF-оригинал](https://github.com/victorekuznetsov/Cummins_Parts_Book/raw/main/bulletins/procedures/00-011-151.pdf)

### Select Service Tools

#### Recommended Cummins® Service Tools

- No Cummins® service tools required.

#### Additional Service Items

- No additional service items required.

### Remove

Remove and discard the plug.

Remove and discard the o-ring.

![[11400345.png]]

Use the threaded end of the tool and carefully screw into the pressure relief valve. The tool is included in the tool kit.

Pull out the pressure relief valve by hand.

Discard the pressure relief valve.

![[11400346.png]]

### Install

> [!note] Note · Примечание
> Make sure the aftertreatment diesel exhaust fluid (DEF) dosing unit remains free from contamination during installation to the vehicle. To reduce the possibility of false DEF leak reports, use a clean, damp cloth to wipe away any DEF that spilled during the repair process.

Use the opposite (non-threaded) end of the tool and push in the new pressure relief valve in fully.

> [!note] Note · Примечание
> Do **not** use the threaded end of the tool as it can damage the pressure relief valve.

![[11400347.png]]

Insert the new plug and o-ring. Tighten.

> [!tip] Момент затяжки · Torque Value
> 5 n•m [44 in-lb]

![[11400345.png]]

### Finishing Steps

Clean all DEF deposits from the dosing unit before installing back on the unit.

Operate the engine and check for leaks.
