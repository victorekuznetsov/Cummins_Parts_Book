### Контроль при обслуживании

Если они оборудованы, слейте бутылку и правильно утилизируйте содержимое.

Осмотрите выпускную трубку капкан-дыша для следующих условий, которые могут блокировать или ограничивать трубку капкан-дыша.

> [!note] Примечание
> Если в конце трубки для дышащего чемодана имеется бутылка для ловли, то для осмотра розетки для дышащего чемодана может потребоваться удаление бутылки для ловли.

- шлам
- Обломки
- Лед.

Если существует какое-либо из вышеперечисленных условий, розетка дыхательной трубки из картерного клапана ** должна быть очищена.

Проверяйте выход из трубки капкан-дыша чаще, когда температура окружающей среды ниже нуля. Частые накопления льда в трубке капельницы могут потребовать одного из следующих действий.

- Устанавливается вариант трубки для нагревания капельной заслонки.
- Если нагреватель дыхательной трубки для капканов уже установлен, устраните неисправность нагревателя дыхательной трубки для капканов, чтобы он не работал.

Обратитесь в авторизованный сервисный центр Cummins®.

![[10200085.png]]

> [!warning] ОСТОРОЖНО
> Если установлен вариант нагревателя трубки для дыхательных путей из картера, нагреватель для дыхательных путей из картера должен быть удален до погружения трубки для дыхательных путей из картера в воду и/или раствор для очистки. В результате повреждается трубка для нагревания капельницы.

Очистите выход из трубки капкан-духовника моющим средством и теплой водой.

Если оборудован, очистите затворную бутылку для захвата. Используйте моющие средства и теплую воду.

Если для выхода из трубки капкан-духовка требуется очистка, может потребоваться удаление трубки-духовки. Если требуется удаление, обратитесь в авторизованное место ремонта Cummins®.

![[03d00017.png]]

Визуально осмотрите трубку капельницы для дыхания для следующих условий.

- Трещины
- Материалы ухудшения состояния
- Общий ущерб.

Если существует какое-либо из вышеперечисленных условий, замените трубку капельницы. Обратитесь в авторизованный сервисный центр Cummins®.

Если они оборудованы, проверьте бутылку для захвата капельницы для следующих условий.

- Трещины
- дыры
- Общий ущерб.

Если обнаружено какое-либо из вышеперечисленных условий, замените бутылку для захвата трубки для капканов. Обратитесь в авторизованный сервисный центр Cummins®.

![[03900083.png]]


> [!quote]- Original (English) · английский оригинал
> ### Maintenance Check
>
> If equipped, drain the catch bottle and properly dispose of contents
>
> Inspect the crankcase breather tube outlet for the following conditions that may be blocking or restricting the crankcase breather tube.
>
> **Note · Примечание**
> If equipped with a catch bottle at the end of the crankcase breather tube, removal of the catch bottle may be required to inspect the crankcase breather tube outlet.
>
> - Sludge
> - Debris
> - Ice.
>
> If any of the above conditions exist, the crankcase breather tube outlet **must** be cleaned.
>
> Inspect the crankcase breather tube outlet more frequently when ambient temperatures are below freezing. Frequent ice build up in the crankcase breather tube may require one of the following actions.
>
> - A crankcase breather tube heater option be installed.
> - If a crankcase breather tube heater is already installed, troubleshoot the crankcase breather tube heater for not operating.
>
> Contact a Cummins® Authorized Repair Location.
>
> **CAUTION · Осторожно**
> If a crankcase breather tube heater option is installed, the crankcase breather heater must be removed prior to submerging the crankcase breather tube in water and/or cleaning solution. Damage to the crankcase breather tube heater will result.
>
> Clean the crankcase breather tube outlet with detergent and warm water.
>
> If equipped, clean the crankcase breather catch bottle. Use detergent and warm water.
>
> If more than the crankcase breather tube outlet requires cleaning, removal of the crankcase breather tube may be required. If removal is required, contact a Cummins® Authorized Repair Location.
>
> Visually inspect the crankcase breather tube for the following conditions.
>
> - Cracks
> - Material deterioration
> - General damage.
>
> If any of the above conditions are exist, replace the crankcase breather tube. Contact a Cummins® Authorized Repair Location.
>
> If equipped, inspect the crankcase breather catch bottle for the following conditions.
>
> - Cracks
> - Holes
> - General damage.
>
> If any of the above conditions are found, replace the crankcase breather tube catch bottle. Contact a Cummins® Authorized Repair Location.
