### General Information

Most of the maintenance operations described in this manual can be performed with common hand tools (metric and SAE wrenches, sockets, and screwdrivers).

The following is a list of special service tools required for some maintenance operations:

| Tool Part Number | Description |
|---|---|
| ST-1293 | Belt Tension Gauge (V-Belts) |
| 3400157 | Oil Filter Wrench (Band Type), Filter Diameter 118 to 130 mm \[4.7-5.12 in\] |
| 3400158 | Water, Fuel, Oil Filter Wrench (Strap Type), Filter Diameter up to 152 mm \[6.0 in\] |
| 3822524 | Belt Tension Gauge (Click Type) 63-203 N•m \[50-150 ft-lb\] |
| 3822525 | Belt Tension Gauge (Click Type) 136-407 N•m \[100-300 ft-lb\] |
| 3164795 | Torque Wrench (Dial Type) 0-34 N•m \[0-300 in-lb\] |
| 3824901 | Valve Lash Gauge Kit |
| 3164794 | Torque Wrench (Click Type) 14-136 N•m \[10-100 ft-lb\] |
| CC2602 | Fleetguard Coolant Test Kit |
| CC2800 | Fleetguard Battery Refractometer |
| 4918282 | Cylinder Head Protective Cover |

- Refer to the appropriate sections for a description of the tools and how to use them.
- Contact your nearest Cummins Authorized Repair Location for the required service tools.
