### Install

Wet Flywheel Housing

Install a new o-ring on the seal housing.

Use vegetable oil to lubricate the o-ring.

![[01400067.png]]

Apply a small amount of Lubriplate™ 105, Part Number 3163086, or equivelant, to the inside diameter of the oil seal.

> [!warning] CAUTION · Осторожно
> Do not allow oil to come in contact with other areas of the seal to avoid damage to the sealing surfaces.

![[01f00001.png]]

Use the pin supplied in the seal kit to align the seal mounting holes with the mounting capscrew holes in the flywheel housing.

Use hand pressure to push the seal onto the crankshaft as far as possible.

![[01400070.png]]

Use three flywheel mounting capscrews to attach the seal installation tool, Part Number 3824971, to the crankshaft.

![[01d00855.png]]

Tighten the three capscrews alternately and evenly in one-half of a turn increments until the seal carrier seats against the flywheel housing.

![[01400073.png]]

Remove the seal installation tool.

![[01d00855.png]]

Install the seal mounting capscrews. Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 11 n•m [97 in-lb]

![[01400075.png]]

Dry Flywheel Housing

Install the four socket head set screws. Place the seal on the socket head set screws and set the seal squarely against the crankshaft face, pushing **only** against the rubber face.

![[01400665.png]]

Set the blue colored plastic seal installation tool squarely against the seal face. Make certain that the raised portion of the rear installation tool is facing away from the flywheel housing and that the gray rubber sealing bead is facing toward the flywheel housing.

Place washers and nuts on the four socket head set screws and hand snug evenly.

![[01400666.png]]

Tighten the nuts in equal increments (about 2 turns per nut in a criss-cross pattern) until the seal flange contacts the flywheel housing. Install the four new capscrews, Part Number [[4922215]], and washers (use washers from the old seal capscrews) in the remaining holes and finger-tighten.

![[01400667.png]]

Tighten the four nuts, 1, 2, 3, and 4, against the installer tool in a criss-cross pattern.

> [!tip] Момент затяжки · Torque Value
> 11 n•m [97 in-lb]

Tighten the four capscrews, 5, 6, 7, and 8, Part Number [[4922215]], in a criss-cross pattern.

> [!tip] Момент затяжки · Torque Value
> 11 n•m [97 in-lb]

![[01400668.png]]

Remove the nuts, washers, plastic installation tool, and the four socket head set screws.

![[01400669.png]]

Install the remaining four new capscrews, Part Number [[4922215]], along with plain washers (use washers from the old seal capscrews). Tighten the capscrews in a crisscross pattern.

> [!tip] Момент затяжки · Torque Value
> 11 n•m [97 in-lb]
