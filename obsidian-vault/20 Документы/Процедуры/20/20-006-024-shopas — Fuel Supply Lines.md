### Install

with Mechanically Actuated Injector

Install new o-rings on the control valve body inlet fitting and fuel pump outlet fitting. Make sure the o-rings are installed properly.

![[06400031.png]]

Install and tighten the fuel control valve supply hose.

> [!tip] Момент затяжки · Torque Value
> 61 n•m [45 ft-lb]

![[06400048.png]]

Install new o-rings on the fuel pump inlet line fitting and fuel filter head outlet fitting. Make sure the o-rings are installed properly.

![[06400031.png]]

Install the hose at the fuel pump inlet and fuel filter head outlet fitting.

Tighten the hose.

> [!tip] Момент затяжки · Torque Value
> 88 n•m [65 ft-lb]

![[06400046.png]]

Install and tighten the fuel inlet line that connects the fuel tank to the fuel filter.

> [!tip] Момент затяжки · Torque Value
> 115 n•m [85 ft-lb]

![[19400315.png]]

Loosely assemble the fuel tubes and clamps for the fuel rail and timing lines.

![[06400042.png]]

It is a good service practice to use two wrenches when tightening the fuel fittings.

Support the fitting. Use a crowfoot wrench and a torque wrench to tighten the fuel tube nut.

> [!tip] Момент затяжки · Torque Value
> 27 n•m [20 ft-lb]

![[06400230.png]]

Tighten the fuel tube clamps.

> [!tip] Момент затяжки · Torque Value
> 27 n•m [20 ft-lb]

![[06400042.png]]

with Electronically Actuated Injector

Install the tee fitting in the top port of the fuel pump by first positioning the locknut.

1. Locknut
2. Washer
3. O-ring.

![[06400328.png]]

Install the tee fitting in the fuel pump port until the backup washer (1) contacts the port face.

![[06400329.png]]

Using two wrenches, hold the tee fitting in the desired position and tighten the locknut.

> [!tip] Момент затяжки · Torque Value
> 95 n•m [70 ft-lb]

![[06400330.png]]

Install the tee fitting in the port on the back of the fuel pump by first positioning the locknut.

1. Locknut
2. Washer
3. O-ring.

![[06400328.png]]

Install the tee fitting in the fuel pump port until the backup washer (1) contacts the port face.

![[06400332.png]]

Using two wrenches, hold the tee fitting in the desired position and tighten the locknut.

> [!tip] Момент затяжки · Torque Value
> 95 n•m [70 ft-lb]

![[06400333.png]]

Install new o-rings on the union and install the union in the port next to the inlet actuator.

> [!tip] Момент затяжки · Torque Value
> 95 n•m [70 ft-lb]

![[06400334.png]]

Install new o-rings on the union and install the union in the port on the back of the fuel pump.

> [!tip] Момент затяжки · Torque Value
> 72 n•m [53 ft-lb]

![[06400335.png]]

Install the fuel supply line (5) from the back of the fuel pump to the stage 2 fuel filter inlet.

> [!tip] Момент затяжки · Torque Value
> 54 n•m [40 ft-lb]

![[06400322.png]]

Install the fuel supply line (2) from the tee fitting on the back of the fuel pump to the union next to the fuel inlet actuator.

> [!tip] Момент затяжки · Torque Value
> 65 n•m [48 ft-lb]

![[06400320.png]]

Install the fuel supply line (1) from the second stage fuel filter to the tee fitting next to the inlet actuator.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[06400325.png]]

Install the fuel supply line (3) from the tee fitting next to the inlet actuator to the return manifold.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]
