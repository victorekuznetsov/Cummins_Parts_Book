![[05600304.png]]

QSK19 MCRS Marine Sea ProTM 5 Stage 1 Single Flow топливный фильтр

Фильтр 0 стадии - Морские приложения определяют основную систему фильтрации двигателя, которая поставляется заказчиком. Это первая система фильтрации после бака для хранения топлива, которая называется системой фильтрации 0-й стадии. Система фильтрации 0 стадии должна включать в себя водоотделитель и обычно использует больше носителей (10 микрон максимум) с большей емкостью по сравнению с системами фильтрации 1 стадии (7 микрон) и 2 стадии (3 микрон). Топливная центрифуга является распространенной приемлемой альтернативой фильтрующим средам для фильтрации на стадии 0.

1. Запуск топлива из фильтра 0 стадии
2. фильтр
3. Топливо от фильтра до коллектора
4. Отсасывание насоса лифта
5. Подъемный насос

7. Фильтровый выход к геротору

> Stage 0 Filter - Marine applications specifiy a primary, off engine filtration system that is supplied by the customer. This is the first filter system after the fuel storage tank and is referred to as the Stage 0 filtration system. The Stage 0 filter system **must** include a water separator and typically uses a more course media (10 micron maximum) with a larger capacity as compared to the Stage 1 (7 micron) and Stage 2 (3 micron) filter systems. A fuel centrifuge is a common accetable alternative to element type filter media for Stage 0 filtration.
