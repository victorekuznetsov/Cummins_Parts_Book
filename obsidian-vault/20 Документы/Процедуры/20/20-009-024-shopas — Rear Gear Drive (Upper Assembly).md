### Install

Use gasket adhesive on the gasket. Do **not** use an excessive amount of adhesive on the gasket.

Align and install the rear gear train upper housing gasket to the rear gear train lower housing.

![[hd4gkla.png]]

> [!danger] WARNING · Опасно
> This component or assembly weighs greater than 23 kg \[50 lb\]. To prevent serious personal injury, be sure to have assistance or use appropriate lifting equipment to lift this component or assembly.

> [!warning] CAUTION · Осторожно
> Use extra care when aligning the upper housing onto the lower housing to prevent gasket damage.

Use the dowel pins to align the upper housing onto the lower housing.

![[hd4hsva.png]]

Use **only** SAE Grade 8 capscrews to install the upper housing. Install the following capscrews according to the table below.

| Ref | Location | Part No. | Size \[Inch\] | Quantity |
|---|---|---|---|---|
| 1 | Top-Front | 3202224 | 1/2-13 x 9 1/4 | 2 |
| 2 | Top-Rear | 3202223 | 1/2-13 x 7 1/2 | 2 |
| 3 | Internal | 169195 | 1/2 -13 x 1 1/4 | 4 |
| 4 | Bottom-Left Side | [[3202222]] | 1/2-13 x 1 3/4 | 2 |
| 5 | Bottom-Right Side | [[3202222]] | 1/2-13 x 1 3/4 | 3 |

![[hd4csva.png]]

Use the sequence shown to tighten the capscrews.

| **Torque Value:** | Step 1 | 70 n.m \[50 ft-lb\] |
|---|---|---|

|  | Step 2 | 150 n.m \[110 ft-lb\] |
|---|---|---|

![[hd4csvb.png]]

Use a dial indicator. Be sure the lower idler gear is secure. If the gear is **not** secure, the indicator reading includes the lower idler gear to the crankshaft gear backlash.

Measure the backlash between the center drive gear and the lower idler gear.

| mm |  | in |
|---|---|---|
| 0.05 | MIN | 0.002 |
| 0.51 | MAX | 0.020 |

![[dr4geta.png]]

If the gear lash is less than the specified limits, thicker gaskets are available. Do **not** use more than two gaskets to correct the backlash.

If the gear lash is greater than the specification and the thinnest gasket is used, the upper and lower gears **must** be replaced.

![[hd4hsna.png]]

Install the outer hydraulic pump support drive.

Use Lubriplate® 105, or equivalent. Lubricate the outer hydraulic pump support bushings in the upper housing. Lubricate the bushing surfaces on both shafts in the outer hydraulic pump support drive assemblies.

![[hd4bsva.png]]

> [!note] Note · Примечание
> Some engines do **not** have an outer hydraulic pump support drive. These engines require a cover plate and a non-splined shaft, but do **not** use a hydraulic gear.

Use gasket adhesive sparingly. Install the hydraulic support housing gaskets on both support mounting flanges on the outer hydraulic pump support drive assemblies.

![[09400015.png]]

If using the outer hydraulic pump support cover plate, install the non-splined shaft onto the cover plate. Use a \[3/8-16 x 1-1/4 in\] capscrew.

> [!tip] Момент затяжки · Torque Value
> 40 n•m [30 ft-lb]

![[hd4cvwa.png]]

Use three \[7/16-14 x 4 inch\] guide studs. Install one outer hydraulic pump support drive assembly.

![[hd4piwa.png]]

Install four capscrews. Hand-tighten the capscrews. Remove the guide studs. Install the remaining three capscrews. Use the sequence and apply torque as shown.

> [!tip] Момент затяжки · Torque Value
> 70 n•m [50 ft-lb]

![[hd4csla.png]]
