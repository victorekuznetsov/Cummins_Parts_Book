> ### Cylinder Head
>
> | **Tool Number** 3824955 | **Cylinder Head Capscrew Length Gauge** Used to check the length of the cylinder head capscrews. |  |
> |---|---|---|
> | **Tool Number** ST-448 | **Valve Spring Compressor** Used to compress the valve spring to allow the valve to be removed or installed. |  |
> | **Tool Number** 3375960 | **Valve Spring Compressor** Used to compress the valve spring to allow the valve to be removed or installed. This tool is air-operated. |  |
> | **Tool Number** ST-1012 | **Hydrostatic Tester** Used to check for coolant leaks in the cylinder head. Requires shop air, a lifting hoist, a water tank, and the appropriate test adapter plate and o-ring. |  |
> | **Tool Number** 3375070 | **Water Test Plates** Used to check for coolant leaks in the cylinder head. Use with hydrostatic tester, Part Number ST-1012. Use with water test plate o-rings, Part Number 3375071. |  |
> | **Tool Number** 3823495 | **Depth Gauge Assembly** Used to measure cylinder liner counterbore ledge angle and injector protrusion. |  |
> | **Tool Number** ST-685 | **Valve Seat Grinding Machine** Used to grind the valve seats. |  |
> | **Tool Number** ST-1257 | **Valve Vacuum Tester** Used to test the valve to valve seat connection. |  |
> | **Tool Number** ST-1323-1 | **Exhaust Valve Seat Extractor** Used to remove the valve seats. |  |
> | **Tool Number** 3376799 | **Intake Valve Seat Extractor** Used to remove the valve seats. |  |
> | **Tool Number** 3375182 | **Valve Spring Tester** Used to test the valve springs. |  |
> | **Tool Number** 3375805 | **Valve Lapping Compound** An abrasive compound used to lap the valves. |  |
> | **Tool Number** 3824861 | **Valve Head Thickness Gauge** Used to check the intake and exhaust valve head thickness after reconditioning. |  |
> | **Tool Number** 3164341 | **Cylinder Head Leak Test Kit** Used to check for coolant passage leaks on the cylinder head. |  |
> | **Tool Number** 4918779 | **Drop Gauge** Used to check the valve guide for proper inside diameter and straightness. |  |
