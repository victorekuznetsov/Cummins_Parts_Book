### Remove

Rail Applications

> [!danger] WARNING · Опасно
> This component or assembly weighs greater than 23 kg \[50 lb\]. To prevent serious personal injury, be sure to have assistance or use appropriate lifting equipment to lift this component or assembly.

Intake Manifold - Remove

Remove the turbocharger drain line from the turbocharger.

![[17400018.png]]

Remove the turbocharger drain line from the scavenge cross.

Discard the face seal o-ring.

![[17400032.png]]

Loosen the hose clamp and remove the hose.

![[17400064.png]]

> [!danger] WARNING · Опасно
> This component or assembly weighs greater than 23 kg \[50 lb\]. To prevent serious personal injury, be sure to have assistance or use appropriate lifting equipment to lift this component or assembly.

Remove the 24 capscrews and intake manifold.

![[17400065.png]]

### Install

Rail Applications

> [!danger] WARNING · Опасно
> This component or assembly weighs greater than 23 kg \[50 lb\]. To prevent serious personal injury, be sure to have assistance or use appropriate lifting equipment to lift this component or assembly.

Intake Manifold - Install

Install the intake manifold and 24 capscrews. Tighten the 24 capscrews in the sequence shown.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [35 ft-lb]

![[xm400oa.png]]

Install the turbocharger drain line to the turbocharger.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [35 ft-lb]

![[17400018.png]]

Install the face seal o-ring.

Install the turbocharger drain line to scavenge cross.

> [!tip] Момент затяжки · Torque Value
> 80 n•m [60 ft-lb]

![[17400032.png]]

Install hose and tighten hose clamp.

> [!tip] Момент затяжки · Torque Value
> 8 n•m [75 in-lb]

![[17400064.png]]
