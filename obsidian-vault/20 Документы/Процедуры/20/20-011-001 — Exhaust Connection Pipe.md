# Exhaust Connection Pipe

### Preparatory Steps

Rail Applications

> [!danger] WARNING · Опасно
> Do not remove the pressure cap from a hot engine. Wait until the coolant temperature is below 50°C \[120°F\] before removing the pressure cap. Heated coolant spray or steam can cause personal injury.

> [!danger] WARNING · Опасно
> Coolant is toxic. Keep away from children and pets. If not reused, dispose of in accordance with local environmental regulations.

- Remove the turbocharger. Refer to Procedure [[20-010-033-tr — Turbocharger|010-033]]).
- Drain the coolant. Refer to Procedure [[20-008-018-tr — Cooling System|008-018]].

![[ck800wa.png]]

### Remove

Rail Applications

Remove the four capscrews from the exhaust transfer connection and support brackets.

![[17400071.png]]

Remove the four capscrews, nuts, gasket, and exhaust transfer connection from the exhaust manifold. Discard gasket.

![[17400072.png]]

Remove the number 2 and number 3 rocker lever covers. Refer to Procedure [[20-003-011-tr — Rocker Lever Cover|003-011]].

![[07400026.png]]

Remove the number 2 and number 3 rocker lever assemblies. Refer to Procedure [[20-003-009-tr — Rocker Lever Assembly|003-009]].

![[03400026.png]]

Remove the number 2 and number 3 rocker lever housings. Refer to Procedure [[20-003-013-tr — Rocker Lever Housing|003-013]].

![[rh4hsma.png]]

Remove the four capscrews, and two exhaust transfer connection brackets from the rocker lever housings.

![[17400073.png]]

### Inspect for Reuse

Rail Applications

Inspect the exhaust transfer connection and brackets for cracks or other damage.

![[17400074.png]]

### Install

Rail Applications

Install the four capscrews and two exhaust transfer connection brackets on the rocker lever housings. Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 135 n•m [100 ft-lb]

![[17400073.png]]

Install the number 2 and number 3 rocker lever housings. Refer to Procedure [[20-003-013-tr — Rocker Lever Housing|003-013]].

![[rh4hsma.png]]

Install the number 2 and number 3 rocker lever assemblies. Refer to Procedure [[20-003-009-tr — Rocker Lever Assembly|003-009]].

![[03400026.png]]

The valves and injectors **must** be correctly adjusted for the engine to operate efficiently.

Adjust the overhead settings. Refer to Procedure [[20-003-006-tr — Overhead Set (OBC)|003-006]].

![[03400018.png]]

Install the number 2 and number 3 rocker lever covers. Refer to Procedure [[20-003-011-tr — Rocker Lever Cover|003-011]].

![[07400026.png]]

Apply an anti-seize compound on the capscrew threads.

Install the four capscrews, nuts, gasket, and exhaust transfer connection on the exhaust manifold. Tighten the nuts.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[17400072.png]]

Apply an anti-seize compound on the capscrew threads.

Install four capscrews and exhaust transfer connection on the support brackets. Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 135 n•m [100 ft-lb]

![[17400071.png]]

### Finishing Steps

Rail Applications

> [!danger] WARNING · Опасно
> Coolant is toxic. Keep away from children and pets. If not reused, dispose of in accordance with local environmental regulations.

- Install the turbocharger. Refer to Procedure [[20-010-033-tr — Turbocharger|010-033]].
- Fill the cooling system. Refer to Procedure.
- Operate the engine and check for leaks.
