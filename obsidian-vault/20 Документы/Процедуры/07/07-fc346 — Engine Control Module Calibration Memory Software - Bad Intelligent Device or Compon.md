### Описание цепи

ECM - это компьютер, который отвечает за управление двигателем, диагностику и функции пользователя.

### Расположение компонента

ECM расположен на боковой стороне двигателя. См. процедуру 100-002 в разделе E.

### Практические замечания

Этот код неисправности может быть вызван внутренней неисправностью ECM. Это также может быть вызвано, если питание батареи отключено до завершения последовательности выключения питания. Ремонт в ЦСКА ** невозможен.

См. Код 346 устранения неполадок.

> Engine Control Module (ECM)
>
> ### Circuit Description
>
> The ECM is a computer that is responsible for engine control, diagnostics, and user features.
>
> ### Component Location
>
> The ECM is located on the side of the engine. Refer to Procedure 100-002 in Section E.
>
> ### Shoptalk
>
> This fault code can be caused by an internal ECM malfunction. This can also be caused if battery power is disconnected before the power-down sequence is completed. Repairs to the ECM are **not** possible.
>
> Refer to Troubleshooting Fault Code 346.
