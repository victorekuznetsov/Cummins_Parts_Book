### Измерение

Измерить осевой зазор вала турбокомпрессора. Ссылка на Руководство по турбокомпрессорам, Вестник 3810321.

![[tb8shic.png]]

Измерить осевой зазор вала турбокомпрессора.

| Осевой зазор турбокомпрессора |  |  |
|---|---|---|
| мм |  | в |
| 0.025 | Мин | 0.001 |
| 0.127 | Макс | 0.005 |

Турбокомпрессор должен быть заменен, если зазоры выходят за эти пределы.[[41-010-033-tr — Turbocharger|См. процедуру 010-033 в разделе 10.]].

![[tb200tf.png]]


> [!quote]- Original (English) · английский оригинал
> ### Measure
>
> Measure the turbocharger shaft end play. Reference the Turbocharger Manual, Bulletin 3810321.
>
> Measure axial clearance of the turbocharger shaft.
>
> | Turbocharger Axial Clearance |  |  |
> |---|---|---|
> | mm |  | in |
> | 0.025 | MIN | 0.001 |
> | 0.127 | MAX | 0.005 |
>
> The turbocharger **must** be replaced if the clearances are beyond these limits. [[41-010-033-tr — Turbocharger|Refer to Procedure 010-033 in Section 10]].
