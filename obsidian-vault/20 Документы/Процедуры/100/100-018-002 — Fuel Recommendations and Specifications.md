### Рекомендации по топливу

> [!danger] ОПАСНО
> Не смешивайте бензин, алкоголь или газохол с дизельным топливом. Эта смесь может вызвать взрыв.

> [!warning] ОСТОРОЖНО
> Из-за точных допусков систем впрыска дизельного топлива топливо должно быть чистым и свободным от грязи или воды. Грязь или вода в системе могут нанести серьезный ущерб как топливному насосу, так и топливному форсунке.

Cummins Inc. Рекомендуем использовать топливо ASTM No2D. Использование дизельного топлива № 2 приведет к оптимальным характеристикам двигателя.

При рабочих температурах ниже 0°C \[32°F\] приемлемую производительность можно получить с помощью смесей числа 2D и числа 1D.

> [!note] Примечание
> Более легкие виды топлива могут снизить экономию топлива.

> [!note] Примечание
> Двигатели, оснащенные дизельными фильтрами для твердых частиц, требуют использования дизельного топлива с максимальным содержанием серы 30 ppm. Не существует приемлемых заменителей.

Вязкость топлива должна быть выше 1,3 сС при 40°С \[104°F\], чтобы обеспечить адекватные характеристики накачки и смазки компонентов топливной системы.

> [!quote]- Original (English) · английский оригинал
> ### Fuel Recommendations
>
> **WARNING · Опасно**
> Do not mix gasoline, alcohol, or gasohol with diesel fuel. This mixture can cause an explosion.
>
> **CAUTION · Осторожно**
> Because of the precise tolerances of diesel injection systems, fuel must be kept clean and free of dirt or water. Dirt or water in the system can cause severe damage to both the fuel pump and the injectors.
>
> Cummins Inc. recommends the use of ASTM number 2D fuel. The use of number 2 diesel fuel will result in optimum engine performance.
>
> At operating temperatures below 0°C \[32°F\], acceptable performance can be obtained by using blends of number 2D and number 1D.
>
> **Note · Примечание**
> Lighter fuels can reduce fuel economy.
>
> **Note · Примечание**
> Engines equipped with diesel particulate filters require the use of diesel fuel with 30 ppm sulfur maximum. There are no acceptable substitutes.
>
> The viscosity of the fuel **must** be kept above 1.3 cSt at 40°C \[104°F\] to provide adequate pumping and lubricating characteristics to fuel system components.
>
> The following chart lists acceptable substitute fuels for this engine.
>
> | Acceptable Substitute Fuels |  |  |  |  |  |  |  |  |  |
> |---|---|---|---|---|---|---|---|---|---|
> | Number 1D Diesel (1) (2) (3) | Number 2D Diesel (3) | Number 1K Kerosene | Jet-A | Jet-A1 | JP-5 | JP-8 | Jet-B | JP-4 | CITE |
> | A | OK | **Not** OK | A | A | A | A | **Not** OK | **Not** OK | **Not** OK |
> | An "A" means OK only if fuel lubricity is adequate. This means the BOCLE number is 3100 or greater as measured by ASTM specification D6078, Scuffing Load Ball On Cylinder Evaluator (SLBOCLE). Lubricity can also be measured by ASTM, specification D6079, ISO 12156, High Frequency Reciprocating Rig (HFRR) in which the fuel must have a wear scar diameter of 0.45 mm \[0.02 in\] or less. Any adjustment to compensate for reduced performance with a fuel system using alternate fuel is not warrantable. Winter blend fuels, such as found at commercial fuel-dispensing outlets, are combinations of number 1D and 2D diesel fuels and are acceptable. |  |  |  |  |  |  |  |  |  |
