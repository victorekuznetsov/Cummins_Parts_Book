### Select Service Tools

#### Recommended Cummins® Service Tools

- Spray cleaner, Part Number 3375433, or equivalent

#### Additional Service Items

- Allen wrench or socket

### General Information

Two types of straight thread plugs are used:

1. Straight thread plug with o-ring
2. Straight thread plug with formed-in-place sealant.

The two plugs are interchangeable and reusable. The **only** difference between the two plugs is the installation torque value. See the install step of this procedure.

![[17900066.png]]

### Remove

Select the appropriate size Allen wrench or socket, and remove the plug.

![[14900031.png]]

### Clean and Inspect for Reuse

> [!danger] WARNING · Опасно
> When using solvents, acids, or alkaline materials for cleaning, follow the manufacturer's recommendations for use. Wear goggles and protective clothing to reduce the possibility of personal injury.

Use spray cleaner, Part Number 3375433, or equivalent, to clean the threads of the straight-thread plugs and threaded bores.

![[17900033.png]]

Inspect the threads of the pipe plugs for mutilation or damage.

Replace the plugs, if damaged.

Inspect the threaded bores for damage.

Repair the bores, if necessary.

![[17900034.png]]

For straight thread plugs with an o-ring, inspect the o-ring for cuts, tears, or deformation. Replace the o-ring, if necessary.

For straight thread plugs with formed in-place sealant, inspect the sealant for damage. If damaged, replace the entire plug.

![[17900067.png]]

### Install

If equipped with a straight thread plug with o-ring, install a new o-ring on the straight-thread plug, if required.

Lubricate the o-ring with clean engine oil.

Install and tighten the plug.

> [!tip] Момент затяжки · Torque Value
> M10 10 n•m [89 in-lb]

> [!tip] Момент затяжки · Torque Value
> M12 20 n•m [177 in-lb]

> [!tip] Момент затяжки · Torque Value
> M14 25 n•m [221 in-lb]

> [!tip] Момент затяжки · Torque Value
> M16 35 n•m [25 ft-lb]

> [!tip] Момент затяжки · Torque Value
> M18 45 n•m [33 ft-lb]

![[17900035.png]]

If equipped with a straight thread plug with formed in-place sealant, install and tighten the plug.

> [!tip] Момент затяжки · Torque Value
