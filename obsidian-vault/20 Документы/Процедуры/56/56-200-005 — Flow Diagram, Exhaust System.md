### Диаграмма потока

с форсункой механического управления

![[11600027.png]]

QSK45 Exhaust System - одноступенчатый турбокомпрессор, послеохлажденный

1. Выхлопной порт
2. Многообразие выхлопных газов
3. Выхлопная труба турбокомпрессора.

![[11600029.png]]

QSK60 Exhaust System - одноступенчатый турбокомпрессор, послеохлажденный

1. Выпускной коллектор
2. Впускной клапан турбокомпрессора
3. Выход выхлопных газов турбокомпрессора
4. Выхлопная розетка (слева **не** показана).

![[11600028.png]]

QSK60 Exhaust System - двухступенчатый турбокомпрессор, послеохлажденный и интеркулированный

1. Многообразие выхлопных газов
2. Впуск турбокомпрессора высокого давления
3. Выход турбокомпрессора высокого давления на вход турбокомпрессора низкого давления
4. Выхлопная труба турбокомпрессора низкого давления.

с форсункой электронного управления

![[11600154.png]]

QSK60 Exhaust System - одноступенчатый турбокомпрессор, послеохлажденный

1. Выпускной коллектор
2. Впускной клапан турбокомпрессора
3. Выход выхлопных газов турбокомпрессора
4. Выхлопная розетка (слева **не** показана).

![[11600155.png]]

QSK60 Exhaust System - двухступенчатый турбокомпрессор, послеохлажденный и интеркулированный

1. Многообразие выхлопных газов
2. Впуск турбокомпрессора высокого давления
3. Выход турбокомпрессора высокого давления на вход турбокомпрессора низкого давления
4. Выхлопная труба турбокомпрессора низкого давления.
