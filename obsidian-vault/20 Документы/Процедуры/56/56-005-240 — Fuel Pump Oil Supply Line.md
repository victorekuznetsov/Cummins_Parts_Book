# Fuel Pump Oil Supply Line

> [!abstract] Процедура · `56-005-240`
> **Двигатели:** [[33210083 — QSK60 CM500 CPL 2699|33210083]], [[33219033 — QSK60 CM500 CPL 2848|33219033]], [[33224343 — QSK60 CM500 CPL 2849|33224343]]
> **Семейство:** QSK60
> **Входит в руководства:** [[4021530 — QSK45 and QSK60 Service Manual|4021530]]
> **Секции:** Section 5 - Fuel System - Group 05
> **Даты:** изменён 2021-08-12
> **Источник:** [QuickServe](https://quickserve.cummins.com/qs3/pubsys2/xml/en/procedures/56/56-005-240.html) · [PDF-оригинал](https://github.com/victorekuznetsov/Cummins_Parts_Book/raw/main/bulletins/procedures/56-005-240.pdf)

### Exploded View

![[05300099.png]]

The exploded view above shows the high pressure supply line installed.

### Remove

Disconnect both unions and pillow supporting block on rear of the engine.

![[05500166.png]]

Disconnect union and the rear and center the engine and supporting P-clips.

![[05500167.png]]

Disconnect the union from center and the engine

Disconnect the hose from Fuel pump oil filter head

Disconnect supporting P-clips.

![[05500168.png]]

### Install

Fit the fuel pump oil filter head. [[56-007-111 — Fuel Pump Drive Lubricating Oil Filter Head|Refer to Procedure 007-111 in Section 7.]]

> [!note] Note · Примечание
> The standard fuel pump dedicated lube filter head is different to the one required for the oil pressure supplied from the flywheel end of the engine.

Install union support bracket on aftercooler joint using M8 x1.5 20mm long bolts.

> [!tip] Момент затяжки · Torque Value
> 18 n•m [159 in-lb]

![[05500169.png]]

Remove the fuel manifold. [[56-006-021-tr — Fuel Manifold (Drain)|Refer to Procedure 006-021 in Section 6.]]

Install bracket behind fuel manifold.

Install fuel manifold using new M8 30mm bolts.

> [!tip] Момент затяжки · Torque Value
> 18 n•m [159 in-lb]

![[05500170.png]]

Pass the hose through the two brackets.

Attach hose using the P-Clip to fuel manifold hose bracket.

> [!tip] Момент затяжки · Torque Value
> 36 n•m [26 ft-lb]

![[05500171.png]]

Attach the straight edge swivel section of the Hose to the union support bracket.

> [!tip] Момент затяжки · Torque Value
> 65 n•m [48 ft-lb]

![[05500172.png]]

Install P-clip on hose and supporting bracket behind fuel manifold.

> [!tip] Момент затяжки · Torque Value
> 36 n•m [27 ft-lb]

![[05500173.png]]

Connect the supply hose to the oil filter head.

> [!tip] Момент затяжки · Torque Value
> 65 n•m [49 ft-lb]

![[05500174.png]]

Install brackets to aftercooler cover using M8 20mm bolts.

> [!tip] Момент затяжки · Torque Value
> 18 n•m [159 in-lb]

![[05500175.png]]

Fit large bracket to aftercooler cover using four long aftercooler intake bolts.

> [!tip] Момент затяжки · Torque Value
> 18 n•m [159 in-lb]

![[05500176.png]]

Install smaller bracket. right bolt using longer aftercooler bracket and right bolt using M8 20mm bolt.

> [!tip] Момент затяжки · Torque Value
> 18 n•m [159 in-lb]

![[05500177.png]]

Pass hose through brackets and attach right end of hose to the union.

> [!note] Note · Примечание
> Do **not** tighten the joint at this point.

![[05500178.png]]

Install P-clips and M8 16mm bolts underneath the larger bracket to support the hose.

> [!tip] Момент затяжки · Torque Value
> 18 n•m [159 in-lb]

![[05500179.png]]

Attach hose to lower union.

> [!tip] Момент затяжки · Torque Value
> 65 n•m [48 ft-lb]

![[05500180.png]]

Install P-clips to aftercooler brackets using M10 16mm bolt and nut.

> [!tip] Момент затяжки · Torque Value
> 36 n•m [27 ft-lb]

![[05500181.png]]

Install bracket on rear of engine using M10 20mm bolt.

> [!tip] Момент затяжки · Torque Value
> 36 n•m [27 ft-lb]

![[05500182.png]]

Fit union on top of flywheel housing.

> [!tip] Момент затяжки · Torque Value
> 65 n•m [48 ft-lb]

Tighten top union hose.

> [!tip] Момент затяжки · Torque Value
> 65 n•m [48 ft-lb]

![[05500183.png]]

Pass hose through routing of the brackets. Connect the hose to the union on the side of the engine.

Connect the hose to the 90 degree union.

Fit pillow block on to the bracket tube using M10 16mm bolt and nut.

> [!tip] Момент затяжки · Torque Value
> 36 n•m [27 ft-lb]

Tighten hose on union connected to side of the engine.

> [!tip] Момент затяжки · Torque Value
> 65 n•m [48 ft-lb]
