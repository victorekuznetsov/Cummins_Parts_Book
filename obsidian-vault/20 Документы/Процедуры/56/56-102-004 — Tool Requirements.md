### Общие сведения

Большинство операций по техническому обслуживанию, описанных в этом руководстве, могут выполняться с помощью обычной ручной оснастки (метрические гаечные ключи, розетки и отвертки).

Ниже приведен список специальных инструментов обслуживания, необходимых для некоторых операций по техническому обслуживанию:

| Инструмент Часть Номер | Наименование |
|---|---|
| СТ-1293 | Измеритель напряжения ремня Берроуза (v-пояса) |
| 3375049 | Фильтр маслом гаечный ключ |
| 3376807 | Ремень охлаждающего и топливного фильтра |
| 3376592 | Фронтальный ключ - Inch-pound |
| 3824901 | Калибр для измерения ресниц |

Смотрите соответствующие разделы для описания инструментов и как их использовать.

Свяжитесь с ближайшим авторизованным ремонтным центром Cummins для получения необходимых инструментов обслуживания.
