### Install

with Mechanically Actuated Injector

> [!danger] WARNING · Опасно
> This assembly weighs 23 kg \[50 lb\] or more. To reduce the possibility of personal injury, use a hoist or get assistance to lift this assembly.

Connect the lifting straps to the two-stage frame lifting eyes.

Position and align the two stage frame on the three center support brackets on the engine.

![[10600127.png]]

Do **not** tighten the two-stage frame assembly capscrews until all capscrews have been in the supports and brackets.

Align the two-stage frame assembly capscrew holes with the center support bracket capscrew holes.

Install the 10 capscrews connecting the two-stage frame to each of the center support brackets.

![[10600126.png]]

Align the two-stage frame assembly capscrew holes with the outboard support brackets.

Install the capscrews connecting the two-stage frame to each of the outboard support brackets.

![[10600125.png]]

Align the two-stage frame assembly capscrew holes with the two low temperature thermostat housing bracket capscrew holes.

Install the capscrews connecting the two-stage frame to each of the two low temperature aftercooling thermostat housing brackets.

![[10600124.png]]

Tighten all of the two-stage frame assembly mounting capscrews.

> [!tip] Момент затяжки · Torque Value
> 80 n•m [59 ft-lb]

![[10600123.png]]

Remove the lifting eyes from the two-stage frame.

![[10600122.png]]

> [!danger] WARNING · Опасно
> This assembly weighs 23 kg \[50 lb\] or more. To reduce the possibility injury, use a hoist or get assistance to remove this assembly.

Install a 12 mm \[0.47 in\] lifting device in the top of the intercoolers.

Install the Intercoolers.

![[10600121.png]]

Remove the lifting eye from the intercoolers.

Install the lifting eye onto the two-stage frame assembly.

Tighten the lifting eye capscrew.

> [!tip] Момент затяжки · Torque Value
> 195 n•m [144 ft-lb]

![[10600120.png]]

Install the intercooler mounting capscrews.

Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 280 n•m [207 ft-lb]

![[10600119.png]]

Install the coolant supply and return piping onto the intercoolers.

Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[10600118.png]]

Install the low temperature aftercooling thermostat housing coolant supply lines.

Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 54 n•m [40 ft-lb]

![[08600242.png]]

Install the four intercooler intake crossovers.

Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[10600104.png]]

Install the hoses and clamps on the right-bank rear and left-bank front high-pressure turbochargers.

> [!tip] Момент затяжки · Torque Value
> 9 n•m [80 in-lb]

![[10600103.png]]

Install the intake hoses and clamps on each of the four high-pressure turbochargers.

![[10600097.png]]

Make sure the oil supply line o-ring is **not** damaged.

Install the oil supply lines on the four high-pressure turbochargers and tighten the fittings.

> [!tip] Момент затяжки · Torque Value
> 54 n•m [40 ft-lb]

![[10600076.png]]

Install new o-ring seals on all of the turbocharger oil drain lines.

Install the oil drain lines into the cylinder block.

Tighten the oil drain line capscrews.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[07600373.png]]

Make sure the oil supply line o-ring is **not** damaged.

Install the low-pressure turbocharger oil line to each low-pressure turbocharger.

Tighten the fittings.

> [!tip] Момент затяжки · Torque Value
> 54 n•m [40 ft-lb]

![[10600076.png]]

Connect the two oil supply lines at the flywheel housing.

Tighten the fittings.

> [!tip] Момент затяжки · Torque Value
> 54 n•m [40 ft-lb]

![[07600372.png]]

Install the air crossover that connect the left bank front and right bank rear high-pressure turbocharger to the aftercoolers.

Install the clamps on the hose connections at the air crossover to the high-pressure turbochargers.

> [!tip] Момент затяжки · Torque Value
> 9 n•m [80 in-lb]

![[10600103.png]]

Install the air crossover supports.

Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[11600043.png]]

Install the V-band clamp and the exhaust bellows to the turbocharger exhaust outlet flanges.

Tighten the V-band clamp nut.

> [!tip] Момент затяжки · Torque Value
> 9 n•m [80 in-lb]

![[10600096.png]]

Connect the intake pipping between the air filter(s) and the low-pressure turbochargers at the inlet side of the turbochargers.

![[11600048.png]]
