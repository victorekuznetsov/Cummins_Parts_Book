### Preparatory Steps

with Mechanically Actuated Injector

> [!danger] WARNING · Опасно
> Depending on the circumstance, fuel is flammable. Keep all cigarettes, flames, pilot lights, arcing equipment, and switches out of the work area and areas sharing ventilation to reduce the possibility of severe personal injury or death when working on the fuel system.

> [!danger] WARNING · Опасно
> Batteries can emit explosive gases. To reduce the possibility of personal injury, always ventilate the compartment before servicing the batteries. To reduce the possibility of arcing, remove the negative (-) battery cable first and attach the negative (-) battery cable last.

- Disconnect the battery cables. See equipment manufacturer service information.
- Remove the fuel filters. [[56-006-015-tr — Fuel Filter (Spin-On Type)|Refer to Procedure 006-015 in Section 6.]]

with Electronically Actuated Injector

> [!danger] WARNING · Опасно
> Depending on the circumstance, fuel is flammable. Keep all cigarettes, flames, pilot lights, arcing equipment, and switches out of the work area and areas sharing ventilation to reduce the possibility of severe personal injury or death when working on the fuel system.

> [!danger] WARNING · Опасно
> Batteries can emit explosive gases. To reduce the possibility of personal injury, always ventilate the compartment before servicing the batteries. To reduce the possibility of arcing, remove the negative (-) battery cable first and attach the negative (-) battery cable last.

- Disconnect the battery cables. See equipment manufacturer service information.
- Disconnect the fuel temperature sensor. Use the following procedure found in the QSK38, QSK50 and QSK60 (CM850 Modular Common Rail System), Troubleshooting and Repair, Bulletin 4021533. Refer to Procedure 019-119 in Section 19.
- Disconnect the fuel pressure sensor. Use the following procedure found in the QSK38, QSK50 and QSK60 (CM850 Modular Common Rail System), Troubleshooting and Repair, Bulletin 4021533. Refer to Procedure 019-398 in Section 19.
- Remove the fuel filters. [[56-006-015-tr — Fuel Filter (Spin-On Type)|Refer to Procedure 006-015 in Section 6.]]
- Disconnect the fuel supply lines. [[56-006-024-tr — Fuel Supply Lines|Refer to Procedure 006-024 in Section 6.]]

### Disassemble

with Mechanically Actuated Injector

Remove the straight thread o-ring plugs (1) and the o-rings (2).

Remove the inlet and outlet elbows (3) and the o-rings (2).

The fuel filter adapters (4) do **not** need to be removed unless they are loose or damaged.

If it is necessary to remove the fuel adapter, remove the adapters (4), lock plates (5), and o-rings (6).

Discard all removed o-rings.

![[06600110.png]]

Remove the filter head adapter spuds and the adapter rings.

Remove and discard the six o-rings.

![[06600459.png]]

with Electronically Actuated Injector

#### Stage Two Filter Head

- Remove the fuel temperature sensor (1). Use the following procedure found in the QSK38, QSK50 and QSK60 (CM850 Modular Common Rail System), Troubleshooting and Repair, Bulletin 4021533. Refer to Procedure 019-398 in Section 19.
- Remove the fuel pressure sensor (2). Use the following procedure found in the QSK38, QSK50 and QSK60 (CM850 Modular Common Rail System), Troubleshooting and Repair, Bulletin 4021533. Refer to Procedure 019-119 in Section 19.
- Remove the fuel inlet (3) and fuel outlet (4) fittings.
- Discard the o-rings.

> [!note] Note · Примечание
> Plugs can be used in locations (1) and (2) instead of sensors, if required.

![[06600519.png]]

**For Generator Model DQKAN with Low NOx Emissions Capability**

Remove the fuel temperature sensor (1). Use the following procedure in the QSK38, QSK50, and QSK60 CM2150 Electronic Control System Troubleshooting and Repair Manual, Bulletin [[4022102 — QSK38, QSK50, and QSK60 CM2150 Electronic Control System Troubleshooting and Repair M\|4022102]]. Refer to Procedure 019-119 in Section 19.

Remove the fuel pressure sensor (2). Use the following procedure in the QSK38, QSK50, and QSK60 CM2150 Electronic Control System Troubleshooting and Repair Manual, Bulletin [[4022102 — QSK38, QSK50, and QSK60 CM2150 Electronic Control System Troubleshooting and Repair M\|4022102]]. Refer to Procedure 019-398 in Section 19.

Remove the fuel outlet (3), and fuel inlet (4). Discard o-rings.

Remove the filter screen assembly (5) and discard the o-rings.

Remove the threaded plugs (6 and 7) and discard the o-rings.

### Assemble

with Mechanically Actuated Injector

Install new o-rings.

Install the lock plate. Locate the 90-degree bend in the drilled hole in the fuel filter head.

Apply one drop of Loctite® 601 on the threads of the adapter that engages the threads in the filter head and install the adapter.

> [!tip] Момент затяжки · Torque Value
> 102 n•m [75 ft-lb]

![[06600113.png]]

> [!note] Note · Примечание
> The position of the plugs and the inlet and outlet elbows can be different than illustrated due to the various fuel plumbing installations.

Use new o-rings (2) to install the straight-thread o-ring plugs (1).

> [!tip] Момент затяжки · Torque Value
> 102 n•m [75 ft-lb]

![[06600114.png]]

Use new o-rings (2) to install the fuel inlet and outlet elbows (3).

> [!tip] Момент затяжки · Torque Value
> 102 n•m [75 ft-lb]

![[06600115.png]]

Install new o-rings above the filter head adapter spuds. Apply thread locker to the smaller threaded portion of the spud.

Install the spuds in the filter head.

> [!tip] Момент затяжки · Torque Value
> 88 n•m [65 ft-lb]

Install new o-rings above the filter head adapter rings. Apply thread locking compound to the inside of the threads. Thread the rings into the spuds until the o-rings contact the filter head. Use care to make sure the o-ring is properly seated.

> [!tip] Момент затяжки · Torque Value
> 88 n•m [65 ft-lb]

![[06600459.png]]

with Electronically Actuated Injector

- Install the fuel temperature sensor (1). Use the following procedure found in the QSK38, QSK50 and QSK60 (CM850 Modular Common Rail System), Troubleshooting and Repair, Bulletin 4021533. Refer to Procedure 019-119 in Section 19.
- Install the fuel pressure sensor (2). Use the following procedure found in the QSK38, QSK50 and QSK60 (CM850 Modular Common Rail System), Troubleshooting and Repair, Bulletin 4021533. Refer to Procedure 019-398 in Section 19.

M18 straight threaded plugs can be used in locations (1) and (2) instead of sensors, if required.

> [!tip] Момент затяжки · Torque Value
> 41 n•m [30 ft-lb]

![[06k00089.png]]

Use new o-rings and install the fuel inlet (1) and fuel outlet (2) fittings.

> [!tip] Момент затяжки · Torque Value
> 62 n•m [46 ft-lb]

![[06k00090.png]]

Make sure the fuel outlet and inlet elbow joints are positioned at 10 o'clock (1) and 12 o'clock (2) orientations as shown.

> [!tip] Момент затяжки · Torque Value
> 115 n•m [85 ft-lb]

![[06600615.png]]

**For Generator Model DQKAN with Low NOx Emissions Capability**

Install the union fittings into the filter head at the following locations.

1. Fuel inlet
2. Fuel oulet

> [!tip] Момент затяжки · Torque Value
> 85 n•m [63 ft-lb]

![[06j00269.png]]

Install new o-rings onto the filter screen assembly.

Install the filter screen assembly into the fuel filter head.

> [!tip] Момент затяжки · Torque Value
> 60 n•m [44 ft-lb]

![[06300058.png]]

Install the fuel temperature sensor (1). Use the following procedure in the QSK38, QSK50, and QSK60 CM2150 Electronic Control System Troubleshooting and Repair Manual, Bulletin [[4022102 — QSK38, QSK50, and QSK60 CM2150 Electronic Control System Troubleshooting and Repair M\|4022102]]. Refer to Procedure 019-119 in Section 19.

Install the fuel pressure sensor (2). Use the following procedure in the QSK38, QSK50, and QSK60 CM2150 Electronic Control System Troubleshooting and Repair Manual, Bulletin [[4022102 — QSK38, QSK50, and QSK60 CM2150 Electronic Control System Troubleshooting and Repair M\|4022102]]. Refer to Procedure 019-398 in Section 19.

Install new o-rings on the threaded plugs (6) and install the plugs.

> [!tip] Момент затяжки · Torque Value
> 40 n•m [26 ft-lb]

Install new o-ring on threaded plug (7) and install plug.

> [!tip] Момент затяжки · Torque Value
> 35 n•m [26 ft-lb]

### Install

with Mechanically Actuated Injector

Install the fuel filter head and install the fuel filter head mounting capscrews.

> [!tip] Момент затяжки · Torque Value
> 55 n•m [41 ft-lb]

Install the fuel filter supply and return hoses.

Clean the gasket sealing surface with a clean, lint-free towel.

![[07600256.png]]

with Electronically Actuated Injector

#### Stage 2 Filter Head

- Install the fuel filter head assembly to the engine with the six mounting capscrews.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

- Install the fuel supply and return hoses.
- Connect the engine wiring harness to the pressure and temperature sensors on the fuel filter head, if equipped.

![[06k00091.png]]

**For Generator Model DQKAN with Low NOx Emissions Capability**

> [!note] Note · Примечание
> If the fuel filter head is remote-mounted, reference the equipment manufacturer service information.

Install the fuel filter head assembly onto the engine with the two-piece vibration isolators and six capscrews.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[06k00097.png]]
