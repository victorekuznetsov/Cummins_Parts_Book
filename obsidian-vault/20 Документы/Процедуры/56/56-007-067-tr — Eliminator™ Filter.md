### Install

Single-piece Bracket

> [!warning] CAUTION · Осторожно
> The Eliminator™ filter can be installed on either side of the engine. Check to be sure the lubricating oil transfer tube has been installed correctly. The filter must be on the opposite bank from the oil transfer tube. If the Eliminator™ filter is installed on the wrong bank, the engine will be severely damaged because of the lack of lubrication.

> [!note] Note · Примечание
> It is recommended that you install the eliminator with the three-piece bracket, where applicable.

Install the Eliminator™ filter handhole cover with the handhole cover o-ring.

Make sure the handhole cover is in correct position on engine.

Tighten the handhole cover capscrews.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

![[07e00202.png]]

Lubricate the new o-ring seals with vegetable oil and install on both ends of the connection tube.

Install the connection tube into the filter housing.

![[07e00212.png]]

Install four guide studs to the engine in the locations shown.

> [!note] Note · Примечание
> Do **not** use threaded guide studs. This will aid in guide stud removal once the Eliminator™ filter is installed.

Install new gaskets over the guide studs.

Make sure the six mounting holes are visible through each gasket.

> [!note] Note · Примечание
> The gasket part number **must** face away from the cylinder block.

![[07e00209.png]]

> [!danger] WARNING · Опасно
> This component or assembly weighs greater than 23 kg \[50 lb\]. To prevent serious personal injury, be sure to have assistance or use appropriate lifting equipment to lift this component or assembly.

Install the filter over the guide studs while guiding the connection tube into the handhole cover.

Install six capscrews and washers and hand-tighten.

Remove the guide studs and install the remaining capscrews and washers, and hand-tighten.

![[07e00210.png]]

Tighten the capscrews in sequence illustrated.

> [!tip] Момент затяжки · Torque Value
> 45 n•m [33 ft-lb]

> [!note] Note · Примечание
> Due to the difficulty in accessing the lower capscrews, the use of a 3/8 drive socket and torque wrench is recommended to gain access to achieve the correct torque value on these capscrews.

![[07e00203.png]]

Install the support bracket to the engine and Eliminator™. Hand-tighten all of the capscrews to align the bracket with the block and the Eliminator™ filter.

Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> Pan Rail (1) 80 n•m [59 ft-lb]

> [!tip] Момент затяжки · Torque Value
> Eliminator™ Filter (2) 68 n•m [50 ft-lb]

![[07e00211.png]]

### Pressure Test

This test will indicate oil pressure before and after the oil flows through the Eliminator™ filter.

Use a differential pressure gauge or one pressure gauge with two oil hoses and two valves (1 and 2) to eliminate gauge error. Use a gauge with a minimum pressure capacity of 1400 kPa \[200 psi\].

Be sure the engine is switched OFF.

![[07e00184.png]]

Remove the two plugs from the filter housing.

Install the end of the valve assembly in the port of the filter nearest to the centrifuge from where the plug has been removed.

Install the end of the valve assembly in the port of the filter furthest away from the centrifuge from where the other plug has been removed.

![[07600238.png]]

Operate the engine at rated rpm until the engine oil reaches its normal operating temperature. Continue running the engine at rated rpm for the duration of the pressure test.

![[oi400la.png]]

Close valve (1), open valve (2), and record the pressure value before the Eliminator™ filter.

Close valve (2), open valve (1), and record the pressure value after the Eliminator™ filter.

If the difference in pressure is more than the maximum allowable value, inspect and clean the Eliminator™ filter screens before checking the oil pressure differential again.

| **Measurements** |  |  |  |
|---|---|---|---|
|  | kpa | psi |  |
| Measurements | Maximum Oil Pressure Differential | 60 | 9 |

![[07e00184.png]]

Shut the engine OFF.

Remove the valve assembly from the Eliminator™ filter and install the two plugs.

Tighten the plugs.

> [!tip] Момент затяжки · Torque Value
> 10 n•m [89 in-lb]

Where an oil sampling fitting is used, install the fitting in the position marked 1.

Tighten the oil sampling fitting.

> [!tip] Момент затяжки · Torque Value
> 10 n•m [89 in-lb]
