> ### Cylinder Head
>
> | **Tool Number** 3163293 | **Boot Pliers** Used to remove the valve stem seals in the cylinder head during engine rebuild. |  |
> |---|---|---|
> | **Tool Number** 3163424 | **Valve Guide Arbor Set** Use tapered arbors with valve seat insert tool (ST-257). |  |
> | **Tool Number** 3163430 | **Crosshead Guide Installer** Used to install the crosshead guide pin in the cylinder head to the proper assembly height. |  |
> | **Tool Number** 3163639 | **Valve Spring Compressor** Used to compress the valve springs to allow the valves to be removed or installed. This tool is air-operated. |  |
> | **Tool Number** 3163760 | **Cylinder Head Capscrew Length Gauge** Used to measure free-length stretch of the used cylinder head capscrews that have been used in the torque-to-yield tightening method. |  |
> | **Tool Number** 3375068 | **Cup Plug Loctite™** Used to lock bolts in place and prevent from loosening. |  |
> | **Tool Number** 3375182 | **Valve Spring Tester** Used to compress the valve spring to measure spring force. |  |
> | **Tool Number** 3375784 | **Light-Duty Puller** Used to remove small seals, sleeves, bearing races, and bushings. |  |
> | **Tool Number** 3375805 | **Lapping Paste** Used to lap valve and seat. |  |
> | **Tool Number** 3376405 | **Valve Seat Grooving Kit** Used to extend the life of the valve seat extractor. |  |
> | **Tool Number** 3376617 | **Valve Seat Extractor (exhaust)** Used to remove valve seats from the cylinder head without damaging the cylinder head valve seat. |  |
> | **Tool Number** 3375043 | **Valve Spring Compressor Plate** Used with valve spring compressor stand to compress the valve springs. |  |
> | **Tool Number** 3376793 | **Cup Plug Driver** Used to install cup plug to its proper depth. |  |
> | **Tool Number** 3376795 | **Cup Plug Driver Handle** Universal cup plug driver handle. |  |
> | **Tool Number** 3377396 | **Valve Seat Extractor (intake)** Used to remove valve seats from the cylinder head without damaging the cylinder head valve seat. |  |
> | **Tool Number** 3823495 | **Depth Gauge Assembly** Used to measure cylinder liner counterbore ledge angle and injector protrusion. |  |
> | **Tool Number** 3824895 | **Cup Plug Driver (30-mm)** Used to install expansion plugs in the cylinder block or cylinder head. Handle, Part Number 3376795, is required with this driver. |  |
> | **Tool Number** 3824896 | **Cup Plug Driver (40-mm)** Used to install expansion plugs in the cylinder block or cylinder head. Handle, Part Number 3376795, is required with this driver. |  |
> | **Tool Number** 3824919 | **Valve Guide Extractors** Used to remove the valve guides from the cylinder head during engine rebuild. |  |
> | **Tool Number** 4918644 | **Valve Stem Seal Driver** Used to install the valve stem seals in the cylinder head during engine rebuild. |  |
> | **Tool Number** 6304260 | **Valve Guide Driver** Used to press the valve guides into the cylinder head at their proper height. |  |
> | **Tool Number** ST-257 | **Valve Seat Insert Tool** Used with appropriate cutters to counterbore cylinder heads for installation of valve seat inserts. |  |
> | **Tool Number** ST-583 | **Head-Holding Fixture** Used to hold and rotate the cylinder head to various positions during the rebuild process. |  |
> | **Tool Number** ST-876 | **Fuel Passage Cleaning Brush** Used when cleaning internal fuel passages when rebuilding cylinder heads. |  |
> | **Tool Number** ST-1012 | **Hydrostatic Tester** Used to check for coolant leaks in the cylinder head. Requires shop air, a lifting hoist, a water tank, and the appropriate test adapter plate and o-ring. |  |
> | **Tool Number** ST-1022 | **Valve Spring Compressor Stand** Used to compress the valve springs. |  |
> | **Tool Number** ST-1134 | **Dowel Pin Puller** Used to remove crosshead guides or dowels throughout the engine. |  |
