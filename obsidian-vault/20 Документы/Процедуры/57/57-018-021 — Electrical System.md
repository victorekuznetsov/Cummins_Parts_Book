### Спецификации

| Минимальная рекомендуемая емкость батареи |  |  |  |  |  |
|---|---|---|---|---|---|
| Модель двигателя | Диапазон температур | Напряжение системы | Холодный кран Ампер | Амперские часы | Резервный потенциал |
| QST30 | от -18° до 0°С | 24 VDC | 1800 | 400 | 640 |
| [0 ° до 32 ° F ] |  |  |  |  |  |

Количество пластин в пределах заданного размера батареи определяет резервную емкость. Резервная емкость - это промежуток времени, в течение которого может происходить устойчивое скручивание.

Амперы холодного проворачивания основаны на двух 12-VDC батареях серии.

Ниже перечислены размеры кабеля батареи в американском измерительном приборе (максимальная длина в коленчатой цепи двигателя).

#### 24-32 VDC

Номер 00 6.1 м \[20 футов \]Численность 000 8.2 м \[27 футов \]Численность 0000 или два числа 0\* 10.7 м \[35 футов \]Два числа 00 13.7 м \[45 футов]

| Минимальная скорость проворачивания без стартовой помощи | 150 об/мин |
|---|---|

* Две резьбы кабеля с числом 0 могут использоваться вместо одного кабеля с числом 0000, при условии, что все соединения тщательно продуманы таким образом, чтобы в каждом параллельном кабеле был одинаковый поток тока.
