### Измерение

с форсункой механического управления

Удалите шланг для слива топлива.

Установите адаптер и датчик измерения давления Часть номер ST-1273, или эквивалент, между шлангом для слива топлива и установкой слива топлива двигателя. Минимальная мощность калибра должна составлять 200 мм рт.ст. \[8 in-Hg\].

- Установите адаптер на входном конце контрольного клапана (если он оборудован).
- Используйте адаптер шланга от Part Number ST-434 для подключения шланга для измерения давления.
- Этот шланг должен быть достаточно длинным, чтобы калибр можно было считывать в моторном отсеке оператора.
- Потечет воздух из линии измерительной стрелки.

![[06400051.png]]

Работайте с двигателем при номинальной оборотах и полной нагрузке. Это может быть достигнуто с помощью класса и нагрузки, которая требует двигателя для получения максимальной мощности.

![[oi8gaga.png]]

Убедитесь, что линия стока ** не имеет каких-либо петель или ** не ** обжимается.

![[ft8hoca.png]]

Наблюдайте за показаниями на измерительной шкале. Держите калибр на том же уровне, что и соединение.

Максимальное ограничение водосточных линий выглядит следующим образом:

| Сопротивление магистрали слива топлива |  |  |  |  |
|---|---|---|---|---|
|  | хг |  | в хг |  |
| С проверочным клапаном |  | 165 | Макс | 6.5 |
| Без проверочного клапана |  | 65 | Макс | 2.5 |

![[nobox.png]]

Если ограничение выше спецификаций, удалите крышку топливного бака и проверьте еще раз.

![[ft8vacb.png]]

Если ограничение находится в пределах спецификаций при снятии крышки, замените вентиляционные отверстия резервуара.

![[ft8vama.png]]

Если ограничение все еще выше спецификаций, проверьте наличие возвратной подставки.

- Удалите линию возврата топлива из топливного бака.
- Установите адаптер, который позволит подключать ручной насос и манометр к резервуару. Калибр должен иметь минимальную емкость 500 мм Н2 О[20 in-H2 О].

![[ft8hoha.png]]

- Нанесите давление воздуха с помощью ручного насоса. Если давление развивается и удерживается, то существует подставная труба.
- Удалите подставную трубу или переместите обратное соединение топлива в подходящую установку в пространстве расширения топливного бака.

![[oi8tota.png]]

с форсункой электронного управления

Удалите линию слива топлива.

Установите адаптер шланга, номер детали ST-434-2 и калибр давления, номер детали ST-1274-1, между шлангом для слива топлива и установкой слива топлива двигателя.

![[06300060.png]]

Запуск и эксплуатация двигателя при высоком холостом ходу, **no** нагрузке. Ограничение линии слива топлива ** должно быть менее 34 кПа \[10 in-Hg\].

![[06400053.png]]

Если ограничение линии слива топлива выше спецификаций, проверьте линию слива топлива.[[28-006-013 — Fuel Drain Lines|См. процедуру 006-013 в разделе 6.]]

![[fp8hoca.png]]

Удалите измерительное оборудование.

Установите линию слива топлива.

Затяните топливный коридор.

> [!tip] Момент затяжки
> 75 Н·м [55 фунт-фут]

![[06300060.png]]


> [!quote]- Original (English) · английский оригинал
> ### Measure
>
> with Mechanically Actuated Injector
>
> Remove the fuel drain hose.
>
> Install an adapter and pressure gauge Part Number ST-1273, or equivalent, between the fuel drain hose and the engine fuel drain fitting. Minimum gauge capacity must be 200 mm-Hg \[8 in-Hg\].
>
> - Install the adapter on the inlet end of the check valve (if equipped).
> - Use hose adapter from Part Number ST-434 to connect the pressure gauge hose.
> - This hose **must** be long enough to allow the gauge to be read in the operator's compartment.
> - Bleed the air from the gauge line.
>
> Operate the engine at rated rpm and full load. This can be accomplished by using a grade and load that requires the engine to produce maximum power.
>
> Make sure the drain line does **not** have any loops or is **not** crimped.
>
> Observe the reading on the gauge. Hold the gauge at the same level on as the connection.
>
> The maximum drain line restriction is as follows:
>
> | Fuel drain line Restriction |  |  |  |  |
> |---|---|---|---|---|
> |  | mm-hg |  | in-hg |  |
> | With check valve |  | 165 | MAX | 6.5 |
> | Without check valve |  | 65 | MAX | 2.5 |
>
> If the restriction is above specifications, remove the fuel tank fill cap and check again.
>
> If the restriction is within specifications when the cap is removed, replace the tank vents.
>
> If the restriction is still above specifications, check for a return stand-pipe.
>
> - Remove the fuel return line from the fuel tank.
> - Install an adapter that will allow a hand pump and manometer to be connected to the tank. The gauge must have a minimum capacity of 500 mm H 2 O \[20 in-H 2 O\].
>
> - Apply air pressure using the hand pump. If pressure develops and is held, a stand pipe exists.
> - Remove the stand pipe or relocate the fuel return connection to a suitable fitting in the expansion space of the fuel tank.
>
> with Electronically Actuated Injector
>
> Remove the fuel drain line.
>
> Install hose adapter, Part Number ST-434-2, and pressure gauge, Part Number ST-1274-1, between the fuel drain hose and the engine fuel drain fitting.
>
> Start and operate the engine at high idle, **no** load. The fuel drain line restriction **must** be less than 34 kPa \[10 in-Hg\].
>
> If the fuel drain line restriction is above specifications, inspect the fuel drain line. [[28-006-013 — Fuel Drain Lines|Refer to Procedure 006-013 in Section 6.]]
>
> Remove the measuring equipment.
>
> Install the fuel drain line.
>
> Tighten the fuel line.
>
> **Момент затяжки · Torque Value**
> 75 n•m [55 ft-lb]
