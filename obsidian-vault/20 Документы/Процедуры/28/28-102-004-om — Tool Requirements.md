### Общие сведения

Большинство операций по техническому обслуживанию, описанных в этом руководстве, могут выполняться с помощью обычной ручной оснастки.

Ниже приведен список специальных инструментов обслуживания, необходимых для некоторых операций по техническому обслуживанию.

| Инструмент Часть Номер | Наименование |
|---|---|
| СТ-1293 | Измеритель напряжения ремня Берроуза (v-пояса) |
| 3823772 | Измеритель напряжения пояса (пояс фана) |
| 3375049 | Фильтр маслом гаечный ключ |
| 3400158 | Ремень охлаждающего и топливного фильтра |
| 3376592 | Фронтальный ключ (Inch-pound) |
| 3822575 | форсунка и комплект для регулировки клапанов |

Смотрите соответствующие разделы для описания инструментов и как их использовать. Свяжитесь с ближайшим авторизованным ремонтным центром Cummins® для получения необходимых инструментов обслуживания.
