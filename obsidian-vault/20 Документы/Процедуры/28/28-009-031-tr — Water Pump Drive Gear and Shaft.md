### Разборка

с форсункой механического управления

**Снимите с вала только тогда, когда необходимо заменить передачу или вал**.

Используйте пресс-форму беседки. Поддерживайте вал и шестерню, как показано.

Выталкивайте вал из шестерни.

![[dw6gema.png]]

### Проверка при повторном использовании

с форсункой механического управления

Измерить внешний диаметр вала в месте расположения зубчатой передачи.

| Вал вне диаметра |  |  |
|---|---|---|
| мм |  | в |
| 39.776 | Мин | 1.5660 |
| 39.802 | Макс | 1.5670 |

![[dw6shtb.png]]

Измерьте внутренний диаметр шестерни.

| Груша внутри диаметра |  |  |
|---|---|---|
| мм |  | в |
| 39.726 | Мин | 1.5640 |
| 39.751 | Макс | 1.5650 |

Проверьте зубья зубчатой передачи на износ или повреждение.

![[dp8geta.png]]

### Сборка

с форсункой механического управления

Установите вал в кожух.

Применять Loctite® 609, Part Number 3823718 или эквивалент к шестеренкам внутреннего диаметра

Поддержите шестерню в прессе.

Нажмите вал в шестерню.

![[09600016.png]]

Измерьте зазор привода водяного насоса.

| Водонасосный привод End Clearance |  |  |
|---|---|---|
| мм |  | в |
| 0.23 | Мин | 0.009 |
| 0.33 | Макс | 0.013 |

Если конечный зазор **не** в пределах спецификаций, убедитесь, что оба подшипника тяги правильно расположены в противолодках корпуса водяного насоса.

Если подшипники расположены правильно и конечный зазор **не** в пределах спецификаций, привод должен быть полностью разобран и проверялись размеры отдельных компонентов.

![[dw6drta.png]]

### Установка

с форсункой механического управления

Смазать втулку в кожухе передней передачи с помощью LubriplateTM 105, Part Number 3163086, 3163087 или эквивалента.

Установите прокладку (1) на привод пилота.

Установите насосный привод (2), позволяя шестерне поворачиваться, когда она сливается с шестерней бездельника.

Выровняйте отверстия болтов и установите насос для воды, устанавливающие болты и запирающие мойки.

> [!note] Примечание
> Болты (4) составляют 7/16-14x2 3⁄4 дюйма. Болты (5) составляют 7/16-14x1 1⁄4 дюйма.

Установите и затяните болты.

> [!tip] Момент затяжки
> 60 Н·м [40 фунт-фут]

![[dw6drha.png]]

Измерьте зазор водяного насоса после установки привода.

| Окончательный зазор водяного насоса - установлен |  |  |
|---|---|---|
| мм |  | в |
| 0.23 | Мин | 0.009 |
| 0.33 | Макс | 0.013 |
