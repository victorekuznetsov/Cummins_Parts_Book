### Измерение

Удалите шланг для слива топлива.

Установите адаптер, номер 3376719, и датчик измерения давления, номер ST-1273, между установкой слива топлива двигателя и шлангом слива топлива.

![[06400051.png]]

Если двигатель имеет дренажный боковой контрольный клапан, установите адаптер и датчик измерения давления между выпускным отверстием контрольного клапана и шлангом для слива топлива.

![[06400052.png]]

Запуск и эксплуатация двигателя на высоком холостом ходу, без нагрузки.

|  | каша |  | пси |  |
|---|---|---|---|---|
| С проверочным клапаном |  | 21 | Макс | 3 |
| Без проверочного клапана |  | 30 | Макс | 5 |

Все двигатели QSK23 построены без проверочных клапанов.

![[06400053.png]]

Если ограничение линии слива топлива выше спецификаций, проверьте линию слива топлива. См. процедуру[[89-006-013 — Fuel Drain Lines|006-013]].

![[fp8hoca.png]]

Удалите измеритель давления. Установите линию слива топлива.

Затяните топливный коридор.

> [!tip] Момент затяжки
> 95 Н·м [70 фунт-фут]

![[06400039.png]]


> [!quote]- Original (English) · английский оригинал
> ### Measure
>
> Remove the fuel drain hose.
>
> Install the adapter, Part Number 3376719, and pressure gauge, Part Number ST-1273, between the engine fuel drain fitting and the fuel drain hose.
>
> If the engine has a drain side check valve, install the adapter and pressure gauge between the check valve outlet and fuel drain hose.
>
> Start and operate the engine at high idle, no load.
>
> |  | kpa |  | psi |  |
> |---|---|---|---|---|
> | With check valve |  | 21 | MAX | 3 |
> | Without check valve |  | 30 | MAX | 5 |
>
> All QSK23 engines are built without check valves.
>
> If the fuel drain line restriction is above specifications, inspect the fuel drain line. Refer to Procedure [[89-006-013 — Fuel Drain Lines|006-013]].
>
> Remove the pressure gauge. Install the fuel drain line.
>
> Tighten the fuel line.
>
> **Момент затяжки · Torque Value**
> 95 n•m [70 ft-lb]
