> ### Cylinder Block
>
> | **Tool Number** 3164438 | **Depth Gauge Assembly** Used to measure cylinder liner protrusion and cylinder liner counterbore ledge angle. |  |
> |---|---|---|
> | **Tool Number** ST-647 | **Puller** Used to remove the alternator and accessory drive pulleys. |  |
> | **Tool Number** 3163720 | **Dowel Pin Extractor** Used to remove dowel pins and crosshead guides. |  |
> | **Tool Number** ST-1232 | **Drill Ream Fixture** Machine dowel hole used to install oversize dowels in cylinder block and flywheel housing. Use with a drill, reamer, and the appropriate drill/ream bushing set. |  |
> | **Tool Number** 3164401 | **Piston Ring Expander** Used to install piston rings on the piston without damaging or distorting the rings. |  |
> | **Tool Number** 3164207 | **Liner Installation Tool** Used to install cylinder liner in the engine. |  |
> | **Tool Number** 3375432 | **Crack Detection Kit** Used to check for cracks in any engine component. Contains cleaner, developer, and penetrant. |  |
> | **Tool Number** 3375784 | **Light Duty Puller Kit** Used to remove small bushings, oil seals, and bearings. |  |
> | **Tool Number** 3165049 | **Puller Assembly** Used to remove the front crankshaft gear from the crankshaft. Use with the puller jaw, Part Number 3375835. |  |
> | **Tool Number** 3163745 | **Cylinder Liner Puller** Used to remove cylinder liner from engine. Use with puller plate, Part Number 3163751. |  |
> | **Tool Number** 3823494 | **Cummins Sealant** Used to prevent coolant or oil leaks. This is one part room temperature vulcanizing (RTV) silicone rubber, adhesive, and sealant material having high heat and oil resistance, and low compression rate. |  |
> | **Tool Number** 3823621 | **Camshaft Bushing Tool Hydraulic Actuator Kit** Used with hydraulic ram force to install/remove cam bushings when used with installation/removal kit. |  |
> | **Tool Number** 3163015 | **Camshaft Bushing Installation/Removal Kit** Used with the Camshaft Bushing Hydraulic Actuator Kit, Part Number 3823621, to remove the camshaft bushing. |  |
> | **Tool Number** 3164067 | **Loctite® 5699 RTV Sealant** Loctite® 5699 grey RTV sealant (1, 2) is used to provide a seal. |  |
> | **Tool Number** 3164610 | **Camshaft Removal and Installation Kit** Used to install the camshaft without damaging the camshaft bushings or camshaft. Use with the Camshaft Pilot Kit, Part Number 3164845. |  |
> | **Tool Number** 3164375 | **Hydraulic Camshaft Gear Remover Kit** Use with camshaft and crankshaft gear remover kit, Part Number 3164378, air/hydraulic pump, Part Number 3823622, and hydraulic hose, Part Number 3823624. |  |
> | **Tool Number** 3164845 | **Camshaft Pilot Kit** Used to install the camshaft without damaging the camshaft bushings or camshaft. Use with the Camshaft Removal and Installation Kit, Part Number 3164610. |  |
> | **Tool Number** 3823818 | **Main Bearing Roll-out Tool** Used to remove upper main bearing shell. |  |
> | **Tool Number** ST-1116 | **Main Bearing Cap Puller** Used to remove the main bearing caps. |  |
> | **Tool Number** 5298540 | **Crankshaft Seal Replacer Kit** Used to remove/install the rear crankshaft seal. |  |
