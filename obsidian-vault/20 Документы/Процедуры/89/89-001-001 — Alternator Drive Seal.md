# Alternator Drive Seal

> **Двигатели:** [[85017333 — QSK23 CM500 CPL 2858|85017333]]

> **Секции:** Section 1 - Cylinder Block - Group 01
> **Даты:** изменён 2003-08-04
> **Источник:** [QuickServe](https://quickserve.cummins.com/qs3/pubsys2/xml/en/procedures/89/89-001-001.html) · [PDF-оригинал](https://github.com/victorekuznetsov/Cummins_Parts_Book/raw/main/bulletins/procedures/89-001-001.pdf)

### Preparatory Steps

Remove the alternator drive belt. Refer to Procedure [[89-013-005 — Charging System Alternator Drive Belt|013-005]].

![[ck800wa.png]]

### Remove

> [!note] Note · Примечание
> Some components shown removed from engine for clarity.

Loosen the four alternator drive housing capscrews and remove the alternator drive housing.

Remove the o-ring seal from the alternator drive housing.

![[01400532.png]]

### Install

Lubricate the o-ring seal with clean engine oil.

Install the o-ring seal into the alternator drive housing.

Verify that the fuel pump coupling is in place.

Install the alternator drive housing and four capscrews into the front gear housing.

Bar the engine, if necessary, to align the drive gear with the idler gear and the drive coupling with the fuel pump coupling.

Tighten the four capscrews alternately and evenly.

> [!tip] Момент затяжки · Torque Value
> 113 n•m [83 ft-lb]

![[01400533.png]]

### Finishing Steps

Install the alternator drive belt. Refer to Procedure [[89-013-005 — Charging System Alternator Drive Belt|013-005]].

![[ck800wa.png]]
