### Общие сведения

Большинство операций по техническому обслуживанию, описанных в этом руководстве, могут выполняться с помощью обычной ручной оснастки (венчей, розеток и отверток Общества автомобильных инженеров (SAE)).

Ниже приведен список специальных инструментов обслуживания, необходимых для некоторых операций по техническому обслуживанию:

| Инструмент Часть Номер | Наименование |
|---|---|
| 3163569 | Измеритель напряжения пояса (v-пояса) |
| 3375049 | Фильтр маслом гаечный ключ |
| 3376807 | Водный/топливный фильтр-гаечный ключ |
| 3822524 | Измеритель напряжения ремня (тип щелчка) |
| 3822525 | Измеритель напряжения ремня (тип щелчка) |
| 3824783 | Дальнобойный ключ (диал) |
| 3824901 | Оборудование для измерения ресниц |

- Смотрите соответствующие разделы для описания инструментов и как их использовать.
- Свяжитесь с ближайшим авторизованным ремонтным центром Cummins для получения необходимых инструментов обслуживания.
