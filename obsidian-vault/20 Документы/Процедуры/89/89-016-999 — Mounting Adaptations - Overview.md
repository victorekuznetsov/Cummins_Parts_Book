### Общие сведения

QSK23 доступен с комбинацией обсадных колес SAE 0 или SAE 1. Маховик SAE 0 имеет 138 зубцов с кольцевой передачей. Кольцевое колесо SAE 1 имеет 118 зубов.

3.2.1 Защелкнутые отверстия для монтажа трансмиссии представляют собой:

- 24 - 7/16-14 UNC-2B для корпуса маховика SAE № 1
- 16 - M12 x 1,75 для корпуса маховика SAE № 0.

Корпус маховика имеет два магнитных места пикапа. В настоящее время магнитное отверстие для пикапа предназначено для использования электронной системой управления двигателем. Магнитное отверстие для пикапа, доступное для использования клиентами, составляет M22 x 1,5.

> [!quote]- Original (English) · английский оригинал
> ### General Information
>
> The QSK23 is available with a SAE 0 or SAE 1 flywheel/flywheel housing combination. The SAE 0 flywheel has a ring gear count of 138 teeth. The SAE 1 flywheel ring gear has 118 teeth.
>
> Tapped holes for transmission mounting are:
>
> - 24 - 7/16-14 UNC-2B for SAE number 1 flywheel housing
> - 16 - M12 x 1.75 for SAE number 0 flywheel housing.
>
> The flywheel housing has two magnetic pickup locations. A magnetic pickup hole is currently dedicated for use by the electronic engine control system. The magnetic pickup hole available for customer use is M22 x 1.5.
