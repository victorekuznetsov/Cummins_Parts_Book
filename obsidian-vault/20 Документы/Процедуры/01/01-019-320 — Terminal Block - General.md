### Общие сведения

Терминальные блоки обеспечивают подключение клиентов для проводов, поставляемой клиентами, которая взаимодействует с управлением. Блоки терминала расположены на всех печатных платах ECM (кроме топливной платы), за исключением TB3, который монтируется на собственной терминальной рельсе.

![[19802812.png]]

### Снятие

Отвинтить крепежный винт на каждом конце блока терминала, чтобы удалить блок терминала TB4, TB5, TB6 или TB8.

![[19802835.png]]

Вытащите блок терминала из платы.

![[19802837.png]]

Отключите все проводов клиента к блоку терминала. Устраните каждый соответствующий винт вдоль стороны блока терминала. Обязательно пометьте провода для установки.

![[19802836.png]]

### Установка

Установите все проводов клиента в новый блок терминала. Затягивайте каждый соответствующий винт вдоль стороны блока терминала. Убедитесь, что провода безопасны.

![[19802836.png]]

Найдите терминальный блок в правильном положении на правильной плате.

![[19802837.png]]

Закрепите крепежный винт на каждом конце блока терминала.

Используя инструмент электронного сервиса, проверьте наличие активных кодов неисправностей.

![[19802835.png]]


> [!quote]- Original (English) · английский оригинал
> ### General Information
>
> The terminal blocks supply customer connections for customer-supplied wiring that interfaces with the control. Terminal blocks are located on all ECM circuit boards (except fuel board), with the exception of TB3, which is mounted on its own terminal rail.
>
> ### Remove
>
> Unscrew the mounting screw at each end of the terminal block to remove terminal block TB4, TB5, TB6, or TB8.
>
> Pull the terminal block off of the circuit board.
>
> Disconnect all customer wiring to the terminal block. Loosen each corresponding screw along the side of the terminal block. Be sure to label wires for installation.
>
> ### Install
>
> Install all customer wiring into the new terminal block. Tighten each corresponding screw along the side of the terminal block. Make sure the wires are secure.
>
> Locate the terminal block in the proper position on the correct circuit board.
>
> Tighten the mounting screw on each end of the terminal block.
>
> Using the electronic service tool, check for active fault codes.
