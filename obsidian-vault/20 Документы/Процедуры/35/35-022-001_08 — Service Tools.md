> ### Cooling System
>
> | **Tool Number** CC-2602 | **Cooling System Test Kit** The Fleetguard® coolant test kit is used to check the concentration of coolant additives in the cooling system. |  |
> |---|---|---|
> | **Tool Number** CC-2800 | **Refractometer** The Fleetguard® refractometer is used to measure the freezing point protection and antifreeze concentration. |  |
> | **Tool Number** ST-647 | **Standard Puller** Use to remove the stamped steel water pump pulley. Use in conjunction with two capscrews 5/16 x 18 x 2. |  |
> | **Tool Number** ST-1225 | **Thermostat Seal Mandrel** Use to install the thermostat seal in the thermostat housing. |  |
> | **Tool Number** ST-1293 | **Belt Tension Gauge** Use to measure the fan drive v-ribbed belt tension. |  |
> | **Tool Number** 3376326 | **Pulley Installation Tool** Used to install drive pulleys. Use in conjunction with Part Number 3377401 adapter. |  |
> | **Tool Number** 3377462 | **Digital Optical Tachometer** Used to measure rpm of a viscous fan. |  |
> | **Tool Number** 3376488 | **Guide Pin** Two guide pins are used to install the water heater plate. |  |
> | **Tool Number** 3822985 | **Combustion Gas Leak Test Kit** Includes: Part No. 3822986, test fluid; Part No. 3822987, adapter; and Part No. 3877612, instructions. |  |
> | **Tool Number** 3822994 | **Coolant Pressure/Temperature/Flow Analyzer Kit** Includes: Part Number 3822995 pressure gauge; Part Number 3822996, temperature gauge; Part Number 3822997, flow sight glass, Part Number 3822998 Compuchek™ fitting (Female); and Part Number 3377613, instructions. Optional: Part Number 3823099, hose extension kit, is also available. |  |
> | **Tool Number** 3824117 | **Bearing Installation Tool** Used to replace the water pump drive needle bearing in the gear housing. |  |
> | **Tool Number** 3823815 | **Water Pump Seal Driver** Used to install the unitized seal in the water pump. For use on engines with EGR. For use with Chicago-Allis™ seal. The seal is identified by the Cummins® part number only. |  |
> | **Tool Number** 4918797 | **Water Pump Seal Driver** Used to install the unitized seal in the water pump. For use on engines with EGR. For use with Kaco™ seals. The seal is identified by the Kaco™ name. |  |
