### Снятие

Если контрольный клапан в передаточном насосе возвратного локтя остается открытым или закрытым, замените локтевой.

![[fp8vacc.png]]

Проверьте резьбу по локтю. Сделайте **не** установить локоть, который имеет прямую резьбу машины в отверстие, которое имеет резьбу для крана трубы. Переключающий насос, имеющий прямую резьба, будет иметь пятно 19 мм \[0,750-в\] в области клапана. Переключающий насос, который имеет резьба для крана трубы, будет иметь 16-мм \[0,625-в\] пятно или без пятнышка.

![[gr8vasa.png]]

Удалите дренажную линию.

Удалите локтевой клапан.

![[gr8tbmb.png]]

### Установка

Установите локтевой клапан.

- Если локтевой клапан имеет машинную резьбу на максимальную глубину резьбы, выверните локтевую кость, пока она не будет направлена к дренажной линии. Затяните локон.

> [!tip] Момент затяжки
> 6 Н·м [50 фунт-дюйм]

- Если контрольный клапан имеет резьба трубы, установите локоть, пока он не будет плотным и не будет направлен к дренажной линии.

![[fp8vahh.png]]

Установите дренажную линию.

![[gr8tbha.png]]


> [!quote]- Original (English) · английский оригинал
> ### Remove
>
> If the check valve in the gear pump return elbow stays open or closed, replace the elbow.
>
> Check the elbow threads. Do **not** install an elbow that has straight machine threads in a hole that has a pipe tap thread. A gear pump that has a straight thread will have a 19-mm \[0.750-in\] spotface in the valve area. A gear pump that has a pipe tap thread will have a 16-mm \[0.625-in\] spotface or no spotface.
>
> Remove the drain line.
>
> Remove the check valve elbow.
>
> ### Install
>
> Install the check valve elbow.
>
> - If the check valve elbow has machine threads to the maximum thread depth, turn the elbow out until it is pointed toward the drain line. Tighten the jam nut.
>
> **Момент затяжки · Torque Value**
> 6 n•m [50 in-lb]
>
> - If the check valve has a pipe thread, install the elbow until it is tight and pointed toward the drain line.
>
> Install the drain line.
