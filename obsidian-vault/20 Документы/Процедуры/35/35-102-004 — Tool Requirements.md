### Общие сведения

Большинство операций по техническому обслуживанию, описанных в этом руководстве, могут выполняться с помощью обычной ручной оснастки, метрических и SAE гаечных ключей, розеток и отверток.

Ниже приведен список специальных инструментов обслуживания, необходимых для некоторых операций по техническому обслуживанию:

| Номер детали инструмента: | Наименование: |
|---|---|
| 3400157 | Фильтр маслом гаечный ключ |
| 3376592 | Зубной ключ (клапанная и топливная регулировка форсунки) |
| 3163196 | Адаптер гаечного ключа крутящего момента (используется с гаечным ключом 3376592) |
| 3400158 | Охладитель двигателя и гаечный ключ топливного фильтра |
| 3822524 | Измеритель напряжения ремня, тип щелчка (v-поясы и v-пояс с 4 или 5 ребрами) |
| 3822525 | Измеритель напряжения ремня, тип щелчка (v-риббированный с 6 до 12 ребер) |
| ST-1138 | Измеритель напряжения пояса (v-пояса) |
| СТ-537 | Диапазон глубины измерения |
| 3164019 | Инструмент для удаления чипов |
| СТ-1293 | Измеритель напряжения пояса (v-образные ремни) |
| CC-2800 | Рефрактометр |
| CC-2602 | Измерительный комплект с охлаждающим покрытием |

Свяжитесь с авторизованным местом ремонта Cummins® для необходимых инструментов обслуживания.
