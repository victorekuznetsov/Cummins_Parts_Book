| **Tool Number** ST-647 | **Standard Puller** Used to remove alternator drive pulley. Used with two 5/16 x 18 x 2 inch capscrews. |  |
|---|---|---|
| **Tool Number** ST-821 | **Piston Ring Expander** Used to remove and install piston rings on pistons. |  |
| **Tool Number** ST-1178 | **Main Bearing Cap Puller** Used to remove main bearing caps. |  |
| **Tool Number** ST-1293 | **Belt Tension Gauge** Measure drive V-ribbed belt tension. |  |
| **Tool Number** 3162873 | **Universal Cylinder Liner Puller** Used to remove cylinder liners from cylinder block. Requires cylinder liner puller plate, Part Number 3376049. |  |
| **Tool Number** 3376637 and 3376636 | **Slide Hammer Kit/Mandrel Kit** Used to install and remove camshaft bushings. Includes slide hammer and extension shaft. Used with camshaft bushing mandrel, Part Number 3373363. |  |
| **Tool Number** 3375840 | **Crankshaft Gear Puller Kit** Used to remove the crankshaft gear. Requires puller, Part Number 3375834, and jaw, Part Number 3375839, to be used. |  |
| **Tool Number** 3376038 | **Connecting Rod Guide Pins** Guide connecting rods over crankshaft during removal or installation of connecting rods. |  |
| **Tool Number** 3376326 | **Pulley Installation Tool** Install drive pulleys. Use pulley pusher adapter, Part Number 3377401, to install the alternator drive pulley. |  |
| **Tool Number** 3376388 | **Camshaft Guide Pilot** Aid in removal and installation of the camshaft. |  |
| **Tool Number** 3376488 | **Guide Pin** Two guide pins are used to install the water header plate. |  |
| **Tool Number** 3823621 | **Hydraulic Actuator Kit** Used with installation/removal kit. |  |
| **Tool Number** 3823642 | **Installation/Removal Kit** Used to install/remove camshaft bushings. |  |
| **Tool Number** 3376695 | **Guide Pin Kit** Aid during installation of vibration damper. The kit consists of two each guide pins, Part Numbers 3376488, 3376638, 3376696, 3376697, and 3376698. |  |
| **Tool Number** 3823309 | **Piston Ring Compressor** Compress piston rings on pistons during installation of pistons in the cylinder block. |  |
| **Tool Number** 3823495 | **Gauge Block** Measure cylinder protrusion on the cylinder block and gear housing protrusion below the cylinder block. |  |
| **Tool Number** 3823774 | **Needle Bearing Kit** Used to remove and install needle bearings in the gear housing and hydraulic pump adapter. Use mandrel, Part Number 3823776, to install hydraulic pump needle bearings. |  |
| **Tool Number** 3162895 | **Cam Gear Puller Kit** Used to remove the camshaft gear from the camshaft without removing the camshaft from the engine. |  |
| **Tool Number** 3824117 | **Needle Bearing Installation Tool** Used to remove and install the water pump drive needle bearing in the gear housing. |  |
| **Tool Number** 3824270 | **Engine Barring Tool** Used to bar the engine by hand. |  |
| **Tool Number** 3824272 | **Liner/Installation Tool** Used to seat and hold the liner while liner protrusion is measured. |  |
| **Tool Number** 4918798 | **Crankshaft Seal Used to remover** Used to remove and install the front crankshaft oil seal. |  |
