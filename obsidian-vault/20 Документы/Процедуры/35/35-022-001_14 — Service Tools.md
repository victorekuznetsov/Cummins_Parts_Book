> |---|---|---|
> | **Tool Number** ST-1111-3 | **Manometer** Used with tool, Part Number 3375150, for measuring blowby. |  |
> | **Tool Number** ST-1135 | **Lubricating Oil Sampling Filter** Used to monitor oil contamination. |  |
> | **Tool Number** ST-1273 | **Pressure Gauge** Used to measure intake manifold pressure. The pressure gauge is not needed if INSITE™ electronic service tool is available. |  |
> | **Tool Number** 3375275 | **Pressure Gauge (0 to 160 psi)** Used to measure lubricating oil pressure. The pressure gauge is not needed if INSITE™ electronic service tool is available. |  |
> | **Tool Number** 3375932 | **Pressure Gauge (0 to 300 psi)** Used to measure fuel pressure. Includes necessary hoses and hardware to attach to a fuel pump. Part Number ST-435-1 is the hose and Part Number ST-435-6 is the pressure gauge. |  |
> | **Tool Number** 3376375 | **Fuel Measuring Device** Used to measure the rate of fuel consumption of a Cummins® diesel engine. |  |
> | **Tool Number** 3377462 | **Digital Optical Tachometer** Used to measure engine speed (rpm). The digital optical tachometer is not needed if INSITE™ electronic service tool is available. |  |
> | **Tool Number** 3822566 | **Blowby Check Tool (.302 Orifice)** Used with manometer, Part Number ST-1111-3, to measure the engine crankcase pressure. |  |
> | **Tool Number** 3823948 | **CELECT™/CELECT™ Plus Engine Dynamometer Control** Used on an engine dynamometer to control the CELECT™/CELECT™ Plus engine. |  |
> | **Tool Number** 3823978 | **Dynamometer-Room Charge Air Cooler** Used to cool intake air when an air-to-air engine is operated on an engine dynamometer. |  |
> | **Tool Number** 3162844 | **Datalink Adapter Kit** INLINE 2™ adapter and associated cables are used to connect a computer to an engine datalink. |  |
> | **Tool Number** 3886206 | **INSITE™ Electronic Service Tool Software Kit** This INSITE™ software kit, Part Number 3885790, is for use with interact system engines. Each software kit can also be ordered separately. The kits are used to troubleshoot, program, and adjust the electronic control system. |  |
