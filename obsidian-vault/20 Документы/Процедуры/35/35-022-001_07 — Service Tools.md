> ### Lubricating Oil System
>
> | **Tool Number** 3397929 | **Oil Filter Wrench** Used to remove and install the lubricating oil filters. |  |
> |---|---|---|
> | **Tool Number** 3375182 | **Spring Compression Tester** Measures spring force at a given spring height. |  |
> | **Tool Number** 3375784 | **Light-Duty Puller Kit** Used to remove the high oil pressure regulator retainer plug. |  |
> | **Tool Number** 3376486 | **Regulator Valve Seat Driver** Used to install the high oil pressure seat in the cylinder block. |  |
> | **Tool Number** 3376489 | **Retainer Plug Driver** Used to install the high oil pressure regulator retainer plug in the cylinder block. |  |
> | **Tool Number** 3376579 | **Tube Cutter** Used to open the oil filter for filter element inspection. |  |
> | **Tool Number** 3376861 | **Lubricating Oil Cooler Pressure Test Kit** Used to pressure-test the lubricating oil cooler element. The test kit consists of two gaskets, Part Number 3376866, plates, Part Number 3376890, and Part Number 3376889. |  |
