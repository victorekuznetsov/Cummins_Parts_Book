# Temperature Sensor Harness

> [!abstract] Процедура · `97-019-296`
> **Двигатели:** [[35354607 — QSM11 CM570 CPL 8608|35354607]], [[35373113 — QSM11 CM570 CPL 8471|35373113]], [[71156161 — QSM11 CM570 CPL 8543|71156161]], [[80141463 — QSX15 CM570 CPL 3088|80141463]], [[80248213 — QSX15 CM570 CPL 8760|80248213]]

### Remove

Turn the keyswitch to the OFF position.

Remove any wire ties or other similar material securing the temperature sensor harness to an air line or wire conduit (under the fifth wheel).

Disconnect the temperature sensor harness from the ambient air temperature sensor.

![[19c00945.png]]

Disconnect the temperature sensor harness from the cab thermostat.

Remove the temperature sensor harness.

![[19c00949.png]]

### Install

Turn the keyswitch OFF.

Secure the temperature sensor harness to an air line or wire conduit (under the fifth wheel).

Connect the temperature sensor harness to the ambient air temperature sensor.

![[19c00945.png]]

Connect the temperature sensor harness to the cab thermostat.

![[19c00949.png]]
