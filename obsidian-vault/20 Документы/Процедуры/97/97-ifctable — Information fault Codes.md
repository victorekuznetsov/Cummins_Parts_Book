> [!note] Note · Примечание
> The following Fault Code Priority Table shows which faults are severe (shown as severity of “1”). Severe faults will deactivate the ICON™ system or not allow the ICON™ system to be activated. The ICON™ lamp will only display the highest priority fault. Use the priority level to determine which fault codes have a priority level lower than the active fault. This information can help eliminate troubleshooting circuits with a higher priority level and help reduce troubleshooting time.

CODE:

442 (Aftermarket)

LAMP:

ICON™

REASON:

Battery OOR high. This fault code is set when 33 VDC is observed at the batteries for more than 3 seconds. This code was originally considered for a 24 volt system.

EFFECT:

ACTION:

Severity level 1; priority level 13.
