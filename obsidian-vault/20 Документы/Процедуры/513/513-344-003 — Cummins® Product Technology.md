### Общие сведения

Название модели сервиса для этого продукта - **C Command Connect и Connect Premier Marine Panel System PS102, PS103 и PS108**.

Система C Command Connect и Connect Premier Marine Panel System используется для мониторинга основных датчиков судна и эксплуатационных характеристик двигателя, а также для управления функциями запуска и остановки двигателя.

Эта система получает информацию о шине данных двигателя Общества автомобильных инженеров (SAE) J1939 от модуля управления двигателем (ECM). Система получает информацию о датчиках судов от Национальной морской электронной ассоциации (NMEA) 2000 или шины данных J1939 CAN.

Данный продукт использует следующую технологию продукта:

#### PS102 - C Command Connect и Connect Premier

- Интерфейсная коробка заказчика
- Компоненты шлема (включает переключатели, дисплей и сигнальный рог)
- Связанные межсоединительные проводные ремни

#### PS103 - C Command Connect и Connect Premier

- Интерфейсная коробка заказчика
- Компоненты шлема (включает переключатели, дисплей и сигнальный рог)
- Связанные межсоединительные проводные ремни
- Функциональность ED4
- Мониторинг датчиков - зависит от выбранного файла личности судна (через C Command Connect или ECM).

#### PS108 - C Command Connect и Connect Premier

- Интерфейсная коробка заказчика
- Компоненты шлема (включает переключатели, дисплей и сигнальный рог)
- Связанные межсоединительные проводные ремни
- ED-4 Функциональность
- ED-5/ED-7 Функциональность
- Функциональность удаленной клавиатуры
- Мониторинг датчиков - зависит от выбранного файла личности судна (через C Command Connect или ECM).

Маркетинговые приложения, которые будут использовать этот продукт, включают:

#### глобальный

- Морской отдых
- Коммерческий морской пехотинец
- Морской пехотинец.


> [!quote]- Original (English) · английский оригинал
> ### General Information
>
> The service model name for this product is **C Command Connect and Connect Premier Marine Panel System PS102, PS103 and PS108**.
>
> The C Command Connect and Connect Premier Marine Panel System is used to monitor basic vessel sensors and engine operating characteristics, as well as to control engine start and stop functions.
>
> This system receives engine Society of Automotive Engineers (SAE) J1939 data link information from the engine control module (ECM). The system receives vessel sensor information from National Marine Electronics Association (NMEA) 2000 or J1939 data link.
>
> This product uses the following product technology:
>
> #### PS102 - C Command Connect and Connect Premier
>
> - Customer Interface Box
> - Helm Components (includes switches, display, and alarm horn)
> - Associated Interconnect Harnesses
>
> #### PS103 - C Command Connect and Connect Premier
>
> - Customer Interface Box
> - Helm Components (includes switches, display, and alarm horn)
> - Associated Interconnect Harnesses
> - ED4 Functionality
> - Sensor Monitoring - depends on selected vessel personality file (through C Command Connect or ECM)
>
> #### PS108 - C Command Connect and Connect Premier
>
> - Customer Interface Box
> - Helm Components (includes switches, display, and alarm horn)
> - Associated Interconnect Harnesses
> - ED-4 Functionality
> - ED-5 / ED-7 Functionality
> - Remote Keypad Functionality
> - Sensor Monitoring - depends on selected vessel personality file (through C Command Connect or ECM)
