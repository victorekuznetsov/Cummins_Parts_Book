### General Information

The service model name for this product is **C Command Connect and Connect Premier Marine Panel System PS102, PS103 and PS108**.

The C Command Connect and Connect Premier Marine Panel System is used to monitor basic vessel sensors and engine operating characteristics, as well as to control engine start and stop functions.

This system receives engine Society of Automotive Engineers (SAE) J1939 data link information from the engine control module (ECM). The system receives vessel sensor information from National Marine Electronics Association (NMEA) 2000 or J1939 data link.

This product uses the following product technology:

#### PS102 - C Command Connect and Connect Premier

- Customer Interface Box
- Helm Components (includes switches, display, and alarm horn)
- Associated Interconnect Harnesses

#### PS103 - C Command Connect and Connect Premier

- Customer Interface Box
- Helm Components (includes switches, display, and alarm horn)
- Associated Interconnect Harnesses
- ED4 Functionality
- Sensor Monitoring - depends on selected vessel personality file (through C Command Connect or ECM)

#### PS108 - C Command Connect and Connect Premier

- Customer Interface Box
- Helm Components (includes switches, display, and alarm horn)
- Associated Interconnect Harnesses
- ED-4 Functionality
- ED-5 / ED-7 Functionality
- Remote Keypad Functionality
- Sensor Monitoring - depends on selected vessel personality file (through C Command Connect or ECM)

Market applications that will use this product include:

#### Global

- Recreation Marine
- Commercial Marine
- Government Marine.
