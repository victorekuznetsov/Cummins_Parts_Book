### Общие сведения

Дисплей Cummins® C Command Connect и Connect Premier Marine Panel System ED-4/ED-5/ED-7 предварительно загружены программным обеспечением с завода. Программное обеспечение Cummins® ED-4 Display и файл личности сосуда **должны быть обновлены и настроены до надлежащей работы дисплея. Дисплей Cummins® ED-5/ED-7** должен быть сконфигурирован для выбора предварительно загруженных файлов/тем личности сосуда до надлежащей работы дисплея.

> [!note] Примечание
> Обновление программного обеспечения стирает настройки конфигурации, файлы журналов и сохраненные файлы личности судна в ED-4.

Конфигурация:

На странице конфигурации ED-4 есть несколько элементов, к которым можно получить доступ.

1. Настройки сети устройств - Используется для устройства, настроенного на ED-4. Эта страница получает доступ к исходному адресу приемопередатчиков сети контроллеров (CAN) ED-4.
2. Файл личности сосуда - используется для выбора файлов личности сосуда, хранящихся во внутренней памяти ED-4.
3. Конфигурация экрана - используется для включения или отключения экранов данных, просматриваемых оператором.
4. IO Configuration - используется для настройки ввода и вывода датчиков.
5. Stbd - используется для установки адреса источника правого двигателя, контролируемого ED-4(ами).
6. Порт - используется для настройки адреса источника двигателя порта, контролируемого ED-4(ами).

> [!note] Примечание
> Параметры 1-4 конфигурации обычно контролируются файлом личности судна.

> [!note] Примечание
> Настройка элементов 5 и 6 относится к двигателю (двигателям) или генератору (генераторам) и важна для надлежащей функциональности и мониторинга данных с помощью ЭД-4. На странице может быть доступно более или менее двигателей и/или генераторов для установки в зависимости от файла личности судна, загруженного в ED-4.

Конфигурация - Настройки сети устройств

Существует четыре варианта в настройках сети устройств:

1. Канал 1 КАН
2. Канал 2 (Изолированный)
3. Стыковка PGN
4. родитель

> [!note] Примечание
> Настройка родительского ED-4 должна быть обновлена для системы после обновления программного обеспечения и/или файла личности сосуда. В системе всегда будет один родитель. Родитель обычно устанавливается в ED-4, расположенном в C.I.B. Смотрите ниже для более подробной информации.

![[15e00196.png]]

Настройки сети устройств - Настройки канала 1 CAN - J1939

- Бауд Рейтинг: **всегда** должен быть установлен в соответствии с частотой вещания ECM, которая обычно составляет 250 Кб. Если настройка скорости baud неверна, данные на экране данных ED-4 будут тире.
- Семенной адрес: Используется для ручного установления адреса источника ЭД-4. Диапазон адреса семян обычно составляет от 228 до 231 для C.I.B. ЭД-4. Адрес семени ED-4 обычно 128 или выше. Когда Предпочтительный адрес включен и установлен на действительный адрес в файле личности судна, Семенной адрес будет отображаться как «Предпочтительный».
- Предпочтительный адрес: Адрес, который, вероятно, будет использоваться ED-4, если он доступен, и важен для вещания при использовании в качестве шлюза. Адрес информатора. ED-4 будет пытаться утверждать, что обычно находится в диапазоне от 228 до 231. В случае конфликта адреса с предпочтительным адресом, сигнализация будет срабатывать с помощью ED-4. Всякий раз, когда предпочтительный адрес не доступен или заявлен ED-4, срабатывает сигнализация. Предпочтительный адрес будет отображаться как «Отключенный» для дисплеев ED-4.
- Выполните требование адреса: Используется для сохранения адреса семени или предпочтительного адреса, выбранного вручную.
- Фактический адрес: Адрес, заявленный ED-4, который начинается с адреса семени или предпочтительного адреса, затем увеличивается до уникального адреса для каждого ED-4 в общей сети. Адрес 128 устанавливается на ED-4 с наименьшим серийным номером программного обеспечения.

![[15e00161.png]]

- Семенной адрес: Используется для ручного установления адреса источника ЭД-4. Адрес семени ED-4 обычно 128 или выше. Когда Предпочтительный адрес включен и установлен на действительный адрес в файле личности судна, Семенной адрес будет отображаться как «Предпочтительный».
- Предпочтительный адрес: Адрес, который, вероятно, будет использоваться ED-4, если он доступен, и важен для вещания при использовании в качестве шлюза. Адрес информатора. ED-4 будет пытаться утверждать, что обычно находится в диапазоне от 228 до 231. В случае конфликта адреса с предпочтительным адресом, сигнализация будет срабатывать с помощью ED-4. Всякий раз, когда предпочтительный адрес не доступен или заявлен ED-4, срабатывает сигнализация. Предпочтительный адрес будет отображаться как «Отключенный» для дисплеев ED-4.
- Выполните требование адреса: Используется для сохранения адреса семени или предпочтительного выбранного вручную.
- Фактический адрес: Адрес, заявленный ED-4, который начинается с адреса семени или предпочтительного адреса, затем увеличивается до уникального адреса для каждого ED-4 в общей сети. Адрес 128 устанавливается на ED-4 с наименьшим серийным номером программного обеспечения.

Настройки сети устройств - родитель

Для C Command Connect Premier, ED-4 на C.I.B. Обычно он устанавливается как родитель.

Для C Command Connect без C.I.B. ED-4, расположенный на главной станции на судне, будет установлен в качестве Родителя.



Типы родительских заявлений:

- Изолированный J1939 с устройствами, подключенными к J1939 - один родитель на двигатель.
- J1939 — один родитель на судно.
- Независимый J1939, но с мостиком NMEA 2000 или двойной J1939 дисплей - один родитель на судно.

> Перед обновлением программного обеспечения и/или файла личности сосуда важно найти настройку ED-4 в качестве Родителя системы.

Конфигурация - файл личности судна

Используйте следующую процедуру для получения информации о «файле личности судна» на странице «Конфигурация».[[513-015-044 — Managing Vessel Personalities|См. процедуру 015-044 в разделе 15.]]

Изменения настройки и настройки ED-4 сохраняются во внутренней памяти ED-4. Для обновления локально хранящегося файла личности судна файл личности судна должен быть экспортирован на USB-накопитель, а затем импортирован обратно в ED-4 и сохранен в качестве «любимого».

> [!note] Примечание
> Программное обеспечение контролирует количество файлов личности сосуда по умолчанию, хранящихся во внутренней памяти ED-4. Дополнительные файлы личности сосуда могут быть сохранены во внутреннюю память ED-4 путем импорта с USB-накопителя.

Конфигурация IO Configuration

Настройки конфигурации IO контролируются файлом личности судна. Компоненты/датчики, перечисленные на странице, обычно являются датчиками оригинального оборудования (OEM), не связанными с двигателем.

Действие:

- Выберите «IO Configuration» и нажмите клавишу 4 или «Enter».
- Выберите каждый и нажмите клавишу 4 или «Войти».
- Доступны различные типы и диапазоны датчиков.

Тип датчика и диапазон должны быть выбраны, чтобы включить его «Включено» на странице.

Для правильного отображения данных параметр должен выбрать правильный диапазон датчиков.

Для определения типа и диапазона датчика ED-4, который в настоящее время настроен, обратитесь к режиму измерения на странице просмотра ввода/вывода. Используйте измерительный раздел следующей процедуры для доступа.[[513-015-035 — Display(s) and Instrumentation|См. процедуру 015-035 в разделе 15.]].

> [!note] Примечание
> Для того чтобы датчик правильно отображал данные на ЭД-4, он должен иметь правильную калибровочную таблицу, загруженную в файл личности судна. Используйте следующую процедуру для доступа к информации датчика, содержащейся в файле личности судна.[[513-015-044 — Managing Vessel Personalities|См. процедуру 015-044 в разделе 15.]]Группа Cummins® Marine Application Engineering создает файлы личности судна и обновляет папку дисков или дисков Cummins® QuickServe® Online «Cummins® ED-4 Display Vessel Personality File Tracking Sheet» с именем файла, версией и описанием судна, приложения, оборудования и информации датчика судна.

Нажмите клавишу 5 или «Назад», чтобы сохранить настройку и выйти из страницы.

Конфигурация: Adjust Alarms

Действие:

- Выберите «Настройка сигнализации» и нажмите клавишу 4 или «Войти».

Настройка меню Selection

Настройка:

На странице настройки ED-5 / ED-7 есть несколько элементов, к которым можно получить доступ.

1. Режим меню - используется для переключения между базовыми и расширенными настройками уровня ED-5 / ED-7.
2. Подключение - используется для устройства, настроенного на ED-5/ED-7. На этой странице осуществляется доступ к исходному адресу приемопередатчиков сети контроллеров (CAN) и конфигурации аналоговых входов ED-5/ED-7.
3. Темы - Используется для выбора файлов личности сосуда / конфигурации приложения, хранящихся и настройки файлов личности сосуда / конфигурации приложения, хранящихся в памяти ED-5 / ED-7.
4. Двигатели - используются для установки адресов источника двигателей, контролируемых ED-5/ED-7.
5. диапазоны измерительных приборов – используются для корректировки диапазона параметров, отслеживаемых на странице экрана данных для ED-5/ED-7. Корректировка диапазона определяет минимальное и максимальное значение, сообщенное для параметра на дисплее.
6. Local Time Offset — используется для корректировки разницы в часах и минутах между UTC и местным временем.
7. Предустановки уровня подсветки - Используется для настройки предустановок уровня подсветки для Dark Mode и Light Modes.
8. NMEA Switch Bank - используется для настройки удаленной клавиатуры для использования с дисплеем.

Изменение настроек ED-5/ED-7 на странице настройки может привести к потере функциональности системы. Доступ к странице настройки регистрируется как событие во внутреннем журнале событий памяти ED-5/ED-7.

Файлы личности сосуда дисплея поставляются предварительно сконфигурированными с экранами данных по умолчанию, доступными для каждого типа двигателя или приложения. Доступный экран данных контролируется темой или файлом личности сосуда.

> [!note] Примечание
> Настройка параметров компоновки экрана может быть выполнена с экрана данных путем нажатия в середине экрана данных и следования шагу 5 ниже.

Действие:

1. Выберите «Настройка существующего».
2. Выберите «Screens».
3. Выберите «Настройка существующего».
4. Выберите макет экрана, чтобы настроить параметр для отображения на экране данных.
5. Используйте «Prev» или «Next» для настройки параметров экрана данных.

Настройка - Настройка уровня подсветки

Дисплей обеспечивает возможность переключаться между темным режимом и легким режимом. Темный режим настроен с более низким уровнем подсветки, чтобы его было легче увидеть при слабом освещении. Режим освещения настроен с более высоким уровнем подсветки, чтобы было легче видеть при ярком свете.

Действие:

- Выберите «Предустановки уровня подсветки» с помощью сенсорного экрана или с помощью удаленной клавиатуры.
- Настройте уровень подсветки для «темного режима» или «легкого режима», используя кнопки увеличения или уменьшения на сенсорном экране или используя правую или левую кнопку на удаленной клавиатуре.

Когда закончите:

Настройка - NMEA Switch Bank

Конфигурация дисплея включает в себя возможность настройки удаленной клавиатуры, она предоставляет возможность выбора удаленной клавиатуры из меню NMEA Switch Bank. Клавиатура, однажды подключенная к проводах дисплея, должна появиться в списке клавиатуры по умолчанию для выбора. После выбора удаленной клавиатуры меню позволяет идентифицировать подключенное устройство клавиатуры для ситуаций, когда в сети доступно более одной клавиатуры.

Удалённая клавиатура имеет светодиоды подсветки, настраиваемые с различным режимом освещения, доступные как:

- Вон! Светодиоды остаются выключенными все время.
- На: Светодиоды остаются на все время.
- При низкой яркости: Светодиоды **только **загораются, когда подсветка дисплея ниже 20 процентов или равна 20 процентам.
- При высокой яркости: Светодиоды **только **загораются, когда подсветка дисплея выше 20 процентов.
- Не контролируется: Светодиоды остаются выключенными все время и не контролируются уровнем подсветки дисплея.

Действие:

- Выберите «Меню».
- Выберите «Безопасность», введите действительный PIN-код безопасности.
- Выберите «Назад» (IV) мягкий ключ на экране, чтобы выйти.
- Выберите «Setup».
- Выберите «NMEA Switch Bank» с помощью сенсорного экрана.
- Выберите «Кипа по умолчанию» с помощью сенсорного экрана.
- Выберите «PKU2300M» с помощью сенсорного экрана.
- Выберите «Идентифицировать», чтобы подтвердить, что дисплей взаимодействует с удаленной клавиатурой. Удалённая клавиатура начнет мигать светодиодами, если связь активна.

Когда закончите:

- Прокрутите слева направо или используйте мягкий ключ «Назад» (IV) на экране, чтобы выйти.

> Device Network Settings - CAN Channel 1 Settings - J1939
>
> - Baud Rate: Should **always** be set to match the ECM broadcast rate, which is typically 250K. If the baud rate setting is incorrect, the data on the ED-4 data screen will be dashes.
> - Seed Address: Used to manually set the source address of the ED-4. The range of seed address is typically 228 to 231 for the C.I.B. ED-4. The helm ED-4 seed address is typically 128 or higher. When the Preferred Address is enabled and set to a valid address in the vessel personality file, the Seed Address will be displayed as “Preferred”.
> - Preferred Address: The address which will likely be used by the ED-4, if available, and is important for broadcasting when used as gateway. The address the C.I.B. ED-4 will try to claim is typically in range 228 to 231. In case of an address conflict with the preferred address, alarms will be triggered by the ED-4. Whenever the preferred address is **not** available or claimed by the ED-4, an alarm will be triggered. The Preferred Address will be shown as “Disabled” for the helm ED-4 displays.
> - Perform Address Claim: Used to save the seed address or preferred address manually selected.
> - Actual Address: Address claimed by the ED-4, which starts at the seed address or preferred address then increments to a unique address for each ED-4 on a common network. Address 128 is set to the ED-4 with the lowest software serial number.
>
> Device Network Settings - CAN Channel 2 Settings - NMEA 2000
>
> - Baud Rate: Should always be set to match the ECM broadcast rate, which is typically 250K. If the baud rate setting is incorrect, the data on the ED-4 data screen will be dashes.
> - Seed Address: Used to manually set the source address of the ED-4. The ED-4 seed address is typically 128 or higher. When the Preferred Address is enabled and set to a valid address in the vessel personality file, the Seed Address will be displayed as “Preferred”.
> - Preferred Address: The address which will likely be used by the ED-4, if available, and is important for broadcasting when used as gateway. The address the C.I.B. ED-4 will try to claim is typically in range 228 to 231. In case of an address conflict with the preferred address, alarms will be triggered by the ED-4. Whenever the preferred address is **not** available or claimed by the ED-4, an alarm will be triggered. The Preferred Address will be shown as “Disabled” for the helm ED-4 displays.
> - Perform Address Claim: Used to save the seed address or preferred manually selected.
> - Actual Address: Address claimed by the ED-4, which starts at the seed address or preferred address then increments to a unique address for each ED-4 on a common network. Address 128 is set to the ED-4 with the lowest software serial number.

> Setup - Backlight Level Presets

> Setup -\> NMEA Switch Bank
>
> The display configuration includes the capability to configure the remote keypad, it provides capability to select the remote keypad from the NMEA Switch Bank menu. The keypad once connected to the display harness the keypad should appear in the default keypad list for selection. Once a remote keypad is selected the menu allows to identify the connected keypad device for situations when more than one keypad is available on the network.
>
> The remote keypad has backlight LEDs configurable with different lighting mode available as:
>
> - Off: LEDs remain off all the time.
> - On: LEDs remain on all the time.
> - On at low brightness: LEDs **only** light up when display backlight is lower than 20 percent or equal to 20 percent.
> - On at high brightness: LEDs **only** light up when display backlight is above 20 percent.
> - **Not** controlled: LEDs remain off all the time and is **not** controlled by the display backlight level.
>
> Action:
>
> - Select “Menu”.
> - Select “Security”, enter valid security PIN.
> - Select “Back”(IV) soft key on the screen to exit.
> - Select “Setup”.
> - Select “NMEA Switch Bank” using the touch screen.
> - Select “Default Keypad” using the touch screen.
> - Select “PKU2300M” using the touch screen.
> - Select “Identify” to confirm the display is communicating with the remote keypad. The remote keypad will start blinking LEDs if communication is active.
>
> When finished:
>
> - Swipe left to right or use “Back”(IV) soft key on the screen to exit.
