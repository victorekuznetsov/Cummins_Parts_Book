### Общие сведения

**PS102**

Командный коммутатор C Command Connect и коммутатор Start/Stop 1 расположен в поле интерфейса клиента (CIB).

Переключатель нажимается и удерживается для запуска двигателя. Один быстрый нажатие стартового выключателя задействует стартер, но не запустит двигатель.

Используйте следующую процедуру для получения подробной информации, удаления, проверки и установки. См. процедуру 015-023 в разделе 15.

**PS103**

Некоторые приложения будут использовать один выключатель запуска/остановки нажатия. Однократное быстрое нажатие на стартовый/стоп-переключатель (1) задействует стартер и запускает двигатель. Если выключатель запуска/остановки нажимается во время работы двигателя, двигатель отключается.

> ### General Information
>
> **PS102**
>
> The C Command Connect and Connect Premier start/stop switch (1) is located on the customer interface box (CIB).
>
> The switch is pressed and held to start the engine. A single quick press of the start switch will engage the starter but will **not** start the engine.
>
> Use the following procedure for details, removal, inspection, and installation information. Refer to Procedure 015-023 in Section 15.
>
> **PS103**
>
> Some applications will use a single press start/stop switch. A single quick press up of the start/stop switch (1) will engage the starter, and start the engine. If the start/stop switch is pressed while the engine is running, the engine will shutdown.
>
