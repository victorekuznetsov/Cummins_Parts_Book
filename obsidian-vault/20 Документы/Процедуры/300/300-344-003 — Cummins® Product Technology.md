### Общие сведения

Название модели сервиса для этого продукта — C Command HD Elite Panel System PS106 и C Command HD Elite Panel System PS107.

Панельная система C Command HD EliteTM Marine используется для мониторинга эксплуатационных характеристик двигателя и управления локальными и удаленными функциями запуска и остановки.

Эта система получает информацию о данных двигателя и имеет возможность получать информацию о шине данных CAN Общества автомобильных инженеров (SAE) J1939 от модуля управления двигателем (ECM) и имеет соединения для дополнительных датчиков судна.

Данный продукт использует следующую технологию продукта:

#### C командной панелью HD Elite Panel System PS106

- Клиентский интерфейс (C.I.B) с дизельным блоком управления
- Дистанционный пульт
- Компоненты шлема (включает переключатели, дисплей и сигнальный рог)
- Связанные проводные ремни.

#### C командной панелью HD Elite Panel System PS107

- Клиентский интерфейс (C.I.B) с дизельным блоком управления
- Дистанционный пульт
- Компоненты шлема (включает переключатели, дисплей и сигнальный рог)
- Связанные межсоединительные проводные ремни
- Датчик давления подачи топлива контролируется с помощью DCU410E
- Переключатель отключения охлаждающего давления отслеживается через SDU
- Предфильтровый датчик давления масла, контролируемый с помощью DCU410E
- Датчик температуры выхлопа контролируется с помощью ECM
- Переключатель уровня охлаждающей жидкости больше не контролируется с помощью ECM
- Защита двигателя отключения Override Switch контролируется через ECM и DCU
- Обновление Circuit Breaker с 16 А до 25 А
- Редюндантный силовой селектор (RPS) заменен на PULS-устройство.

Маркетинговые приложения, которые будут использовать этот продукт, включают:

#### глобальный

- Морской отдых
- Коммерческий морской пехотинец
- Морской пехотинец.


> [!quote]- Original (English) · английский оригинал
> ### General Information
>
> The service model name for this product is C Command HD Elite Panel System PS106 and C Command HD Elite Panel System PS107.
>
> The C Command HD Elite™ Marine panel system is used to monitor engine operating characteristics and control local and remote start and stop functions.
>
> This system receives engine data information and has the ability to receive Society of Automotive Engineers (SAE) J1939 data link information from the engine control module (ECM), and has connections for additional vessel sensors.
>
> This product uses the following product technology:
>
> #### C Command HD Elite Panel System PS106
>
> - Customer Interface Box (C.I.B) with diesel control unit
> - Remote panel
> - Helm Components (includes switches, display, and alarm horn)
> - Associated Interconnect Harnesses.
>
> #### C Command HD Elite Panel System PS107
>
> - Customer Interface Box (C.I.B) with diesel control unit
> - Remote panel
> - Helm Components (includes switches, display, and alarm horn)
> - Associated Interconnect Harnesses
> - Fuel Delivery Pressure Sensor monitored via DCU410E
> - Coolant Pressure Shutdown Switch monitored via SDU
> - Pre-Filter Oil Pressure Sensor monitored via DCU410E
> - Exhaust Temperature Sensor monitored via ECM
> - Coolant Level Switch is no longer monitored via ECM
> - Engine Protection Shutdown Override Switch controlled via ECM and DCU
> - Circuit Breaker Upgrade from 16 A to 25 A
> - Redundant Power Selector (RPS) replaced with PULS Device.
>
> Market applications that will use this product include:
>
> #### Global
>
> - Recreation Marine
> - Commercial Marine
> - Government Marine.
