| **Tool Number** 3164491 | **Pressure and Vacuum Module** Used with multimeter, Part Number 3164488, to measure pressures and restriction in the fuel system. |  |
| **Tool Number** 3164621 | **Fuel Line with 1.09 mm \[0.043 in\] Orifice** Used to create rated fuel flows through the low-pressure fuel system without loading the engine. |  |
| **Tool Number** 3824510 | **QD™ Contat Cleaner** A non-petroleum cleaner used to clean electrical connections and fuel pump internal parts. |  |
| **Tool Number** 4918413 | **12 mm Banjo Connector Fitting** A banjo-style pressure gauge adapter can be used to measure pressure or vacuum at any point in the low-pressure fuel system where a 12 mm banjo bolt exists at a fuel line. |  |
| **Tool Number** 4919057 | **16 mm Banjo Connector Fitting** A banjo-style pressure gauge adapter can be used to measure pressure or vacuum at any point in the low-pressure fuel system where a 14 mm banjo bolt exists at a fuel line. |  |
| **Tool Number** 4919073 | **Fuel System Clean Care Kit** Used to cap or plug the fuel system fittings during service to prevent debris from entering the fuel system. |  |
| **Tool Number** 4919546 | **Fuel System Leak Tester** Used to block a single injector and high-pressure fuel connector from pressurized fuel. This tool helps identify a malfunctioning injector when the injector return flow is excessive. |  |
