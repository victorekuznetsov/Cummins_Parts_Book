| **Tool Number** 3164491 | **Pressure and Vacuum Module** Used with multimeter, Part Number 3164488, to measure pressures and restriction in the fuel system. |  |
| **Tool Number** 3164618 | **12 mm Banjo Adapter Fitting (Leakage-Flow Adapter)** Used to isolate drain flow from the fuel drain lines where they connect to the fuel drain manifold. Allows fuel leakage measurement from the fuel pump, injector, or fuel rail pressure relief valve drain lines. |  |
| **Tool Number** 3164621 | **0.043 Inch Diagnostic Fuel Line** Used to create rated fuel flows through the low-pressure fuel system without loading the engine. |  |
| **Tool Number** [[3678921]] | **12 mm Straight Thread O-Ring Plug (STOR) Fitting** Used to plug the port on the fuel filter head when the air bleed transfer tube is removed for measuring high-pressure fuel pump return flow. |  |
| **Tool Number** 3824510 | **Electrical Contact Cleaner** Used to clean electrical connections and fuel pump internal parts. |  |
| **Tool Number** 4919073 | **Fuel System Clean Care Kit** Used to cap or plug the fuel system fittings during service to prevent debris from entering the fuel system. |  |
| **Tool Number** 4919586 | **Fuel Pump Gear Replacer Kit** Used with gear puller ST-647 to remove and install the fuel pump gear. |  |
| **Tool Number** 5572664 | **Fuel Pump Timing Gauge** Used to time fuel pump. |  |
| **Tool Number** 5299721 | **Fuel Pump Test Kit** Used to measure high pressure fuel pump pressure and volume output. Includes Part Number 3164673, Leak Test Hose (1) and Part Number 5299753, Fuel Pump Tester (2). |  |
