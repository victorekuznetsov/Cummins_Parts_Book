| **Tool Number** 3163059 | **Air Impact Wrench** A tool which produces the amount of torque required to rotate Signature™ 600 capscrews. It has a square drive size of 3/4-inch, an output of 75 to 900 ft-lbs, and a continuous working torque of 500 ft-lb when using a 3/8 inch unrestricted hose and a 90 psi pressure source. |  |
| **Tool Number** 3163162 | **Head Bolt Stretch Gauge** Used to measure head bolts. |  |
| **Tool Number** 3163293 | **Valve Seal Puller** Used to remove the valve seal. |  |
| **Tool Number** 3163318 | **Intake Seat Installer** Used to install the intake valve seat into the cylinder head. |  |
| **Tool Number** 3163319 | **Exhaust Seat Installer** Used to install the exhaust valve seat into the cylinder head. |  |
| **Tool Number** 3163321 | **Valve Guide Removal Tool** Used to remove the valve guides from the cylinder head. |  |
| **Tool Number** 3164088 | **Valve Camshaft Bushing Installation and Removal Tool** Used with the hydraulic camshaft bushing installation and removal tool, Part Number 3823621. |  |
| **Tool Number** 3164231 | **Leak Test Kit (Air Pressure Regulator)** Used to regulate air pressure to test various passages for leaks. |  |
| **Tool Number** 3164438 | **Depth Gauge Assembly** Used to measure liner protrusion, injector protrusion, cylinder block counterbore depths, and valve intrusion and/or protrusion. |  |
| **Tool Number** 3165161 | **24 mm Impact Socket** Used to tighten both the cylinder head bolts and the main bearing cap bolts. The socket has sufficient length for Signature™ 600 and is laser marked at 90 degree increments. |  |
| **Tool Number** 3375182 | **Valve Spring Tester** Used to measure the valve spring load at the valve spring working height. |  |
| **Tool Number** 3376405 | **Valve Seat Grooving Tool** Used to cut a groove circumferentially in the inside diameter of a valve seat to allow the seat extractor a suitable grip area. |  |
| **Tool Number** 3376617 | **Slide Hammer Assembly** Used with the valve seat puller to remove the valve seat insert from the cylinder head. |  |
| **Tool Number** 3823258 | **Scotch-Brite™ 7448** Used to clean carbon, rust, and corrosion from the engine block and other parts. |  |
| **Tool Number** 3823621 | **Hydraulic Camshaft Bushing Installation and Removal Tool** Used to remove and install camshaft bushings. |  |
| **Tool Number** 3824277 (110V) / 3824278 (220V) | **Valve Vacuum Tester** Used to determine if the valves are correctly seated in the cylinder head. The seal ring, Part Number ST1257-35, and vacuum cup, Part Number ST1257-6, are purchased separately. |  |
| **Tool Number** 3824864 | **Spacer** Used with the Camshaft Bushing Replacer Kit, Part Number 3164088. |  |
| **Tool Number** 4918319 | **Protective Plug Kit** Used to plug oil passages and drillings during a repair process. |  |
| **Tool Number** 4919358 | **Four-Valve Spring Compressor** Used to remove or install valve spring retainers, valve springs, and valve seals. |  |
| **Tool Number** 4919360 | **Cylinder Head Lifting Kit** Used to remove the cylinder head from the cylinder block. The kit includes the cylinder head lifting fixture, Part Number 4919361, and mounting capscrews. |  |
| **Tool Number** 4919546 | **Cylinder Head Fuel Passage Leak Test Kit** Used to test the fuel passages in the cylinder head. Use with Leak Test Kit, Part Number 3164231, purchased separately. |  |
| **Tool Number** 5299837 | **Valve Camshaft Installation and Removal Kit** Used to install valve camshaft into the cylinder head. The kit includes a sleeve, Part Number 5299841, that fits over the camshaft gear nose to allow installation from the rear of the cylinder head. |  |
| **Tool Number** 5394735 | **Retaining Ring Installer** Used to install a retaining ring that will recreate a seal around the top of the injector sleeve to prevent further leaks of coolant into the fuel or fuel into the coolant. |  |
| **Tool Number** 5395348 | **Camshaft Removal and Installation Kit** Used to remove the camshaft from the cylinder head. |  |
| **Tool Number** ST1166-1 | **Magnetic Crack Detector** Used to inspect cylinder heads and other ferrous castings that can not be magnafluxed for crack detection. |  |
| **Tool Number** ST1276-1 | **Exhaust Seat Puller** Used to remove the exhaust valve seat from the cylinder head. |  |
| **Tool Number** ST1279-1 | **Intake Seat Puller** Used to remove the intake valve seat from the cylinder head. |  |
