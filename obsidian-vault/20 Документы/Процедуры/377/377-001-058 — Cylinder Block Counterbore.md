### Initial Check

This repair procedure describes the method for machining the cylinder liner counterbore ledge using the Counterbore Ledge Cutter Kit, Part Number 2892436. The tool is designed to be used to do light clean-up cuts.

This procedure can be performed in or out of chassis.

Liner protrusion should be checked and verified. [[377-001-028 — Cylinder Liner|Refer to Procedure 001-028 in Section 1.]]

![[01c00377.png]]

Remove the cylinder liner of the cylinder being cut. [[377-001-028 — Cylinder Liner|Refer to Procedure 001-028 in Section 1.]]

[[4383753 — Cylinder Liner Counterbore Ledge Reuse Guidelines|Refer to the Cylinder Liner Counterbore Ledge Reuse Guidelines, Bulletin 4383753]], to inspect the counterbore ledge surface areas for signs of pitting, fretting, or wear.

During service repair it is **only** required to machine a mid-stop which does **not** meet the reuse guidelines. A mid-stop which meets the reuse guidelines does **not** need to be machined.

­All service liners contain brass shims. All engines **must** contain brass shims on all cylinders after repair.

­Engine serial number (ESN) first for factory installed brass shims is 79583578.

### Machine

Cover the crankshaft. Plug any oil hole galleries and coolant passages to prevent machining chips from entering. Install chip catcher, Part Number 5296519 or Part Number 5296520 (depending on block part number), into the cylinder bore.

Install cylinder liner plug, Part Number 5296543, into the adjacent cylinders that are **not** being cut.

![[01a00307.png]]

Make sure the top deck of the cylinder block is clean and free of burrs.

Use a medium grit stone, or equivalent, to clean the deck of the block and the counterbore ledge.

Vacuum and remove any debris from the deck of the block, counterbore ledge, and cylinder head capscrew holes.

![[01a00308.png]]

Zero the counterbore depth dial indicator, Part Number 3164438, with the master gauge tool, Part Number 2892460.

This will set the indicator to the original machining depth of 120 mm \[4.724 in\] from the cylinder deck to the counterbore ledge.

![[01a00309.png]]

Measure the counterbore ledge in four locations in a crisscross pattern and mark the lowest point. Subtract the lowest number from the highest number. This is the minimum amount to be machined for clean-up to make the counterbore ledge even all the way around.

![[01a00310.png]]

Use 30W non-detergent oil to lubricate the counterbore drive unit, Part Number 3163785. Fill the reservoir with 30W oil to maintain lubrication on the counterbore drive unit while machining the counterbore ledge. Assemble the base plate, Part Number 2892423, to the counterbore drive unit with the four hex key screws provided and tighten in a crisscross pattern.

> [!tip] Момент затяжки · Torque Value
> 27 n•m [239 in-lb]

![[01a00311.png]]

> [!warning] CAUTION · Осторожно
> Make sure of proper installation of the counterbore cutter bit. Damage will occur if improperly installed.

Install the cutter plate assembly, Part Number 5296533, to the counterbore drive unit. Use the cutter plate holder to tighten securely. The hole in the side of the cutter plate accepts the holder.

![[01a00312.png]]

Install the cutter plate assembly, Part Number 5296533, to the counterbore drive unit. Use the cutter plate holder to tighten securely. The hole in the side of the cutter plate accepts the holder. Position the cutter bit insert so the tapered edge faces the cutter bit. Install the cutter bit screw into the center of the cutter bit insert. The cutter bit insert is machined to allow the cutter bit screw to be fully recessed. Tighten the screw using the provided cutter bit wrench until the insert is fully seated against the cutter bit. Loosen the screw and tighten it again until there is no visible air gap around the insert and the bit.

![[01a00325.png]]

Install the cutter bit, Part Number 5296531, into the cutter plate. The cutter bit **must** be installed with the part number facing to the left and the cutting edge facing to the left, as viewed from the bottom of the cutter plate. Make sure of proper installation of the cutter bit, as damage will occur if improperly installed. Fully retract the cutter bit using the provided hex key wrench. Make sure the cutter bit can extend and retract freely.

![[01a00326.png]]

Position the counterbore ledge cutter unit into the cylinder bore by backing off the upper depth set collar and lower depth set collar in a **counterclockwise** direction.

This will allow the counterbore ledge cutting plate to lower and center itself on the counterbore ledge.

Care should be taken to verify the base plate of the counterbore ledge cutting tool is positioned flat on the deck surface of the cylinder block, and the cutting plate is centered into the counterbore ledge with no side-to-side movement.

![[01a00313.png]]

Secure the base plate to the cylinder block with the capscrews, special washers, and spacers included with the tool. Capscrews need to be lubricated with engine oil, installed hand-tight, and then tightened in a crisscross pattern.

> [!tip] Момент затяжки · Torque Value
> 67 n•m [49 ft-lb]

Install the T- handle onto the counterbore ledge cutter unit and adjust the lower stop collar in a **clockwise** rotation 0.127 mm \[0.005 in\] (each graduation on the collar is 0.025 mm \[0.001 in\]) to raise the cutter plate off the counterbore ledge and rotate the tool **clockwise**. No contact should be made with the counterbore ledge.

> [!note] Note · Примечание
> If adequate clearance is **not** available, a 1/2 inch drive ratchet and 15/16 inch socket can be used in place of the T-handle for counterbore drive unit rotation.

![[01a00314.png]]

Raise the counterbore ledge cutter by grasping the T-handle and pulling in an upward motion.

Install the depth set collar (C spacer) below the lower depth set collar and lower the tool until it makes contact with the depth set collar.

Install a 0.812 mm \[0.032 in\] feeler gauge between the counterbore ledge wall and the cutter bit. This will make sure that the cutter bit does **not** make contact with the step machined into the counterbore ledge.

Extend the cutter bit with the hex key wrench installed in the friction screw until the cutter bit makes contact with the feeler gauge, and lock the bit down by tightening the two cutter bit hold-down capscrews with the hex key wrench.

![[01a00315.png]]

> [!warning] CAUTION · Осторожно
> Make sure the cutter bit does not contact the step machined into the counterbore ledge. Damage to the cylinder block will occur during machining if the cutter bit is contacting the step.

Install a 0.812 mm \[0.032 in\] feeler gauge between the counterbore ledge wall and the cutter bit. This will make sure that the cutter bit does **not** make contact with the step machined into the counterbore ledge.

Extend the cutter bit with the hex key wrench installed in the friction screw until the cutter bit makes contact with the feeler gauge, and lock the bit down by tightening the two cutter bit hold-down capscrews with the hex key wrench.

![[10o00071.png]]

Position the T-handle so that the long portion of the handle is directly above the cutter bit, or as close as possible. There is no guarantee that the long portion of the handle will line up with the cutter bit.

> [!note] Note · Примечание
> If adequate clearance is **not** available, a 1/2 inch drive ratchet and 15/16 inch socket can be used in place of the T-handle for counterbore drive unit rotation. The ratchet handle should initially be positioned so that it is directly above the cutter bit or as closely behind it as possible.

Rotate the counterbore ledge cutter unit **clockwise** for 360 degrees. A slight noise may be heard.

Lower the counterbore ledge cutter unit by adjusting the lower depth set collar in a **counterclockwise** rotation, until the cutter bit makes contact with the counterbore ledge. Raise the counterbore cutter unit 0.127 mm \[0.005in\] by adjusting the lower depth set collar in a **clockwise** direction.

Loosen the two cutter bit hold-down capscrews with the hex key wrench and extend the cutter bit until it makes contact with the counterbore ledge wall. Lock the cutter bit.

![[01a00316.png]]

Lower the counterbore ledge cutter unit by 0.025 mm \[0.001 in\] at a time, while rotating the unit 360 degrees **clockwise** by adjusting the lower depth set collar in a **counterclockwise** rotation until it makes contact with the counterbore ledge.

With the cutter bit making full contact with the counterbore ledge, rotate the counterbore ledge cutter unit 360 degrees **clockwise** to clean up the counterbore ledge.

> [!note] Note · Примечание
> If adequate clearance is **not** available, a 1/2 inch drive ratchet and 15/16 inch socket can be used in place of the T-handle for counterbore drive unit rotation. The ratchet handle should initially be positioned so that it is directly above the cutter bit or as close behind it as possible.

> [!note] Note · Примечание
> Care **must** be taken to maintain consistent downward pressure on the top of the T-handle or ratchet head during the cutting portion of the stroke. Each 360 degree revolution should take at least 10 seconds. Any deviation in speed will result in chatter on the counterbore ledge.

![[01a00317.png]]

Remove any chips on the counterbore ledge with a vacuum.

![[01a00318.png]]

With the counterbore depth dial indicator, Part Number 3164438, measure the depth of the counterbore ledge. This will determine what the final cut depth will be.

> [!note] Note · Примечание
> Counterbore ledge machining should **not** exceed 0.813 mm \[0.032 in\].

![[01a00319.png]]

Adjust the upper depth set collar **counterclockwise** to the final depth cut.

Example: If cutting 0.127 mm \[0.005 in\], adjust the upper depth set collar to contact the lower depth step collar and then back it off 0.127 mm \[0.005 in\].

Adjust the lower depth set collar **counterclockwise** 0.025 mm \[0.001 in\] at a time until the final cut is reached.

Rotate the counterbore ledge cutter unit **clockwise** with the T-handle positioned so the long portion of the handle is directly above the cutter bit.

> [!note] Note · Примечание
> If adequate clearance is **not** available, a 1/2 inch drive ratchet and 15/16 inch socket can be used in place of the T-handle for counterbore drive unit rotation. The ratchet handle should initially be positioned so that it is directly above the cutter bit or as closely behind it as possible.

> [!note] Note · Примечание
> Care **must** be taken to maintain consistent downward pressure on the top of the T-handle or ratchet head during the cutting portion of the stroke. Each 360 degree revolution should take at least 10 seconds. Any deviation in speed will result in chatter on the counterbore ledge.

![[01a00317.png]]

The counterbore ledge **must** be vacuumed out before each measurement.

> [!note] Note · Примечание
> It is recommended to stop with 0.025 mm \[0.001 in\] left to cut and take one final measurement to verify the cutting depth.

![[01a00318.png]]

Adjust the lower depth set collar by rotating it **clockwise** to raise the cutter plate off the counterbore ledge.

Loosen the two cutter bit hold-down capscrews with the hex key wrench and retract the cutter bit into the cutter plate.

Remove the capscrews that secured the counterbore ledge cutter unit to the deck of the cylinder block and remove the tool from the engine.

Clean any machined chips from the counterbore chip catcher, counterbore ledge, and the deck of the cylinder block. Use a medium grit stone, or equivalent, to clean up the leading edge of the counterbore ledge.

![[01a00322.png]]

With the counterbore depth dial indicator, Part Number 3164438, measure the depth of the counterbore ledge and the ledge angle in four places.

The four measurements **must not** vary more than 0.025 mm \[0.001 in\]. If the measurements exceed the specifications, the counterbore ledge **must** be machined again.

Dimension A should be 0.0127 mm \[0.0005 in\] lower or equal to Dimension B.

![[01a00323.png]]

Remove the chip catcher and any oil gallery or coolant passage plugs that were installed.

Inspect the counterbore seating area for cracking using Crack Detection Kit, Part Number 3375432, or equivalent. If there are any cracks present, the block counterbore ledges may be machined to the next shim thickness, if a thicker shim is offered.

> [!note] Note · Примечание
> Do **not** remove more material from the counterbore ledge than can be made up with the current shims offered.

| Maximum Counterbore Ledge Machining Depth |  |  |
|---|---|---|
| mm |  | in |
| 0.813 | MAX | 0.032 |

If the counterbore ledge machining is repeated, recheck the seating area for cracking using Crack Detection Kit, Part Number 3375432, or equivalent. If cracks are still present, the cylinder block will need to be replaced.

Install a hardened bronze shim, Part Number 5298564 or Part Number 5298565, into the cylinder that was cut.

![[01a00325.png]]

Install a new cylinder liner into the cylinder that was cut. [[377-001-028 — Cylinder Liner|Refer to Procedure 001-028 in Section 1.]]

![[01c00159.png]]

Liner protrustion needs to be checked and verified. [[377-001-028 — Cylinder Liner|Refer to Procedure 001-028 in Section 1.]]

![[01c00377.png]]
