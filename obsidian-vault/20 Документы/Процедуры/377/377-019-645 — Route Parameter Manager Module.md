### General Information

> [!note] Note · Примечание
> See the following link to download the latest version of the Cummins Guidanz™ electronic service tool. [https://www.cummins.com/support/electronic-service-tools-support/guidanz-support](https://www.cummins.com/support/electronic-service-tools-support/guidanz-support)

The Cummins® route parameter manager will facilitate the addition of several new fuel economy features, including Predictive Cruise Control.

Cummins Inc. offers two solutions for route parameter manager installation:

- First fit installation is installed by the original equipment manufacturer (OEM) during the initial vehicle build.
- An Aftermarket Route Parameter Manager Kit is available as a retrofit option for most vehicle installations. This kit is sold and installed by Cummins® Authorized Repair Locations.

During first fit installation, Cummins Inc. provides **only** the route parameter manager. The OEM is responsible for the following:

- Harness
- Global Positioning System (GPS) antenna
- Installation
- All associated hardware.

The Route Parameter Manager Aftermarket Kit consists of the following:

The Route Parameter Manager Kit can be installed in all Cummins® Authorized Repair Locations.

#### Identifying First Fit Installation and Aftermarket Installation

- The Aftermarket Route Parameter Manager Kit harness is RED in color.
- The Aftermarket Route Parameter Manager Kit harness will have a Cummins® Part Number sticker located at the Universal Serial Bus (USB) and power branch of the harness.
- This can be verified at the location of the fuse panel.

Identifying first fit installation versus aftermarket installation is critical for warranty processing.

### Preparatory Steps

> [!danger] WARNING · Опасно
> Batteries can emit explosive gases. To reduce the possibility of personal injury, always ventilate the compartment before servicing the batteries. To reduce the possibility of arcing, remove the negative (-) battery cable first and attach the negative (-) battery cable last.

- Disconnect the batteries. See equipment manufacturer service information.

### Install

Route Parameter Manager Module

Mount the route parameter manager module to the cab structure. Use double-sided tape or wire ties.

Make sure the module has appropriate support and will **not** become loose over time.

Connect the square, black connector of the harness to the route parameter manager module.

![[19l00141.png]]

As the connector is inserted and snaps past the locking tab, make sure the locking lever is turned 90 degrees.

![[19l00151.png]]

Connect the USB cable connector of the harness to the route parameter manager module.

![[19l00138.png]]

Connect the blue GPS antenna connector to the blue plug on the route parameter manager module.

Make sure it has fully snapped into place.

To complete installation:

- Connect the batteries. See equipment manufacturer service information.
- Verify the route parameter manager module software version. Update if needed. [[377-019-647 — Route Parameter Manager Module Calibration Code|Refer to Procedure 019-647 in Section 19.]]
- Verify the route parameter manager GPS map version. Updated if needed. [[377-019-648 — Route Parameter Manager Module Global Positioning System (GPS) Map|Refer to Procedure 019-648 in Section 19.]]
- Check for active or inactive fault codes.

> [!note] Note · Примечание
> Map and route parameter manager module software updates are required only if identified as a warrantable requirement in the engine control module (ECM) Calibration Revision History in QuickServe® Online.

Install all cab decorative covers. See equipment manufacturer service information.

![[19l00139.png]]

Route Parameter Manager Harness

Install the wiring harness.

Connect the battery fuse adapter to the route parameter manager harness.

Connect the Key-ON fuse adapter to the route parameter manager harness.

> [!note] Note · Примечание
> The battery fuse adapter is RED in color. The Key-ON fuse adapter is BLUE in color.

![[19l00154.png]]

Install the battery fuse adapter and Key-ON fuse adapter.

Mount the map update USB connector next to the cab fuse panel.

> [!note] Note · Примечание
> The use of a multimeter can be required to verify power availability at the selected fuse location and powered side of the fuse.

> [!note] Note · Примечание
> Only one side of the fuse opening will have power. Insert the fuse adapter into the powered side of the fuse mounting location.

![[19l00142.png]]

Connect the ground wire.

> [!note] Note · Примечание
> If the eyelet terminal (ground lug) (1) is too small for proper assembly, replace the eyelet terminal with one of appropriate size.

![[19l00155.png]]

Connect the Y-adapter to the OEM harness.

Install the terminating resistor on the Y-adapter.

![[19l00156.png]]

Connect the Y-adapter to the route parameter manager harness data link connector.

There are two connectors on the route parameter manager harness:

- 250k baud connector for all 2013 to 2015 engines, and for 2016 and newer engines with a split data link network (1)
- 500k baud connector for 2016 and newer engines with 500k baud network **only** (2).

> [!note] Note · Примечание
> For more information on the data link selection, see the Route Parameter Manager Aftermarket Kit installation instruction.

> [!note] Note · Примечание
> Failure to select correct data link network speed will cause Fault Codes 6575 and 6753 to become active.

Secure the route parameter manager harness to the cab and dash substructure. Use zip ties.

> [!note] Note · Примечание
> If there is extra wire left due to routing, coil it and tack neatly away to avoid wire damage.

![[19l00157.png]]

Connect the square, black connector of the harness to the route parameter manager module.

Make sure the locking lever is turned 90 degrees as the connector is inserted and snaps past the locking tab.

![[19l00141.png]]

Make sure the locking lever is turned 90 degrees as the connector is inserted and snaps past the locking tab.

![[19l00151.png]]

Connect the USB cable connector of the harness to the route parameter manager module.

![[19l00138.png]]

Connect the blue GPS antenna connector to the blue plug on the route parameter manager module.

Make sure it has fully snapped into place.

Install all cab decorative covers. See equipment manufacturer service information.

![[19l00139.png]]

Route Parameter Manager Module GPS Antenna

Clean the mounting surface. Use the alcohol swab included in the kit.

Attach the GPS antenna to the dashboard. Use double-sided tape. The GPS antenna cable **must** point down once the antenna is mounted.

> [!note] Note · Примечание
> The GPS antenna should be located inside the cab near the windshield so it gets good satellite signal.

> [!note] Note · Примечание
> Failure to mount the GPS antenna will cause incorrect position readings for the route parameter manager.

Secure the GPS antenna cable with zip ties.

> [!note] Note · Примечание
> Do **not** cut the GPS antenna cable.

![[19l00148.png]]

Connect the blue GPS antenna connector to the blue plug on the route parameter manager module.

Make sure it has fully snapped into place.

Install all cab decorative covers. See equipment manufacturer service information.
