## Variable Geometry Turbocharger Actuator Installation

**Product Affected**

Variable Geometry Turbocharger Actuator

**Issue Summary**

Variable Geometry Turbocharger Actuators have been improperly diagnosed as faulty after incorrect install or calibration steps were performed. This document is intended to reduce the risk of errors while calibrating a turbocharger actuator. The corresponding Service Manual **must** be referenced for detailed turbocharger actuator installation and calibration procedure.

Symptom:

- “Failed” message received on Turbocharger Electric Actuator Installation and Calibration Test in the electronic service tool
- Active fault code

Root Causes:

- The variable geometry turbocharger actuator was mounted to the turbocharger during the Install/Prealign Actuator step.
- Improper alignment of turbocharger sector gear while mounting the turbocharger actuator.

**Resolution**

- See corresponding Service Manual. Reference Procedure 010-134 in Section 10. All steps **must** be followed in order.
- If the Variable Geometry Turbocharger Actuator Install or Calibrate steps do **not** pass, the installation procedure **must** be started over from the beginning.
- The Variable Geometry Turbocharger Actuator **must** be removed, unplugged for 30 seconds, and the turbocharger sector gear placed into the correct fully clockwise position.
