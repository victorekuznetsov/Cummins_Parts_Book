## Duplicate Kit Installations

The purpose of this document is to guide the user through the installation steps for the kits being combined to decrease duplicate kits. This is due to an improvement process.

The parts listed in Table 1 are the kits that have been combined and their instructions.

| Table 1. |  |  |  |
|---|---|---|---|
| Purchased Part Number | Description | Part Number Replaced | Service Notes |
| 4030118 | Wastegate Actuator Kit | 4030214 | Kits were identical. |
| 4029762 | Wastegate Actuator Kit | 4029724 | Kit has additional washer 3518004 and capscrew 3524262 added to kit. |
| 4030213 | Wastegate Actuator Kit | 4030226 | A jam nut [[3528414]] was needed. |
| BM99820 | Main Bearing Kit | BM99830 | For V352 **Only**: Need two main bearings 182210 and 182400. Will have one extra of each for V470. |
| BM99821 | Main Bearing Kit | BM998831 | For V352 **Only**: Need two main bearings 182211 and 182401. Will have one extra of each for V470. |
