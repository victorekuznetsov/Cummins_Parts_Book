## Повторная установка комплектов

Цель этого документа состоит в том, чтобы направлять пользователя по этапам установки комплектов, которые объединяются, чтобы уменьшить дубликаты комплектов. Это связано с процессом улучшения.

Части, перечисленные в таблице 1, представляют собой наборы, которые были объединены, и их инструкции.

| Таблица 1. |  |  |  |
|---|---|---|---|
| Купленный номер детали | Наименование | Заменить номер детали | Обслуживание заметок |
| 4030118 | турбинный обходной клапан Actuator Kit | 4030214 | Костюмы были идентичны. |
| 4029762 | турбинный обходной клапан Actuator Kit | 4029724 | Набор имеет дополнительную шайбу 3518004 и болты 3524262, добавленные в комплект. |
| 4030213 | турбинный обходной клапан Actuator Kit | 4030226 | Локаут[[3528414]]Это было необходимо. |
| BM99820 | Комплект коренных подшипников | BM99830 | Для V352 **Только**: Нужны два основных подшипника 182210 и 182400. Каждый из них будет иметь по одному лишнему для V470. |
| BM99821 | Комплект коренных подшипников | BM998831 | Для V352 **Только**: Нужны два основных подшипника 182211 и 182401. Каждый из них будет иметь по одному лишнему для V470. |

> The purpose of this document is to guide the user through the installation steps for the kits being combined to decrease duplicate kits. This is due to an improvement process.
>
> The parts listed in Table 1 are the kits that have been combined and their instructions.
>

> |---|---|---|---|

> | 4029762 | Wastegate Actuator Kit | 4029724 | Kit has additional washer 3518004 and capscrew 3524262 added to kit. |
> | 4030213 | Wastegate Actuator Kit | 4030226 | A jam nut [[3528414]] was needed. |
> | BM99820 | Main Bearing Kit | BM99830 | For V352 **Only**: Need two main bearings 182210 and 182400. Will have one extra of each for V470. |
