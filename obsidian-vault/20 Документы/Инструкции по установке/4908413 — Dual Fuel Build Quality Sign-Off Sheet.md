## Лист приёмки качества сборки газодизельной системы

Для каждой установки двойной топливной системы используйте следующие инструкции для правильной установки всех компонентов до ввода системы в эксплуатацию.

#### Инструкции по процессу

1. Перед установкой любых компонентов двойной топливной системы, специалист по установке дистрибьютора должен завершить этап подготовки базового двигателя.
2. Используйте отдельные инструкции по установке двойного топлива QSK50 Tier 2, чтобы правильно прикрепить высокие компоненты комплекта двойного топлива к базовому двигателю QSK50.
3. Используйте этот лист, чтобы убедиться, что QSK50 Tier 2 Dual Fuel Installation Instructions была соблюдена.
4. Техник установочного дистрибьютора заполнит всю необходимую информацию на этом листе.
5. Действующий менеджер по сборке распределительных устройств должен подписаться на этом листе, где он уведомлен.
6. Действующий дистрибутор сборки должен хранить полную копию каждого листа у дистрибутора в течение срока службы двигателя.
