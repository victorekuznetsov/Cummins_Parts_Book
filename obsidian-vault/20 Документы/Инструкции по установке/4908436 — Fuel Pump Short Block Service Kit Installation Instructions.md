## Fuel Pump Short Block Service Kit Installation Instructions

**Product Affected**

- ISX15 CM2250
- ISX15 CM2250 SN
- ISX15 CM2350 X101
- QSX15 CM2250 ECF
- QSX15 CM2250 X115
- QSX15 CM2350 X105
- QSX15 CM2350 X106
- QSX15 CM2350 X118
- X15 CM2350 X114B

This document contains information for the use of a fuel pump short block service kit, Part Number 2872658PX.

**Remove**

Perform the following steps:

- Remove fuel pump.
- Remove fuel pump gear pump.
- Remove fuel pump head.

![[ck800wa.png]]

Remove roller tappet guide pins and plugs.

Clean and inspect for reuse.

![[05r00032.png]]

**Install**

Install new fuel pump tappets into new fuel pump short block.

Fuel pump tappet guide slot **must** face towards tappet guide pin bore.

![[05r00031.png]]

Install fuel pump roller tappet guide pins.

Slot on rear of fuel pump guide pin **must** be vertical when installing fuel pump guide pin.

![[05r00032.png]]

If necessary, use a small flat blade screw driver to verify correct fuel pump guide pin alignment to fuel pump tappet slot.

Figure at right shows correct fuel pump tappet guide pin alignment.

![[05r00029.png]]

> [!warning] CAUTION · Осторожно
> Verify correct fuel pump guide pin alignment after installing fuel pump guide pin plugs. Rotate fuel pump cam gear by hand. While rotating, both fuel pump tappets should move freely up and down in fuel pump bores. Damage to fuel pump will occur if fuel pump guide pins are installed incorrectly.

Install fuel pump guide pin plugs.

Torque Value:

![[05r00030.png]]

- Install fuel pump head.
- Install fuel pump gear pump.
- Install fuel pump.

![[ck800wa.png]]
