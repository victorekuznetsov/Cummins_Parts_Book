### Description

Data Link Cable

### Purpose

This document provides information for Data Link Cable, Part Number 4919098. The cable connects to the Private J1939 Communication Network via 3-Pin connector off the ECM harness.

The cable is used on electronically controlled engines and will allow datalink adapters **not** manufactured by Cummins Inc. to connect to the 3-pin connector which was previously **not** possible. The cable acts as an adapter to transform the 3-pin connection to resemble a dash 9-pin Deutsch™ connection.
