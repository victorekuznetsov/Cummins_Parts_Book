### Наименование

CAN Data Bus Кабель

### Назначение

В этом документе представлена информация для шины данных CAN Cable, Part Number 4919098. Кабель подключается к частной сети связи J1939 через 3-Pin-разъем от электропроводки ECM.

Кабель используется на двигателях с электронным управлением и позволит использовать адаптеры шины данных CAN**, не**, произведенные Cummins Inc. Подключить к 3-контактному разъему, который ранее был невозможен. Кабель действует как адаптер для преобразования 3-контактного соединения, чтобы напоминать 9-контактное соединение DeutschTM.

> ### Purpose
>
> This document provides information for Data Link Cable, Part Number 4919098. The cable connects to the Private J1939 Communication Network via 3-Pin connector off the ECM harness.

> The cable is used on electronically controlled engines and will allow datalink adapters **not** manufactured by Cummins Inc. to connect to the 3-pin connector which was previously **not** possible. The cable acts as an adapter to transform the 3-pin connection to resemble a dash 9-pin Deutsch™ connection.
