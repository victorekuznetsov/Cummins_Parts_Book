### Description

Main Bearing Cap Remover

### Purpose

This document provides information for main bearing cap remover, Part Number 4919744. The remover is used to remove the main bearing caps in the K38, K50, QSK45, QSK60, and QSK78 engines. For additional information, reference the following procedures.

- Use the following procedure in the QSK45 and QSK60 Service Manual, Bulletin [[4021530 — QSK45 and QSK60 Service Manual\|4021530]]. [[56-001-006-tr|Refer to Procedure 001-006 in Section 1.]]
- Use the following procedure in the QSK45G and QSK60G Industrial Troubleshooting and Repair Manual, Bulletin 4021383. Refer to Procedure 001-006 in Section 1.
- Use the following procedure in the QSK60G Generator CM700 Troubleshooting and Repair Manual, Bulletin 4021396. Refer to Procedure 001-006 in Section 1.
- Use the following procedure in the K38, K50, QSK38, and QSK50 Service Manual, Bulletin [[4021528 — K38, K50, QSK38, and QSK50 Service Manual\|4021528]]. [[28-001-006-tr — Bearings, Main|Refer to Procedure 001-006 in Section 1.]]
- Use the following procedure in the KTA38GC CM558 Service Manual, Bulletin 4021642. Refer to Procedure 001-006 in Section 1.
- Use the following procedure in the QSK78 Troubleshooting and Repair Manual, Bulletin 3666727. Refer to Procedure 001-006 in Section 1.
