### Наименование

Пластина съёмника гильзы

### Назначение

Эта инструкция по инструменту для обслуживания предоставляет информацию для использования пластины NH, NT, N14, V28 и V903 для удаления цилиндров, номер детали 3823784.

![[22100108.png]]

|---|---|---|---|

| 1 | 3823784 | Пластина съёмника гильзы | 1 |

| Таблица 2, Предметы, используемые с линейкой цилиндров Remover Plate, приобретенные отдельно |  |  |  |
|---|---|---|---|
| Пункт | Номер детали | Наименование | Количество |
| **Не показана** | 3163745 | Удаление цилиндров | 1 |
| **Не показана** | 3162880 | Лайнерная пластина для удаления | 1 |

Пластина для удаления цилиндрового вкладыша, номер детали 3823784, используется для удержания верхнего палубного спасательного втулки при удалении вкладыша цилиндра.

Поместите пластину для удаления вкладыша цилиндра над удаляемым вкладышем цилиндра и поместите пластину для удаления с плоской стороной, очищающей соседний вкладыш. Поместите линейный устранитель цилиндров, Номер детали 3163745, на верхнюю часть пластины устранителя цилиндров и используйте устранитель для удаления цилиндрового устранителя.

> ### Description
>
> Cylinder Liner Remover Plate

> ### Purpose
>
> This service tool instruction provides information for the use of the NH, NT, N14, V28 and V903 cylinder liner remover plate, Part Number 3823784.
>
> | Table 1, Cylinder Liner Remover Plate, Part Number 3823784 |  |  |  |
> |---|---|---|---|
> | Item | Part Number | Description | Quantity |
> | 1 | 3823784 | Cylinder liner remover plate | 1 |
>
> | Table 2, Items Used with Cylinder Liner Remover Plate, Purchased Separately |  |  |  |
> |---|---|---|---|
> | Item | Part Number | Description | Quantity |
> | **Not** shown | 3163745 | Cylinder liner remover | 1 |
> | **Not** shown | 3162880 | Liner remover plate | 1 |
>
> The cylinder liner remover plate, Part Number 3823784, is used to retain the upper deck salvage bushing when removing the cylinder liner.
>
> Place the cylinder liner remover plate over the cylinder liner being removed and position the remover plate with the flat side clearing the adjacent liner. Position the cylinder liner remover, Part Number 3163745, onto the top of the cylinder liner remover plate and use the remover to remove the cylinder liner.
