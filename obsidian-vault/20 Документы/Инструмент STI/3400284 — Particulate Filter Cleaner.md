### Наименование

Очиститель фильтров твердых частиц

### Назначение

В этом документе содержится информация для очистителя фильтров твердых частиц, номер детали 4919052. Очиститель используется для очистки 1-го уровня дизельного фильтра с заряженной золой (DPF) от двигателей ISB, QSB, ISC, ISL, QSL, ISM, ISX и QSX. Уборщик **не** предназначен для очистки сажи, загруженной DPF. Очиститель требует 8,5 бар \[120 psi\] минимального подачи сжатого воздуха и 110 VAC 60 HZ электроэнергии. Наборы адаптера, необходимые для прикрепления DPF (продаются отдельно), показаны в таблице 4. Программная карта разблокировки требуется и продается отдельно, но также включена в комплект ISC, ISL, ISM, ISX и адаптер. Заменяющие фильтры, доступные для чистильщика и продаваемые отдельно, показаны в таблицах 2 и 3. См. руководство пользователя производителя для соответствующих процедур очистки. Используйте следующие процедуры для получения дополнительной информации о фильтре для дизельных частиц после обработки.

- Используйте следующую процедуру в Руководстве по обслуживанию SignatureTM, ISX и QSX15, Бюллетень [[3666239 — Signature™, ISX, and QSX15 Service Manual\|3666239]].[[101-011-041-tr — Aftertreatment Diesel Particulate Filter|См. процедуру 011-041 в разделе 11.]]
- Используйте следующую процедуру в руководстве по обслуживанию ISM, ISMe и QSM11, Бюллетень [[3666322 — ISM, ISMe, and QSM11 Service Manual\|3666322]].[[101-011-041-tr — Aftertreatment Diesel Particulate Filter|См. процедуру 011-041 в разделе 11.]]
- Используйте следующую процедуру в руководстве по обслуживанию ISC и ISL CM2150, Bulletin 4021569. См. процедуру 011-041 в разделе 11.
- Используйте следующую процедуру в руководстве по обслуживанию ISB CM2100 и CM2150, Бюллетень 4021578. См. процедуру 011-041 в разделе 11.
- Для Tier 4i QSB используйте следующую процедуру в руководстве по обслуживанию QSB6.7 CM2250, Bulletin 4022255. См. процедуру 011-041 в разделе 11.
- Для Tier 4i QSL используйте следующую процедуру в руководстве по обслуживанию QSL9 CM2250, Bulletin 4022256. См. процедуру 011-041 в разделе 11.
- Используйте следующую процедуру в руководстве по обслуживанию ISX15 CM2250, в бюллетене 4022250. См. процедуру 011-041 в разделе 11.
- Используйте следующую процедуру в руководстве по обслуживанию ISX11.9 CM2250, Бюллетень 2883445. См. процедуру 011-041 в разделе 11.
- Для Tier 4i QSX15 используйте следующую процедуру в руководстве по обслуживанию QSX15 CM2250, Bulletin 2883557. См. процедуру 011-041 в разделе 11.

> ### Description
>
> Particulate Filter Cleaner
>
> ### Purpose
>
> This document provides information for Particulate Filter Cleaner, Part Number 4919052. The cleaner is used to Level 1 clean an ash loaded Diesel Particulate Filter (DPF) from the ISB, QSB, ISC, ISL, QSL, ISM, ISX, and QSX engines. The cleaner is **not** designed to clean soot loaded DPFs. The cleaner requires 8.5 bar \[120 psi\] minimum shop air and 110 VAC 60 HZ electrical power. Adapter kits required to attach the DPF (sold separately) are shown in Table 4. A software unlock programmed card is required and sold separately, but is also included in the ISC, ISL, ISM, ISX,and adapter kit. Replacement filters available for the cleaner, and sold separately, are shown in Tables 2 and 3. Refer to the manufacturer's user manual for appropriate cleaning procedures. Use the following procedures for additional information on the Aftertreatment Diesel Particulate Filter.
