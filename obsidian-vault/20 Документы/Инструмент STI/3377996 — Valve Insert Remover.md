### Description

Valve Insert Remover

### Purpose

This document provides information for using various valve insert removers. The removers are used with slide hammer remover, Part Number 3376617, to remove valve inserts from cylinder heads. Without damaging the heads. Some engine applications have cylinder heads with valve inserts that do **not** have a groove for the remover. If there is **not** a groove for the remover, it may be necessary to use the valve insert cutter kit, Part Number 3376405, to cut a groove into the valve insert to allow for the use of the valve insert remover.

> [!note] Note · Примечание
> QSK95 insert removers do **not** require use of the cutter kit.
