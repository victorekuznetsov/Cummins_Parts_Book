### Наименование

Съёмник седла клапана

### Назначение

В этом документе приводится информация об использовании различных клапанных вставок. Удаляющие устройства используются с помощью слайд-молотильного устранителя, номер детали 3376617, для удаления вставок клапанов из головок цилиндров. Не повреждая головы. Некоторые приложения двигателя имеют головки цилиндров с вставками клапанов, которые ** не ** имеют канавку для снятия. Если для вытяжки имеется **не** канавка, может потребоваться использовать набор резца для вставки клапана, Номер детали 3376405, для врезки канавки в вставку клапана, чтобы обеспечить использование вырезки вставки клапана.

> [!note] Примечание
> Удаление вставок QSK95 не требует использования набора резца.

> [!quote]- Original (English) · английский оригинал
> ### Description
>
> Valve Insert Remover
>
> ### Purpose
>
> This document provides information for using various valve insert removers. The removers are used with slide hammer remover, Part Number 3376617, to remove valve inserts from cylinder heads. Without damaging the heads. Some engine applications have cylinder heads with valve inserts that do **not** have a groove for the remover. If there is **not** a groove for the remover, it may be necessary to use the valve insert cutter kit, Part Number 3376405, to cut a groove into the valve insert to allow for the use of the valve insert remover.
>
> **Note · Примечание**
> QSK95 insert removers do **not** require use of the cutter kit.
