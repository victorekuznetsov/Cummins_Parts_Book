### Наименование

Жгут переключения нескольких модулей в сборе

### Назначение

Многоразовая испытательная подставка для калибровки электропроводки ECM, номер детали 4919022, должна быть постоянно прикреплена к соответствующей испытательной подставке для калибровки электропроводки для двигателей QSK38, QSK50 и QSK60 CM850 и CM2150. Многофункциональный модуль коммутаторной коробки электропроводки, номер детали 4918894, может быть отключен и использован на других ROM загрузочных электропроводках, которые были оснащены испытательным стендом калибровки электропроводки, номер детали 4919022, которые можно приобрести отдельно.

### Назначение

Сборка многомодуля электропроводки жгут

Вставьте проводные терминалы из многомодулевой проводной упряжки, номер детали 4919022, в полость разъема, пока они не будут полностью размещены на испытательном стенде калибровочной проводной упряжки OEM-разъема. См. таблицу 2.

Подтяните провод и убедитесь, что штифт заперт в полости.

![[19601262.png]]

Строй снимает соединение, устанавливая проводной галстук через зажим фиксатора, прикрепленный к 4-контактному разъему. Это обеспечит переключатель проводов жгута свиньи на ROM загрузочной проводов жгута.

![[19601263.png]]

Установите многокомпонентную коробку переключателя жгута, Номер детали 4918894, в многокомпонентную жгутку проводов, Номер детали 4919022.

> [!quote]- Original (English) · английский оригинал
> ### Description
>
> Multi Module Switch Harness Assembly
>
> ### Purpose
>
> The multiple ECM Bench Calibration Harness, Part Number 4919022, is to be attached permanently to the appropriate bench calibration harness for the QSK38, QSK50, and QSK60 CM850 and CM2150 engines. The multiple module switch box harness, Part Number 4918894, can be disconnected and used on other ROM boot harnesses that have been fitted with bench calibration harness pigtail, Part Number 4919022, which can be purchased separately.
>
> | Table 1, Multiple ECM Bench Calibration Harness, Part Number 4919064 |  |  |  |
> |---|---|---|---|
> | Item Number | Part Number | Description | Quantity |
> | 1 | 4918894 | Switchable bench calibration harness | 1 |
> | 2 | 4919022 | Bench calibration harness pigtail | 1 |
>
> ### Purpose
>
> Assembly of Multiple Module Harness
>
> Insert the wire terminals from the multiple module harness, Part Number 4919022, into the connector cavity until they are fully seated on the bench calibration harness OEM connector. See Table 2.
>
> Pull on the wire and make certain the pin is locked into the cavity.
>
> | Table 2, Pin and Wire Locations |  |  |
> |---|---|---|
> | Bench Calibration Harness Part Number | 3164185 | 4918583 |
> | White wire location | Pin 7 | Pin 18 |
> | Yellow wire location | Pin 8 | Pin 7 |
> | Gray wire location | Pin 12 | Pin 8 |
> | Red wire location | Pin 34 | Pin 41 |
>
> Strain relieve the connection by installing a wire tie through the retainer clip attached to the 4-pin connector. This will secure the switch harness pigtail to the ROM boot harness.
>
> Install the multiple module switch box harness, Part Number 4918894, into the multiple module harness, Part Number 4919022.
