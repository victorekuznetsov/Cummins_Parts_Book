### Наименование

Установщик клапан Stem Seal

### Назначение

В настоящем документе содержатся инструкции по установке герметиков клапанных стеблей, номер детали 3164430. Установщик герметизации клапанов используется для установки уплотнения клапана на двигателях QSK23 и QSK78.

![[22400158.png]]

| Таблица 1, Установщик штифта клапана, номер детали 3164430 |  |  |  |
|---|---|---|---|
| Номер позиции | Номер детали | Наименование | Количество |
| 1 | 3164431 | Установщик штампов клапан | 1 |
| 2 | 3164432 | Проставка | 1 |

| Таблица 2, Предметы, используемые с установщиком штифта клапана, приобретенные отдельно |  |  |  |
|---|---|---|---|
| Номер позиции | Номер детали | Наименование | Количество |
| **Не показана** | 3163293 | Плиеры для сапог | 1 |

Удалите шток клапана с помощью плоскогубцев багажника, номер детали 3163293, используя движение скручивания и тяги.

![[22400146.png]]

Убедитесь, что направляющая и стволовая уплотнение клапана чисты и сухие перед установкой.

Нанесите LubriplateTM на стебель.

Установите новый шток клапана на ствол клапана. Нажмите на стволовую запечатку клапана, пока не будет достигнут контакт с верхней частью направляющего клапана.

![[22400147.png]]

Сдвиньте прокладку, номер детали 3164432, по стволу клапана и вниз по направляющему клапану.

Используя пластиковый молот и установщик уплотнения клапана, номер детали 3164431, осторожно нажмите на уплотнение клапана на место.

![[22400148.png]]

> ### Description

> Valve Stem Seal Installer

> ### Purpose
>
> This document provides instructions for the valve stem seal installer, Part Number 3164430. The valve stem seal installer is used to install the valve seal on the QSK23 and QSK78 engines.
>
> | Table 1, Valve Stem Seal Installer, Part Number 3164430 |  |  |  |
> |---|---|---|---|
> | Item Number | Part Number | Description | Quantity |
> | 1 | 3164431 | Valve stem seal installer | 1 |
> | 2 | 3164432 | Spacer | 1 |
>
> | Table 2, Items Used with the Valve Stem Seal Installer, Purchased Separately |  |  |  |
> |---|---|---|---|
> | Item Number | Part Number | Description | Quantity |
> | **Not** shown | 3163293 | Boot pliers | 1 |
>
> Remove the valve stem seal with the boot pliers, Part Number 3163293, using a twist-and-pull motion.
>
> Make sure the valve guide and valve stem seal are clean and dry before installation.
>
> Apply Lubriplate™ on the stem.
>
> Install the new valve stem seal on the valve stem. Push the valve stem seal down until contact is made with the top of the valve guide.
>
> Slide the spacer, Part Number 3164432, over the valve stem and down over the valve guide.
>
> Using a plastic mallet and the valve stem seal installer, Part Number 3164431, gently tap the valve seal into place.
