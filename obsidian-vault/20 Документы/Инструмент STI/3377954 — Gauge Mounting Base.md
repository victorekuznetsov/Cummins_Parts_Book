### Наименование

Калибр Mounting Base

### Назначение

В настоящем документе приводится информация об использовании базы для монтажа измерительной шкалы, номер детали 3165168. База используется с циферблатом индикатора, калибром, Частью № 3375006, для проверки движения привода обходного клапана турбины на двигателях Signature, ISX и QSX15.

![[22c00246.png]]

| Таблица 1, калибр Монтажная база, номер детали 3165168 |  |  |  |
|---|---|---|---|
| Номер позиции | Номер детали | Наименование | Количество |
| 1 | 3165162 | калибр для монтажа основания | 1 |
| 2 | 3165167 | Магнит | 1 |

| Таблица 2, Предметы, используемые с измерительной установочной базой, приобретенные отдельно |  |  |  |
|---|---|---|---|
| Номер позиции | Номер детали | Наименование | Количество |
| 3 | 3375006 | Калибр для индикаторов на циферблате | 1 |

Установите калибр для монтажа основания и прибор для измерения индикатора на крышку обходного клапана турбины с помощью индикатора для измерения индикатора циферблата, опирающегося на конец рычага обходного клапана турбины.

См. процедуру 010-050 в Руководстве по устранению неполадок и ремонту (Troubleshooting and Repair Manual Signature, ISX, and QSX15 Engines, Bulletin [[3666239 — Signature™, ISX, and QSX15 Service Manual\|3666239]]) для проверки требуемого перемещения привода обходного клапана турбины.
