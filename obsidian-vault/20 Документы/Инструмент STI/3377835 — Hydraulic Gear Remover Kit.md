### Description

Hydraulic Gear Remover Kit

### Purpose

This instruction provides procedures for use of the hydraulic camshaft gear remover kit, Part Number 3164375. When used with the optional engine-specific kits, this tool will remove the camshaft gear from Cummins® L10, L10G, M11, ISM, QSM11, K19, K19G, K38, K50, QSK19, QSK23, QSK45, QSK60, QSK78, and QST30 series engines.
