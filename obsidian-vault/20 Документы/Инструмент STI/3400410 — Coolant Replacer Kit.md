### Description

Coolant Replacer Kit

### Purpose

This document provides information for coolant replacer kit, Part Number 2892459. The kit is used to drain and fill the engine coolant for all Cummins® engines.

Use the following procedures for more information on the operation of the coolant replacer kit.

- For the ISX15 CM2250, use the following procedure in the ISX15 CM2250 Service Manual, Bulletin 4022250. Refer to Procedure 008-018 in Section 8.
- For the Signature™, ISX, and QSX15, use the following procedure in the Signature™, ISX, and QSX15 Service Manual, Bulletin [[3666239 — Signature™, ISX, and QSX15 Service Manual\|3666239]]. [[10-008-018-tr — Cooling System|Refer to Procedure 008-018 in Section 8.]]
- For the ISM, ISMe, and QSM11, use the following procedure in the ISM, ISMe, and QSM11 Service Manual, Bulletin [[3666322 — ISM, ISMe, and QSM11 Service Manual\|3666322]]. [[35-008-018-tr — Cooling System|Refer to Procedure 008-018 in Section 8.]]
- For the ISB CM2100 and CM2150, use the following procedure in the ISB CM2100 and CM2150 Service Manual, Bulletin 4021578. Refer to Procedure 008-018 in Section 8.
- For the ISB6.7 CM2250, use the following procedure in the ISB6.7 CM2250 Service Manual, Bulletin 4022254. Refer to Procedure 008-018 in Section 8.
- For the ISC and ISL CM2150, use the following procedure in the ISC and ISL CM2150 Service Manual, Bulletin 4021569. Refer to Procedure 008-018 in Section 8.
- For the ISC8.3 and ISL9 CM2250, use the following procedure in the ISC8.3 and ISL9 CM2250 Service Manual, Bulletin 4022257. Refer to Procedure 008-018 in Section 8.
- For the ISB, ISBe, ISBe4, QSB4.5, QSB5.9, and QSB6.7 (Common Rail Fuel System), use the following procedure in the ISB, ISBe, ISBe4, QSB4.5, QSB5.9, and QSB6.7 (Common Rail Fuel System) Service Manual, Bulletin 4021271. Refer to Procedure 008-018 in Section 8.
- For the QSL9 CM2250, use the following procedure in the QSL9 CM2250 Service Manual, Bulletin 4022256. Refer to Procedure 008-018 in Section 8.
- For the QSB6.7 CM2250, use the following procedure in the QSB6.7 CM2250 Service Manual, Bulletin 4022255. Refer to Procedure 008-018 in Section 8.
