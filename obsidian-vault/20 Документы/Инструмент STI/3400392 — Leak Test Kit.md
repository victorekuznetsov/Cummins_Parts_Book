### Наименование

Комплект для опрессовки

### Назначение

В этом документе представлена информация для комплекта испытаний на утечку, номер детали 2892320, используемого для обнаружения утечек во всех системах жидкости двигателя (смазка, охлаждающая жидкость и топливо) с использованием беспроводного ультрафиолетового света, который будет обнаруживать присутствие флуоресцентной красительной добавки. Набор также способен обнаруживать утечки в системах кондиционирования воздуха, используя соответствующий краситель.

Набор для тестирования утечки, номер детали 2892320, заменит все предыдущие комплекты для тестирования утечки и комплекты для черного света.

>
> Leak Test Kit
>
> ### Purpose
>
> This document provides information for Leak Test Kit, Part Number 2892320, used to detect leaks in all engine fluid systems (lubrication, coolant, and fuel) using a cordless “True UV” light that will detect the presence of fluorescent dye additive. The kit is also capable of detecting leaks in air conditioning systems, using the appropriate dye.
>
> Leak Test Kit, Part Number 2892320, will replace all previous leak test kits and black light kits.
>
> Reference the appropriate service manual for the recommended test procedure.
