# Main Bearing Replacer
**Приспособление для замены коренных вкладышей**

### Description

Main Bearing Replacer

### Purpose

This service tool instruction provides instructions for the main bearing replacer, Part Number 3823818, used on the B3.9, B5.9, B5.9G, ISB, QSB, ISB e, C8.3, C8.3G, ISC, QSC8.3, ISC e, ISL, QSL9, L10, L10G, M11, ISM, QSM, NH, NT, N14, Signature, ISX, QSX15, K19, QSK19, QSK19G, V28, and QST30 engines. The main bearing replacer is used to remove and install the upper main bearings “in chassis”. The replacer's bronze material protects the cylinder block and crankshaft when the replacer is inserted in the crankshaft oil hole and “rolling out” the upper bearing.

To remove the upper main bearing, install the main bearing replacer, Part Number 3823818, in the oil hole of the crankshaft main bearing journal.

Rotate the crankshaft so that the replacer contacts the upper main bearing on the side opposite the tang.

Continue to rotate the crankshaft in the direction that will remove the tang side (1) of the upper main bearing first.

![[mb800mb.png]]

> [!warning] CAUTION · Осторожно
> To reduce the possibility of engine damage, do not lubricate the cylinder block side of the main bearing.

Make sure the main bearing to be installed is the same size as the main bearing removed. The size is marked on the back of the bearing.

Apply a coat of Lubriplate™ 105, Part Number 3163086, Part Number 3163087, or equivalent, to the crankshaft side of the new upper main bearings.

![[cx9besb.png]]

> [!warning] CAUTION · Осторожно
> The tang side of the main bearing must not be inserted first. This will reduce the possibility of damage to the tang.

Insert the side of the main bearing opposite the tang first.

Install the main bearing as far as possible by hand.

![[mb9behd.png]]

Using the main bearing replacer, Part Number 3823818, finish installing the main bearing by rotating the crankshaft. Make sure the tang (1) on the main bearing is located in the notch (2) of the cylinder block.

Some engines do **not** not have an oil hole in the front crankshaft journal. Main bearing replacer, Part Number 3823818, can **not** be used on these journals.
