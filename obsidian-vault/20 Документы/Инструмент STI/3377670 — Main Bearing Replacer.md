### Наименование

Приспособление для замены коренных вкладышей

### Назначение

Эта инструкция по оснащению службы предоставляет инструкции для основного заменителя подшипников, Номер детали 3823818, используемого на двигателях B3.9, B5.9G, ISB, QSB, ISB e, C8.3, C8.3G, ISC, QSC8.3, ISC e, ISL, QSL9, L10, L10G, M11, ISM, QSM, NH, NT, N14, Signature, ISX, QSX15, K19, QSK19G, V28 и QST30. Основной подшипник замена используется для удаления и установки верхних основных подшипников «в шасси». Бронзовый материал заменителя защищает блок цилиндров и коленчатый вал, когда заменитель вставляется в масляную дыру коленчатого вала и «выкатывается» верхний подшипник.

Для удаления верхнего основного подшипника установите главный подшипниковый заменитель, номер детали 3823818, в масляную скважину коленчатого вала основного подшипника.

Вращайте коленчатый вал так, чтобы замещающий контактировал с верхним основным подшипником на стороне, противоположной тангу.

Продолжайте вращать коленчатый вал в направлении, которое сначала удалит сторону касания (1) верхнего основного подшипника.

![[mb800mb.png]]

> [!warning] ОСТОРОЖНО
> Чтобы уменьшить вероятность повреждения двигателя, не смазывайте блок цилиндра стороной основного подшипника.

Убедитесь, что основной подшипник, который должен быть установлен, имеет тот же размер, что и основной подшипник. Размеры маркируются на задней части подшипника.

Нанесите пальто LubriplateTM 105, Part Number 3163086, Part Number 3163087 или эквивалентное покрытие на сторону коленчатого вала новых верхних основных подшипников.

![[cx9besb.png]]

> [!warning] ОСТОРОЖНО
> Ступенчатая сторона основного подшипника не должна быть вставлена первой. Это уменьшит возможность повреждения танга.

Вставьте сначала сторону основного подшипника напротив танга.

Установите основной подшипник как можно дальше вручную.

![[mb9behd.png]]

Используя заменитель подшипника, номер детали 3823818, завершите установку основного подшипника поворотом коленчатого вала. Убедитесь, что тан (1) на главном подшипнике расположен в выемке (2) блока цилиндров.

Некоторые двигатели не имеют масляной дыры в переднем коленчатом валу журнала. Заменитель подшипника, номер детали 3823818, может **не** использоваться в этих журналах.

> [!quote]- Original (English) · английский оригинал
> ### Description
>
> Main Bearing Replacer
>
> ### Purpose
>
> This service tool instruction provides instructions for the main bearing replacer, Part Number 3823818, used on the B3.9, B5.9, B5.9G, ISB, QSB, ISB e, C8.3, C8.3G, ISC, QSC8.3, ISC e, ISL, QSL9, L10, L10G, M11, ISM, QSM, NH, NT, N14, Signature, ISX, QSX15, K19, QSK19, QSK19G, V28, and QST30 engines. The main bearing replacer is used to remove and install the upper main bearings “in chassis”. The replacer's bronze material protects the cylinder block and crankshaft when the replacer is inserted in the crankshaft oil hole and “rolling out” the upper bearing.
>

> |---|---|---|---|
> | Item Number | Part Number | Description | Quantity |
> | 1 | 3823818 | Main bearing replacer | 1 |
>
> | Table 2, Items Used with the Main Bearing Replacer, Purchased Separately |  |  |  |
> |---|---|---|---|
> | Item Number | Part Number | Description | Quantity |
> | **Not** shown | ST-1178 | Main bearing cap remover (C and J, NH, NT, V378, V555, V903, V504, L10, and M11) | 1 |
> | **Not** shown | 3375356 | Main bearing cap remover (V28) | 1 |
> | **Not** shown | ST-1116 | Main bearing cap remover (K19, K38, K50, and QSK19) | 1 |
>
> To remove the upper main bearing, install the main bearing replacer, Part Number 3823818, in the oil hole of the crankshaft main bearing journal.
>
> Rotate the crankshaft so that the replacer contacts the upper main bearing on the side opposite the tang.
>
> Continue to rotate the crankshaft in the direction that will remove the tang side (1) of the upper main bearing first.
>
> **CAUTION · Осторожно**
> To reduce the possibility of engine damage, do not lubricate the cylinder block side of the main bearing.
>
> Make sure the main bearing to be installed is the same size as the main bearing removed. The size is marked on the back of the bearing.
>
> Apply a coat of Lubriplate™ 105, Part Number 3163086, Part Number 3163087, or equivalent, to the crankshaft side of the new upper main bearings.
>
> **CAUTION · Осторожно**
> The tang side of the main bearing must not be inserted first. This will reduce the possibility of damage to the tang.
>
> Insert the side of the main bearing opposite the tang first.
>
> Install the main bearing as far as possible by hand.
>
> Using the main bearing replacer, Part Number 3823818, finish installing the main bearing by rotating the crankshaft. Make sure the tang (1) on the main bearing is located in the notch (2) of the cylinder block.
>
> Some engines do **not** not have an oil hole in the front crankshaft journal. Main bearing replacer, Part Number 3823818, can **not** be used on these journals.
