### Description

Valve Guide Replacer

### Purpose

This document provides instructions for the valve guide replacer, Part Number 3164427. The valve guide replacer is used to remove and install the valve guides on the QSK23 and QSK78 engines.

![[22400149.png]]

| Table 1, Valve Guide Replacer, Part Number 3164427 |  |  |  |
|---|---|---|---|
| Item Number | Part Number | Description | Quantity |
| 1 | 3164428 | Valve guide installer | 1 |
| 2 | 3164429 | Spacer | 1 |
| 3 | 3164436 | Valve guide remover | 1 |

Use an arbor press and a valve guide remover, Part Number 3164436, to remove the worn valve guide.

![[22400150.png]]

> [!danger] WARNING · Опасно
> Wear appropriate eye and face protection when using compressed air. Flying debris or dirt can cause personal injury.

> [!danger] WARNING · Опасно
> When using solvents, acids, or alkaline materials for cleaning, follow the manufacturer's recommendations for use. Wear goggles and protective clothing to avoid personal injury.

Use solvent to clean the valve guide bores.

Dry with compressed air.

![[02a00042.png]]

> [!warning] CAUTION · Осторожно
> Make sure the mandrel does not damage the top of the valve guide. If the guide is damaged, the valves can stick, causing severe engine damage.

Position the valve guide in the valve guide bore in the cylinder head.

Slide the spacer, Part Number 3164429, over the valve guide. Use an arbor press and a valve guide installer, Part Number 3164428, to press the guide into the cylinder head.
