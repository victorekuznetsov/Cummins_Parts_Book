### Description

Radiator Cap Adapter

### Purpose

This document provides information for various radiator cap adapters that are used with Coolant System Tester Kit, Part Number 3824319. Reference the descriptions in Table 1 to select the correct adapter for the appropriate radiator.

Reference the appropriate service manual for the recommended test procedure.
