### Наименование

Калибр для проверки блока цилиндров

### Назначение

В этом документе представлена информация для калибра для проверки цилиндрических блоков, номер детали 4918968. Изменение инженерного дизайна двигателей QSK45 и QSK60 изменило конструкцию шатуна с углового разреза на прямое раздельное конструкцию. Из-за этого изменения блока цилиндров двигателей, уже находящихся в эксплуатации, требуют внутренней обработки для принятия нового шатуна. Калибр должен использоваться только для для бокового зазора стенки каждого блока цилиндров, чтобы определить, была ли выполнена требуемая обработка в соответствии с требуемыми спецификациями.

Для получения дополнительной информации обратитесь к сервисному бюллетеню 4022147 по процедурам обработки цилиндров QSK45, QSK60, QSK45G, QSK60G для обновления до прямого разделения соединительного шнура.

> ### Purpose
>
> This document provides information for Cylinder Block Inspection Gauge, Part Number 4918968. An engineering design change to the QSK45 and QSK60 engines altered the design of the connecting rod from angle split to a straight split design. Due to this change, the cylinder blocks of engines already in service require internal machining to accept the new connecting rod. The gauge is to be used **only** for the side wall clearance of each cylinder location of the cylinder block, to determine if the required machining has been completed to the required specification.
>
> For additional information, refer to Service Bulletin 4022147 on the QSK45, QSK60, QSK45G, QSK60G Cylinder Block Machining Procedure To Upgrade To Straight Split Connecting Rod.
