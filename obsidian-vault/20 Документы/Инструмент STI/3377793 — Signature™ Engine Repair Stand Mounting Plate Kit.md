### Наименование

Комплект монтажной плиты стенда для двигателей Signature™

### Назначение

Эта инструкция по оснащению служб обеспечивает процедуры использования комплекта для крепления стендов для ремонта двигателей SignatureTM, номер детали 3162464, на двигателях Cummins SignatureTM.

![[22100093.png]]

| SignatureTM Engine Repair Stand Mounting Plate Kit, Part Number 3162464 |  |  |  |
|---|---|---|---|
| Номер позиции | Номер детали | Наименование | Количество |
| 1 | 3163623 | Горячая пластина | 1 |
| 2 | [[3925344]] | болты, M10 x 1,5 x 50-мм (10,9) (1 показан) | 3 |
| 3 | 3171717 | болты, M16 x 2 x 50-мм (10,9) (1 показан) | 6 |
| 4 | [[3093807]] | болты, M10 x 1,5 x 30 мм (10,9) (1 показан) | 11 |

| Предметы, используемые в монтажной плите, номер детали 3163623, приобретенные отдельно |  |  |  |
|---|---|---|---|
| Номер позиции | Номер детали | Наименование | Количество |
| ** Не показана** | 3163820 | Проточенная вставка* | 1 |
| ** Примечание: ** Резьбовая вставка нажимается на монтажную пластину и используется для ремонта **только **. |  |  |  |

Установите монтажную пластину (1) на стенде ремонта двигателя с шестью болтами (3).

Затяните болты.

> [!tip] Момент затяжки
> 75 Н·м [55 фунт-фут]

![[22100094.png]]

> [!danger] ОПАСНО
> Не используйте заменяющие болты без предварительной проверки того, что они имеют ту же степень и длину, что и болты, которые находятся в комплекте. Невыполнение этого требования может привести к серьезным травмам или повреждениям двигателя, если болты ломаются при креплении к стенду для восстановления.

Поместите стенд для ремонта двигателя и монтажную пластину против блока двигателя, как показано, и установите 11 болтов (4) через монтажную пластину и в блок двигателя.

Затяните болты.

> [!tip] Момент затяжки
> 60 Н·м [44 фунт-фут]

![[22100095.png]]

Установите три более коротких болта (2) через монтажную пластину и в блок двигателя.

Затяните болты.

> [!tip] Момент затяжки
> 60 Н·м [44 фунт-фут]

![[22100096.png]]

>
> Tighten the capscrews.
>

> **WARNING · Опасно**

> Position the engine repair stand and mounting plate assembly against the engine block, as shown, and install 11 capscrews (4) through the mounting plate and into the engine block.
>
> Tighten the capscrews.

> **Момент затяжки · Torque Value**
