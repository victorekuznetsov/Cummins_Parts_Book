### Description

Signature™ Engine Repair Stand Mounting Plate Kit

### Purpose

This service tool instruction provides procedures for the use of the Signature™ engine repair stand mounting plate kit, Part Number 3162464, on Cummins Signature™ engines.

![[22100093.png]]

| Signature™ Engine Repair Stand Mounting Plate Kit, Part Number 3162464 |  |  |  |
|---|---|---|---|
| Item Number | Part Number | Description | Quantity |
| 1 | 3163623 | Mounting plate | 1 |
| 2 | [[3925344]] | Capscrew, M10 x 1.5 x 50-mm (10.9) (1 shown) | 3 |
| 3 | [[3171717]] | Capscrew, M16 x 2 x 50-mm (10.9) (1 shown) | 6 |
| 4 | [[3093807]] | Capscrew, M10 x 1.5 x 30-mm (10.9) (1 shown) | 11 |

| Items Used in Mounting Plate, Part Number 3163623, Purchased Separately |  |  |  |
|---|---|---|---|
| Item Number | Part Number | Description | Quantity |
| **Not** shown | 3163820 | Threaded insert\* | 1 |
| \* **Note:** The threaded insert is press fit into the mounting plate and is used for repair purposes **only**. |  |  |  |

Install the mounting plate (1) on the engine repair stand with six capscrews (3).

Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 75 n•m [55 ft-lb]

![[22100094.png]]

> [!danger] WARNING · Опасно
> Do not use substitute capscrews without first verifying that they are the same grade and length as the capscrews that are in the kit. Failure to do so can result in serious injury or damage to the engine if the capscrews break while attached to the rebuild stand.

Position the engine repair stand and mounting plate assembly against the engine block, as shown, and install 11 capscrews (4) through the mounting plate and into the engine block.

Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 60 n•m [44 ft-lb]

![[22100095.png]]

Install the three shorter capscrews (2) through the mounting plate and into the engine block.

Tighten the capscrews.

> [!tip] Момент затяжки · Torque Value
> 60 n•m [44 ft-lb]
