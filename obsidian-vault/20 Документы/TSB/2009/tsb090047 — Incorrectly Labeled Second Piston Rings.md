## Incorrectly Labeled Second Piston Rings

### Core Issue

The purpose of this Early Field Notification is to inform the field that second piston rings labeled with Part Number [[3090460]] could possibly be labeled incorrectly. The piston rings could possibly have been manufactured to the specifications of another piston ring.

### Confirmation

K19, K38, K50, QSK45, QSK45G, QSK60, and QSK60G

Any piston ring labeled with Part Number [[3090460]] (see Figure 1 in the Repair Instructions) could be labeled incorrectly. Part sets or kits which include this ring in them are Part Numbers 4025115, 4025116, 4089247, 4089500, 4924652, 4924653, 4955790, 4955910, 4955975, and 4956091.

Inspect the piston ring for a paint mark on the outer diameter. If it is marked with yellow paint, it was labeled correctly and can be used normally. If it is marked with blue paint, this ring has been mislabeled and can **not** be used (see Figures 2 and 3 in the Repair Instructions).

Piston ring, Part Number 3068813, was manufactured and labeled with Part Number [[3090460]] at the supplier, but painted with the correct identification color.

A study has been performed to confirm that the incorrect ring can **not** be installed into an engine. This is because the ring compressor will **not** fully close with the wrong ring installed. If an attempt is made to force the ring compressor to close; the ring groove on the piston could possibly be damaged.

### Resolution

Contact Customer Support and request a Return Goods Authorization (RGA) to return the piston ring set back to the Parts Distribution Center (PDC) from where it was purchased. If the piston ring set was purchased as part of an engine piston kit or overhaul kit, **only** return the piston ring set and keep the remaining parts in the kit.
