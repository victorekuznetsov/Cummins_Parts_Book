## New Valve Spring Rotator

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Technical Service Bulletin supersedes Service/Parts Topic 08T2-5. Replace Service/Parts Topic 08T2-5 with this Topic.

This Technical Service Bulletin includes additional information on the K19/QSK19 and cylinder head part numbers **not** covered in Service/Parts Topic 08T2-5.

This Technical Service Bulletin announces the introduction of a new valve spring rotator for use on K19, QSK19, K38, QSK38, K50, and QSK50 series engines. The new valve spring rotator is reduced in height by 0.5 mm \[0.0197 in\] to reduce contact pressure from the valve spring.

| Description | New Part Number | Old Part Number |
|---|---|---|
| Valve Rotator | [[3640315]] | 3081081 |

> [!note] Note · Примечание
> It is recommended to install new valve springs and collets when replacing old-stye rotators with new-style rotators.

The new rotators were structured into new cylinder head part numbers. The related part number changes are described in Table 1.

The new rotator was made available for service on 16-January-2008. The new rotator was implemented at Cummins Industrial Center on 11-February-2008. The ESN first for Daventry built engines is 33173180, which was built on 31-March-2008. The ESN first for India built engines is 25334936, which was built on 09-July-2008.
