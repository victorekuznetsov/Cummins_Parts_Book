## Optimized Lubricating Oil Filter

### Core Issue

This Early Field Notification informs the field of a product improvement which will optimize oil filter life in present ISX engines. Please see Early Field Notification EO8002 for additional details on Premature Oil Filter Plugging.

### Confirmation

ISX Engines utilizing LF9001 and LF9000 filters and experiencing short oil filter life should benefit from this filter improvement. An inspection of the date code stamped on the filter canister will indicate if an optimized filter is in use. A part number change is planned later this year.

Optimized LF9000 and LF9001 filters were manufactured beginning November 5, 2009. The filters will display a date code – inkjet printed on the bottom of the filter – in the format shown in the photograph in the Repair Instruction section.

The top line reflects the filter manufacturing code. Filters with the modification will read: 09309 and higher. The products could also reflect code 10001 and higher. The bottom line of the filter code is **not** necessary for filter identification in this instance.

Optimized LF9001 filters are presently on the shelf. LF9000 filters are expected to become available in mid-December 2009.

Engines coming into the repair location with the following complaints could benefit from this improvement:

- Amber dash lamp caused by multiple counts of active or inactive Fault Code 143 (Engine Oil Rifle Pressure - Data Valid But Below Normal Operational Range - Moderately Severe Level)
- Progressive drop of oil pressure on the dashboard gauge.

None

The ISX engine could be susceptible to oil pressure fault codes due to several different operational and component related factors. An opportunity to minimize the issue of short filter life by improving the filter was identified. The oil filter full-flow element has been balanced to optimize the present engine protection, filter life, and cold flow properties of the filter. The by-pass portion of the filter continues to provide high efficiency cleaning of the oil and high capability for collecting engine oil sludge. The combination of the filter rebalancing, and following approved troubleshooting procedures for an engine issue, will make sure that oil filter life is optimized.

Engines should **not** be run for extended periods of time under low oil pressure conditions.

### Resolution

![[07c00651.png]]

When troubleshooting an ISX engine for low oil pressure, be sure to follow the published symptom trees appropriate for the problem, such as t105, Lubricating Oil Pressure Low, and if necessary, t103-56, Lubricating Oil Filter Plugged. If the engine is ready to be returned to operation and the root cause is unclear, compare the date code of the used filter to the date code listed above. If the filter was manufactured before the date above, make sure the new filter is manufactured after this date. If the used filter date code is after the change date and the root cause is unclear, then contact your appropriate Cummins® technical assistance resource.
