## New Straight Thread Plug

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Service/Parts Topic introduces a new straight thread plug that will be used on all MidRange engines.

> [!note] Note · Примечание
> This is a product improvement and not subject to campaign.

The new straight thread plug (2) has a pre-applied sealant. The previous straight thread plug (1) had a removable/replaceable o-ring.

![[17900065.png]]

The two plugs are interchangeable and reusable. The **only** difference between them is the installation torque value.

| Straight Thread Plug with O-Ring |  |  |  |
|---|---|---|---|
| Size | Part Number\* | O-ring Part Number | Torque |
| M10 | [[3678923]] | [[3678925]] | 10 N•m \[89 in-lb\] |
| M12 | 3678910 | [[3678603]] | 20 N•m \[177 in-lb\] |
| M14 | [[3678921]] | [[3678912]] | 25 N•m \[221 in-lb\] |
| M16 | [[3089567]] | [[3679139]] | 35 N•m \[25 ft-lb\] |
| M18 | [[3678873]] | [[3678786]] | 45 N•m \[33 ft-lb\] |

\* Part number includes o-ring.

| Straight Thread Plug with Formed Pre-Applied Sealant |  |  |
|---|---|---|
| Size | Part Number | Torque |
| M10 | 3977851 | 18 N•m \[160 in-lb\] |
| M12 | 3977852 | 25 N•m \[221 in-lb\] |
| M14 | 3977853 | 30 N•m \[22 ft-lb\] |
| M16 | 3977854 | 40 N•m \[30 ft-lb\] |
| M18 | 3977855 | 50 N•m \[37 ft-lb\] |

Both styles of plugs, and o-rings for straight thread plugs with o-rings, are available for service. Either plug can be used when a replacement plug is needed. The correct installation torque **must** be used.

The straight thread plug with pre-applied sealant can be reinstalled until the pre-applied sealant becomes damaged. Once damaged, the plug **must** be replaced. New sealant can **not** be applied.

Procedure 017-011, Straight Thread Plug, has been updated to include this new service information.
