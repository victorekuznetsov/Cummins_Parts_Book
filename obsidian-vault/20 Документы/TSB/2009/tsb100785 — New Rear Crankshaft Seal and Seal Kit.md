## New Rear Crankshaft Seal and Seal Kit

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Technical Service Bulletin announces a change to the rear crankshaft seal used on B, C, and L engines. Rear crankshaft seal, Part Number 3970548, will be replaced by rear crankshaft seal, Part Number 3933262.

The rear crankshaft seal, Part Number 3933262, has a lip profile that is more robust against static and dynamic leaks, and will improve rear crankshaft seal reliability and durability. See Table 1 for new and old rear crankshaft seal and crankshaft seal kit part numbers.

Engine serial number (ESN) first for Rocky Mount Engine Plant is: 46961419.

| Table 1: New and Old Rear Crankshaft Seal |  |  |  |
|---|---|---|---|
| New Part Number | Description | Old Part Number | Part Disposition |
| 3933262 | Rear Crankshaft Seal | 3970548 | Use to Depletion |
| [[3934486]] | Rear Crankshaft Seal Kit | 4089342 | Use to Depletion |
