## Navistar® Dashboard Odometer Discrepancy

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

Engine:

- B6.7 CM2350 B121B
- B6.7 CM2450 B155B
- ISB CM2350 B101
- ISL CM2350 L101
- ISX CM2350 X101
- L9 CM2350 L116
- L9 CM2450 L126B
- X15 CM2350 X114B
- X15 CM2350 X116B
- X15 CM2450 X124B
- X15 CM2450 X134B

Original Equipment Manufacturer (OEM):

- Navistar™

**Issue**

Symptom:

- Navistar truck dashboard odometer can show incorrect value under certain conditions. When electronic control module (ECM) is replaced or the ECM is ROM booted.

Root Cause:

- Navistar™ algorithm is adding the existing odometer reading to the odometer value during key start after an ECM is replaced or ROM booted, doubling truck mileage on the dashboard odometer.

**Verification**

- Truck dashboard odometer displays incorrect mileage.

**Service Instructions**

- Contact nearest Navistar® Certified Dealer.
