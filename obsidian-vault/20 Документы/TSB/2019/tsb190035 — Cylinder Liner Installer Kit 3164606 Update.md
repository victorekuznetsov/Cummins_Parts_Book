**Проблема**

Симптом:

Отсутствие адекватного взаимодействия ниток при использовании комплекта для установки гильзы, номер детали 3164606. Короткие затворы головы могут привести к резьбе с раздетым затвором или повреждению резьбы блока цилиндров.

Первопричина:

Цилиндровые блоки теперь обрабатываются более глубоким противоболотным затвором цилиндра, который предотвращает адекватное зацепление резьбы при использовании коротких затворов головки. Длинные головные болты слишком длинные, чтобы использовать их без спейсеров.

**Решение**

Существующий комплект, номер детали 3164606, был обновлен, чтобы включить прокладки, номер детали 5395470, которые позволяют использовать более длинные головные болты цилиндра с набором для достижения адекватного взаимодействия резьбы.

Спейсеры индивидуально продаются для обновления существующих комплектов.

> **Issue**
>
> Symptom:
>
> Lack of adequate thread engagement when using liner installation kit, Part Number 3164606. Short head bolts can lead to stripped head bolt threads or damaged cylinder block threads.
>
> Root Cause:
>
> Cylinder blocks are now machined with a deeper cylinder head bolt counterbore that prevents adequate thread engagement when using the short head bolts. The long head bolts are too long to use without spacers.
>
> **Resolution**
>
> Existing Kit, Part Number 3164606, has been updated to include spacers, Part Number 5395470, that allow the longer cylinder head bolts to be used with the kit to achieve adequate thread engagement.
>
> Spacers are individually saleable for upfit of existing kits.
>
> Figure 1, Top: Long Cylinder Head Bolt to be Used With Spacers. Bottom: Short Cylinder Head Bolt.
>
> **Service Instructions**
>
> Cummins Inc. recommends that all repair network kits have one of the following actions performed:
>
> - Order quantity 2 of spacer, Part Number 5395470.
> - Replace existing kit.
> - Individual owners are fully responsible for any cost associated with upfit or replacement.
>
