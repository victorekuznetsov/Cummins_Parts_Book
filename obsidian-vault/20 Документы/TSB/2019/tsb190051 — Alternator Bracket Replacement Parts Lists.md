**Description of Change**

Charging system alternator brackets, Part Numbers 4086629, 4016218, 4100808, and 4001232 are being obsoleted. This document provides instruction on replacing existing alternator brackets with new charging system alternator brackets and necessary associated components if applicable.

**Service Instructions**

Replace existing charging system alternator bracket with new charging system alternator bracket and all associated components as specified in Tables 1, 2, 3, 4, and 5 below.

**Service Parts Availability**
