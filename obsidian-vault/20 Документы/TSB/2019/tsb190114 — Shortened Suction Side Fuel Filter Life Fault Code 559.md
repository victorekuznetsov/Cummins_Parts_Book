## Shortened Suction Side Fuel Filter Life: Fault Code 559

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- X12 CM2350 X119B
- X12 CM2450 X137B
- X15 CM2350 X114B
- X15 CM2350 X116B
- X15 CM2450 X124B
- X15 CM2450 X134B
- X15 CM2450 X142B

**Issue**

Symptom:

- Customer repeatedly experiences plugged suction side fuel filter prior to required maintenance interval. See corresponding Operation and Maintenance Manual, Bulletin 5411187. Reference Procedure 359-008 in Section 3 for fuel filter maintenance interval.

Root Cause:

- Suction side fuel filter plugging

**Verification**

- Confirm suction side fuel filter is plugged. See corresponding Service Manual. Reference Procedure 006-020 in Section 6 to measure suction side fuel filter restriction.
- Confirm suction side fuel filter is a 10 micron fuel filter. Reference Table 1 for corresponding fuel filter part number.
- Confirm pressure side fuel filter restriction is within specification. Perform pressure side fuel filter restriction test. See corresponding Service Manual. Reference Procedure 005-236 in Section 5 to measure pressure side fuel filter restriction.

**Resolution**

New suction side fuel filter options for units repeatedly experiencing short suction side fuel filter life are available. New filter options offer adequate protection to the fuel system while extending suction side fuel filter life. See Table 1.

**Service Instructions**

Verify correct pressure side fuel filter is installed. Pressure side fuel filter, Part Number FF5971NN, with new suction side fuel filter, Part Number FS20337, is recommended, but pressure side fuel filter, Part Number FF5825NN or FF5971NN, **must** be used when utilizing a new suction side fuel filter.
