### Contents

**Product Affected**

- X15 CM2350 X114B
- X15 CM2350 X116B

**Issue**

A PACCAR TIB has been published to help address intermittent engine Fault Code 197 experiences.

Symptom:

- CEL illuminates intermittently, Fault Code 197.

Root Cause:

- Internal wire fractures on wiring leading to low coolant sensor.
- Improper fill level of coolant overflow tank.

**Resolution**

Reference PACCAR TIB 42-058.
