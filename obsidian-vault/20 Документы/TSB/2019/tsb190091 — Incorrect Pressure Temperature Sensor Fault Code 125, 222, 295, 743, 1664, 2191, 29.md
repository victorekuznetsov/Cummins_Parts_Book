**Issue**

Symptom:

- Fault Codes

- Low power
- White smoke
- Engine misfire
- Aftertreatment performance complaints

Root Cause:

- Incorrect pressure/temperature sensor installed in the incorrect location on the engine.

**Verification**

- Remove the pressure/temperature sensor in question and verify pressure/temperature sensor part number.
- View pressure/temperature sensor values in a key on engine off condition using Cummins® electronic service tool or equivalent, an incorrect pressure/temperature sensor can give an incorrect value.
- At key ON engine off, the barometric air pressure should read the local barometric air pressure, and the intake manifold pressure should read 0.0 in-hg.

**Resolution**

Refer to QuickServe Online parts catalog on to determine the correct sensor to use in the correct location for a given engine.

Install correct pressure/temperature sensor. See Table 1 for part numbers.
