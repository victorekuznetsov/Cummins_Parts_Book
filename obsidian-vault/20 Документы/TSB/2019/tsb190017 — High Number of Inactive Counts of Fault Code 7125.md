## High Number of Inactive Counts of Fault Code 7125

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- X12 CM2350 X119B
- X15 CM2350 X114B

**Issue**

- High number of inactive counts of FC7125

Root Cause:

- Engine control module (ECM) calibration code issue leading to FC7125 appearing after a power down.

**Verification**

- Verify if there are any performance or drivability issues with operator.
- Confirm multiple inactive counts of FC7125 are logged.

**Resolution**

If no performance or drivability issues are present, check the ECM Calibration Revisions page on QuickServe® Online (QSOL) for applicable fixes. Calibrate the ECM if necessary. See corresponding Service Manual. Reference Procedure 019-032 in Section 19.
