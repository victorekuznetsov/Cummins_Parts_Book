## Diesel Exhaust Fluid (DEF) Exhaust Blockage (Crystallization/Polymerization) and Fault Codes 1682, 2973, 2772, 2773, 3548, 3538, 3568, 3582, and 5655

### Core Issue

Product Affected

- All midrange engines equipped with aftertreatment selective catalyst reduction (SCR)

Symptoms:

- Exhaust pipe diameters reduced by diesel exhaust fluid (DEF) crystallization or polymerization and/or DEF crystals visible externally.
- Fault Codes 1682, 2973, 2772, 2773, 3548, 3538, 3568, 3582, and 5655.

Root Cause:

- DEF crystals can build up in exhaust system for a number or reasons, including:
- DEF crystals occur first and then turn into a polymer with prolonged temperature exposure below 290°C \[ 554°F \].

### Confirmation

Crystallization or polymerization can lead to four types of exhaust piping blockage/restriction.

1. Less than 20% DEF Accumulation (See Figure 1 below)
2. 20 to 40 % DEF accumulation (See Figure 2 below)
3. 40 to 50 % DEF Accumulation (See Figure 3 below)
4. 50 to 80 % DEF Accumulation (See Figure 4 below)

**Additional Items**

- External Buildup
- Internal Decomposition Pipe Cleaning when crystallization leak is witnessed externally (DEF Injector Gasket). (See Figure 6 below).
- DEF injector changes, Injectors seen to be “wet” or with a “drip” during system prime.
- Duty Cycle and Exhaust System Design Considerations

### Resolution

- DEF accumulation covering less than 50% of cross sectional area does **not** need to be removed.
- DEF accumulation above 50% **must** be removed. See corresponding Service Manual. Reference Procedure 011-062 in Section 11.
- For any instances of reoccurring DEF accumulation where a resolution is **not** found using above information, a Technical Service Request (TSR) is to be raised.
