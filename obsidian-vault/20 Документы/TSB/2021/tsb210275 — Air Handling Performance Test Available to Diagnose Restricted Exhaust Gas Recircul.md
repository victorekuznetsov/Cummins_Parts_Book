## Air Handling Performance Test Available to Diagnose Restricted Exhaust Gas Recirculation (EGR) Cooler

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

**Issue Summary**

Engine experiences one or more of the following fault codes:

- 3342, 3361, 3382, 3383, or 3389

**Verification**

- New Air Handling Performance Test is used when troubleshooting certain engine fault codes. Throughout the test engine speed and the position of air handling actuators are controlled to create conditions for the various diagnostics to run.
- To determine the health of the EGR cooler, the Air Handling Performance Test raises exhaust gas recirculation (EGR) flow and assesses both the restriction level and thermal effectiveness of the EGR cooler.
- The Air Handling Performance Test is to be performed when directed by troubleshooting to verify the root cause of malfunction is identified and repaired the first time without unnecessary component replacements. The Air Handling Performance Test is presently being used by Guidanz®, EDS, and QuickServe® Online (QSOL) troubleshooting for multiple ECM fault codes.

**Resolution**

- Perform the Air Handling Performance Test when directed by published troubleshooting.
- Reference the appropriate Fault Code Troubleshooting procedure. See corresponding Service Manual. Reference Procedure 014-032 in Section 14.
- The EGR cooler should **only** be replaced when directed by the Air Handling Performance Test. Visual inspection should **not** drive the replacement of restricted EGR coolers.

**Description of Change**

- This document is intended to highlight the ability of the Air Handling Performance Test to diagnose EGR cooler problems.
- The Air Handling Performance Test is now available. This diagnostic test was developed to evaluate the health of components in the air handling system.
- The Air Handling Performance Test can accurately identify plugged or otherwise restricted EGR coolers. The use of this diagnostic test reduces the chance of a repeat fault code event for the customer because of EGR cooler misdiagnosis.
