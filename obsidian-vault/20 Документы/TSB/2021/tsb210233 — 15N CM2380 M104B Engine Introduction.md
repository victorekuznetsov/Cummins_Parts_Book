**Service Tools**

New Cummins® service tools released to support the 15N CM2380 M104B engine are:

- EGR cooler leak test, Part Number 5573379
- Valve spring compressor, Part Number 5573421
- Valve seat installer, Part Number 5573423

For a complete list of Cummins® service tools needed to support this engine, consult a local Cummins® distributor.

**INSITE™ Electronic Service Tool**

INSITE™ electronic service tool version 8.7.2 or later supports full production engines. Version 8.7.2 or later includes all diagnostic tests and features necessary to fully support the 15N CM2380 M104B engine. INSITE™ electronic service tool updates are available through the Cummins® update manager. Reference the following website to access Cummins® update manager.
