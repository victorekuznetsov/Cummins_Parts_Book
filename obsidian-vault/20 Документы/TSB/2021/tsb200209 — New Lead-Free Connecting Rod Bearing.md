**Описание изменения**

В этом документе объявляется о выпуске новых подшипников для шатунов без свинца.

Начиная с июня 2020 года некоторые двигатели для беспосадочного запуска начали производство с различными подшипниками стержня.

> [!note] Примечание
> Этот TSB не применяется для приложений стоп-старта. Справочная часть.cummins.com для подшипников стержня для остановки / замены для приложений остановки запуска.

Ключевые различия:

- Выпущенный подшипниковый материал обеспечивает большую устойчивость к мусору
- Подшипники стержня будут иметь темно-серый наклад
- Подшипники для подключения стержней будут иметь конструкцию танга и штрих-коды ID

**Причина изменения**

- Были разработаны новые подшипники для стержней без свинца, чтобы повысить устойчивость к мусору.

**Указания по обслуживанию**

- Из-за окисления наложения верхний соединительный подшипник стержня может казаться зеленым. См. рисунок 1. Это ** не считается вредным для долговечности или производительности подшипника. Следуйте существующим рекомендациям по использованию для критериев повторного использования.
- Существующие и новые номера деталей ** не** должны быть смешаны, верхние и нижние подшипники ** должны быть заменены в виде набора.

> **Description of Change**
>
> This document announces the release of new lead-free connecting rod bearings.
>
> Beginning in June 2020 some engines for non-stop-start applications began manufacturing with different connecting rod bearings.
>
> **Note · Примечание**
> This TSB does **not** apply to stop-start applications. Reference parts.cummins.com for supersession/replacement connecting rod bearings for stop-start applications.
>
> Key differences:
>
> - Released bearing material offers more debris robustness
> - Connecting rod bearings will have a dark grey overlay
> - Connecting rod bearings will have staked tang design and ID bar-codes
>
> **Reason for Change**
>
> - New lead-free rod bearings were developed to improve debris robustness.
>
> **Service Instructions**
>
> - Due to overlay oxidation, upper connecting rod bearing may appear green. See Figure 1. This is **not** considered detrimental for bearing durability or performance. Follow existing service guideline for re-use criteria.
> - Existing and new part numbers are **not** to be mixed, upper and lower rod bearings **must** be replaced as a set.
>
