## Choosing Correct Exhaust Gas Recirculation (EGR) Temperature Sensor with Replacement of Main Engine Wiring Harness

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Products Affected**

- X15 CM2350 X114B - Efficiency Series
- X15 CM2350 X116B - Performance Series

**Description of Change**

- The exhaust gas recirculation (EGR) temperature sensor and engine wiring harness designs of the products affected have changed.
- Because of differences between the existing EGR temperature sensor design and the new EGR temperature sensor design used on the products affected, there will be an incompatibility encountered when attempting to reconnect the existing EGR temperature sensor, Part Number 2872140, to the replacement engine wiring harness, Part Number [[5484117]].
- A new EGR temperature sensor, Part Number [[5461596]], will need to be ordered if installing replacement engine wiring harness, Part Number [[5484117]], and the engine is equipped with the existing EGR temperature sensor, Part Number 2872140.

**Service Instructions**

If the existing EGR temperature sensor requires replacement due to engine wiring harness compatibility, see Figure 1 below and Routing Instructions, to securely route and tie down new EGR temperature sensor lead cable.

![[19r99718.png]]

Figure 1, New Engine Wiring Harness, Part Number [[5484117]] and New EGR Temperature Sensor, Part Number [[5461596]].

Routing Instruction

1. Route cable on top of engine wiring harness and use one wire tie, Part Number [[3062329]], or equivalent.
2. Route cable behind engine wiring harness as shown.
3. Position cable underneath P-clip as shown, connect to engine wiring harness connector and secure secondary (red) latch.
4. Tie down EGR temperature sensor interconnect to harness exactly at location shown using one wire tie, Part Number [[3062329]], or equivalent.

**Part Compatibility**

Visual differences between the two versions of EGR temperature sensors are as follows:

![[19r99719.png]]

Figure 2, Existing EGR Temperature Sensor, Part Number 2872140.

- The existing production EGR Temperature Sensor, Part Number 2872140, as shown in Figure 2 above has a wire lead assembly made up of two individual white Teflon insulated wires encased within a loose fitting, woven sleeve. There is a short, grey silicone rubber wire seal found at the top of the sensor casing body.
- The lead cable on the existing sensor has a shorter wire lead assembly cable length. The lead cable will not reach its respective connector on the new engine wiring harness, Part Number [[5484117]].

![[19r99720.png]]

Figure 3, New Production EGR Temperature Sensor, Part Number [[5461596]].

- Figure 3 above shows the new production version of the EGR temperature sensor, Part Number [[5461596]]. The sensor connector **must** be held in place with one wire tie as shown above in Figure 1.
- This new sensor uses a single jacketed, silicone rubber-insulated cable with a long grey, flexible silicone rubber strain relief/seal component.
- Existing and new EGR temperature sensors will have their respective part numbers stamped upon the stainless-steel casing below the hex flats.
