## False Occurrences of Fault Code 555 and 556

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- X15 CM2350 X114B
- X15 CM2350 X116B
- X15 CM2450 X124B
- X15 CM2450 X134B

**Issue**

False occurrences of Fault Code 555 or 556.

Symptom:

- Fault Code 555 or 556 is active or has more than one inactive count within the last 25 engine operating hours

Root Cause:

- Engine control module (ECM) calibration code

**Verification**

- Compare the ECM calibration code and revision number in the ECM to the ECM calibration revision listed in the ECM calibration revision history on QuickServe® Online (QSOL) for applicable changes.

**Resolution**

- If an ECM calibration code update for this fault code is available, the ECM calibration code revision **must** be that revision or higher. Update ECM calibration as necessary. See corresponding Service Manual. Reference Procedure 019-032 in Section 19.
