## New Turbocharger Adapter and O-ring

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- X15 CM2350 X114B
- X15 CM2350 X116B
- X15 CM2350 X123B
- X15 CM2350 X125M
- X15 CM2450 X124B
- X15 CM2450 X134B

**Description of Change**

This document announces the release of a new turbocharger adapter part number and o-ring, option CA1713, to improve sealing between turbocharger adapter and turbocharger.

**Service Parts Availability**

Service parts are available. See Table 1 below for part numbers.

| Table 1, Service Parts |  |  |  |  |
|---|---|---|---|---|
| Part Description | Existing Part Number | Obsolete | Superseded | New Part Number |
| O-ring | - | - | - | [[2863701]] |
| Turbocharger Adapter | [[3691072]] | Yes | Yes | 5687906 |

**Part Compatibility**

- Turbocharger adapter, Part Number 5687906, **must** be accompanied by new o-ring, Part Number [[2863701]].
- O-ring, Part Number [[2863701]], is **not** able to be used with existing turbocharger adapter, Part Number [[3691072]].
- When assembling the turbocharger adapter Part Number [[3691072]], apply a bead of silicone sealant, Part Number 3164067, in the adapter to turbocharger joint.

**Part Identification**

- New Turbocharger Adapter was introduced with ESN first 80365876 and can be identified by the groove on the v-band mating face.
- New O-ring can be identified by the pink color.

**Part Inventory Action**

Use existing part number inventory before using the new part number.
