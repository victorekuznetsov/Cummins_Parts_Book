## Новая топливная система MCRS

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом документе анонсирована новая топливная система MCRS, которая включает в себя новый форсунка, топливный насос, электропроводные ремни, модуль управления двигателем (ECM), калибровку и служебную информацию. Эту новую систему обычно называют топливной системой C3. Это обеспечивает улучшенную надежность. Эта топливная система будет первоначально выпущена для промышленных применений, морских применений и двигателей QSK50 CM2150 с системой мониторинга двигателя.

> [!note] Примечание
> Обновление форсунки в стиле C2 до форсунки в стиле C3 является **не** требованием.

При обслуживании двигателя необходимо проверить ESN для определения типа топливной системы. Тип топливной системы можно определить визуально проверяя ECM.

Топливная система нового типа (C3) может быть заменена на предыдущие части топливной системы. Производственные двигатели будут переходить от старого стиля к новому стилю топливной системы в течение определенного периода времени. Части топливной системы старого стиля должны оставаться в эксплуатации для существующих двигателей. См. Таблицу 1 для перечня новых номеров частей топливной системы. В комплекте с изменениями Marine имеется возможность установки термостата для двигателей Marine QSK50 CM2150 с охлаждением киля, чтобы уменьшить внешний поток от двигателя к охладителям киля.

Для всех топливных систем MCRS были изменены процедуры обслуживания, включающие в себя шаги по снижению давления топлива при обслуживании топливной системы.

Новые электропроводки двигателя требуют новых схем электропроводки и руководств по устранению неполадок и ремонту с обновленным искусством схемы. Процедуры устранения неполадок являются общими для обеих топливных систем. См. Таблицу 2 для перечня номеров бюллетеней для новых публикаций.

При обслуживании двигателей с топливной системой нового стиля требуется электронный сервисный инструмент INSITETM версии 7.4. Существует также электропроводка на стенде ECM, специфичная для CM2150 ECM (номер детали обслуживания 4918583).

> ## New Modular Common Rail System (MCRS) Fuel System
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This document announces a new MCRS fuel system that includes new injectors, fuel pump, wiring harnesses, engine control module (ECM), calibration, and service information. This new system is commonly referred to as a C3 fuel system. It provides improved robustness. This fuel system will be initially released on Industrial applications, Marine applications, and the QSK50 CM2150 Power Generation engines with Advanced Engine Monitoring system.
>
> **Note · Примечание**
> Updating C2 style injectors to the C3 style injectors is **not** a requirement.
>
> When servicing an engine, the ESN **must** be checked to determine the fuel system type. The fuel system type can be determined by visually checking the ECM.
>
> Old Style - CM850 (Part Number 4921797)
>
> New Style - CM2150 (Part Number [[4995445]])
>
> New style fuel system (C3) parts can **not** be interchanged with previous fuel system parts. Production engines will be transitioning from the old style to the new style fuel system over a period of time. The old style fuel system parts **must** remain in service for existing engines. See Table 1 for a list of new fuel system part numbers. Included with the Marine changes is an available customer option for a thermostat insert for keel cooled Marine QSK50 CM2150 engines, to reduce the external flow from the engine to the keel coolers.
>
> The service procedures have been modified for all MCRS fuel systems to include steps to relieve the fuel pressure when servicing the fuel system.
>
> **Note · Примечание**
> Extension harness, Part Number 2881173, **must** be used when installing a fast IMV pump on a slow IMV engine to bridge the gap in the wiring harness.
>
> - Use the following procedure in Service Manual, QSK19, QSK19 CM850 MCRS, QSK19 CM2150 MCRS, Bulletin [[4021592 — QSK19, QSK19 CM850 MCRS, and QSK19 CM2150 MCRS Service Manual\|4021592]]. [[20-006-051-tr — Injector Supply Lines (High Pressure)|Refer to Procedure 006-051 in Section 6.]]
> - Use the following procedure in Service Manual, K38, K50, QSK38, and QSK50, Bulletin [[4021528 — K38, K50, QSK38, and QSK50 Service Manual\|4021528]]. [[28-006-051-tr — Injector Supply Lines (High Pressure)|Refer to Procedure 006-051 in Section 6.]]
> - Use the following procedure in Service Manual, QSK45 and QSK60, Bulletin [[4021530 — QSK45 and QSK60 Service Manual\|4021530]]. [[56-006-051-tr — Injector Supply Lines (High Pressure)|Refer to Procedure 006-051 in Section 6]]
> - Use the following procedure in the Troubleshooting and Repair Manual, QSK38, QSK50, and QSK60 CM850 Modular Common Rail System, Bulletin 4021533. Refer to Procedure 019-115 in Section 19.
> - Use the following procedure in the Troubleshooting and Repair Manual, QSK38, QSK50, and QSK60 CM2150 Modular Common Rail System, Bulletin [[4022102 — QSK38, QSK50, and QSK60 CM2150 Electronic Control System Troubleshooting and Repair M\|4022102]]. Refer to Procedure 019-115 in Section 19.
> - Use the following procedure in the Troubleshooting and Repair Manual, Electronic Control System QSK19 CM850 Modular Common Rail System, Bulletin 4021493. Refer to Procedure 019-115 in Section 19.
> - Use the following procedure in the Troubleshooting and Repair Manual, QSK19 CM2150 Electronic Control System, Bulletin [[4022094 — QSK19 CM2150 and CM2670 Electronic Control System Troubleshooting and Repair Manual\|4022094]]. Refer to Procedure 019-115 in Section 19.
>
> The new engine wiring harnesses require new wiring diagrams and Troubleshooting and Repair manuals with updated circuit art. Troubleshooting procedures are common for both fuel systems. See Table 2 for a list of new publication bulletin numbers.
>
> When servicing engines with the new style fuel system, INSITE™ electronic service tool version 7.4 is required. There is also an ECM benchtop harness specific for the CM2150 ECM (Service Part Number 4918583).
>
> Training beyond the existing MCRS training is **not** required.
