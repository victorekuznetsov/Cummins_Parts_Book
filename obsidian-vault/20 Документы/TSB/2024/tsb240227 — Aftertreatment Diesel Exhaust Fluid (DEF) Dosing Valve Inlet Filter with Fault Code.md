**Issue Summary**

Symptom:

- Fault Code 1682
- Fault Code 7325

Root Cause:

- Aftertreatment diesel exhaust fluid (DEF) dosing valve inlet filter blocked or restricted leading to improper DEF dosing unit replacement.

**Verification**

- There is an inlet filter in both the aftertreatment DEF dosing unit, Figure 3 and 4, and aftertreatment DEF dosing valve, Figure 1 and 2.
- Replace the aftertreatment DEF dosing valve inlet filter. Refer to Procedure 011-059 in Section 11 of the corresponding service manual.
