## Двигатели ReCon без электронных модулей управления (ECM)

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- ISM CM570
- ISM CM570/870
- ISM CM876
- QSM11 M570

**Описание изменения**

Начиная с 29 июля 2024 года, номера деталей двигателя ReCon®, перечисленные в таблице 1, будут поставляться без модуля управления двигателем (ECM).

**Причина изменения**

Ограничения в цепочке поставок привели к тому, что некоторые двигатели были отправлены без ECM.

**Указания по обслуживанию**

При выполнении обмена двигателя, ECM от существующего двигателя должен быть сохранен для использования на новом двигателе ReCon®.

Процедура:

1. Удалить ECM из ядра/существующего двигателя. См. соответствующее Руководство по обслуживанию. Справочная процедура 019-031 в разделе 19.
2. Установите ECM на новый двигатель ReCon®. См. соответствующее Руководство по обслуживанию. Справочная процедура 019-031 в разделе 19.
3. Обновить серийный номер двигателя в ECM с серийным номером двигателя ReCon®.
4. Все затронутые двигатели ReCon® будут поставляться с биркой (см. Рисунок 1) вместо ECM. Этот бирка должен быть прикреплен к основному двигателю до его возврата.

> **Service Instructions**
>
> When performing an engine exchange, the ECM from the existing engine **must** be retained to use on the new ReCon® engine.
>
> Procedure:
>
> 1. Remove ECM from the core/existing engine. See corresponding Service Manual. Reference Procedure 019-031 in Section 19.
> 2. Install ECM on to the new ReCon® engine. See corresponding Service Manual. Reference Procedure 019-031 in Section 19.
> 3. Update the Engine serial number in ECM with ReCon® engine serial number.
> 4. All affected ReCon® engines will arrive with a hang tag (see Figure 1) in place of the ECM. This hang tag **must** be attached to the core engine prior to being returned.
