# New Injector Kit Part Numbers

> **Даты:** изменён 2024-02-27

## New Injector Kit Part Numbers

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- X15 CM2350 X114B
- X15 CM2350 X116B
- X15 CM2350 X123B
- X15 CM2350 X129B
- X15 CM2450 X124B
- X15 CM2450 X134B
- X15 CM2450 X142B

**Description of Change**

Fuel injector kits for the X15 engine contain the injector, Part Number [[4327147]]. New kit part numbers are being released (see Table 1).

**Reason for Change**

Beginning in January 2024, Part Number [[4327147]] fuel injector(s) have improved durability for the MY21 X3/X600 duty cycle.

**Service Parts**

| Table 1, Service Parts |  |  |  |  |
|---|---|---|---|---|
| Part Description | Existing Part Number | Obsolete | Superseded | New Part Number |
| Fuel Injector Kit | [[5579421]] | No | Yes | 6513590 |
| Fuel Injector Kit | [[5579421]] | No | Yes | [[6513589]] |

**Part Compatibility**

- Reference kit part number shown in Table 2 for the engine being serviced.
- Part Number [[6513589]] **must** be used for X15 CM2450 X134B and X15 CM2450 X142B.
- Part Number [[6513589]] can be used for All Engines listed in Table 2.
- If Part Number 6513590 is **not** available, use either Part Number [[5579421]] or Part Number [[6513589]].

| **Table 2, Injector Kit Part Number Compatibility** |  |
|---|---|
| Injector Part Number | Engine Service Model Name |
| [[5579421]] or 6513590 or [[6513589]] | X15 CM2350 X114B X15 CM2350 X116B X15 CM2350 X123B X15 CM2350 X129B X15 CM2450 X124B |
| [[6513589]] | X15 CM2450 X134B X15 CM2450 X142B |

**Part Identification**

New and Recon injectors with SN S24001xxx and later have the improvement. All new X15 engines since ESN 80608247 built 24 January 2024 have this improvement.
