**Проблема**

Номера деталей двигателя ReCon®, перечисленные в [[tsb230228 — ReCon® Engines Without Electronic Control Modules (ECM)\|TSB230228]], TSB240194 и [[tsb240195 — ReCon® Engines without Electronic Control Modules (ECM)\|TSB240195]], будут отправлены без модуля управления двигателем (ECM).

**Решение**

Этот документ должен помочь вам найти номера деталей ECM для этих двигателей.

**Указания по обслуживанию**

- Перейдите на сайт quickserveonline.com и войдите.
- Использование поиска серийных номеров двигателя ReCon® в Каталоге частей / ReCon®, как показано на рисунке 1.

![[17r02224.png]]

Рисунок 1 Серийный номер двигателя Поиск.

- Найдите опцию PH для поиска номера детали ECM. Например, PH01844-SM из рисунка 2.

![[17r02225.png]]

Рисунок 2, пример варианта PH.

- Используйте строку поиска «Поиск всех продуктов / энгинов / системы для:», чтобы найти опцию PH. В этом примере опция PH01844-SM в сборке материалов двигателя ReCon®, ноль и -SM должны быть удалены, чтобы появиться в строке поиска, как показано на рисунке 3.

![[17r02226.png]]

Рисунок 3, Поиск по всем продуктам Пример.

- Выберите ссылки из результатов поиска, пока не будет найден номер детали ECM, как показано на рисунке 4.

![[17r02227.png]]

Рисунок 4, номер детали ECM, найденный в результатах поиска.

- Если номер детали ECM не найден, создайте билет QSOL для ответа на этот запрос. См. рисунок 5.

![[17r02228.png]]

Рисунок 5, Интерфейс билетов QSOL.
