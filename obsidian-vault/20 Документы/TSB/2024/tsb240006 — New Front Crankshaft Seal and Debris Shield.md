## Новый передний сальник коленвала и защитный экран

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- ISC (все версии)
- ISL (все версии)
- L9 (все версии)
- QSC (все версии)
- QSL (все версии)

**Описание изменения**

- Доступен новый передний уплотнитель коленчатого вала.
- Доступен новый щит для мусора.

**Причина изменения**

- Передняя уплотнение коленчатого вала была улучшена, чтобы уменьшить внешние утечки масла.
- Новый щит мусора был разработан для работы с новым передним уплотнением коленчатого вала для улучшения эффективности удаления пыли / мусора.

**Указания по обслуживанию**

- Если существующая передняя уплотнение коленчатого вала неисправно и поверхность коленчатого вала **не **имеет чрезмерный износ, замените на новую переднюю уплотнение коленчатого вала.
- Если существующая передняя уплотнение коленчатого вала неисправно **и **поверхность коленчатого вала имеет чрезмерный износ, замените использование служебных комплектов с включенным износом рукава. См. соответствующее Руководство по обслуживанию. Справочная процедура 001-023 в разделе 1.

> ## New Front Crankshaft Seal and Debris Shield
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> **Product Affected**
>
> - ISC (All Versions)
> - ISL (All Versions)
> - L9 (All Versions)
> - QSC (All Versions)
> - QSL (All Versions)
>
> **Description of Change**
>
> - A new front crankshaft seal is available.
> - A new debris shield is available.
>
> **Reason for Change**
>
> - Front crankshaft seal was improved to reduce external oil leaks.
> - New debris shield was developed to work with new front crankshaft seal to improve dust/debris exclusion performance.
>
> **Service Instructions**
>
> - If existing front crankshaft seal has malfunctioned and crankshaft surface does **not** have excessive wear, replace with new front crankshaft seal.
> - If existing front crankshaft seal has malfunctioned **and** crankshaft surface has excessive wear, replace using service kits with wear sleeve included. See corresponding Service Manual. Reference Procedure 001-023 in Section 1.
>
> **Service Parts**
>
> Service parts are offered. See Table 1 for part numbers.
>
> | Table 1, Service Parts |  |  |  |  |
> |---|---|---|---|---|
> | Part Description | Existing Part Number | Obsolete | Superseded | New Part Number |
> | Oil seal | 3942535 | Yes | Yes | 5682528 |
> | Oil seal | 3921927 | Yes | No | - |
> | Installation kit | - | - | - | 5573509 |
> | Debris shield | 5401041 | Yes | Yes | 5682529 |
> | Seal kit (with wear sleeve) | 3925343 | No | No | - |
>
> **Part Compatibility**
>
> New front crankshaft seal is **only** compatible with new debris shield.
>
> **Part Identification**
