## Idler Pulley Bracket Installation for Option FA1611 and FA1608

**Description of Change**

Releasing a new idler pulley bracket mounting capscrew for options FA1611 and FA1608. The new capscrew will improve the joint robustness and allow the installation torque to be increased.

**Reason for Change**

The previous idler pulley bracket, part number 3688069, load column had a soft p-clip under the capscrew and insufficient thread engagement resulting in poor bolt load retention and risk of thread strip. This change moves the p-clip to an alternative location, increases thread engagement, and increases the capscrew grade to allow an increase in installation torque.

**Service Instructions**

- Remove and discard capscrews, Part Number [[3901446]], see Table 2.
- Relocate P-clip for breather tube options BR1774 or BR1775 from hole number 6 (seen in Figure 1) to hole number 3 (seen in Figure 2), according to the gear cover capscrew numbers displayed in Figure 3.
- Install capscrews, Part Number [[3966976]], see Table 2.
