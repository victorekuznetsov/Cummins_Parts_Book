## Fault Code 1881, 1883, 3133, 3134, 3135, 5715 5716, or 6786 with Fault Code 1921, 1922, 1981, or 2639

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- B6.7 CM2350 B121B
- B6.7 CM2450 B155B

- L9 CM2450 L126B
- X12 CM2350 X119B

- X15 CM2450 X142B

**Issue Summary**

Symptom:

- Fault Code 1881, 1883, 3133, 3134, 3135, 5715, 5716, and/or 6786 active or has more than one inactive count within the last 25 engine operating hours along with Fault Code 1921, 1922, 1981, and/or 2639 active or has more than one inactive count within the last 25 engine operating hours.

Root Cause:

- Aftertreatment diesel particulate filter (DPF) differential pressure sensor is susceptible to moisture intrusion that can cause false occurrences of 1921, 1922, 1981, and/or 2639, which will lead to unnecessary aftertreatment DPF replacement.

**Verification**

- Use the recommended Cummins® electronic service tool or equivalent to read the fault codes.
- Fault Codes 1881, 1883, 3133, 3134, 3135, 5715, 5716, and/or 6786 are active or has more than one inactive count within the last 25 engine operating hours.
- Fault Codes 1921, 1922, 1981, and/or 2639 active or has more than one inactive count within the last 25 engine operating hours.
- If the fault code does **not** return, no further troubleshooting is required. If Fault Code 1921, 1922, 1981, and/or 2639 return, complete the remainder of the troubleshooting steps.

**Resolution**

- If an ECM calibration code update for this fault code is available, the ECM calibration code revision **must** be that revision or higher.
- If fault codes are **not** active or do **not** have more than one inactive count within the last 25 engine operating hours, continue with published troubleshooting.
