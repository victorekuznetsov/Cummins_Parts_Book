## Air Handling Performance Test and NOx Sensor Diagnostic Steps with Engine Control Module (ECM) Calibration Code Revision with DEF Header Calibration Revision

### Warranty Statement

**Product Affected**

**Issue Summary**

The aftertreatment engine control module (ECM) calibration code revision with DEF header calibration revision (See Technical Service Bulletin, Fault Codes 3868, 4572 and 4677 Caused by Diesel Exhaust Fluid (DEF) Header Malfunction, [[tsb210187 — Fault Codes 3868, 4572 and 4677 Caused by Diesel Exhaust Fluid (DEF) Header Malfunc\|TSB210187]]) does **not** contain the Air Handling Performance Test, the Aftertreatment Intake NOx Sensor Test, or the Aftertreatment Outlet NOx Sensor Test. Troubleshooting may prompt the user to run these diagnostics, and if the unit has the ECM calibration code revision with DEF header calibration revision these diagnostic tests will **not** be available in INSITE ™ electronic service tool.

**Verification**

If troubleshooting is directing to run the Air Handling Performance Test, the Aftertreatment Intake NOx Sensor Test, or the Aftertreatment Outlet NOx Sensor Test and the diagnostic test needed is **not** appearing in INSITE ™ electronic service tool follow the Resolution section below.

**Resolution**

To complete the needed diagnostics the original base ECM calibration **must** be downloaded.

**Service Instructions**

1. See the engine data plate for the original base ECM calibration code.
2. Navigate the Calibration Revisions on QuickServe® Online and search the Description column for the ECM calibration code that has the needed diagnostic test.
3. Download the ECM calibration code with the needed diagnostic test from QSOL and complete the needed troubleshooting.
4. Once repair is completed, download the ECM calibration code revision with DEF header calibration revision (See Technical Service Bulletin, Fault Codes 3868, 4572 and 4677 Caused by Diesel Exhaust Fluid (DEF) Header Malfunction, [[tsb210187 — Fault Codes 3868, 4572 and 4677 Caused by Diesel Exhaust Fluid (DEF) Header Malfunc\|TSB210187]]).
