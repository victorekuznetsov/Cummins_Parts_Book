## Новый масляный фильтр Eliminator™ в сборе

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- KV38 Все
- KV50 Все
- Все клипы 38
- QSK45 Все
- QSK50 все
- QSK60 Все
- QSK78 Все
- QSK95 Все

**Описание изменения**

Новые сборки EliminatorTM выпускаются с пересмотренными внутренними элементами, такими как улучшенный гидравлический двигатель, центрифуга и новые фильтрующие элементы, которые имеют более тонкий сетчатый экран для улучшения фильтрации.

**Указания по обслуживанию**

- Экраны фильтрующих элементов больше не покупаются парами, все элементы теперь должны быть заменены в виде полной сборки.
- Процедура очистки и проверки экранов фильтрующих элементов теперь рекомендуется только в случае неисправности или если требуется уборка в рабочем состоянии.
- Если обнаружено повреждение любого из существующих экранов элементов, рекомендуется заменить все фильтрующие элементы новым номером детали, хотя в качестве альтернативы поврежденные элементы могут быть заменены существующим номером детали. Новые фильтрующие элементы **не** смешиваются с существующими номерами деталей.

**Совместимость частей**

Новые экраны фильтрующих элементов не должны смешиваться с существующими номерами деталей, если новые и существующие экраны используются вместе, это может привести к повреждению внутренних органов.

**Идентификация детали**

Экраны фильтрующих элементов различимы только по номеру детали 1800-03335 для нового экрана и 1800-03336 для старых экранов.

**Часть инвентаризации**

Используйте существующий инвентарь номеров деталей перед использованием нового номера деталей.

> **Description of Change**
>
> New Eliminator™ Assemblies are being released with revised internals such as an improved hydraulic motor, centrifuge, and new filtering element screens which have a finer mesh screen to improve filtering capability.
>
> **Service Instructions**
>
> - The filter element screens are no longer purchased in pairs, all elements must now be replaced as a full assembly.
> - The cleaning and inspecting procedure for the filter element screens is now **only** recommended in the case of a malfunction event or if in service cleaning is required.
> - If damage is found to any of the existing element screens the recommended direction is to replace all filter elements with the new part number, although alternatively the damaged elements could be replaced with the existing part number. The new filter elements is **not** be mixed in with the existing part numbers.
