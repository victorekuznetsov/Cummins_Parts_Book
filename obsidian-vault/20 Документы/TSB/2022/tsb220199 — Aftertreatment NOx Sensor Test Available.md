## Aftertreatment NOx Sensor Test Available

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

**Issue Summary**

Symptom:

- Fault Codes: 3748, 3749, 5655, 6459 or 6463

**Verification**

- New Aftertreatment Intake and Outlet NOx Sensor Tests is used when troubleshooting certain engine fault codes. Throughout each test heater response, stability and accuracy are checked to diagnose the NOx sensor.
- The Aftertreatment Intake or Outlet NOx Sensor Test is to be performed when directed by troubleshooting to verify the root cause is identified and repaired the first time without unnecessary repairs.

**Resolution**

- Perform the Aftertreatment Intake or Outlet NOx Sensor Test when directed by published troubleshooting.
- Reference the appropriate Fault Code Troubleshooting procedure. See corresponding Service Manual. Reference Procedures 014-36 and 014-037 in Section 14.
- The Aftertreatment Intake or Outlet NOx Sensor should **only** be replaced when directed by the Aftertreatment Intake or Outlet NOx Sensor Test. Visual inspection should **not** drive the replacement of NOx Sensor malfunction.

**Description of Change**

- This document is intended to highlight the ability of the Aftertreatment Intake and Outlet NOx Sensor Tests to diagnose NOx Sensor functionality.
- The Aftertreatment Intake and Outlet NOx Sensor Tests are now available. This diagnostic test was developed to evaluate the functionality of the NOx Sensor.
- The Aftertreatment Intake and Outlet NOx Sensor Test can accurately identify a NOx Sensor malfunction. The use of this diagnostic test reduces the chance of misdiagnosis and is used to validate repair of the NOx Sensor.
