## Reducing Occurrences of Fault Code 197

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- X15 CM2350 X114B
- X15 CM2350 X116B
- X15 CM2450 X124B
- X15 CM2450 X134B

**Issue Summary**

Symptoms:

- Audible coolant level warning
- Light on screen with ‘Low Coolant Level' message
- Active or inactive Fault Code 197

Root Cause:

- Coolant level fluctuations are higher than expected during normal engine operation triggering the Fault Code 197.

**Verification**

- Verify that Fault Code 197 is active or has more than one inactive count within the last 25 engine operating hours.
- Compare the ECM calibration code and revision number in the ECM to the ECM calibration code revision listed in the ECM calibration revision history for applicable changes.

**Resolution**

- A new ECM calibration code revision has been released that reduce occurrences of low coolant level fault code 197.
- If a calibration update for this fault code is available, the ECM calibration revision **must** be that revision or higher.
