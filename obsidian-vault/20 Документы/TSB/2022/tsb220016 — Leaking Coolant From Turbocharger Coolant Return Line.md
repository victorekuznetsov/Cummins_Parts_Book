## Leaking Coolant From Turbocharger Coolant Return Line

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- QSK60 CM2150 MCRS

**Issue Summary**

Symptom:

- Coolant leak

Root Cause:

- Incorrect hose clamp sizing

**Verification**

If a coolant leak from turbo coolant plumbing return line, Part Number 5375486, is observed, follow instructions in resolution section for fix.

**Resolution**

- If a coolant leak from turbo coolant plumbing return line, Part Number 5375486, has been observed replace the coolant plumbing hose with a new one, Part Number 5375486, and secure hose with quantity three of clip, Part Number 3649927.
- For proper removal and install instructions, see QSK60 CM2150 MCRS, Bulletin [[4021530 — QSK45 and QSK60 Service Manual\|4021530]]. [[56-010-041 — Turbocharger Coolant Hoses|Refer to Procedure 010-041]] in Section 10.

**Reason for Change**

Original clips did **not** have proper fit which allowed fretting between turbocharger coolant hose and clamps resulting in coolant leak.
