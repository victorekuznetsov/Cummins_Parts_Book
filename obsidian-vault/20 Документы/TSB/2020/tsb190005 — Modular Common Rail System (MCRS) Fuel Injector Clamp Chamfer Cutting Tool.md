**Проблема**

Симптом:

- Неисправность зажимных болтов форсунки, позволяющая выпячивать форсунка из клапанного чехла.

Первопричина:

- Помехи между зажимом зажима топливного форсунка и болтами.

**Проверка**

Режущий инструмент для зажима зажима топливного топлива рекомендуется для использования на любом двигателе с модульной общей железнодорожной системой высокой мощности (MCRS), где обслуживается форсунка, требующий установки новых болтов. Если идентифицируется помеха между филе болтов и зажимным шамфером (визуальное подтверждение зазора между головкой болтов и верхней поверхностью зажима при **не** установленной в двигателе, или любым измеренным зазором между головкой болтов и верхней поверхностью зажима в установленном состоянии), зажим форсунки **должен** иметь зажим, модифицированный с помощью режущего инструмента. Если проблема была выявлена в установленном состоянии, форсунка зажима зажима * должен быть заменен на переустановку.

**Решение**

Новый инструмент для резки зажима форсунки, номер детали 5395114, был выпущен для обеспечения контролируемого способа переформирования зажима зажима зажима форсунки. Инструмент оснащен направляющим цилиндром и плечом для управления глубиной и предназначен для использования с ручной оснасткой с питанием.

Был выпущен пересмотренный зажим форсунки, который включает в себя модифицированную конструкцию чамфера для обеспечения допуска размеров существующих болтов. См. таблицу 1 ниже для информации об обслуживающих частях топливного форсунка. Размеры режущего инструмента отражают те же размеры, что и пересмотренный зажим форсунки.

**Наличие сервисных деталей**

Существующие зажимы, уже находящиеся в эксплуатации, могут быть заменены на пересмотренный зажим форсунки или они могут быть изменены с помощью режущего инструмента для обрезки чамфера во время мероприятий по обслуживанию.

Пересмотренная дата очистки зажима - 1 октября 2020 года.

До внедрения на заводе пересмотренного топливного форсунка для поддержки производства заводам были предоставлены модифицированные детали поставщика под тем же номером детали, что и существующий зажим. > **Issue**
>
> Symptom:
>
> - Injector clamp capscrew malfunction allowing injector protrusion from the valve cover.
>
> Root Cause:
>
> - Interference between the fuel injector clamp chamfer and capscrew.
>
> **Verification**
>
> The fuel injector clamp chamfer cutting tool is recommended for use on any High Horsepower Modular Common Rail System (MCRS) engine where injectors are being serviced requiring a new capscrew to be installed. If interference between the capscrew fillet and clamp chamfer is identified (visual confirmation of a gap between the capscrew head and the clamp top surface while **not** installed in the engine, or by any measured gap between the capscrew head and clamp top surface in an installed condition), the injector clamp **must** have the chamfer modified through use of the chamfer cutting tool. If the issue was identified in the installed condition, the injector hold down clamp capscrew **must** be replaced on re-installation.
>
> **Resolution**
>
> A new injector clamp chamfer cutting tool, Part Number 5395114, was released to provide a controlled method for reshaping the capscrew bore chamfer on the injector hold-down clamp. The tool features a bore guide and a depth-controlling shoulder and is designed for use with powered hand tools.
>
> A revised injector clamp has been released that incorporates a modified chamfer design to accommodate the dimensional tolerance of the existing capscrew. See Table 1 below for injector clamp service parts information. The chamfer cutting tool dimensions reflect the same dimensions as the revised injector clamp.
>
> **Service Parts Availability**
>
> Existing clamps already in service can be replaced with the revised injector clamp or they can be modified with the chamfer cutting tool during service events.
>
> Revised clamp clean date is October 1, 2020.
>
> Prior to plant implementation of the revised injector clamp, modified supplier parts under the same part number as the existing clamp were provided to plants to support manufacturing. The build period for these modified parts began on 16 March 2017 and extended through the implementation dates of the new parts listed below in Table 2.
