## Новая поддержка Accessory Drive

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- QSK23 CM500 FCO

**Проблема**

Принадлежность привода опоры передних подшипников испытывает повышенную радиальную нагрузку за счет установленной конфигурации генератора 140А и увеличения свеса.

Признак неисправности

- Чрезмерный шум спереди двигателя
- Аксессуарный привод поддерживает переднюю неисправность подшипника. См. рисунок 1.

Коренная причина

- Избыточная нагрузка, приложенная к вспомогательному приводу опоры переднего подшипника.

![[09h00028.png]]

Рисунок 1, поддержка разобранного аксессуара, передняя часть в красном ящике

**Проверка/подтверждение**

- Двигатель оснащен генератором 140А.
- Аксессуарный привод поддерживает переднюю неисправность подшипника.

**Решение**

- Выпущена новая вспомогательная поддержка привода с передним цилиндрическим роликовым подшипником.
- Сервисные детали доступны для заказа. Номера деталей приведены в таблице 1.

| Таблица 1, Части обслуживания |  |  |  |  |  |
|---|---|---|---|---|---|
| Часть описание | Существующий номер детали | устарелый | Заменённый | Новый номер детали | Количество необходимо |
| Драйв, топливный насос / Поддержка, аксессуар Drive | 4096329 | Да | Да | 5633425 | 1 |

**Совместимость частей**

Поддержка привода, часть 4096329, может использоваться только для конфигураций генератора переменного тока 75A.

Новая поддержка привода, номер детали 5633425, с цилиндрическим роликовым подшипником совместима как с конфигурациями генератора переменного тока 75А, так и 140А.

После того, как запас Части 4096329 исчерпан, используйте Часть Номер 5633425.

> [!quote]- Original (English) · английский оригинал
> ## New Accessory Drive Support
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> **Product Affected**
>
> - QSK23 CM500 FCO
>
> **Issue**
>
> The accessory drive support front bearing experiences increased radial load due to the fitted 140A alternator configuration and increase in overhang.
>
> Symptom
>
> - Excessive noise from the front of the engine
> - Accessory drive support front bearing malfunction. See Figure 1.
>
> Root Cause
>
> - Excessive load applied to the accessory drive support front bearing.
>
> Figure 1, Disassembled Accessory Drive Support, Front Bearing In Red Box
>
> **Verification/Confirmation**
>
> - Engine is equipped with 140A alternator.
> - Accessory drive support front bearing malfunction.
>
> **Resolution**
>
> - A new accessory drive support with a front cylindrical roller bearing has been released.
> - Service parts are available. See Table 1 for part numbers.
>
> | Table 1, Service Parts |  |  |  |  |  |
> |---|---|---|---|---|---|
> | Part Description | Existing Part Number | Obsolete | Superseded | New Part Number | Quantity Needed |
> | Drive, Fuel Pump / Support, Accessory Drive | 4096329 | Yes | Yes | 5633425 | 1 |
>
> **Part Compatibility**
>
> Accessory drive support, Part Number 4096329, can **only** be used for 75A alternator configurations.
>
> The new accessory drive support, Part Number 5633425, with cylindrical roller bearing is compatible with both the 75A and 140A alternator configurations.
>
> Once Part Number 4096329 stock is exhausted, use Part Number 5633425.
>
