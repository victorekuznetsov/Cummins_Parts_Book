## New QSK60 Lube Filter

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- QSK60 CM2150
- QSK60 CM850

**Description of Change**

A new lube filter is available that has improved filtration capabilities and filter life.

**Reason for Change**

There have been multiple reports of filter plugging across QSK60 construction engines. This filter improved filter debris capacity that will improve the hours until plugging allowing engines to meet service intervals.

**Service Parts Availability**

Service parts are available. See Table 1 for part numbers.

**Customer Communication**

This change only applies to Marine and Construction engines. Generator sets must still use the original part number.

| Table 1, Service Parts |  |  |  |  |
|---|---|---|---|---|
| Part Description | Existing Part Number | Obsolete | Superseded | New Part Number |
| QSK60 Lube Filter | [[4920071]] | No | No | LF14005NN [[5375337]] |

**Part Compatibility**

Full compatibility. The new lube filters will fit the original filter heads with no changes to the installation procedure and service intervals.

**Part Identification**

All lube filters will have a Cummins label clearly displaying filter part numbers.
