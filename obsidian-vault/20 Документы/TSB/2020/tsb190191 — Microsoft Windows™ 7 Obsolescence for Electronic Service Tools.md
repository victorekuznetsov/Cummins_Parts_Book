## Прекращение поддержки Windows™ 7 в электронных сервисных инструментах

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- Все продукты двигателя с электронным управлением.

**Проблема**

По состоянию на январь 2020 года поддержка Microsoft прекратилась для WindowsTM 7 SP1 и более низких версий.

- Техническая поддержка электронного инструментария INSITETM может быть недоступна при использовании операционных систем Windows 7 SP1 и более низкой версии.
- Инструменты для электронных сервисов INSITETM больше не будут поддерживаться для Microsoft Windows 7 после выпуска версии 8.6.2. после или после 09 июля 2020 года.
- Конфигурационный инструмент для лицензионных отредактированных версий больше не будет поддерживаться для Microsoft Windows 7 15 июля 2020 года.
- Cummins® Inc. Менеджер обновлений больше не будет поддерживаться для Microsoft Windows 7 20 декабря 2020 года.
- Для сотрудников Cummins®, Cummins® Inc. Менеджер обновлений перестанет работать на компьютерах с Microsoft Windows 7 20 декабря 2020 года.

**Решение**

Обновление до поддерживаемой версии Microsoft WindowsTM.

>
