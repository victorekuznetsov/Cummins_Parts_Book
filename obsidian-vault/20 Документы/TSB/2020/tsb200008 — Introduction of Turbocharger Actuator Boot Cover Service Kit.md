## Introduction of Turbocharger Actuator Boot Cover Service Kit

### Contents

**Product Affected**

- X15 CM2350 X114B
- X15 CM2350 X116B

**Description of Change**

This document announces a new turbocharger actuator boot cover service kit, Part Number 5579449.

**Reason for Change**

Turbocharger actuator corrosion found due to water intrusion through actuator connector.

**Service Instructions**

Turbocharger actuators without a boot cover and with Fault Code 1894 active, **must** have a boot cover installed.

![[10r00326.png]]

Figure 1, Boot Cover and Zip Tie

Prior to installing boot cover, make sure grey tab is fully inserted (clip locked) into the black connector.

1. Incorrect: grey tab **not** fully inserted.
2. Correct: grey tab fully inserted.

![[10r00327.png]]

Figure 2, Location of Grey Tab

Place boot cover, Part Number 5566729, on top of turbocharger actuator connector, as shown below, and make sure boot cover is fully seated.

Secure zip tie, Part Number [[3691058]], around boot cover and corrugated harness sleeve. Pull snug and cut end of zip tie.

![[10r00328.png]]

Figure 3, Boot Cover Correctly Installed
