## Снятие с производства топливного насоса с медленным дозирующим клапаном

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- QSKTA38
- QSKTA50
- QSKTA60
- КАКТА19

**Описание изменения**

Медленные впускные клапанные топливные насосы больше не доступны для обслуживания и должны быть заменены на быстрые впускные клапанные топливные насосы. Модуль управления двигателем (ECM) обновления необходимы для этого изменения, см. таблицы ниже для соответствующих рейтингов топлива в соответствии с приложением.

**Причина изменения**

Медленный впуск клапана топливных насосов больше не доступен для обслуживания.

**Клиентская коммуникация**



**Указания по обслуживанию**

Калибровка ECM **должна** выполняться при замене топливного насоса с медленным впускным клапаном на топливный насос с быстрым впускным клапаном. См. таблицы приложений ниже для соответствующих вариантов рейтинга топлива.

> [!note] Примечание
> Расширение жгута проводов, номер детали 2881173, должно использоваться при установке быстрого насоса IMV на медленном двигателе IMV для преодоления разрыва в жгуте проводов.

> [!note] Примечание
> Для применения в строительстве, ссылка TSB130102

> **Description of Change**
>
> Slow inlet metering valve fuel pumps are no longer available for service, and are to be replaced with fast inlet metering valve fuel pumps. Engine control module (ECM) updates are necessary for this change, see tables below for corresponding fuel ratings according to application.
>
> **Reason for Change**
>
> Slow inlet metering valve fuel pumps are no longer available for service.
>
> **Customer Communication**
>
> Recommend upgrade **only** if a replacement is necessary.
>
> **Service Instructions**
>
> ECM calibration **must** be performed when replacing slow inlet metering valve fuel pump with fast inlet metering valve fuel pump. See application tables below for corresponding fuel rating options.
>
> **Note · Примечание**
> Extension harness, Part Number 2881173, **must** be used when installing a fast IMV pump on a slow IMV engine to bridge the gap in the wiring harness.
