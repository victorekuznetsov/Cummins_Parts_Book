**Description of Change**

This document announces the release of new engine control module (ECM) part number.

**Reason for Change**

Obsolete the existing CM400 24V and supersede with new CM2940.

**Customer Communication**

New CM2940 is physically identical to the old 24V CM400 hardware. Both ECM functions are transparent with no difference in engine performance. CM2940 meets the RoHS (Restriction of Hazardous Substances) requirement while CM400 does not.

> [!note] Note · Примечание
> Continue to use existing functional CM400 in the event of an engine rebuild for marine customers.

**Service Instructions**

Engine ECM change from CM400 to CM2940 requires an ECM base calibration code change. See Table 2 and Table 3 for calibration code reference.

The CPL number changes when CM400 is replaced by CM2940.

Upon completion of the conversion from CM400 to CM2940, an authorized change label (Part Number 5297400) **must** be completed and installed on the engine.
