## Новый компрессор Piston Ring

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- ISX (все 15 литровых продуктов)
- QSX (все 15 литровых продуктов)
- X15 (все версии)

**Проблема**

При установке поршневых и соединительных узлов стержневых, поршень **не** надежно удерживается в поршневом кольцевом компрессоре. Уменьшенное напряжение поршневых колец обеспечивает меньшее сопротивление движению поршня в поршневом кольцевом компрессоре.

**Решение**

- Был выпущен новый номер поршневого компрессора, который включает пару пластиковых наконечников для улучшения удержания поршня. См. таблицу 1 ниже.
- Этот документ также разрешает местам ремонта модифицировать существующие поршневые кольцевые компрессоры путем сверления и прослушивания двух отверстий для установки пластиковых наконечников. См. раздел Инструкции по обслуживанию ниже.

**Доступность инструментов сервиса**

Доступны сервисные инструменты. Номера деталей приведены в таблице 1.

**Указания по обслуживанию**

Компрессор для поршневого кольца, номер детали 3164846, инструкция по модификации:

> [!danger] ОПАСНО
> Чтобы уменьшить вероятность получения травм, надевайте очки и защитную одежду.

1. Расположение зоны для отверстий:
2. Центр ударных мест для отверстий внутри поршневого кольца цилиндра компрессора.
3. Дрильные отверстия с буровым битом 7,94 мм \[5/16 в \].
4. Отверстия для касания с помощью 3/8-16 унифицированного стандарта резьбы (UNC).
5. Проверьте, чтобы в цилиндр не входили заусеницы.
6. Установите два винта, номер детали 5394447. См. рисунки 3 и 4 ниже.

> ### Warranty Statement

> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

> ### Contents
>
> **Product Affected**
>
> - ISX (All 15 Liter Products)
> - QSX (All 15 Liter Products)
> - X15 (All Versions)
>
> **Issue**
>
> When installing piston and connecting rod assemblies, the piston is **not** held securely in piston ring compressor. Reduced tension piston ring packs offer less resistance to piston movement within piston ring compressor.
>
> **Resolution**
>
> - A new piston ring compressor part number has been released that incorporates a pair of plastic tipped thumbscrews to improve piston retention. See Table 1 below.
> - This document also authorizes repair locations to modify existing piston ring compressors by drilling and tapping two holes for installation of plastic tipped thumbscrews. See Service Instructions section below.
>
> **Service Tool Availability**
>
> Service tools are available. See Table 1 for part numbers.
>

> | Thumbscrew Assembly | - | - | - | 5394447\* |
> | \*Quantity of two required **only** if modifying existing part number 3164846. |  |  |  |  |
>
> **Service Instructions**
>
> Piston Ring Compressor, Part Number 3164846, Modification Instructions:
>
> **WARNING · Опасно**

> 1. Locate area for holes:
> 2. Center punch locations for holes on inside of piston ring compressor bore.
> 3. Drill holes with a 7.94 mm \[ 5/16 in \] drill bit.
> 4. Tap holes with a 3/8-16 unified thread standard (UNC) tap.
> 5. Verify no burrs extend into bore.
> 6. Install two thumbscrews, Part Number 5394447. See Figures 3 and 4 below.
