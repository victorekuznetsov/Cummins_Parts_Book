## INSITE™ Electronic Service Tool Error When Adjusting Aftertreatment Diesel Exhaust Fluid Level System Configuration Programmable Parameters

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- ISB4.5 CM2350 B104
- ISB6.7 CM2350 B101
- ISB6.7 CM2350 B103
- ISL9 CM2350 L101
- ISL9 CM2350 L111
- ISX12 CM2350 X101
- ISX15 CM2350 X102

**Issue**

When making adjustments to Aftertreatment Diesel Exhaust Fluid Level System Configuration programmable parameters with INSITE™ electronic service tool, an error message will be encountered.

**Verification**

When adjusting the values of Aftertreatment Diesel Exhaust Fluid Inducement Level, Aftertreatment Diesel Exhaust Fluid Low Level, or Aftertreatment Diesel Exhaust Fluid Warning Level with INSITE™ electronic service tool on Model Year 2015 and Model Year 2016 engines, an error message will display as shown in Figure 1 below.

![[22r00049.png]]

Figure 1, ECM Write Unsuccessful Error Message

**Resolution**

- Disregard the engine control module (ECM) Write Unsuccessful error message. The parameters will write and save to ECM memory.
- The error message issue will be resolved in a future software release scheduled for mid-year 2016.
