**Проблема**

Неисправности двигателя наблюдались, поскольку 150-мм цилиндровые вкладыши используются в блоках цилиндров 152 мм по ошибке. Только 152-мм цилиндровые вкладыши могут быть использованы с 152-мм блоками цилиндров.

В этом документе анонсированы новые сервисные инструменты, которые обеспечивают быстрый и простой способ определения размера цилиндра, а также диаметра цилиндрового вкладыша.

**Проверка**

Для измерения цилиндрических вкладышей используйте калибр, номер детали 5299587.

1. Поместите цилиндрический вкладыш вверх ногами на плоскую рабочую поверхность.
2. Слайд-измеритель, номер детали 5299587, на нижнем конце цилиндрового гильзы.
3. Если калибр способен покоиться на выступе цилиндра с стойкой на середине столба, то цилиндрический гильза представляет собой цилиндрический гильза калибра 150 мм.
4. Если калибр **не** способен покоиться на выступе цилиндра с торцевой стойкой, то цилиндровый вкладыш представляет собой 152-мм цилиндровый вкладыш.

Для измерения блоков цилиндров используйте калибр, номер детали 5394467.

1. С помощью цилиндрового вкладыша, удаленного из блока цилиндров, вставьте калибр в цилиндрический блок цилиндрового вкладыша.
2. Если калибр, номер детали 5394467, способен полностью пройти через цилиндрический штанги, блок цилиндров представляет собой блок цилиндров 152 мм.
3. Если калибр, номер детали 5394467, не может полностью пройти через цилиндрический цилиндр, блок цилиндра представляет собой блок цилиндра 150 мм.

> **Issue**
>
> Engine malfunctions have been observed as 150 mm cylinder liners are being used in 152 mm cylinder blocks in error. **Only** 152 mm cylinder liners can be used with 152 mm cylinder blocks.
>
> This document announces new service tools that provide a quick and easy way to determine the size of the cylinder block bore as well as the cylinder liner diameter.
>
> **Verification**
>
> To measure cylinder liners, use gauge, Part Number 5299587.
>
> 1. Place cylinder liner upside down on a flat work surface.
> 2. Slide gauge, Part Number 5299587, over lower end of cylinder liner.
> 3. If gauge is able to rest on midstop counter bore ledge, cylinder liner is a 150 mm cylinder liner.
> 4. If gauge is **not** able to rest on midstop counter bore ledge, cylinder liner is a 152 mm cylinder liner
>
> To measure cylinder blocks, use gauge, Part Number 5394467.
>
> 1. With cylinder liner removed from cylinder block, insert the gauge into cylinder block liner bore.
> 2. If gauge, Part Number 5394467, is able to pass completely through midstop counter bore, cylinder block is a 152 mm cylinder block.
> 3. If gauge, Part Number 5394467, is **not** able to pass completely through midstop counter bore, cylinder block is a 150 mm cylinder block.
