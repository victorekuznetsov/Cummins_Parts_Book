**Проблема**

- Двигатели испытывают проблемы с замораживанием капусты и / или дыхательной трубки при температурах ниже нуля.

**Симптом**

- Утечка моторного масла и коды неисправностей высокого давления в картере - это внешняя утечка моторного масла
- Код 555, код 556.

### Подтверждение

Фильтр капкаса и замораживание трубки капкаса могут вызвать давление картера, что приводит к:

- Утечки моторного масла на уплотнении турбокомпрессора, уплотнении клапанной крышки и уплотнении прокладки кожуха качалки или передней или задней уплотнительной заслонки коленчатого вала.
- Зарегистрировав высокое давление в картере, коды 555 и 556.

Если эти симптомы и коды неисправностей наблюдаются наряду с ниже температуры замерзания, проверьте фильтр для дыхания (если он оборудован) и трубку для замораживания. Фотографии приведены ниже для справки. Конденсация может наблюдаться на элементе дыхательной системы.

### Решение

- Если фильтр капельного передатчика и/или трубка картера заглушены обледенением, установите комплект для установки в холодную погоду. Эти комплекты содержат нагреватели, которые будут удерживать фильтр и / или трубку от замерзания при температуре ниже нуля. Эти комплекты для ремонта **не** покрываются гарантией.
- Для моделей обслуживания двигателей B6.7 CM2450 B155B, комплект установки, Часть Номер 5690250. Справочная инструкция по установке, Вестник 5414731 для подробных инструкций по установке.
- Для всех других моделей обслуживания, установите комплект, Часть Номер 5314954. Справочная инструкция по установке, Вестник 4908173 для подробных инструкций по установке.

Кроме того, если трубка капкан-дудоховщика имеет прямой конец разреза, разрежьте конец трубки под углом 45 градусов, как показано на иллюстрации ниже. Для двигателей On Highway убедитесь, что открытая сторона трубки либо обращена назад от направления движения транспортного средства вперед, либо к двигателю. Для двигателей Off Highway открытая сторона должна быть обращена к двигателю.

> **Issue**
>
> - Engines experience crankcase breather and/or breather tube freezing issues in below freezing temperatures.
>
> **Symptom**
>
> - Lubricating oil leak and high crankcase pressure fault codes are External Lubricating Oil Leak
> - Fault Code 555, Fault code 556.
>
> ### Confirmation
>
> The crankcase breather filter and crankcase breather tube freezing could cause crankcase pressure to build, resulting in:
>
> - Lubricating oil leaks at the turbocharger seal, valve cover gasket, and rocker housing gasket or front or rear crankshaft seals.
> - Logging high crankcase pressure Fault Codes 555 and 556.
>
> If these symptoms and fault codes are observed along with below freezing temperatures, check the breather filter (if equipped) and crankcase breather tube for freezing. Photographs are shown below for reference. Condensation might be observed on the breather element.
>
> ### Resolution
>
> - If the crankcase breather filter and/or crankcase tube is found to be plugged by icing, install a cold weather upfit kit. These kits contain heaters that will keep the filter and/or tube from freezing in below freezing temperatures. These upfit kits are **not** covered by warranty.
> - For engine service models B6.7 CM2450 B155B, install kit, Part Number 5690250. Reference Installation Instruction, Bulletin 5414731 for detailed installation instructions.
> - For all other service models, install kit, Part Number 5314954. Reference Installation Instruction, Bulletin 4908173 for detailed installation instructions.
