**Issue**

- Engines experience crankcase breather and/or breather tube freezing issues in below freezing temperatures.

**Symptom**

- Lubricating oil leak and high crankcase pressure fault codes are External Lubricating Oil Leak
- Fault Code 555, Fault code 556.

### Confirmation

The crankcase breather filter and crankcase breather tube freezing could cause crankcase pressure to build, resulting in:

- Lubricating oil leaks at the turbocharger seal, valve cover gasket, and rocker housing gasket or front or rear crankshaft seals.
- Logging high crankcase pressure Fault Codes 555 and 556.

If these symptoms and fault codes are observed along with below freezing temperatures, check the breather filter (if equipped) and crankcase breather tube for freezing. Photographs are shown below for reference. Condensation might be observed on the breather element.

### Resolution

- If the crankcase breather filter and/or crankcase tube is found to be plugged by icing, install a cold weather upfit kit. These kits contain heaters that will keep the filter and/or tube from freezing in below freezing temperatures. These upfit kits are **not** covered by warranty.
- For engine service models B6.7 CM2450 B155B, install kit, Part Number 5690250. Reference Installation Instruction, Bulletin 5414731 for detailed installation instructions.
- For all other service models, install kit, Part Number 5314954. Reference Installation Instruction, Bulletin 4908173 for detailed installation instructions.

For On Highway engines, make sure that the open side of the tube either faces rearward from the vehicle's forward direction or toward the engine. For Off Highway engines, the open side **must** be facing toward the engine.
