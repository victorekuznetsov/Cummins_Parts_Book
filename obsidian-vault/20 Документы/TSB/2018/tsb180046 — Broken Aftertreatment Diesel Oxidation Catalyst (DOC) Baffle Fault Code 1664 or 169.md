## Broken Aftertreatment Diesel Oxidation Catalyst (DOC) Baffle: Fault Code 1664 or 1691

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- X12 CM2350 X119B
- X15 CM2350 X114B
- X15 CM2350 X116B

**Issue**

Symptom:

- Fault Code 1664 or 1691
- Possible noise coming from aftertreatment diesel oxidation catalyst (DOC)

Root Cause:

- Welding issues have been found inside inlet tube of aftertreatment DOC causing baffle breakage.
- See Figures 1 and 2 for examples of broken aftertreatment DOC baffles.

![[11r00330.png]]

Figure 1, Broken Baffle in Inlet of Aftertreatment DOC.

![[11r00331.png]]

Figure 2, Broken Aftertreatment DOC Baffle.

**Verification**

Troubleshoot fault code and inspect inlet of aftertreatment DOC for broken baffle.

**Resolution**

- If troubleshooting the applicable Fault Codes 1691 and 1664 lead to finding a cracked or broken baffle, replace the aftertreatment DOC. See corresponding Service Manual. Reference Procedure 011-049 in Section 11.
- If applicable Fault Codes 1691 and 1664 are **not** present, do **not** replace the aftertreatment DOC, even if a cracked or broken baffle is found. If a piece of the baffle is detached, as in Figure 2 above, remove detached baffle piece and install the aftertreatment DOC as is. See corresponding Service Manual. Reference Procedure 011-049 in Section 11.
