## Fault Code 4769 and 6255

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- B6.7 CM2350 B121B
- L9 CM2350 L116B
- X15 CM2350 X114B
- X15 CM2350 X116B

**Issue**

Symptom:

- Fault Code 4769 active with more than 2 counts in 25 hours and active FC6255

Root Cause:

- Engine operated with active FC4769 for at least one hour, resulting in reduced engine performance and an active FC6255 in the engine control module (ECM).

**Verification**

- FC4769 and FC6255 are active.

**Resolution**

- Follow the published troubleshooting for FC4769.
- Once FC4769 has gone inactive, turn the vehicle on and idle for 5 minutes.
- Verify FC6255 is inactive.
- If FC6255 is still active, reference Technical Service Bulletin, Fault Code 6255 Present With No Other Fault Codes and Possible Diesel Exhaust Fluid (DEF) Lamp Illumination, [[tsb170031 — Fault Code 6255 Present With No Other Fault Codes and Possible Diesel Exhaust Fluid\|TSB170031]] for further instructions.
