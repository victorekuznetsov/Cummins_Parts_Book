## Navistar® Aftertreatment Backpressure Diagnostic FC6786 on International HX520 and HX620 Chassis

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

Engines:

- X15 CM2350 X114B
- X15 CM2350 X116B

Original Equipment Manufacturer (OEM):

- Navistar **®**

Chassis:

- Internationa **l®Issue**

Symptom:

- Reduced engine power.
- Fault Code 6786.

Root Cause:

- Exhaust aftertreatment backpressure diagnostic that triggers Fault Code 6786 was found to be out of adjustment resulting in false occurrences of Fault Code 6786.

**Verification**

Verify repeated instances of Fault Code 6786 logging but aftertreatment and exhaust system are within specification and in normal working order.

**Resolution**

Calibrate electronic control module (ECM) with correct ECM calibration code. See Table 1 below.
