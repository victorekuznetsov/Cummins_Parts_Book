## Changes to Base Engine Timing

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- ISX15 CM2250
- ISX15 CM2350
- QSX15 CM2250
- QSX15 CM2350
- X15 CM2350

**Description of Change**

This document announces the release of revised procedures for Base Engine timing (001-088) and Gear Train Backlash (001-055).

Major changes include:

- A new nominal target of 0.004” for both adjustable fuel pump idler gear meshes
- Used bolts are to be discarded for fuel pump idler gear when removing Gear
- New bolts with pre-applied thread-locker are to be used for fuel pump idler gear when reinstalling gear
- Fuel pump idler gear install was moved to verify thread locker is **not** disturbed for 15 minutes after initial run down (to prevent compromising thread-locker).
- Torque Value was increased for fuel pump idler gear from 30 n•m \[ 22 ft-lb \]+60° to 35 n•m \[ 26 ft-lb \]+60°

**Reason for Change**

In 2017, a solid lower idler gear, and adjustable fuel pump idler gear shaft were introduced. Several changes were put in place to accomadate this change:

- Factory began using gears with tape as an assembly aid. This eliminated need for feeler gages to set lash.
- New bolts with thread-locker are now specified for fuel pump idler gear when reinstalling gear to increase bolt retention margin.
- Fuel pump idler gear installation steps were moved to highlight the importance of the thread locker not being disturbed for 15 minutes after initial run down.
- Torque value for fuel pump idler gear bolts was increased from 30 n•m \[ 22 ft-lb \]+60° to 35 n•m \[ 26 ft-lb \]+60° to align with factory practices.
