## Fault Code 3567and 3568: PACCAR™

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

Engines:

- X15 CM2350 X114B
- X15 CM2350 X116B

Original Equipment Manufacturer (OEM):

- PACCAR™

**Issue**

Symptom:

- Fault Code 3567
- Fault Code 3568

Root Cause:

- PACCAR™ wire harness connector to aftertreatment diesel exhaust fluid (DEF) dosing system has a pin that can be pushed back during assembly; Resulting in an intermittent connection causing a low voltage condition, logging Fault Code 3567 and or Fault Code 3568.

**Verification**

- Verify Fault Code 3567 or Fault Code 3568 are present.
- Locate connector on left side lower bulkhead.
- Check condition of connector.
- Open connector.
- Check for bent, broken, corroded, or pushed back pins.
- Reference PACCAR™ direction to repair or replace connector.

**Resolution**

Contact PACCAR™ for direction.
