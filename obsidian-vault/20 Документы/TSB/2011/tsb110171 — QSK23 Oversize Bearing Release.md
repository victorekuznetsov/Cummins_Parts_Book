## QSK23 Oversize Bearing: новый релиз

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом документе представлены новые подшипники для двигателей QSK23. Это включает в себя основной, шатун и подшипники тяги.

Подшипники негабаритного размера доступны для того, чтобы коленчатый вал мог быть меньше по размеру, если внешний диаметр основных и/или соединительных штанговых штанговых журналов или расстояние тяги **не** в пределах спецификаций. Спецификации можно найти в руководстве по устранению неполадок и ремонту QSK23, Bulletin [[4021375 — QSK23 Troubleshooting and Repair Manual\|4021375]].[[89-001-016-tr — Crankshaft|См. процедуру 001-016 в разделе 1.]]Если один из основных журналов подшипников **не** в пределах спецификаций и меньшего размера, **всегда** измельчают все основные журналы подшипников меньшего размера. Если один из журналов шатунов **не** в пределах спецификаций и меньшего размера, **всегда** измельчают все журналы с соединительными стержнями меньшего размера.

Если один из главных или соединительных журналов коленчатого вала имеет меньший размер, все основные или соединительные журналы стержня должны быть меньше одинакового размера. По этой причине подшипники для негабаритных размеров доступны только **в комплекте. **необязательно использовать подшипники с большой тягой при использовании основных подшипников с большой тягой. Также **не** необходимо использовать подшипники тяги одинакового размера на обеих тяговых гранях коленчатого вала. Однако верхние и нижние подшипники тяги, используемые либо спереди, либо сзади главного подшипника, должны быть одинакового размера.

> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This document introduces new oversize bearings for QSK23 engines. This includes main, connecting rod, and thrust bearings.
>
> Oversize bearings are available to allow the crankshaft to be ground undersize, if the outside diameter of the main and/or connecting rod bearing journals or the thrust distance is **not** within specifications. The specifications can be found in the QSK23 Troubleshooting and Repair Manual, Bulletin [[4021375 — QSK23 Troubleshooting and Repair Manual\|4021375]]. [[89-001-016-tr — Crankshaft|Refer to Procedure 001-016 in Section 1.]] If one of the main bearing journals is **not** within specifications and ground undersize, **always** grind all of the main bearing journals undersize. If one of the connecting rod journals is **not** within specifications and ground undersize, **always** grind all of the connecting rod journals undersize.
>
> If one of the crankshaft main or connecting rod journals is undersize, all main or connecting rod journals **must** be undersize the same amount. For this reason, oversize bearings are available **only** in complete kits. It is **not** necessary to use oversize thrust bearings when using oversize main bearings. It is also **not** necessary to use the same size oversize thrust bearings on both thrust faces of the crankshaft. However, the upper and lower thrust bearings used on either the front or rear of main bearing location number six **must** be of the same size.
