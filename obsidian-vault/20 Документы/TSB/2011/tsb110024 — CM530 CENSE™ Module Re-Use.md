## Повторное использование модуля CM530 CENSE™

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

Флеш-память и микропроцессорные компоненты модуля CM530 CENSETM были устарели поставщиком, и нет альтернативы, другие поставщики не могут предоставить вышеупомянутые компоненты; поэтому теперь доступно только конечное число.

Чтобы позволить модулю CM530 продолжать работать, Cummins Inc. обеспечила текущий запас этих компонентов. Однако имеющиеся запасы могут быть **не** достаточными при нынешних темпах потребления в результате производства и обслуживания. В результате, нынешний модуль CM530 CENSETM был размещен на ассигнованиях до выпуска обновленного модуля, прогнозируемого в середине 2014 года.

Чтобы свести к минимуму ненужную замену модуля CM530 CENSETM, в этом документе описаны рекомендации по повторному использованию модуля при устранении неполадок, капитальном ремонте и повторном строительстве. Необходимо приложить все усилия для повторного использования существующего модуля до его замены. Используйте руководящие принципы ниже.

Устранение неполадок:

Перед заменой модуля CM530 CENSETM следует попробовать калибровку модуля. Если связь с модулем установить невозможно, то может потребоваться замена модуля.

> [!note] Примечание
> Если модуль подвергся повторному возникновению ошибки в повреждении данных, сделайте **не** повторно использовать модуль, например. если ESN, часовой счетчик двигателя, данные о расходе топлива и т.д. не имеет смысла после перекалибровки и тестирования модуля.

Ремонт и восстановление:

Если модуль функционировал должным образом до капитального ремонта/реконструкции, модуль должен быть откалиброван и повторно использован. Если проблема идентифицирована с модулем, пожалуйста, устраните неполадки, как указано выше.

> ## CM530 CENSE™ Module Re-Use
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> The flash memory and microprocessor components of the CM530 CENSE™ module have been made obsolete by the supplier, and there is no alternative Other suppliers cannot provide the above components; therefore only a finite number are now available.
>
> To allow the CM530 module to continue being available, the present stock of these components has been secured by Cummins Inc. However, available stocks may **not** be sufficient at the present consumption rate by production and service. As a result, the present CM530 CENSE™ module has been placed onto allocation prior to the release of the updated module, projected in mid 2014.
>
> To minimize unnecessary replacement of the CM530 CENSE™ module, this document describes the module re-use recommendations during troubleshooting, overhaul, and re-build. All efforts should be made to reuse the existing module prior to replacement. Use the guidelines below.
>
> Troubleshooting:
>
> Before the CM530 CENSE™ module is replaced, calibration of the module should be attempted. If no communication can be established with the module, then replacement of the module may still be required.
>
> **Note · Примечание**
> If the module has suffered a reoccurrence of a data corruption fault, do **not** reuse the module, e.g. if ESN, engine hour meter, fuel consumption data, etc. do **not** make sense after the module has been recalibrated and tested.
>
> Overhaul and Rebuild:
>
> If the module functioned adequately prior to overhaul/rebuild, the module should be calibrated and reused. If a problem is identified with the module, please troubleshoot as above.
