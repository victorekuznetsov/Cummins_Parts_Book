**Description of Change**

This document informs the field of optional air filtration upgrades. The new air filters use NanoForce® nanofiber filtering media and offer higher cleaning efficiency than filters with cellulose media.

**Reason for Change**

The upgraded filtration options offer higher capacity and improved filtration performance.

**Service Parts Availability**

Service parts are available. See Table 1 for part numbers.

| **Table 1, Air Filter Part Numbers** |  |  |  |
|---|---|---|---|
| **Type** | **Description** | **Original Fleetguard® Part Number Part Numbers** | **Upgrade NanoForce® Fleetguard® Part Numbers** |
| Axial Seal | Primary | AF1605 or AF1605M | AF1605NF |
| Secondary | AF1604 | No change in part number |  |
| Axial Seal | Primary | AF879 or AF879M | AF879NF |
| Secondary | AF857 | No change in part number |  |
| Axial Seal | Primary | AF899 or AF899M | AF899NF |
| Secondary | AF880 | No change in part number |  |
| Radial Seal | Primary | AF27696 | AF27993NF + SP1307 service cover\* |
| Secondary | AF27695 | AF27994 |  |
| \*See part compatibility section below. |  |  |  |

**Part Compatibility**

The upgraded radial seal air filter, Part Number AF27993NF, requires a new service cover, Fleetguard® Part Number SP1307.

**Part Identification**

The new upgraded air filters can be distinguished using the part number printed on the air filter can.

**Part Structure**

The new upgraded filtration part numbers do **not** obsolete or supersede the existing filtration part numbers. The existing filtration part numbers will remain available.
