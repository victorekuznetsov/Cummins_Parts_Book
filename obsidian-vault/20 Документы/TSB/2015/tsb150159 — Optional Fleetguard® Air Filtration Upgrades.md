## Опциональные улучшения воздушной фильтрации Fleetguard®

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

**Затронутая продукция**

- K19 (все версии)
- K38 (все версии)
- K50 (все версии)
- QSK19 (все версии)
- QSK23 (все версии)

**Описание изменения**

Этот документ информирует область о дополнительных обновлениях фильтрации воздуха. Новые воздушные фильтры используют нановолоконные фильтрующие среды NanoForce® и обеспечивают более высокую эффективность очистки, чем фильтры с целлюлозными средами.

**Причина изменения**

Модернизированные варианты фильтрации предлагают более высокую емкость и улучшенную производительность фильтрации.

**Наличие сервисных деталей**

Сервисные детали доступны для заказа. Номера деталей приведены в таблице 1.

| **Таблица 1, фильтр для очистки воздуха Номер деталиов** |  |  |  |
|---|---|---|---|
| **Тип** | **Описание** | **Оригинальный Fleetguard® Часть Номер Номер Части**| **Обновить номера запасных частей NanoForce® Fleetguard®** |
| Осевая уплотнение | первичный | AF1605 или AF1605M | AF1605NF |
| вторичный | AF1604 | Не меняет номер детали |  |
| Осевая уплотнение | первичный | AF879 или AF879M | AF879NF |
| вторичный | AF857 | Не меняет номер детали |  |
| Осевая уплотнение | первичный | AF899 или AF899M | AF899NF |
| вторичный | AF880 | Не меняет номер детали |  |
| Радиальная уплотнение | первичный | AF27696 | AF27993NF + SP1307 Обслуживание* |
| вторичный | AF27695 | AF27994 |  |
| \* См. раздел совместимости ниже. |  |  |  |

**Совместимость частей**

Модернизированный фильтр для очистки воздуха с радиальным уплотнением, Part Number AF27993NF, требует нового сервисного покрытия Fleetguard® Part Number SP1307.

**Идентификация детали**

Новые модернизированные воздушные фильтры можно отличить, используя номер детали, напечатанный на фильтре воздухоочистителя.

**Часть структуры**

Новые обновленные номера фильтрационных деталей не являются устаревшими или заменяют существующие номера фильтрационных деталей. Существующие номера фильтрационных деталей останутся в наличии.

> **Description of Change**
>
> This document informs the field of optional air filtration upgrades. The new air filters use NanoForce® nanofiber filtering media and offer higher cleaning efficiency than filters with cellulose media.

> **Reason for Change**
>
> The upgraded filtration options offer higher capacity and improved filtration performance.
>

> **Part Compatibility**
