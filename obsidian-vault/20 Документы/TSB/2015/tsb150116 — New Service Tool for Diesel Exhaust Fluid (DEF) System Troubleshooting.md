## New Service Tool for Diesel Exhaust Fluid (DEF) System Troubleshooting

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Issue**

1. Repeat occurrences of fault code 1682, 3574, or 3596 after repair.

2. Root cause not identified after troubleshooting occurrences of fault code 1682, 3574, or 3596.

Published troubleshooting is being updated and a new diagnostic tool is being released.

The ISX15 CM2350 X101 Fault Code Troubleshooting Manual, Bulletin Number 4310637 and the ISX12 CM2350 X102 Fault Code Troubleshooting Manual, Bulletin Number 4310642 will have choice paths created for fault codes 1682, 3574, and 3596 to allow shops that get the diesel exhaust fluid (DEF) diagnostic tool early to begin to use the new tool. Once all tools have been auto-shipped the choice path will be removed and troubleshooting will require the DEF diagnostic tool. At that time the revised troubleshooting will also be published in the Fault Code Troubleshooting Manuals for all of the other engines listed below.

**Service Tools and Training Available**

A new diagnostic tool, Part Number 5299833, has been created to improve DEF system troubleshooting capability. This tool is being automatically shipped to authorized Cummins® repair locations in the United States and Canada. The auto-ship process is expected to be complete October 2015. After that the tool will be available for purchase through the regular process.

Figure 1, DEF System Diagnostic Tool, Part Number 5299833

Training on the new diagnostic tool and troubleshooting process will be available at Cummins® Distributor locations in the United States and Canada in September 2015.
