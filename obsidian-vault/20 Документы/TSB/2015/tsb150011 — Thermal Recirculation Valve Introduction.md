**Description of Change**

The purpose of this document is to notify the field of thermal recirculation valve options available. Thermal recirculation valves were released to improve resistance to fuel filter gelling during engine operation in cold weather conditions.

**Thermal Recirculation Valve Overview**

- The thermal recirculation valve functions by recirculating warm return fuel from various fuel system components into cold fuel tank(s), and fuel supply plumbing.
- Fuel recirculation occurs when supply fuel temperature is below 25°C \[ 77°F \].
- There are two thermal recirculation valve options:
- Thermal recirculation valve is an optional fuel routing component that can be bypassed if desired. Engine performance is **not** affected if thermal recirculation valve is bypassed.
