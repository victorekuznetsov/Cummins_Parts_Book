## Новый элемент охлаждения для ISX15

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

Новый элемент охладителя масла из нержавеющей стали был выпущен в качестве служебной части **только**. Новый масляный охладитель устарел и заменил предыдущий 63 мм \[2,5 дюйма \] алюминиевый масляный охладитель, и используется во всех рейтингах двигателей ISX15, построенных до 1 ноября 2007 года.

Для охлаждения элемента из нержавеющей стали требуется два уплотнения с кольцом вместо двух прокладок. Два уплотнения с кольцевым кольцом, номер детали[[4966084]]Его следует заказывать с каждым новым масляным охладителем. Установочные болты неизменны.

См. таблицу замены деталей ниже:

| Имя существительное | Новый номер детали | Устаревший номер детали |
|---|---|---|
| Круто, масло. | 2892304\* | 4965870 |
| 4952494 |  |  |
| 4920187 |  |  |
| Требуется два уплотнения с кольцом (упорядочено отдельно) |  |  |

Части стали доступны на MDC 2 марта 2012 года.

Уплотнительное кольцо подвергает монтажные отверстия, которые ранее были защищены прокладкой, охлаждающей жидкости. Нанесите красный, химически устойчивый, анаэробный сцепляющий клей, такой как LoctiteTM 2760, для герметизации резьбы масляного охладителя, устанавливающего болты при использовании новой детали.

> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> A new stainless steel oil cooler element was released as a service **only** part. The new oil cooler element obsoletes and supersedes the previous 63 mm \[ 2.5 in \] aluminum oil cooler element, and is used in all engine ratings for ISX15 engines built before 1 November 2007.
>
> The stainless steel oil cooler element requires two o-ring seals instead of two gaskets. Two o-ring seals, Part Number [[4966084]], should be ordered with every new oil cooler. The mounting bolts are unchanged.
>
> Reference the part replacement table below:
>
> | Noun Name | New Part Number | Obsolete Part Number |
> |---|---|---|
> | COOLER, OIL | 2892304\* | 4965870 |
> | 4952494 |  |  |
> | 4920187 |  |  |
> | \* Two o-ring seals required (ordered separately) |  |  |
>
> Parts became available at MDC on 2 March 2012.
>
> The sealing o-ring exposes the mounting holes, that were previously protected with a gasket, to the coolant. Apply red, chemical resistant, anaerobic thread locker, such as Loctite™ 2760, to seal the threads of the oil cooler element mounting capscrews when using the new part.
