## Injector Return Flow Specification Change for ISB CM2150, ISB6.7 CM2250, QSB6.7 CM2250, QSB6.7 CM2250 EC and ISB6.7 CM2350

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This document announces the change in the injector return flow specification on the following engines:

| Service Model Name and Service Manual and Procedure Numbers Affected |  |  |
|---|---|---|
| Service Model Name | Service Manual Bulletin Number | Procedure Number |
| ISB CM2150 | 4021578 | 006-026 |
| ISB6.7 CM2250 | 4022254 | 005-236 |
| QSB6.7 CM2250 | 4022255 | 005-236 |
| QSB6.7 CM2250 EC | 2883621 | 005-236 |
| ISB6.7 CM2350 | 2883567 | 005-236 |

The reason for the change was determined under a Rapid Problem Solving (RPS) project. Tests were conducted to determine the accurate injector return flow measurement. The new approved maximum injector return flow specification is 150 ml in 30 seconds \[5 fluid oz in 30 seconds\].
