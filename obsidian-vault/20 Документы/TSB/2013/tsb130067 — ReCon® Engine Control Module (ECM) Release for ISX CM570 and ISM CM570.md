## Модуль управления двигателем ReCon® (ECM) для ISX CM570 и ISM CM570

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом документе анонсирован выпуск ReCon® CM570 ECM Part Number 4309175RX для двигателей ISX CM570 и ISM CM570. Новая часть устарела и заменяет предыдущую ECM, как показано в таблице ниже.

| Устаревший и новый номер детали |  |  |
|---|---|---|
| Устаревший номер детали | Часть описание | Новый номер детали |
| 3408501RX | ЭКМ | 4309175RX |

Часть 4309175RX содержит две упаковки с ECM. В большом корпусе установлены изоляторы вибрации для двигателей ISX. В большой упаковке содержится следующее:

| Изолятор вибраций ECM для ISX CM570 |  |  |
|---|---|---|
| Номер детали | Часть описание | Количество |
| [[3009329]] | Шайба, Плейн | 3 |
| [[3677204]] | К черту, самоудар | 1 |
| [[3687573]] | Изолятор, Вибрация (Grommet) | 12 |
| [[3900589]] | Гайка, Хексагон Фланж | 3 |
| [[4298993]] | Винт, SDD Captive Washer | 3 |
| [[4298994]] | Проволока, земля | 1 |
| [[4311968]] | Спейсер, Маунтинг | 6 |
| [[5255716]] | К черту, Пленный Охотник | 3 |

Пакет, обозначенный как «ISM двигатель только», содержит следующие элементы для ISM CM570:

| ISM CM570 |  |  |
|---|---|---|
| Номер детали | Часть описание | Количество |
| Поставка с ECM | Шайба, заземление | 1 |
| Поставка с ECM | Шайба, Пластик | 5 |

> [!note] Примечание
> Инструкции по установке этих деталей включены в ECM.

> [!note] Примечание
> Следуйте инструкциям, предоставленным ECM для установки на двигатели ISX или ISM.
