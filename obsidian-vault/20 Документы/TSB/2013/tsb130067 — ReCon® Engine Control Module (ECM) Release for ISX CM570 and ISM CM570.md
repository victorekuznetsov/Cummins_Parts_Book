## ReCon® Engine Control Module (ECM) Release for ISX CM570 and ISM CM570

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This document announces the release of ReCon® CM570 ECM Part Number 4309175RX for ISX CM570 and ISM CM570 engines. The new part obsoletes and supersedes the previous ECM, as shown in the table below.

| Obsolete and New Part Number |  |  |
|---|---|---|
| Obsolete Part Number | Part Description | New Part Number |
| 3408501RX | ECM | 4309175RX |

Part Number 4309175RX, contains two packages with the ECM. The large package contains vibration isolators for ISX engines. The large package contains the following:

| ECM Vibration Isolator Parts for ISX CM570 |  |  |
|---|---|---|
| Part Number | Part Description | Quantity |
| [[3009329]] | Washer, Plain | 3 |
| [[3677204]] | Screw, Self tapping | 1 |
| [[3687573]] | Isolator, Vibration (Grommet) | 12 |
| [[3900589]] | Nut, Hexagon Flange | 3 |
| [[4298993]] | Screw, SDD Captive Washer | 3 |
| [[4298994]] | Wire, Ground | 1 |
| [[4311968]] | Spacer, Mounting | 6 |
| [[5255716]] | Screw, Captive Washer | 3 |

The package labeled for ‘ISM engine **only** ' contains the following for ISM CM570:

| ISM CM570 |  |  |
|---|---|---|
| Part Number | Part Description | Quantity |
| Supplied with ECM | Washer, Grounding | 1 |
| Supplied with ECM | Washer, Plastic | 5 |

> [!note] Note · Примечание
> Instructions for installing these parts are included with the ECM.

> [!note] Note · Примечание
> Follow the instructions provided with the ECM for upfit to ISX or ISM engines.
