## Camshaft Gear Remover Jaw Kit

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Technical Service Bulletin introduces a new camshaft gear remover jaw kit, Part Number 3164244. The kit is used to remove L10, M11, K19, K38, and K50 camshaft gears using the mechanical camshaft gear remover kit, Part Number 3162895. The new remover kit, Part Number 3164244, obsoletes and supersedes the previous remover assembly, Part Number 3162896.

> [!note] Note · Примечание
> The stud, Part Number 3164362, used in this kit can be slightly large for use in some existing remover plates. This can require the remover plate slots to be widened to accept the larger diameter studs.

> [!note] Note · Примечание
> Two kits of Part Number 3164244 are required to pull the camshaft gear. Do **not** use in combination with the camshaft jaw remover, Part Number 3162896.
