**Issue Summary**

Symptom:

- Fault Code 2198 is active during VGT Hysteresis Test with Cummins® Electronic Service Tool.

Root Cause:

- False occurrences of Fault Code 2198 during VGT Hysteresis Test.

**Verification**

- Review active and inactive fault codes with Cummins® electronic service tool or equivalent.
- Fault Code 2198 became active during the VGT Hysteresis Test.

**Resolution**

- If Fault Code 2198 becomes active during VGT Hysteresis test and is **not** accompanied by Fault Code 1894, no troubleshooting of Fault Code 2198 is required.
