## Leaking Coolant From Low Temperature Aftercooler (LTA) Core

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- QSK60 CM850 MCRS
- QSK60 CM2150 K132M
- QSK60 CM2150 MCRS
- QSK60 CM2150 MCRS G

**Issue Summary**

Symptom:

- Excessive coolant use; external coolant leak

Root Cause:

- Capscrews used for the aftercooler cores are loose or broken; aftercooler core is cracked

**Verification**

If a coolant leak from the aftercoolers is observed, or excessive coolant use has been confirmed, follow instructions in resolution section.

**Resolution**

- If a coolant leak from the aftercoolers is verified, replace aftercooler cores and capscrews with new ones.
- A new capscrew part number should be used which allows for a greater torque value. See Table 1 for part numbers.
- For aftercooler core removal and installation instructions, see corresponding Service Manual. Reference Procedure 010-002 in section 10. See Table 3 for Service Manual information.
