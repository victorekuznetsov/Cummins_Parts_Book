**Issue Summary**

Variable geometry turbocharger (VGT) actuators have been improperly diagnosed as faulty after incorrect install or calibration steps were performed.

Symptom:

- “Failed” message received on VGT Electronic Actuator Installation and Calibration test in INSITE™ electronic service tool
- Active Fault Code 6432, 2449, or 1898

Root Causes:

- The VGT actuator was mounted to the turbocharger during the Install Actuator step.
- Improper alignment of turbocharger sector gear on the turbocharger while mounting the VGT electronic actuator.

**Resolution**

- See corresponding Service Manual. Reference Procedure 010-134 in Section 10. Reference video link below.
- If VGT electronic actuator Install or Calibrate steps do **not** pass, the installation procedure **must** be started over from the beginning.
- The VGT electronic actuator **must** be removed, unplugged for 30 seconds, and the turbocharger sector gear placed into the correct fully clockwise position.
- If unsuccessful after two attempts, contact 1-800-CUMMINS™ to escalate this issue.
