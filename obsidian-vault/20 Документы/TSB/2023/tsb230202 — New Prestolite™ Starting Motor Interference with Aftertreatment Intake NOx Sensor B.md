## New Prestolite™ Starting Motor Interference with Aftertreatment Intake NOx Sensor Bracket: Engine Will Not Crank or Cranks Slowly

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- ISX15 CM2350 X101
- QSX15 CM2350 X105
- QSX15 CM2350 X106
- X15 CM2350 X114B
- X15 CM2350 X116B
- X15 CM2450 X124B
- X15 CM2450 X134B

**Issue Summary**

Symptom:

- Interference between new Prestolite™ M128 starting motor and aftertreatment intake NOx sensor bracket

Root Cause:

- Flywheel housing options FH11089, FH11099, FH11106, or FH11121 are **not** compatible with the Prestolite™ Starter M128, Part Number 5575820, and the aftertreatment intake NOx sensor bracket, Part Number [[3687330]].

**Verification**

- Verify the engine is equipped with flywheel housing options FH11089, FH11099, FH11106, or FH11121
- Prestolite™ M128 Starter, Part Number 5575820
- If replacing a Prestolite™ M125 starting motor, Part Number 3690809, with superseding Prestolite™ M128 starting motor, Part Number 5575820, and one of the above FH options is present, there will be a hard interference with the aftertreatment NOx sensor bracket, Part Number [[3687330]]. In this instance aftertreatment NOx sensor bracket, Part Number [[3687330]], will need to be replaced with aftertreatment NOx sensor bracket, Part Number 5725892.

**Resolution**

Order and install new aftertreatment intake NOx sensor bracket in Table 1 below.

See corresponding Service Manual. Reference Procedure 011-079 in Section 11.

**Service Parts**

Service parts are offered. See Table 1 for part numbers.

| Table 1, Service Parts |  |  |  |  |
|---|---|---|---|---|
| Part Description | Existing Part Number | Obsolete | Superseded | New Part Number |
| SUPPORT, MODULE | [[3687330]] | No | No | 5725892 |
