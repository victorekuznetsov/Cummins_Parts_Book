**Issue Summary**

Symptom:

- Fault Codes:

Root Cause:

- Debris in the old style aftertreatment diesel particulate filter (DPF) differential pressure sensor.

**Verification**

- Use the recommended Cummins® electronic service tool or equivalent to read the fault codes.
- Fault Codes 1881, 1883, 3133, 3134, 3135, 5715, 5716, and/or 6786 are active or has more than one inactive count within the last 25 engine operating hours.
- The old style aftertreatment DPF differential pressure sensor has **only** one sticker with the part number information and the words "MOUNT VERTICALLY / THIS END UP" cast into the aftertreatment DPF differential pressure sensor body.
- New style aftertreatment DPF differential pressure sensor has two separate stickers which include this information.

**Resolution**

- If the old style aftertreatment DPF differential pressure sensor is in place, replace the old style with the new style aftertreatment DPF differential pressure sensor.
- If the new style aftertreatment DPF differential pressure sensor is already installed, continue with published troubleshooting.
