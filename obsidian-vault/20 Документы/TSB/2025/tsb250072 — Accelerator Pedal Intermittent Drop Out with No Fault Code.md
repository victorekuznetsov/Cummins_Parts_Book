**Issue Summary**

- In units with analog accelerator pedals, damage or improper connection to the engine control module (ECM) can cause a voltage short preventing fueling.

**Symptoms**

- Intermittent drop out of the accelerator pedal. Fueling will return after the operator has completely released and reapplied the pedal. This event may occur multiple times, often every few seconds.
- No active fault code.

**Verification**

- Confirm unit is utilizing an analog pedal and **not** a pulse width modulation pedal.
- Confirm no new fault codes are appearing with the above symptoms.
- Inspect Accelerator Pedal Sensor 1 and 2 pins on the ECM. Reference wiring diagram for correct pins.

**Resolution**

- See corresponding Service Manual. Reference Procedure 019-031 in Section 19 and inspect for reuse.
- If engine control module (ECM) pin damage is found, repair or replace damaged components or pins.
