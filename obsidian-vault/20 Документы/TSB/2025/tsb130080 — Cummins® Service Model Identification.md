## Cummins® Service Model Identification

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Introduction to Service Model Names**

The purpose of this document is to introduce Cummins® Service Model Name. Prior to 2007, Cummins Inc. primarily relied on the marketing model name to identify products. As Cummins Inc. introduced more products, the marketing model names were found to be too generic and did **not** identify variations of a product with the same marketing model name. Beginning in 2007, Cummins Inc. started using service model names to:

- Match the correct Cummins® service information and tools to a specific product.
- Assist repair locations with finding service information when the product serial number (PSN), engine serial number (ESN), or system serial number (SSN) is **not** available.

The original service model name used a suffix with letters to designate emissions-related hardware/technology used for that product. The Cummins® Service Engine Model Product Identification procedure provided a description of that service model name strategy. Refer to Procedure 100-003 in Section E.

**2013 Service Model Name**

Beginning in 2013, a new service model name strategy was implemented, replacing the previous strategy. Limitations were found with the previous service model name strategy. Products that used the previous service model name will **not** be updated with new service model names. The Cummins® Service Engine Model Identification procedure describes this new service model name strategy. Refer to Procedure 100-005 in Section E.

In addition to the new service model name strategy procedure, an additional new procedure was created, Cummins® Product Technology. This procedure can be used to identify the:

- Service model name for the product covered by the manual.
- Emission regulations the product was first released to meet.
- Hardware/technology used by the product.
- Market applications for which the product is used.

**2017 Service Model Name**

Beginning in 2017, an update was made to the service model name strategy to support a change to marketing model names. The change to the marketing model name was to remove the “IS” and “QS”, which previously could be used to differentiate automotive and industrial applications. To continue to support application identification, the service model name will have a new letter designation at the end of the suffix to identify the application type. The Cummins® Service Engine Model Identification (2017) procedure provides details. Refer to Procedure 100-008 in Section E. **Only** new products that use the new marketing model name will have an additional letter designation at the end of the suffix of the service model name.

**Non-Engine Products**

The Cummins® Service Transmission Model Identification procedure provides details of the service model name strategy to support transmissions. Refer to Procedure 344-004 in Section E.
