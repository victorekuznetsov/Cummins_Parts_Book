## New HE-851 Turbocharger

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Technical Service Bulletin announces a new turbocharger for QSK60 single stage industrial engines.

A more robust HE-851 turbocharger is now available for QSK60 single stage haul truck applications.

The HE-851 uses a machined from solid titanium compressor wheel to enhance compressor durability.

The following HE-851 turbocharger part numbers obsolete and supersede the HX-83 part numbers.

| Parts Information |  |  |
|---|---|---|
| Obsolete | HX-83 | 4035965 |
| Obsolete | HX-83 Kit | 4089756 |
| New | HE-851 | 4041787 |
| New | HE-851 Kit | 4955188 |
