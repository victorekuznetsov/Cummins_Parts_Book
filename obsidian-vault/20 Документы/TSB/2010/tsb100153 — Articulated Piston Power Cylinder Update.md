## Обновление Piston Power Cylinder

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом бюллетене технического обслуживания представлен новый закаленный цилиндровый гильза и верхнее поршневое кольцо для двигателей QSK45 и QSK60 с сочлененными поршнями. Новое изменение цилиндрового подкладки и верхнего поршневого кольца (только верхнего кольца) осуществляется для повышения долговечности цилиндра.

Новый цилиндрический гильза, номер детали[[4085917]]Нитрид затвердевает для повышения прочности и заменяет старый цилиндровый гильза, номер детали 3410342. Новый цилиндрический гильза по размерности такой же, как и его предшественник. Используйте Таблица 1 для номеров компонентов и Таблица 2 для номеров компонентов Service Kit.

Новое верхнее поршневое кольцо, номер детали 3410861, представляет собой чугунное кольцо с оберткой вокруг хрома твердых частиц. Старое верхнее поршневое кольцо, часть 3070589, не будет использоваться с новым закаленным цилиндрическим гильзой. Старое поршневое кольцо не устарело, поскольку используется на некоторых двигателях K38, K50 и QSK19. Средние и нижние поршневые кольца остаются неизменными и не подвержены влиянию этого улучшения. Используйте Таблица 1 для номеров компонентов и Таблица 2 для номеров компонентов Service Kit.

Когда новый закаленный цилиндровый вкладыш не используется, он более тусклый по внешнему виду по сравнению со старым цилиндровым вкладышем из-за затвердевания нитрида. Однако единственный определенный способ определить разницу между цилиндрическими вкладышами - это идентификационный номер детали, проштампованный в вкладыш цилиндра. См. Фиг. 1. Визуальный осмотр верхнего номера поршневой кольцевой части также необходим для определения правильного числа поршневого кольца. Используйте фиг. 2.

> ## Articulated Piston Power Cylinder Update
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This Technical Service Bulletin introduces a new hardened cylinder liner and top piston ring for the QSK45 and QSK60 engines with articulated pistons. The new cylinder liner and top piston ring (top ring only) change is being implemented to improve power cylinder durability.
>
> The new cylinder liner, Part Number [[4085917]], has been nitride hardened for improved robustness and supersedes the old cylinder liner, Part Number 3410342. The new cylinder liner is dimensionally the same as its predecessor. Use Table 1 for component part numbers and Table 2 for Service Kit part numbers.
>
> The new top piston ring, Part Number 3410861, is a cast iron ring with a wrap around hard particle chrome. The old top piston ring, Part Number 3070589, is **not** to be used with the new hardened cylinder liner. The old piston ring is **not** obsolete because it is used on some K38, K50 and QSK19 engines. The middle and bottom piston rings remain the same and are not affected by this product improvement. Use Table 1 for component part numbers and Table 2 for Service Kit part numbers.
>
> When the new-hardened cylinder liner is unused it is duller in appearance when compared to the old cylinder liner because of the nitride hardening. However, the only certain method to tell the difference between the cylinder liners is by the part number identification, stamped into the cylinder liner. See Fig. 1. Visual inspection of the top piston ring part number is also required to determine correct part number piston ring. Use Fig. 2.
