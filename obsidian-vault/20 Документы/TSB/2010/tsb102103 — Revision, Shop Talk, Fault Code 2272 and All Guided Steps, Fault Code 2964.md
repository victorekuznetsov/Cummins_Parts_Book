### Содержание

Эта тема для Сервиса/Частей пересматривает следующее в Руководстве по устранению неполадок и ремонту, подписи электронной системы управления CM870 и двигателях ISX, Бюллетень 4021334:

- Код 2272: Практическая записка была обновлена, чтобы предупредить, что неисправность может быть вызвана сломанным клапаном EGR.
- Код ошибки 2964: Все шаги были обновлены.
