## Пересмотр, несколько шагов, код ошибки 115, 121 и 433

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

Эта тема службы / частей пересматривает несколько этапов в следующих кодах ошибок:

2D, чтобы заменить ECM для активного кода 115 неисправностей, если другие неисправности не идентифицированы.

2D, чтобы заменить ECM для активного кода 121 неисправности, если другие неисправности не идентифицированы.

4E - Замена ECM на код 343 активного отказа, если не выявлены другие неисправности.
