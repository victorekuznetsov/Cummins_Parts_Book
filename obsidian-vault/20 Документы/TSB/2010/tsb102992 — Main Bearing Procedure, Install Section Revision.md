## Основная процедура подшипников, установка пересмотра раздела

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

Эта тема заменяет тему 06T1-12. Заменить тему 06Т1-12 «Сервис/Части» на эту тему «Сервис/Части».

Эта тема / разделы пересматривает Процедуру 001-006 (Подшипники, Главная). Количество основных поверхностей подшипников на каждой крышке для нанесения бусинки герметика LoctiteTM 518 на резьбу изменилось с четырех до двух поверхностей на каждой основной крышке подшипника перед установкой в блок цилиндров. Этот шаг поможет запечатать и защитить поверхности между основной подшипниковой крышкой и блоком цилиндров. Соответствующая иллюстрация была пересмотрена, чтобы показать правильное местоположение для добавления герметика резьбы LoctiteTM 518.

> This Service/Parts Topic revises Procedure 001-006 (Bearings, Main). The number of main bearing cap surfaces on each cap to apply a bead of Loctite™ 518 thread sealant has changed from four to two surfaces on each main bearing cap before installation into the cylinder block. This step will help seal and protect the surfaces between the main bearing cap and cylinder block. The relevant illustration has been revised to show the correct location to add the Loctite™ 518 thread sealant.
