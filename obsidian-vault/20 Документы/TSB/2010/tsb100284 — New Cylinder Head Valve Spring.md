## New Cylinder Head Valve Spring

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Technical Service Bulletin introduces a new valve spring, Part Number [[3635455]], for the QSK45 and QSK60 series engines. The new spring has a revised material which has been changed to increase durability. Table 1 provides information with regard to part numbers and identification for the new and old valve spring.

Cummins Inc recommends replacing the valve spring when the cylinder head is rebuilt.

| Table 1. Cylinder Head Valve Springs |  |  |
|---|---|---|
| Part Number | Color Code Identification | Spring Status |
| 3085962 | Blue | Obsolete |
| [[3635455]] | Red | New |

Engine Serial Number first was 33156447 built April 2004.

> [!note] Note · Примечание
> This is a product improvement and is **not** subject to campaign.
