## New Oil Cooler Kit

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Service/Parts Topic introduces a new Oil Cooler Kit, Part Number 4089900, which supersedes Oil Cooler Kit, Part Number 4089583.

| New Kit Part Number 4089900 |  |  |
|---|---|---|
| Description | Part Number | Quantity |
| Capscrews 12 point (short) | [[4101867]] | 4 |
| Capscrews 12 point (long) | [[4101868]] | 2 |
| Oil cooler core gaskets (rubber flash) | 4101869 | 3 |
| Protective cover | [[4026420]] | 1 |
| Protective cover | [[4058956]] | 1 |

The cooler core element, Part Number 4059460, is **no** longer included in the kit. If the element fails leak testing, a replacement can be ordered separately. Analysis has shown leaks occur at the mounting joints much more often than in the cooler core elements. Elements that do **not** leak do **not** need to be replaced.

It is important to leak test the cooler core element assembly as a unit using lubricating oil cooler test kit, Part Number 4918200, so leaks at the mounting joints can be identified. These leaks can **not** be identified by testing an individual cooler core element removed from the assembly. A cooler core element is replaced **only** if it is found to be leaking.

If **no** leaks are found and the engine serial number is in the range of 14023600 to 14050000 or 79000000 to 79012457 the gaskets and capscrews **only** are replaced.

The cooler core element is to be reused. If **no** leaks are found and the engine serial number is **not** in the above ranges, the cooler core elements are **not** to be removed. Check the capscrew torques and tighten to the specified torque.

Lubricating oil cooler leak test Procedures 007-003, Lubricating Oil Cooler and 007-007, Lubricating Oil Cooler Element have been updated to include the latest leak testing procedures. These procedures **must** be followed if an element is suspected of leaking. Cooler core elements that are **not** leaking, are **not** to be replaced.
