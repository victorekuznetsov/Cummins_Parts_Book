## Новый комплект Oil Cooler Kit

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом разделе «Сервисы/Части» представлен новый комплект охладителей для масла, часть 4089900, которая заменяет комплект охладителей для масла, часть 4089583.

| Номер комплекта 4089900 |  |  |
|---|---|---|
| Наименование | Номер детали | Количество |
| 12 баллов (коротко) | [[4101867]] | 4 |
| болты 12 баллов (длина) | [[4101868]] | 2 |
| Прокладки керна охладителя масла (резиновая вспышка) | 4101869 | 3 |
| Защитная крышка | [[4026420]] | 1 |
| Защитная крышка | [[4058956]] | 1 |

Более холодный основной элемент, часть 4059460, **no** дольше включен в комплект. Если элемент не проходит тестирование на утечку, замену можно заказать отдельно. Анализ показал, что утечки происходят в монтажных соединениях гораздо чаще, чем в более холодных элементах ядра. Элементы, которые делают утечку **не**, должны быть заменены.

Важно проверить утечку в сборе элементов сердечника охладителя в качестве блока с использованием измерительного комплекта охладителя моторного масла, Номер детали 4918200, чтобы можно было определить утечки в монтажных соединениях. Эти утечки могут быть идентифицированы путем тестирования отдельного элемента охладителя, удаленного из сборки. Более холодный основной элемент заменяется только, если он обнаруживается в утечке.

Если утечки обнаружены и серийный номер двигателя находится в диапазоне от 14023600 до 14050000 или от 79000000 до 79012457, прокладки и болты заменяются.

Более холодный основной элемент должен быть повторно использован. Если утечки обнаружены и серийный номер двигателя **не **в вышеуказанных диапазонах, то элементы ядра холодильного двигателя **не **должны быть удалены. Проверьте крутящие моменты болтов и подтяните к указанному крутящему моменту.

Процедуры испытаний на утечку охладителя моторного масла 007-003, охладителя моторного масла и 007-007, элемента охладителя моторного масла были обновлены, чтобы включить в себя последние процедуры тестирования на утечку. Эти процедуры должны соблюдаться, если элемент подозревается в утечке. Более холодные элементы ядра, которые не утекают, не должны быть заменены.

> [!note] Примечание
> Это улучшение продукта, **не **подлежащее кампании.

> ## New Oil Cooler Kit
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This Service/Parts Topic introduces a new Oil Cooler Kit, Part Number 4089900, which supersedes Oil Cooler Kit, Part Number 4089583.
>
> | New Kit Part Number 4089900 |  |  |
> |---|---|---|
> | Description | Part Number | Quantity |
> | Capscrews 12 point (short) | [[4101867]] | 4 |
> | Capscrews 12 point (long) | [[4101868]] | 2 |
> | Oil cooler core gaskets (rubber flash) | 4101869 | 3 |
> | Protective cover | [[4026420]] | 1 |
> | Protective cover | [[4058956]] | 1 |
>
> The cooler core element, Part Number 4059460, is **no** longer included in the kit. If the element fails leak testing, a replacement can be ordered separately. Analysis has shown leaks occur at the mounting joints much more often than in the cooler core elements. Elements that do **not** leak do **not** need to be replaced.
>
> It is important to leak test the cooler core element assembly as a unit using lubricating oil cooler test kit, Part Number 4918200, so leaks at the mounting joints can be identified. These leaks can **not** be identified by testing an individual cooler core element removed from the assembly. A cooler core element is replaced **only** if it is found to be leaking.
>
> If **no** leaks are found and the engine serial number is in the range of 14023600 to 14050000 or 79000000 to 79012457 the gaskets and capscrews **only** are replaced.
>
> The cooler core element is to be reused. If **no** leaks are found and the engine serial number is **not** in the above ranges, the cooler core elements are **not** to be removed. Check the capscrew torques and tighten to the specified torque.
>
> Lubricating oil cooler leak test Procedures 007-003, Lubricating Oil Cooler and 007-007, Lubricating Oil Cooler Element have been updated to include the latest leak testing procedures. These procedures **must** be followed if an element is suspected of leaking. Cooler core elements that are **not** leaking, are **not** to be replaced.
>
> **Note · Примечание**
> This is a product improvement, **not** subject to campaign.
