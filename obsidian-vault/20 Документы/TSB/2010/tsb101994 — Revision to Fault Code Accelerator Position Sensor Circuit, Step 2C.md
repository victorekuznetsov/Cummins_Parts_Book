## Revision to Fault Code Accelerator Position Sensor Circuit, Step 2C

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This Service/Parts Topic revises Step 2C, directing the user to disconnect the accelerator position sensor before checking the resistance. The resistance between the supply wire and the signal wire should read over 100K ohms.
