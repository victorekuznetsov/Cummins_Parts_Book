## Новый турбокомпрессор турбины объездной клапан Монтаж

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом бюллетене технического обслуживания будет представлен новый комплект турбокомпрессора, часть 4090043, выпущенный для двигателя ISX Family 3 CM570. Это изменение затрагивает двигатели семейства ISX 3 с любым из следующих списков контрольных частей: 2442, 2630, 2633, 2801, 2802, 2834, 2835, 8246 и 8247.

Двигатели, построенные до серийного номера двигателя (ESN) 79146928 (29 ноября 2005 года), были построены с корпусами турбин с использованием 4-вольтовой системы крепления для привода обходного клапана турбины.

Двигатели с ESN 79146928 и выше (29 ноября 2005 года) были построены с новым корпусом турбины, который был модифицирован путем удаления одного из турбинных обводных клапанов, устанавливающих боссы.

Когда комплект турбокомпрессора, Часть Номер 4090043, заменяет комплект турбокомпрессора, Часть Номер 4089760, на одном из затронутых CPL, табличка с данными двигателя должна быть проштампована с помощью Field Fix Номер 371. Этот номер требуется по закону для сохранения сертификации двигателя.

Для правильной установки турбокомпрессора обратитесь к процедуре[[10-010-033-tr — Turbocharger|010-033]]в Руководстве по обслуживанию ISX и QSX15, Бюллетень [[3666239 — Signature™, ISX, and QSX15 Service Manual\|3666239]].

Комплект турбокомпрессора, часть 4090043, также используется на некоторых серийных ISX Family 3 CM570 CPL. Настоящие CPL производства **не **требуют, чтобы номер Field Fix был проштампован на табличке с данными.

> ## New Turbocharger Wastegate Mounting
>
> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This Technical Service Bulletin is to announce a new turbocharger kit, Part Number 4090043, released for the ISX Family 3 CM570 engine. This change affects ISX Family 3 engines with any of the following control parts lists (CPL): 2442, 2630, 2633, 2801, 2802, 2834, 2835, 8246 and 8247.
>
> Engines built prior to engine serial number (ESN) 79146928 (November 29, 2005) were built with turbine housings utilizing a 4-bolt mounting system for the wastegate actuator.
>
> Engines with ESN 79146928 and higher (November 29, 2005) were built with a new turbine housing that has been modified by removing one of the wastegate mounting bosses.
>
> When turbocharger kit, Part Number 4090043, replaces turbocharger kit, Part Number 4089760, on one of the affected CPLs, the engine dataplate **must** be stamped with Field Fix Number 371. This number is required by law to retain certification of the engine.
>
> For correct turbocharger installation, refer to Procedure [[10-010-033-tr — Turbocharger|010-033]] in the Signature, ISX and QSX15 Service Manual, Bulletin [[3666239 — Signature™, ISX, and QSX15 Service Manual\|3666239]].
>
> Turbocharger kit, Part Number 4090043, is also used on some present production ISX Family 3 CM570 CPLs. The present productions CPLs do **not** require the Field Fix number to be stamped on the dataplate.
>
