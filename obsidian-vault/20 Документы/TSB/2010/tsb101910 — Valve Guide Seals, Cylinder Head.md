## клапан Guide Seals, головка цилиндра

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

Эта тема службы/частей указывает на изменение в процедуре 002-016, Плитка для клапанов, Голова цилиндра. Изменения, внесенные в процедуру и указанные ниже, разъясняют использование направляющих уплотнений клапана.

В настоящих производственных двигателях используется уплотнение для клапанов, номер детали 4026791, как для впускных, так и для выпускных клапанов, номер детали[[4026657]]Они были введены в марте 2002 года. Настоящее уплотнение для направляющих клапанов, номер детали 4026791, может использоваться вместо уплотнения для направляющих клапанов впуска, номер детали 4026660 и уплотнение для направляющих клапанов выхлопных газов, номер детали 4026791, которые использовались в двигателе, построенном с 15 мая 2000 года до конца февраля 2002 года.

Двигатели, построенные до серийного номера двигателя (ESN) 14010274, должны использовать впускной клапан направляющего уплотнения, номер детали[[4003966]], и уплотнение направляющего клапана, номер детали 3606766 и может **не** использовать настоящее уплотнение направляющего клапана, номер детали 4026791.

> ## Valve Guide Seals, Cylinder Head

> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This Service/Parts Topic indicates a change in Procedure 002-016, Valve Guide Seal, Cylinder Head. The changes made in the procedure and as indicated below clarify the usage of the valve guide seals.
>
> The present production engines use valve guide seal, Part Number 4026791, for both intake and exhaust valve guides, Part Number [[4026657]]; these were introduced in March 2002. The present production valve guide seal, Part Number 4026791, can be used in place of intake valve guide seal, Part Number 4026660, and exhaust valve guide seal, Part Number 4026791, that were used in engine built from 15 May 2000 to the end of February 2002.
>
> Engines built prior to Engine Serial Number (ESN) 14010274 should use intake valve guide seal, Part Number [[4003966]], and exhaust valve guide seal, Part Number 3606766 and can **not** use the present production valve guide seal, Part Number 4026791.
