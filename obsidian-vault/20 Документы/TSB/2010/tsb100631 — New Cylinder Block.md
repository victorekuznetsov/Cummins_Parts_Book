## Новый цилиндрический блок

### Положение о гарантии

Сведения в этом документе не изменяют действующие гарантийные обязательства и практику ремонта и не дают оснований для работ по программам TRP или Campaign.

### Содержание

В этом бюллетене технического обслуживания представлен новый блок цилиндров ISX. Этот новый блок цилиндров имеет переработанный порт блок-нагревателя, а также использование нового блок-нагревателя и новой блок-нагревателя порта. Новый блок цилиндров обратно совместим со старыми блоками цилиндров благодаря установке нового блок-нагревателя или блок-нагревателя. Если новый блок заказан и оригинальный двигатель был оснащен блок-нагревателем, новый стиль блок-нагревателя, номер детали 4965497, а также крепежные болты, номер детали 4965497.[[3093957]]** должен быть заказан. Если оригинальный двигатель был **не** оборудован блок-нагревателем, блок-нагревателем, штепсельным заглушителем, Номер детали 4985436, а также крепежными болтами, Номер детали[[3093957]]** должен быть заказан. Блок-нагреватель старого стиля, номер детали 3681362, по-прежнему будет доступен для использования в сервисе.

> ### Warranty Statement
>
> The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.
>
> ### Contents
>
> This Technical Service Bulletin introduces a new ISX cylinder block. This new cylinder block features a redesigned block heater port as well as the use of a new block heater and a new block heater port plug. The new cylinder block is backwards compatible to older cylinder blocks by virtue of installing a new block heater or block heater port plug. If a new block is ordered and the original engine was equipped with a block heater, a new style block heater, Part Number 4965497, along with the mounting capscrew, Part Number [[3093957]], **must** be ordered. If the original engine was **not** equipped with a block heater, a block heater port plug, Part Number 4985436, along with the mounting capscrew, Part Number [[3093957]], **must** be ordered. The old style block heater, Part Number 3681362, will still be available for service use.
