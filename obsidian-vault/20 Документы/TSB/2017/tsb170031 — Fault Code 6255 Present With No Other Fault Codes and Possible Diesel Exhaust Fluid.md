## Fault Code 6255 Present With No Other Fault Codes and Possible Diesel Exhaust Fluid (DEF) Lamp Illumination

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- B6.7 CM2350 B121B
- ISB6.7 CM2350 B101
- ISL9 CM2350 L101
- ISX12 CM2350 X102
- ISX15 CM2350 X101
- L9 CM2350 L116B
- X15 CM2350 X114B
- X15 CM2350 X116B

**Issue**

Symptom:

- **Only** Fault Code 6255 present (active).
- Diesel exhaust fluid (DEF) lamp may be illuminated.

Root Cause:

- Engine control module (ECM) calibration code issue.

**Resolution**

- Calibrate ECM using a January 2017, or later, INCAL™ DVD. Reference ECM Calibration Revision History on QuickServe™ Online for more information.
- See corresponding Service Manual. Reference Procedure 019-032 in Section 19.
- If any fault codes other than Fault Code 6255 are active, troubleshoot fault codes using corresponding troubleshooting tree.
- Run engine for two minutes after ECM calibration to allow DEF diagnostic to run. Key OFF and key ON; DEF lamp should clear.
