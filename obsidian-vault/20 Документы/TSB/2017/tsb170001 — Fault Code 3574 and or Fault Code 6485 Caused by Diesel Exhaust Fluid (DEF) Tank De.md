## Fault Code 3574 and/or Fault Code 6485 Caused by Diesel Exhaust Fluid (DEF) Tank Debris: Kenworth™ and Peterbilt™ Chassis

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

Information Only - OEM Related Matter Not Covered By Cummins® - Contact Appropriate OEM Dealer or OEM Representative For Additional Information

### Contents

**Product Affected**

Engine:

- X15 CM2350 X114B
- X15 CM2350 X116B

Chassis Make:

- Peterbilt
- Kenworth

**Issue**

Symptom:

- Fault Code 3574 and/or Fault Code 6485

Root Cause:

- Manufacturing sticker debris in diesel exhaust fluid (DEF) tank can clog aftertreatment DEF dosing unit inlet screen and/or DEF tank pickup tube filter.

**Verification**

- Remove DEF tank from chassis. See equipment manufacturer service information.
- Remove DEF tank header assembly and inspect inside of DEF tank for white sticker and sticker debris.

**Resolution**

- If sticker debris is found, drain and flush DEF tank. See corresponding Service Manual. Reference Procedure 011-056 in Section 11.
- Components within DEF tank **must** be inspected for sticker debris and cleaned, including header assembly and sensor assembly.
- Aftertreatment DEF dosing unit inlet screen **must** be replaced.
