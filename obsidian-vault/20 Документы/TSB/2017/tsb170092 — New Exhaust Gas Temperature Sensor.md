## New Exhaust Gas Temperature Sensor

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

**Product Affected**

- QSK60 CM850 MCRS
- QSK60 CM2150 MCRS
- QSK60 CM2350 K116
- QSK60 CM2350 K117
- QSK60 CM2350 K121
- QSK60 G CM2358 K110 (Single Turbocharger)
- QSK60-G CM700 (Single Turbocharger)

**Issue**

Symptom:

- Exhaust gas temperature sensor Fault Codes: FC671, FC672, FC673, FC674, FC675, FC676, FC677, FC678, FC722, FC723, FC724, FC725, FC726, FC727, FC728, FC1521, FC1522, FC1523, FC1524, FC1525, FC1526, FC1527, FC1529, FC1532, FC1533, FC1534, FC1535, FC1536, FC1618, FC1619, FC2735, FC2736.
- Engine can shut down as a result of malfunctioning exhaust gas temperature sensor.

Root Cause:

- Fracture of exhaust gas temperature sensor platinum rhodium wire.

**Resolution**

- If exhaust gas temperature sensor has been found to have malfunctioned by published troubleshooting, install exhaust gas temperature sensor with orange sleeve. See corresponding Service Manual or Troubleshooting and Repair Manual. Reference Procedure 019-013 in Section 19.
- Existing exhaust gas temperature sensor part number has **not** changed.

Orange sleeved exhaust gas temperature sensor can be mixed with black sleeved exhaust gas temperature sensors in the same engine.
