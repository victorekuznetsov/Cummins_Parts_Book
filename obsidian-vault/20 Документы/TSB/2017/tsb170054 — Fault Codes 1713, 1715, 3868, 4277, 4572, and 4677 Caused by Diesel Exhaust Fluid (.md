**Issue**

Symptom

- Fault Codes:

Root Cause

- These fault codes can be caused by an aftertreatment diesel exhaust fluid (DEF) tank heater coolant control valve that is **not** closing completely.

**Verification**

- Perform Troubleshooting for FC1713, Aftertreatment 1 Diesel Exhaust fluid tank heater - Data Valid but Above Normal Operating Range - Moderately Severe Level.

**Resolution**

- A) If aftertreatment diesel exhaust fluid tank heater coolant control valve is functioning normally and no issues are found, continue troubleshooting the following fault codes:
- B) If aftertreatment DEF tank heater coolant control valve is **not** operating correctly and is allowing coolant to flow through aftertreatment DEF tank heater circuit, repair or replace aftertreatment DEF tank heater control valve as directed in Fault Code 1713 troubleshooting tree. See equipment manufacturer service information for direction on aftertreatment DEF tank heater control valve replacement.
- If resolution B above was performed and the fault codes below become active again, continue troubleshooting the following fault codes:
