**Описание изменения**

Для системы фильтров EliminatorTM введен новый центробежный фильтр. Допуск к литью нового крышки центрифуги был скорректирован, и был введен новый полный номер сборочной части EliminatorTM, чтобы отразить эти изменения.

**Причина изменения**

Новый центробежный фильтр предотвратит более низкие сбои в втулке. Центрифужная крышка была изменена, чтобы позволить использовать новый центрифужный фильтр без контакта с центрифужной крышкой во время работы двигателя.

**Указания по обслуживанию**

- Если обнаружены признаки контакта между крышкой центрифуги и фильтром центрифуги, крышка центрифуги, номер детали 4016423 (крышка центрифуги QSK78), может быть приобретена отдельно и установлена в существующей сборке EliminatorTM для предотвращения контакта фильтра центрифуги с крышкой центрифуги. Применяется для QSK45/60. См. рисунок 1 ниже.
- Для установки и удаления см. Бюллетень службы, Фильтр ЭлиминаторTM, Бюллетень[[3666253 — Eliminator™ Filter|3666253]].

> **Description of Change**
>
> A new centrifugal filter has been introduced for the Eliminator™ filter system. The casting tolerance of the new centrifuge cover has been adjusted and a new complete Eliminator™ assembly part number has been introduced to reflect these changes.
>
> **Reason for Change**
>
> The new centrifugal filter will prevent lower bushing malfunctions. The centrifuge cover has been changed to allow the new centrifuge filter to be used without contacting the centrifuge cover during engine operation.
>
> **Service Instructions**
>
> - If evidence of contact between the centrifuge cover and centrifuge filter is found, the centrifuge cover, Part Number 4016423 (QSK78 centrifuge cover), can be purchased separately and installed within the existing Eliminator™ assembly to prevent centrifuge filter contact with the centrifuge cover. Applicable to QSK45/60. See Figure 1 below.
> - For installation and removal, see Service Bulletin, Eliminator™ Filter, Bulletin [[3666253 — Eliminator™ Filter|3666253]].
