## New Valve Springs for QSK45 and QSK60

### Warranty Statement

The information in this document has no effect on present warranty coverage or repair practices, nor does it authorize TRP or Campaign actions.

### Contents

This document announces a new valve spring, valve spring retainer, and the associated cylinder heads for QSK45 and QSK60 diesel and gas engines. The new valve spring and valve spring retainer were released to improve valve spring durability.

When changing valve springs, both valve springs under the same crosshead should be changed. Never install valve springs with different part numbers under the same crosshead. When installing the new valve spring, Part Number [[4372408]], **always** install the new valve spring retainer, Part Number [[4372314]].

The remove and install procedures remain the same for both valve springs. For valve spring height specifications, use the following procedure in the QSK45 and QSK60 Service Manual, Bulletin [[4021530 — QSK45 and QSK60 Service Manual\|4021530]]. [[56-002-004-tr — Cylinder Head|Refer to Procedure 002-004 in Section 2.]]
