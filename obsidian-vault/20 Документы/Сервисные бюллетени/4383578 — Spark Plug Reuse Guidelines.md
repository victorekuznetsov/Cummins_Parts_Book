## Spark Plug Reuse Guidelines

This document provides guidelines for replacement and reuse of spark plugs. Use this information in conjunction with the content provided in the corresponding service manual.

| Spark Plug - Good Used Plug |  |

![[13300034.png]]

| Spark Plug - Acceptable Deposits |  |
|---|---|
| Appearance | Slightly discolored. |
| Cause | Deposits from normal combustion. |
| Action | Reuse |

![[13300035.png]]

| Spark Plug - Oil Deposits |  |
|---|---|
| Appearance | Coated with black, oily sludge. |
| Cause | Oil Deposits, leaking valve stem seals, piston malfunction, piston ring malfunction. |
| Action | Compare with spark plugs from the other cylinders to determine if the issue is isolated to one cylinder or across all cylinders. Investigate possible causes of internal oil leaks and complaints of oil consumption. Replace all spark plugs with the appearance of the above deposits. |

![[13300036.png]]

![[13300037.png]]

| Spark Plug - Unacceptable Deposits |  |
|---|---|
| Appearance | Exceedingly discolored, or coated with ash. |
| Cause | Deposits from oil consumption, coolant consumption, or poor fuel quality. |
| Action | Check for excessive coolant consumption. Check for excessive oil consumption. Compare with spark plugs from the other cylinders to determine if the issue is isolated to one cylinder or across all cylinders. Replace all spark plugs with the appearance of the above deposits. |

![[13300038.png]]

| Spark Plug - Dry Fouling |  |
|---|---|
| Appearance | Dry, black deposits on electrodes and core nose. |
| Cause | Running rich for a prolonged period of time. |
| Action | Compare with spark plugs from the other cylinders to determine if the issue is isolated to one cylinder or across all cylinders. Investigate possible causes of rich running condition. Replace all spark plugs with the appearance of the above deposits. |

![[13300039.png]]

| Spark Plug - Wet Fouling |  |
|---|---|
| Appearance | Wet, black deposits on electrodes and core nose. |
| Cause | Prolonged misfire. |
| Action | Compare with spark plugs from the other cylinders to determine if the issue is isolated to one cylinder or across all cylinders. Investigate possible causes of misfire condition. Replace all spark plugs with the appearance of the above deposits. |

| Spark Plug - Core Nose Damage |  |
|---|---|
| Appearance | Cracked, chipped, or missing core nose ceramic. |
| Cause | Mishandling, knock. |
| Action | Compare with spark plugs from the other cylinders to determine if the issue is isolated to one cylinder or across all cylinders. Replace all spark plugs with a cracked core nose. |

![[13300055.png]]

| Spark Plug - Melted Ground Electrode |  |
|---|---|
| Appearance | Ground electrode melted and/or partially missing. |
| Cause | Excessive temperatures or knock. |
| Action | Compare with spark plugs from the other cylinders to determine if the issue is isolated to one cylinder or across all cylinders. Check for in-cylinder damage or causes of knock. Replace all spark plugs with a melted ground electrode. |

| Spark Plug - Cracked Insulator |  |
|---|---|
| Appearance | Cracked insulator. |
| Cause | Mishandling or over-torqued. |
| Action | Compare with spark plugs from the other cylinders to determine if the issue is isolated to one cylinder or across all cylinders. Replace all spark plugs with cracked insulators. |

![[13300060.png]]

| Spark Plug - Corrosion |  |
|---|---|
| Appearance | Discolored and/or rusted. |
| Cause | Moisture in the spark plug well and/or leaking seal or boot. |
| Action | Check the seal on ignition coil and spark plug boot. Investigate for the source of moisture. Compare with spark plugs from the other cylinders to determine if the issue is isolated to one cylinder or across all cylinders. Replace all spark plugs with corrosion that will **not** wipe off. |

![[13300061.png]]

![[13300062.png]]

| Spark Plug - Beading |  |
|---|---|
| Appearance | Small beads on the electrodes, bridging the gap. |
| Cause | Excessive temperatures and/or fuel which does **not** meet Cummins® specifications. |
| Action | Compare with spark plugs from the other cylinders to determine if the issue is isolated to one cylinder or across all cylinders. Replace spark plug **only** if the gap is out of specification. Verify fuel quality and investigate source of excessive in-cylinder temperature. |

![[13300063.png]]

![[13300064.png]]

| Spark Plug - Uneven Wear on Ground Electrode |  |
|---|---|
| Appearance | Erosion to one side of the ground electrode. |
| Cause | Normal wear in response to severe duty cycle applications. |
| Action | Measure the gap. Replace the spark plug if the gap is out of specification. |

| Excessive Dielectric Grease on Spark Plug |  |
|---|---|
| Appearance | Excessive dielectric grease on the spark plug terminal or insulator. Figure 1 - Normal, Figure 2A and 2B - excessive dielectric grease. |
| Cause | Use of additional dielectric grease. Grease buildup in the ignition coil. |
| Action | Compare with spark plugs from the other cylinders to determine if the issue is isolated to one cylinder or across all cylinders. Remove the grease deposits and reuse spark plug. Replace the old boot with new, pre-greased, boot when replacing spark plug. |

![[13300068.png]]

| Spark Plug - Threads Detached |  |
|---|---|
| Appearance | Spark plug detached from the threads. |
| Cause | Over-torqued. |
| Action | Replace the spark plug. |

![[13300069.png]]

| Spark Plug - Melted Terminal |  |
|---|---|
| Appearance | Top of the spark plug is melted. |
| Cause | Excessive temperatures or knock. |
| Action | Compare with the other spark plugs. Check for knock and/or possible in-cylinder damage. Replace all the spark plugs. |

![[13300070.png]]

| Boot Stuck on Spark Plug |  |
|---|---|
| Appearance | Coil boot covering the spark plug with metal shell. |
| Cause | Coil installed with the boot from the previous coil still on spark plug, Normal wear. |
| Action | Replace all the spark plugs with damaged boots. |
