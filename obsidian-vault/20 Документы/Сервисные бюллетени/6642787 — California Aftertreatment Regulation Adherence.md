## California Aftertreatment Regulation Adherence

**Overview**

This document provides guidance for repair facilities in California to comply with the “California Catalytic Converter Regulation.” For any vehicle serviced in California, if an aftertreatment component with a core value is being installed, the vehicle identification number (VIN) **must** be permanently marked on the new aftertreatment component.

If the aftertreatment component being removed from the vehicle does **not** already have the VIN marked on the removed component, the VIN **must** also be permanently added to that removed aftertreatment component.

**Service Instructions**

The new aftertreatment component being installed **must** have the VIN permanently marked using one of the following methods: etching, pen welding, or chemical etching. Ideally, the VIN should remain visible on the aftertreatment component after the component has been installed back on the vehicle.
