## Single Piece, Open Skirt Piston Reuse Guidelines (недоступная ссылка)

В настоящем Бюллетене по услугам применяются критерии проверки для однокомпонентных поршней с открытой юбкой в SignatureTM, ISX, QSX15, ISX11.9 CM2250 ECF, ISX15 CM2250 ECF, QSX11.9 CM2250 ECF, PowerGen QSX15 CM2250 ECF, QSX15 CM2350 X105 и двигателей QSX15 CM2350 X106. Cummins Inc. Дистрибьюторам и дилерам рекомендуется ознакомиться с этими рекомендациями при попытке определить, допустимы ли для повторного использования одноразовые поршни с открытой юбкой.

Для двигателей ISX и QSX15 см. следующую процедуру в Руководстве по обслуживанию, SignatureTM, ISX и QSX15, Бюллетень [[3666239 — Signature™, ISX, and QSX15 Service Manual\|3666239]], для повторного использования руководящих принципов для трещин в чаше, штифта цилиндра юбки и кольцевых канавок.[[10-001-043 — Piston|См. процедуру 001-043 в разделе 1.]]

Используйте следующую процедуру для повторного использования руководящих принципов для трещин в чаше, штифта цилиндра юбки и кольцевых канавок для двигателей ISX12/ISX11.9 CM22250 в служебном руководстве ISX12/ISX11.9 CM2250, Бюллетень 2883445. См. процедуру 001-043 в разделе 1.

Используйте следующую процедуру для повторного использования руководящих принципов для трещин в чаше, штифта цилиндра и кольцевых канавок для двигателей ISX15 CM22250 в служебном руководстве ISX15 CM2250, бюллетень 4022250. См. процедуру 001-043 в разделе 1.

Используйте следующую процедуру для повторного использования руководящих принципов для трещин в чаше, штифта цилиндра юбки и кольцевых канавок для двигателей QSX15 CM2250 ECF в руководстве по обслуживанию QSX15 CM2250 ECF, Бюллетень 2883557. См. процедуру 001-043 в разделе 1.

Используйте следующую процедуру для повторного использования руководящих принципов для трещин в чаше, штифта цилиндра юбки и кольцевых канавок для двигателей QSX11.9 CM2250 ECF в руководстве по обслуживанию QSX11.9 CM2250 ECF, Бюллетень 2883561. См. процедуру 001-043 в разделе 1.

Используйте следующую процедуру для повторного использования руководящих принципов для трещин в чаше, штифта цилиндра юбки и кольцевых канавок для двигателей PowerGen QSX15 CM22250 в руководстве по эксплуатации PowerGen QSX15 CM2250 ECF, Bulletin 4310661. См. процедуру 001-043 в разделе 1.

Используйте следующую процедуру для повторного использования руководящих принципов для трещин в чаше, штифта цилиндра юбки и кольцевых канавок для двигателей PowerGen QSX15 CM22250 в руководстве по обслуживанию PowerGen QSX15 CM2250, Bulletin 4310664. См. процедуру 001-043 в разделе 1.

Используйте следующую процедуру для повторного использования руководящих принципов для трещин в чаше, штифта цилиндра и кольцевых канавок для двигателей QSX15 CM2350 X105 в руководстве по обслуживанию QSX15 CM2350 X105, бюллетень 4332667. См. процедуру 001-043 в разделе 1.

Используйте следующую процедуру для повторного использования руководящих принципов для трещин в чаше, штифта цилиндра и кольцевых канавок для двигателей QSX15 CM2350 X106 в руководстве по обслуживанию QSX15 CM2350 X106, бюллетень 4332666. См. процедуру 001-043 в разделе 1.
