## QSK45 и QSK60 Cylinder Block Machining Procedure обновятся до прямо разделенных соединительных штанги

В этом бюллетене службы излагаются требования к обработке блоков для обновления старых блоков цилиндров QSK45 и QSK60 для принятия прямораздельного шатуна. Cummins Inc. Клиенты **не **требуются для обновления до прямого сплит-шатуна при реконструкции. Угловой сплит шатуны будут по-прежнему доступны как для восстановления, так и для ремонта на местах. Прямой сплит шатун и связанное с ним оборудование были разработаны для обеспечения улучшенной долговечности во всех приложениях. Новые блоки цилиндров принимают новые шатуны и форсунки для охлаждения поршня без этой обработки. Прямые сплит-шатуны могут **только **использоваться с остеклением поршневого охлаждения нового типа и блоками цилиндров, которые содержат новые изменения литья или блоки цилиндров, которые были модернизированы в соответствии с этой процедурой. Цилиндровые блоки, построенные до марта 2008 года, требуют обработки для нового оборудования.

Пять операций обработки (см. Рисунок 1) необходимы на залив (пару цилиндров) для обеспечения зазора для нового шатуна, который больше на большом конце, чем предыдущий угловой раскол (зазубренный) шатун. Также требуются новые форсунки для охлаждения поршня, болты для охлаждения поршня и процесс установки. Сторона, которая разрешает машиностроительному цеху выполнять механическую обработку блоков, несет ответственность за обеспечение последовательного качества операций по механической обработке.

Верхняя стружка для охлаждения Piston (см. рисунок 2)

- Удалите и отбросьте существующие дюбели перед обработкой.
- Машина верхнего поршневого охлаждающего насадочного узла, как описано позже в этом бюллетене.
- **Не** Увеличьте глубину дюбельных отверстий или резьбы. Внутренние проходы масла могут быть пробиты, и глубина будет влиять на интерференцию штифтов для пресса.
- Установите новые штифты.

Проверочные приборы

Минимальный калибр для обработки юбки блока, Номер детали 4918968, может использоваться для проверки достаточного зазора шатуна. Он был разработан для включения допусков коленчатого вала, шатуна и несущих зазоров. Если инструмент будет соответствовать блоку цилиндра, как показано без связывания, то проверяется достаточный зазор шатуна.

> [!note] Примечание
> Этот инструмент проверяет минимально необходимый допуск. Может иметься избыточный зазор вплоть до размеров, допускаемых на механической уплотнения.

Дополнительные датчики могут быть изготовлены или приобретены на месте и использованы для обеспечения правильной обработки.

Следующие иллюстрации являются примерами инструментов измерительной шкалы местного производства или приобретенных инструментов, которые могут быть использованы для проверки качества и согласованности обработки.

> This Service Bulletin outlines the block machining requirements to upgrade old QSK45 and QSK60 cylinder blocks to accept the straight split connecting rod. Cummins Inc. customers are **not** required to upgrade to the straight split connecting rod at rebuild. Angle split connecting rods will continue to be available for both rebuild and in-field repairs. The straight split connecting rod and related hardware was developed to provide improved durability in all applications. New cylinder block castings accept the new connecting rod and piston cooling nozzles without this machining. Straight split connecting rods can **only** be used with new-style piston cooling nozzles and cylinder blocks which contain the new casting changes or cylinder blocks that have been upgraded per this procedure. Cylinder blocks built prior to approximately March 2008 require machining to allow for the new hardware.
>
> Five machining operations (See Figure 1) are required per bay (pair of cylinders) to provide clearance for the new connecting rod which is larger at the big end than the previous angle split (serrated) connecting rod. New piston cooling nozzles, piston cooling nozzle bolts, and installation process are also required. The party that authorizes the machine shop to perform the block machining is accountable for ensuring consistent quality in the machining operations.

> Inspection Gauges
>
> Block skirt machining minimum clearance gauge, Part Number 4918968, can be used to inspect for sufficient connecting rod clearance. It has been designed to include tolerances of crankshaft, connecting rod, and bearing clearances. If the tool will fit the cylinder block as shown without binding, then adequate clearance of the connecting rod is verified.
>
> **Note · Примечание**
> This tool inspects for minimum required clearance. There may be excess clearance up to the dimensions allowed on the machining prints.
