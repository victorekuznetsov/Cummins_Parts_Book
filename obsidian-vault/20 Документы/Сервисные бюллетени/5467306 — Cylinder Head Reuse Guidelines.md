I. **General Information**

The reuse and replacement guidelines are to be followed to reduce unnecessary repairs.

II. **Introduction**

- Use the information contained within this document in conjunction with the corresponding Service Manual. Reference Procedure 002-004 in Section 2.
- Do **not** replace cylinder head for valve leakage without identifying and attempting to correct root cause of leakage. In some instances, valve leakage is caused by deposits on valve face and/or valve seat. These cylinder heads and valves will be acceptable for reuse after lapping.

V. **Inspections**

a. **General**

Some conditions require removal of valves for cleaning or lapping. Remove valves **only** as directed. All valves **must** be numbered with a paint pen or permanent marker prior to removal. All valves **must** be installed into original location.

b. **Cylinder Head Conditions and Malfunction Modes**

1. **Combustion Face Deposits**

![[02r00037.png]]

Figure 4, Combustion Face Deposits - Light.

| Table 4, Combustion Face Deposits |  |
|---|---|
| Appearance | Light deposits. |
| Cause | Deposits from combustion and acceptable oil consumption. |
| Action | Reuse. No cleaning necessary. |

![[02r00038.png]]

Figure 5, Combustion Face Deposits – Moderate.

| Table 5, Combustion Face Deposits |  |
|---|---|
| Appearance | Moderate deposits. |
| Cause | Deposits from combustion and acceptable oil consumption. |
| Action | Conditional Reuse. Clean, inspect, and reuse. Do **no** t remove valves for cleaning. See corresponding Service Manual. Reference Procedure 002-004 in Section 2. |

![[02r00039.png]]

Figure 6, Combustion Face Deposits – Heavy.

> [!warning] CAUTION · Осторожно
> Caution: Valves must be installed when using a wire wheel or damage can occur.

| Table 6, Combustion Face Deposits |  |
|---|---|
| Appearance | Heavy deposits. |
| Cause | Deposits from combustion and acceptable oil consumption. |
| Action | Conditional Reuse. Clean combustion face and valve head prior to performing any inspections or measurements. This applies to valve leakage, combustion face cracking, valve recession, or flatness. See corresponding Service Manual. Reference Procedure 002-004 in Section 2. If necessary, a powered wire wheel or Scotch-Brite™ 7448 abrasive pad, Part Number 3823258, or equivalent, and solvent can be used to remove deposits from cylinder head and valve heads. |

2. **Cylinder Head Cracking – Bridge and Spark Plug – Non-Leaking**

![[02r00040.png]]

Figure 7, Left: Combustion Face Showing Cracks. Right: Magnafluxed Combustion Face Showing Cracks.

| Table 7, Cylinder Head Combustion Face Cracking – Bridge and Spark Plug – Non-Leaking |  |
|---|---|
| Appearance | Non-leaking crack on combustion face with no crack separation present. All bridges can be cracked and still acceptable for reuse. Reference Cylinder Head Combustion Face Cracking – Leaking for comparison. |
| Cause | Stress relief crack that does **not** leak. |
| Action | Reuse. Clean and inspect cylinder head deck surface. Non-leaking cracking is acceptable at bridge and around spark plugs. |

3. **Cylinder Head Cracking – Leaking**

![[02r00026.png]]

Figure 8, Cylinder Head Combustion Face Cracking - Leaking Bridge.

| Table 8, Cylinder Head Combustion Face Cracking – Leaking Bridge |  |
|---|---|
| Appearance | Leaking crack of combustion face or exhaust port. A leaking bridge crack can be identified by separation. |
| Cause | Excessive cylinder temperature and pressure. Likely caused by prolonged operation during knock conditions. |
| Action | See corresponding Service Manual. Reference Procedure 002-004 in Section 2. |

4. **Chordal Valve Malfunction**

![[02r00027.png]]

Figure 9, Chordal Valve Malfunction.

| Table 9, Chordal Valve Malfunction |  |
|---|---|
| Appearance | Clean fracture of valve head. |
| Action | See corresponding Service Manual. Reference Procedure 002-004 in Section 2. |

5. **Oil Deposits Trapped in Valve Seat**

![[02r00028.png]]

Figure 10, Oil Deposits Trapped in Valve Seat.

| Table 10, Oil Deposits Trapped in Seat |  |
|---|---|
| Appearance | Small deposit visible on valve seat and valve face. Can cause valve to not pass 30 weight oil leak test. Do not replace cylinder head for this observation. Excessive cylinder leakdown and low compression can be caused by deposits between valve and valve seat. |
| Cause | Normal deposits can collect on valve seat or valve face. Deposits do **not** cause any performance issues but can be observed while engine is dissembled for unrelated repair. |
| Action | Reuse after lapping. See lapping procedure. See corresponding Service Manual. Reference Procedure 002-004 in Section 2. |

6. **Exhaust Manifold Mounting Surface Damage**

![[02r00029.png]]

Figure 11, Exhaust Manifold Mounting Surface Damage

| Table 11, Exhaust Manifold Mounting Surface Damage |  |
|---|---|
| Appearance | Indentation at exhaust manifold mounting surface. |
| Cause | Continued operation with leaking exhaust manifold gasket. |
| Action | Clean gasket sealing area prior to inspection. Inspect exhaust manifold sealing surface for damage deep enough to be felt with a fingernail. If a fingernail catches, cylinder head must be replaced. See corresponding Service Manual. Reference Procedure 002-004 in Section 2. |

7. **Intake Oil Buildup**

![[02r00032.png]]

Figure 12, Left: Oil Buildup Least Severe. Right: Oil Buildup Most Severe.

| Table 12, Oil Buildup on Fillet and Stem of Intake Valve |  |
|---|---|
| Appearance | Coated with black, oily sludge or deposits. |
| Cause | All Cylinders: Formation of deposits is dependent on duty cycle. Duty cycles with increased idle are more likely to produce heavier valve fillet deposits. Single cylinder: Power cylinder issue or leaking valve stem seal. |
| Action | Unconditional reuse. Clean valve with brake clean, abrasive wheel is not to be used. |

8. **Asymmetric Valve Seat Contact**

![[02r00034.png]]

Figure 13, Left: Asymmetric Valve Seat Contact. Right: Asymmetric Valve Seat Contact with Pitting.

| Table 13, Asymmetric Valve Seat Contact |  |
|---|---|
| Appearance | Uneven valve seat contact. Valve can **not** pass valve leakage test. Asymmetric valve seat contact and deposits can cause low compression and high cylinder leakdown test results. |
| Cause | Reduced valve and seat contact caused by thermal distortion, wear, and deposit buildup. Oil consumption deposits can collect on valve seat and valve face. |
| Action | Reuse after lapping. Perform valve lapping procedure. See corresponding Service Manual. Reference Procedure 002-004 in Section 2. |

9. **Valve Pitting**

![[02r00036.png]]

Figure 14, Left: Valve Pitting Least Severe. Right: Valve Pitting Most Severe.

| Table 14, Valve Pitting |  |
|---|---|
| Appearance | Indentation on valve or valve seat faces. Valve can fail valve leakage test. A pitted valve can be reused if valve does **not** leak. |
| Cause | Deformation and pitting corrosion caused by power cylinder conditions and deposits collecting on valve and valve seat faces. |
| Action | Reuse after lapping. Perform valve lapping procedure. See corresponding Service Manual. Reference Procedure 002-004 in Section 2. There is a possibility lapping will not remove all pits from valve and valve seat faces. Valve is to be lapped only until valve passes valve leak test. |

10. **Torched Exhaust Valve**

![[02r00035.png]]

Figure 15, Torched Exhaust Valve.

| Table 15, Torched Exhaust Valve |  |
|---|---|
| Appearance | Damaged valve with torch-like cutting appearance. |
| Cause | Prolonged engine knock. |
| Action | Replace cylinder head and inspect pistons for excessive deposits. See corresponding Service Manual. Reference Procedure 002-004 in Section 2. |

11. **Burnt Intake Valve**

![[02r00031.png]]

Figure 16, Left: Burnt Intake Valve Least Severe. Right: Burnt Intake Valve Most Severe.

| Table 16, Burnt Intake Valve |  |
|---|---|
| Appearance | Cracking on valve seat face |
| Cause | Thermal fatigue: cylinder head with improved valve and seat materials released 31 March 2015. |
| Action | Replace cylinder head. See corresponding Service Manual. Reference Procedure 002-004 in Section 2. |

12. **Valve Leakage**

![[02r00033.png]]

Figure 17, Leaking Valve.

| Table 17, Valve Leakage |  |
|---|---|
| Appearance | Visual inspection is not able to determine if a valve is leaking. Valve seating contact can appear asymmetric but still seal effectively. Performing valve leak test is only way to identify leakage. A leak forming after 30 seconds is acceptable. |
| Cause | If no physical valve or seat damage is observed such as burning or torching, valve leakage is likely result of poor contact or a deposit buildup on valve face and valve seat. |
| Action | Reuse. Reference lapping procedure. See corresponding Service Manual. Reference Procedure 002-004 in Section 2. |

VI. **Repair**

a. **Valve Lapping**

![[02r00030.png]]

Figure 18, Left: Valve Seat and Valve Before Lapping. Right: Valve Seat and Valve After Lapping.

| Table 18, Valve Lapping |  |
|---|---|
| Conditions for Valve Lapping | **Only** lap valves as directed. Lapping will correct all valve leakage except for burning, torching, and chordal malfunction conditions. Lapping will repair sealing surface and clear any debris or imperfections from between valve and valve seat. |
| Action | Lap all four valves of only cylinders that did not pass procedure in corresponding Service Manual. Reference Procedure 002-004 in Section 2. Number all valves and remove all four valves from only cylinder that did not pass valve leak test. Use valve spring compressor tool, Part Number 5298756, to remove valves. See corresponding Service Manual. Reference Procedure 002-004 in Section 2. |
